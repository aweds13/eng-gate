# 模块实现落点（按规格分组）

> 对每条规格指出负责模块 + 靠什么机制/取舍保证成立。只给「模块名+职责+取舍」，不贴源码。

## SR-F1 任务管理 → `src/core/tasks/`
- **My Day / 逾期栏 / 状态机**（SR-F1.1/1.2/1.8）：`manager.py` 管 My Day 集合与滚动；`status.py` 管状态机。取舍：**昨日未完成自动进逾期栏而非静默消失**（如实、不假装）；逾期与否由截止日+今天判定，**不强推**。
- **分组 / 多标签**（SR-F1.3）：`groups.py`，任务可归多分组；取舍：分组只是"组织维度"，不改变任务执行逻辑（避免割裂）。
- **Repeat / 子任务**（SR-F1.5/1.6）：`repeat.py` 到点生成下次（按上次完成）；`subtask.py` 子任务全完成父任务才完成（可手动提前勾）。

## SR-F2 B 系统记账 → `src/core/ledger/`
- **两轴记账**（SR-F2.1）：`ledger.py` 投入轴（专注时长）与产出轴（学校KPI/知识资产）分开记；**逾期=债务、专注=投入、悬赏=收益**直接落账。
- **债务口径**（SR-F2.3）：`debt.py` 债务=逾期清单+逾期天数/程度（轻/中/重），**不折算时间**；自动按逾期天数给档位。
- **评分/结算**（SR-F2.5）：`settle.py` 周结算；均衡度指标**温和呈现、不告警**。
- **可视化**（SR-F2.7）：`stats.py` 曲线+热力图+按分组分布；顶部轻量摘要。

## SR-F3 计时与专注 → `src/core/focus/`
- 番茄/普通计时（SR-F3.1/3.2）：`timer.py`；可绑定任务（时长计入任务+反馈+投入）；中断三选（暂停/放弃/记中断）。
- 白名单/勿扰（SR-F3.3）：`guard.py` 默认阻止非白名单；桌面/移动分别配置。
- 多设备同步专注（SR-F3.4）：靠 `src/storage/` 的同步（LWW）转发专注状态。

## SR-F4 反馈/习惯/自检 → `src/core/feedback/`
- 每日反馈（SR-F4.1）、习惯热力图（SR-F4.2，纳入 B 可视化）、自检（SR-F4.3，消费 B 数据）。

## SR-F5 学业追踪 → `src/core/academic/`
- 课程档案（学分/考核/任课）+ 考核提醒；学校任务**同构**进任务系统（只多"课程标签+硬约束元数据"）；GPA/学分手动录入；学期初手动建档。

## SR-F6 复习间隔重复 → `src/core/review/`
- FSRS 调度（SR-F6.1）用现成 Python FSRS 库；复习任务可由学习任务升级或手动建；到期按"重要度+最久未复习"排序；外部 app 只做调度中枢（手动打勾完成）；反馈三态（记得/模糊/忘了）作为与复习工具的联动接口；复习形式字段预留。

## SR-F7 团队/AI → `src/core/team/`
- 管理者/执行者两视角；不强制执行者装软件（状态手动为主）；AI 接口（`src/api/`）第一版只读+新增；团队任务不计个人投入。

## SR-F8 备忘录/知识资产 → `src/core/memo/` + `src/getaways/`
- 备忘录本地记录（可顺手建任务+加到期）；知识资产**只存引用句柄**（Vault路径/KB-ID），读写交给知识资产项目；产出评价器接口预留（第一版手动粗颗粒）。

## SR-F9 存储/同步 → `src/storage/`
- SQLite + schema 版本迁移；LWW 同步（时间戳+version，不静默覆盖）；跨端去重（来源标记）；备份/回滚。
