## 2026-11-17 T-AG636 回放判据的窗口改成按事件够得着：批量取数 + 上界 300 + 一条断言上界够不够的钉子
- tools/pytest_select.py 新增 log_batch：一次 `git log -z --name-only --format=%x01%h%x1f%(trailers:key=Task,valueonly)` 取回每笔的 Task trailer 与改动文件，按 rev 建索引；解析不出的记录不进返回值。

- 新增钉子 test_the_probe_upper_bound_still_reaches_a_judge_body_commit：算出最近一笔判据本体提交到 HEAD 的距离，断言它还在上界内 —— 上界不够时它先红，而不是等 `assert seen` 用「最近 60 笔一笔 fallback 都没有」这种看不出原因的话红。
