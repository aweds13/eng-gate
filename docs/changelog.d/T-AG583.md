## 2026-11-01 · 那七条账号用例，靠宿主机上那份仓外账本站着（卡 E80，T-AG583）

云门禁实测：`tests/test_wb_dispatch.py` 的七条账号用例在本机全绿、在云机全红，红单原文是「账号账本读不到，判不出「这个名字是哪个号」⇒ 拒派」。根因不是代码坏，是**这七条判据靠宿主机上那份仓外账本站着** —— 它们经 `find_ledger()` 向上找，开发机上摸到 `infra/pool/accounts.toml`，云机上没有就全红。本机复现：把账本藏掉即 `7 failed, 211 passed`，与云机逐字同一批。修法是给七条各钉一份**沙箱账本**（一份共享夹具 `_sandbox_ledger()`，不是七份 TOML 字面量），并给留痕那条补一条稳定 id 断言（没有它，locator 范畴判据的变异咬不住）。产品侧 `find_ledger()` / `_account_rows()` / `resolve_account()` 一个字节没动 —— 账本真缺失时拒派并说明三种修法，那本来就是对的。验收：藏掉仓外账本后整文件 `218 passed`，修前同口径 `7 failed`；反向 4/4 咬住，对照按设计不咬住。
