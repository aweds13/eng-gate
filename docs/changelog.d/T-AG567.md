pool 全仓没有一处把 token 数换算成钱，这是**有意的**（`tools/pool/ledger_spend.py:7-10` 的纪律：「不内置价目表，价格是外部事实，内置一份就等于在仓里埋一个会过期的常量」）。代价是调用方要自己算钱时没有任何算术可用，而这件事有几处必须精确：`0.3 USD/百万` 必须是 `"0.0000003"` 而不是 `"2.9999999999999997e-07"`（十进制字符串位移，不许浮点除法）、分档是**严格大于**（等号不算）、整单按档计（不是累进）、1 小时缓存写是 2×。本卡把 magpie `internal/catalog` 的这套算术整块搬过来，**只搬算术、不搬数据** —— `pricing.py` 里零厂商单价。
