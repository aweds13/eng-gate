`tools/pool/lastgood.py` 早有原子写，但它在四个方向上会毁掉现场：**旧的坏了直接跳过备份**（现场永久丢失，事后没人知道它坏成什么样）、换行跟着 `newline` 写死（本仓文本一律纯 CRLF，写一次就抹成 LF）、权限位不保留（`0o600` 的账本写一次变 `0o666`）、BOM 不保留。另有一个更贵的洞：`save_ledger` 用 `_dump_toml` **整份重生成**再写，账本里手写的行首注释会被无声抹掉。本卡把这四条一起补上：坏的先旁存成 `<名>.bad-<stamp>`（`0o600`、`O_EXCL`、同秒加 `-2/-3`、同样字节不存第二份、**旁存失败不挡写盘**）、`keep_bom` / `keep_mode` / `follow_ending` 三个新参数全带默认值（老调用点逐字节不变）、`save_ledger` 写前查 `ledger_would_lose_comments`（只看行首 `#`），有注释就抛 `LedgerError` 且**一个字节都不写**。
