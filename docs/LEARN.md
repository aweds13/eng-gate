# LEARN — 零基础定制指南

> 本文件写给**没有编程基础**的你（或你的同学）。
> 目标：让你能**改配置、填模板**就把软件改成自己想要的样子，不用改代码。
> 对应：`intention/needs.md` N38/N39（开源文档完整 / 零基础定制友好）。

## 〇、先记住一件事

**大部分定制不需要写代码，只需要改一个文件：`config.toml`。**

这个项目特意把"常见可调项"都做成了配置，就是为了让你改配置就能用。

---

## 一、第一步：把配置文件生出来

项目里有个**模板**叫 `config.example.toml`（`example` = 示例）。它是给所有人看的样例。

你要做的是**复制一份**，改个名字：

```bash
cp config.example.toml config.toml
```

> - `config.example.toml` = 模板（入库，大家共享）
> - `config.toml` = **你自己的配置**（不入库，只有你本地有）
>
> **为什么要分开？** 因为你的个人配置里可能有私人路径，不该传到网上。

---

## 二、五个可以马上改的配置

打开 `config.toml`，你会看到这样的内容（下面逐块解释）：

### 1. 数据存在哪

```toml
[database]
path = "data/timeflow.db"
```

- 这是**数据文件的位置**。
- 想换个地方存？把这一行改成你要的路径即可，例如：
  ```toml
  path = "D:/我的数据/timeflow.db"
  ```
- ⚠️ Windows 路径建议用 `/`（正斜杠），比如 `D:/我的数据/...`，避免转义问题。

### 2. 外观：主题与颜色

```toml
[app]
accent_color = "#3b82f6"    # 强调色（十六进制颜色）
theme = "light"             # 亮色 / 暗色
```

- `accent_color`：界面的强调色。`#3b82f6` 是蓝色。想换成绿色？写 `#22c55e`。
  > 不知道颜色代码？搜索引擎搜"颜色选择器"，网站上挑一个颜色，复制它的十六进制值（`#` 开头的那串）。
- `theme`：`light` = 亮色，`dark` = 暗色。

### 3. 专注：白名单与勿扰

```toml
[focus]
block_by_default = true                    # 默认"阻止非白名单"
do_not_disturb = ["22:00-07:00"]           # 勿扰时段
```

- `block_by_default = true`：专注时**默认拦掉一切不在白名单里的东西**。这是"默认收严"的设计（你先被保护，再自己放宽）。
- `do_not_disturb`：**勿扰时段**。`"22:00-07:00"` 表示晚上 10 点到早上 7 点。
  - 想设多个时段？用逗号隔开：`["12:00-14:00", "22:00-07:00"]`
  - 想全天不打扰？留空：`[]`
  - 跨午夜（如 22:00 到次日 7:00）是支持的，直接这么写就行。

### 4. 记账：债务等级怎么算

```toml
[ledger]
debt_mild = 3      # 逾期 ≤3 天 = 轻度
debt_medium = 7    # 逾期 ≤7 天 = 中度；>7 天 = 重度
```

- 觉得"逾期 3 天算轻度"太严格？改成 `5`（那 ≤5 天都算轻度）。
- 这两个数字就是**你自己的标准**，改了立刻生效。

### 5. 学业：GPA 制式

```toml
[academic]
gpa_scale = "4.0"    # 或 "5.0"
```

- 不同学校 GPA 算法不同。你是 4.0 制就写 `"4.0"`，5.0 制就写 `"5.0"`。
- 改完重启程序即生效。

## 三、"改配置"的通用步骤（照做就行）

1. **找到配置项**：打开 `config.toml`，按上面五节找到你要改的那一行。
2. **改值**：只改 `=` **右边**的内容，别动 `[方括号]` 里的和 `=` 左边的名字。
3. **保存**：Ctrl+S。
4. **重启程序**：配置在启动时读取，改完要重开。
5. **不对就改回来**：配置改错了程序可能起不来，把值改回原样即可（所以建议改前先复制一份备份）。

> 💡 **小技巧**：第一次改之前，把 `config.toml` 复制一份叫 `config.toml.bak`，改坏了就换回来。

## 四、进阶：用环境变量临时覆盖（不改文件）

有时你不想改文件，只想**临时**换个值（比如临时换个数据库测试）。

可以用**环境变量**（形如 `TIMEFLOW_XXX`）：

```powershell
# Windows PowerShell 示例：临时把数据库换到另一个文件
$env:TIMEFLOW_DATABASE__PATH = "data/test.db"
timeflow
```

规则：
- 前缀固定是 `TIMEFLOW_`
- **两层用双下划线** `__` 分隔，如 `TIMEFLOW_DATABASE__PATH` → 对应配置里的 `[database] path`
- 关掉这个终端窗口，临时设置就消失（不会污染你的 `config.toml`）

## 五、常见问题

### Q1：改了配置没生效？
- 检查是否**重启了程序**（配置在启动时读一次）。
- 检查文件名是否真的叫 `config.toml`（不是 `config.toml.txt`）。
  > Windows 默认隐藏扩展名，容易踩这个坑。在文件管理器"查看"里勾上"文件扩展名"就能看到真实名字。

### Q2：程序启动报错？
- 多半是配置格式写坏了（比如引号没配对、值写成了不认识的字符）。
- **恢复方法**：把改的那行改回原样，或直接用备份覆盖回去。

### Q3：我想改的不是配置项，是功能本身？
- 那超出"零基础定制"范围了，需要改代码。
- 建议先读 `CODING_GUIDELINES.md`（编码规范）和 `implementation/`（模块划分），并在动手前跑通测试。
- **如果只是想加个新配置项**：在 `src/timeflow/config.py` 加字段 + 同步更新 `config.example.toml`（见 `CODING_GUIDELINES.md` §10）。

### Q4：怎么确认我的配置是对的？
- 配置由 Pydantic 校验，类型不对会直接报错（不会静默出错）。
- 也可以跑测试确认整体没问题：
  ```bash
  python -m pytest
  ```

## 六、我想改的还没有配置项，怎么办？（给未来的扩展清单）

下面是**常见的定制需求**，目前有的还没做成配置项。如果你想贡献，可以按这个方向加：

| 想要的定制 | 现在怎么做 | 理想做法 |
|---|---|---|
| 番茄钟时长 | 暂未开放配置（代码里默认 25 分钟） | 在 `[focus]` 加 `pomodoro_minutes` |
| 债务/储蓄的可视化配色 | 跟随主题 | 在 `[app]` 加状态色配置 |
| 复习到期提前提醒天数 | 暂未开放 | 在 `[review]` 加 `remind_days` |
| 学校任务"提前几天提醒" | 暂未开放 | 在 `[academic]` 加 `remind_days_ahead` |

> 加配置项的**标准步骤**（3 步）：
> 1. 在 `config.example.toml` 加一行（含注释说明）
> 2. 在 `src/timeflow/config.py` 对应的配置类里加字段（含默认值）
> 3. 在用到它的地方读这个字段
>
> ⚠️ 改完必须跑 `python -m pytest` 和 `python scripts/check_layers.py`，全绿才算完成（见 `CODING_GUIDELINES.md`）。
