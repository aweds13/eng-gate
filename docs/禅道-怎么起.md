## 3. 怎么起（步骤）

1. **解压**：把安装包解到 `D:\zentao\`；
2. **起服务**：双击 `D:\zentao\ZenTao\ZenTao.exe`（ZenPanel）→ 在面板里启动 Apache 与 MySQL；
3. **看实际端口**：出厂值 Apache `Listen 80`、MySQL `port = 3306`（2026-10-14 逐字：
   `ZenTao/bin/apache/conf/httpd.conf` L4、`ZenTao/bin/mysql/my.ini` L2）—— 但面板可能因
   端口冲突改口，**以面板显示 + netstat 实测为准**：
   `netstat -ano | findstr LISTENING | findstr ":80 :3306"`；
4. **验活**：`curl -s -o NUL -w "%{http_code}" --max-time 3 http://127.0.0.1:<端口>/zentao/`
   （与 toml `[runtime].probe_command` 同款探法；200/30x = 活着）。
   入口为什么带 `/zentao`：出厂 conf 有 `Alias /zentao …/app/zentao/www/`（逐字：
   `bin/apache/conf/httpd.conf` L147）—— 首跑若对不上，用第 3 步的端口 + 浏览器实测哪个路径出页面，**别猜**。

## 4. 只监听 127.0.0.1（步骤，不是口号）

**不许暴露到局域网。MySQL 出厂已合规；Apache 出厂不合规，必须改：**

| 服务 | 出厂绑定 | 证据（2026-10-14 逐字） | 要做什么 |
|---|---|---|---|
| MySQL | `bind-address = 127.0.0.1` ✓ | `ZenTao/etc/mysql/my.ini` L16、`ZenTao/bin/mysql/my.ini` L14 | 不用动 |
| Apache | `Listen 80`（不带地址 = 全网卡都听）✗ | `ZenTao/bin/apache/conf/httpd.conf` L4 | 改成只听回环，见下 |

1. **改 Apache 绑定**：把生效 conf 里的 `Listen 80` 改成 **`Listen 127.0.0.1:80`**。
   注意包里有**两份** httpd.conf：`ZenTao/bin/apache/conf/httpd.conf`（成品）与
   `ZenTao/etc/apache/httpd.conf`（`%APACHE_PORT%` 占位符模板，L4；面板换端口按它渲染）。
   哪份生效取决于面板怎么渲染 —— **改完必做第 2 步复验，绑定没变就改另一份**。
2. **复验绑定**：重启 Apache 后 `netstat -ano | findstr ":80"` —— 必须看到 **`127.0.0.1:80`**；
   若是 `0.0.0.0:80` 就是改的不是生效那份（回头改另一份再复验）。
3. **换端口**（要换的话）：在 ZenPanel 面板里改（它写的就是 `%APACHE_PORT%` / `%MYSQL_PORT%` 模板），
   改完**重跑第 2 步**复验绑定仍只在回环。
4. **局域网抽查**（有第二台设备才做得了）：从局域网另一台机器
   `curl --max-time 3 http://<本机局域网IP>/` —— 应**拒连**（refused / 超时）。
5. **防火墙兜底**（可选第二道防线，管理员 PowerShell；就算配置回退外部也进不来）：
   `netsh advfirewall firewall add rule name="zentao-local-only" dir=in action=block protocol=TCP localport=80`

## 5. 禅道本体不进 git（做法）

- **主做法 = 放仓外**（§2）：仓外文件根本不会出现在 `git status` 里，什么都不用配。
- **万一解进了仓里**（如误放到仓库根）：
  1. 在 `.gitignore` 加一条目录忽略（按实际目录名，如 `/zentao/`）；
  2. 若已被跟踪过：`git rm -r --cached <目录>` 只摘出索引、不删本地文件；
  3. 判据：`git status` 里不再出现禅道本体的任何路径。
- 仓内**只留**登记与映射：`docs/zentao-bridge.toml`（只放键名、不放口令 —— 该文件头部写死的规矩）。
