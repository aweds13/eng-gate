# 定时巡检 —— 让「每日一批」自己跑，不靠人记（卡 220 · T-G334）

> 本卡要解决的问题：主控 2026-10-13 一天里**七次**靠人肉挂 `sleep` 看守等工人（还漏过一次），
> 而用户定的节奏是「**攒批提交，一日一次**」—— 两件都**依赖人记得**。
> 本仓教义：**没装牙的规矩 = 话**。所以要有「**一条命令 + 一个点**」：命令回答「现在该做什么」，
> 定时器让它自己跑。

## 二、一条命令：`tools/wb_daily.py`

**只读**（不写文件、不杀进程、不占端口、不起 DSH 插件、不调 git 写命令）。

```powershell
python -X utf8 tools/wb_daily.py          # 今天的一页（人读）
python -X utf8 tools/wb_daily.py --json   # 今天的一页（机器读）
python -X utf8 tools/wb_daily.py --root <树>   # 换个真源
```

一页里五+两块（★ **不另造读数**：其中四块直接调卡 207 的 `tools/pipeline_view.py --json`）：

| 块 | 来源 | 读数 |
|---|---|---|
| 待派 | `docs/workbacklog.toml` 的 `status = "pending"` | 几张、卡号 |
| 在飞（租约） | `gates/diag/pool-registry.json` | 谁占着哪棵树 |
| 批·等到提交 | `gates/diag/batch/<批>.json` 的 `state = awaiting-commit` | 批号 + 齐了几张 |
| 批·还在收集 | 同上，`state = collecting` | 批号 + 名单 |
| 已落没翻 status | 已落批的成功成员 vs 队列 `status` | 哪些卡该翻 `done` |
| 内存 | `scripts/run_gates.py` 的内存闸（门禁自己那一套） | 够 / 不够 / 读不到 |
| 门禁 | `gates/last.json` | 最近一次 `rev` / `ok` / 几道 |

**真源默认是「主工作树」**：租约与批状态都住 `gates/diag/`（`pool.task.main_tree_root()` 那条约定，
`wb_plan.py` / `wb_task.py` 都照它）。在卡树里跑，它也会去主树读那份**活的**池状态；
要在别的树上读就加 `--root`。

**缺什么说什么**：`pipeline_view` 挂了 / backlog 坏了 / 某个 `<批>.json` 坏了，都**点名**，
**不**用空对象冒充（例：「★ 读不到：…」）。最后一行 `⇒ 今天该做：` 只据读到的数说话，没有就不说。

## 三、自己挂（Windows 计划任务）

**先在仓根跑一遍**（确认路径与 python）：

```powershell
python -X utf8 tools/wb_daily.py
(Get-Command python).Source          # 记下这个 python 的绝对路径
```

### 3.1 推荐：`Register-ScheduledTask`（PowerShell）

**在仓根**（`tools/wb_daily.py` 所在的那棵树；想让别处也读池状态就换成主树根）逐条粘贴：

```powershell
$repo  = (Resolve-Path .).Path
$out   = Join-Path $repo 'gates\diag\wb_daily.txt'      # 固定落点（见 3.3）
$py    = (Get-Command python).Source
$inner = "& '$py' -X utf8 'tools/wb_daily.py' 2>&1 | Out-File -Encoding utf8 '$out'"
$act   = New-ScheduledTaskAction -Execute 'powershell.exe' `
           -Argument "-NoProfile -WindowStyle Hidden -Command `"$inner`"" `
           -WorkingDirectory $repo
$trg   = New-ScheduledTaskTrigger -Daily -At 09:00      # ← 每天几点，自己改
$set   = New-ScheduledTaskSettingsSet -StartWhenAvailable -MultipleInstances IgnoreNew
Register-ScheduledTask -TaskName 'TraeDailyWatch' -Action $act -Trigger $trg -Settings $set
```

看状态 / 立刻试跑一次 / 卸：

```powershell
Get-ScheduledTask -TaskName 'TraeDailyWatch' | Get-ScheduledTaskInfo   # 上次跑没跑、下次几点
Start-ScheduledTask  -TaskName 'TraeDailyWatch'                        # 现在就跑一次
Unregister-ScheduledTask -TaskName 'TraeDailyWatch' -Confirm:$false    # 卸载
```

### 3.2 命令行派：`schtasks`（等价，引号更绕）

```powershell
schtasks /Create /TN "TraeDailyWatch" /SC DAILY /ST 09:00 /F /TR `
  "powershell.exe -NoProfile -WindowStyle Hidden -Command ""Set-Location '<仓根>'; & '<python 绝对路径>' -X utf8 'tools\wb_daily.py' 2>&1 | Out-File -Encoding utf8 '<仓根>\gates\diag\wb_daily.txt'"""
```

```powershell
schtasks /Query  /TN "TraeDailyWatch" /V /FO LIST
schtasks /Run    /TN "TraeDailyWatch"
schtasks /Delete /TN "TraeDailyWatch" /F
```

把 `<仓根>` / `<python 绝对路径>` 换成上面记下的真值（`schtasks /TR` 有 261 字符上限，
路径长就用 3.1）。

### 3.3 结果写到哪

**固定落点**：`gates/diag/wb_daily.txt`（`gates/diag/` 在本仓 `.gitignore` 里 ——
它是本机诊断产物，**不进 git**，也就不会污染提交）。落点想换就改 3.1/3.2 里的 `$out`。
文件是**整篇覆盖**（每次跑都重写），所以「今天的一页」永远是最新那一份。

## 四、边界（如实写）

- **只读**：`wb_daily.py` 本身**不写任何文件** —— 落盘是计划任务的 `Out-File` 干的，
  不是工具干的。所以`只在终端跑`永远安全。
- **`--json`** 给机器用（同一份读数结构化输出），给未来的面板/桥接留口。
- **不做的事**：本方案**不**碰 `~/.dsh`、**不**注册 DSH 的 schedule 插件、**不**自动提交、
  **不**在跑之前问任何人 —— 它只是「把该做的念一遍」，**收口仍要人拍板**（本仓：机器只报，不放行）。
- **一处已知的慢**：`wb_daily.py` 调 `pipeline_view.py`，后者会逐棵卡树跑 `git status`
  （本机现在 224 棵树）⇒ 实测约 25 秒。一天一次无所谓；要更快的交互读数得改卡 207 那份读数器
  （**不在本卡域内**，本卡不碰）。
