## 准备（4 条命令，按需）

```powershell
python -X utf8 tools/serve.py --window     # 开桌面窗口（⑫ 要看的那个）；开不出来会打印原因再退回浏览器
timeflow                                   # 不带参数 = 老行为：开窗口
```

- ★ **⑪（备份与恢复）之前先留一份**：`Copy-Item data\timeflow.db data\timeflow.db.before-acceptance`
