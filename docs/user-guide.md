# timeflow 使用说明（一页）

> 本地优先的个人**时间 / 学习**工具：任务、专注计时、习惯打卡、复习卡、学业、统计。
> 数据全在你自己的电脑上（一个 SQLite 文件），**不联网也能用**。

界面上的话只留"用的时候要看到的"（按钮、单位、状态、报错原话）。
**怎么用、为什么这么算**这类话住在这里 —— 需要时看一眼，不用时它不占屏幕。

---

## 快速开始

```powershell
cd D:/repo/engineering
python -X utf8 tools\serve.py          # 起服务（只绑回环；会自动备份一次库）
```

浏览器打开它打印的那个 `http://127.0.0.1:…` 地址即可。桌面版想要一个窗口，加 `--app`。

## 每天怎么用

| 页面 | 干什么 |
|---|---|
| **今日** | 「今天要做什么」一行添加；勾完成；**从任务起专注**；右栏计时器常驻 |
| **全部任务** | 分组、子任务、优先级、标记、搁置、档案、回收站；卡上只摆**两个动作**（在做/开始 + 专注），其余在卡右端的 **`…`** 里（含删除）；**点标题**在右栏看详情、改字段 |
| **专注** | 开始/结束计时（结束三选：完成 / 记中断 / 放弃）；本周投入柱状 |
| **习惯** | 一键打卡；打卡日历热力图 |
| **统计** | 近 30 天投入曲线、分组分布、重复节奏、多维度热力图 |
| **复习** | 到期卡片按 FSRS 排期；记错了在「今天复习过的」里**改判** |
| **学业** | 课程、成绩、GPA / 加权平均、硬考核 |
| **备忘录** | 顺手记一句；只存**引用句柄**（Vault 路径），不搬正文 |
| **设置** | 主题与强调色、提醒、附件打开方式、导出、AI 接口、数据与同步、局域网访问 —— **每一节折成一行**（标题 + 当前值），点「展开」才动控件；最上面那排「常用」直接跳到对应节 |

> 卡片上、设置里那些按钮**不是消失了**：低频与危险的动作收进「…」和详情面板，常用的留在手边。

## 几个口径（一句话）

- **投入只算"正常结束"的专注**；中断、放弃不计。手动补记的投入**单列**，不与专注混算
  （统计页那张「学业 vs 自学」对照图也只算专注，手动投入不计入）。
- **任务可属多个分组** → 统计页「投入分布」里各组之和可能大于总投入（一遍专注被每个所属分组各记一次，如实重复）。
- **今日完成度**只算今天的清单与今天完成的（不翻旧账、无目标对标）。
- **债务**是按截止日算出来的（逾期项），不是手动记的账；勾完成就消失。
- **完成满 N 天进档案**（默认 3 天，设置页可改）；删除是**软删除**，回收站里能取回。
- **习惯只记次数**，不折算成投入时间。
- **团队页**：分配出去的任务不计你个人的投入（只记"协调这件事"本身）。
- **复习**：排期按 FSRS；撤销/改判会同时回退账目，不会重复计。
- **产出**分两类（学校 KPI / 知识资产），**分开报数、不折算**。

## 手机与跨端

**断网时（离线记那一页）能做什么、不能做什么**

- 能做：新建任务 / 勾完成与撤销完成 / 习惯打卡 / 一句备忘 / 每日反馈 —— 都先存在手机队列里。
- 不能做：离线**删除**（删要动电脑上的墓碑，手机上判不准）、离线**改字段**（会覆盖电脑上更新的那份）、
  从电脑**回传**到手机（手机没有库，不做反向合并）、离线**专注计时**（它牵动电脑那边的派生账目）。
- 传回电脑有两条路（页面上都有按钮）：**直接传到电脑**（连得上时最快）或**导出同步包**。
  合并规则只在电脑那边（手机不判新旧）；**传失败绝不清空队列**，导出也不会清空；
  重复导入是安全的（电脑那边合并幂等）。
- **断网也能打开这一页**（它就是为断网准备的）。

**怎么让手机连上（按顺序）**

1. 电脑上启动时显式开启局域网访问：`python -X utf8 tools\serve.py --lan`（默认关，只绑回环以外的那张网卡）。
2. 手机浏览器打开电脑的局域网地址（设置页「局域网访问」里能看到地址）。
3. 第一次打开要输**配对码** —— 代码显示在电脑的设置页「局域网访问」里（本机可见，不广播）。
   只在**同一个 WiFi** 里管用，不涉及公网。

**跨端同步（走文件）**

- 一台**导出同步包** → 拷到另一台（U 盘 / 网盘 / 局域网共享）→ 在那台**先预览再导入**。
- 包里**不含**本机设置（导出目录 / Vault / AI 开关 / 口径开关）、本机冲突日志与 schema 版本 ——
  拷过去不会改掉另一台的设置；同名文件不会互相覆盖（同一秒导出两次会加 `-2`）。
- 合并按 `version → 更新时间` 判谁新；覆盖与保留都记进**冲突日志**（不静默，设置页能读）。
- 「同时应用对方的删除」默认**不勾**；勾上之后对方的删除会在本机生效且**不可撤销**
  （要回退用「备份与恢复」）。两种例外仍然不删：本机没有那一行；或你本地在那之后又改过它。
- **跨端专注镜像**：任一设备开始专注，另一台当场进入专注态（只读，可自己停）。

**任务字段的几条口径**

- **备注**只属于这个任务，不参与账本。
- **改截止日**会立刻重算逾期与债务；**已完成的任务也能改**，但不会改写历史完成记录。
- **删除**是软删除（回收站里能取回或彻底删）；完成满 N 天自动进档案（N 在设置页改）。
- **附件/链接**：打开方式在设置页「附件打开方式」里选；可执行/脚本类**任何设置下都只到文件夹**，不会直接运行。


## 数据在哪 · 怎么备份

- 库文件：`data/timeflow.db`（+ 每次起服务时的自动备份 `data/*.db.bak-*`）。
- 导出：Markdown 写到设置页「导出（Markdown）」里指定的目录（默认 `export/`，一天一个文件）。
- 备份与恢复：设置页「数据与同步 → 备份与恢复」。

## 命令行（可选，T-G64）

不开窗口也能看今天的账（只读，不会改任何数据）：

```text
timeflow                开窗口（默认，和以前一样）
timeflow today          今天的摘要：专注 / 手动投入 / 复习 / 产出 / 债务
timeflow plan           今天的清单        timeflow overdue   逾期项
timeflow due            到期复习卡        timeflow done      今天做成了什么
timeflow week           本周结算          timeflow trend     近 N 天走势
timeflow habits         习惯与连续天数    timeflow check     自检
timeflow upcoming       临期/逾期考核项   timeflow focus     现在有没有在专注
timeflow tasks          任务列表          timeflow board     团队视角
timeflow sync           同步现状
timeflow commands       我有哪些命令（`--table` 看整张契约命令表）
```

- 加 `--json` 得到机器读的原始数据（字段与界面完全同一份来源）；
- 加 `--db 路径` 指向另一个库文件；`timeflow <命令> --help` 看参数；
- 退出码：`0` 成功 / `1` 用法错 / `2` 接口错 / `3` 找不到命令表 —— 方便写脚本判断。

## 已知局限

- **学校通知（F10）**：只做界面标注与合作接口；计划任务在「注销/关机」时不会响（那要系统层权限）。
- **移动端只标不通知**：到期/提醒在手机上只显示，不发系统通知。
- **暗色主题**：令牌层与对比度都核过（两套主题的颜色对都在门里），但**没有逐页的暗色版式基线**
  —— 渲染校验只采亮色。**2026-09-25 决定不做全量暗色基线**：版式与主题无关（暗色只换颜色不换布局），
  而"暗色下看不见的东西"改由**非文字对比度表**覆盖 —— 那张表 **2026-09-25（T-G70）已建**：
  控制边界（输入框/下拉/文本域的边框）/ 勾选圈 / 状态点 / 图表数据笔 / 逾期红条逐对 ≥3:1，
  两套主题各自算，每次跑门都查。**不在内的是纯装饰**（卡片边、分隔线、图表网格 / 热力图空格 /
  环轨道）：它们的实测值只作记录（1.1~1.6:1），因为把 365 个热力图空格画成 3:1 的灰会毁掉那张图。
- **同步不做实时推送**：跨端专注之外，其余数据靠同步包按需合并。
