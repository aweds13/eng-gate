# needs.md — 需求清单（intention 层）

> 一页看懂：**一个本地优先、跨平台的个人「时间与学习投入」管理工具**，管要做什么（To-Do）、**用「债务/储蓄」统筹逾期与投入**（该做没做=债务、投入/产出=储蓄）、守住学业不冲突、可外接 AI 与笔记、数据本地可同步。

## 意图声明（一层三件事）
- ① **管要做什么** —— 任务 / 拆解 / 分区 / 每日 My Day / 专注
- ② **算投入是否均衡** —— 债务 / 储蓄 / 重新规划 / 债务重组，长期平均投入（**贯穿**：逾期=债务、专注=投入、悬赏完成=收益）
- ③ **守住底线** —— 不夹带学业冲突，可外接 AI，数据本地可同步

## 参考来源
- 功能形态参考 **Microsoft To Do**（My Day / Important / Planned / Flagged / 分组计数 / Add step / Repeat / 附件等）。
- 「债务 / 储蓄 / 重新规划 / 债务重组」为本项目原创心智模型（见文末校核）。

## 定位
| 维度 | 需求 |
|---|---|
| 使用对象 | 我本人（大学生），学习 + 工作安排；开放给同学（零基础可定制） |
| 运行环境 | **桌面程序**（独立窗口、双击即用，本地单机为主）+ 移动端同步/异步更新 |
| 形态约束 | 尽量轻；复杂外部监测不硬塞进主工具 |

## A. 核心定位与哲学
- **N1** 本地单机 + 轻量 + 跨设备
  - *为什么*：跑在自己电脑，隐私最小、不依赖云端；但常有离开电脑的时刻。
  - *衍生*：需要移动端做「同步/异步更新」；存储本地、可同步（见 N25）。
- **N2** 面向「我的学习与工作」做长期均匀投入
  - *为什么*：可持续，避免一次突击或长期拖延。
  - *衍生*：引出 B 组的记账心智模型，且**贯穿到逾期/专注/悬赏**。

## B. 心智模型：债务 / 储蓄（贯穿）+ 重新规划 / 债务重组
- **N3** 【债务】与【储蓄】记账，实现长期平均投入（**贯穿核心**）
  - *为什么*：把长期目标拆成「均匀投入量」，达成=储蓄、未达成=债务；账本反映投入是否均衡，防突击/拖延。
  - *贯穿口径（已定）*：**逾期任务=债务**；**专注投入=储蓄**；**完成悬赏=收益/储蓄**；**复习逾期=轻度债务**（会遗忘打折，且可由 **FSRS 自愈**）；**复习完成=投入（维持）**，且**温故知新**（有新理解 / 笔记 / 灵感）可**额外计一笔产出**（可选，累加进产出轴）。
  - *量化口径（已定）*：投入量**以时间为主**；**产出分两类、独立记账、分开展示**——① **学校 KPI**（加权/综测，外部硬指标）；② **个人知识资产增加**（内部成长；**资产形态暂定**= 知识笔记 / 开发工具（文件、脚本、软件、skills 文档）/ 项目成果；粗颗粒 + 手动 + 留扩展，**暂不精细打分**——toolkit 只有质检/检索评估/文风评审、**无产出打分器**，知识管理未对齐不写死）。
  - *量化目标（⭐）*：**保证单位时间（周 / 月 / 季）稳定产出**——B 衡量"单位时间有没有稳定产出"，而非单纯计时。
  - *债务口径（已定）*：**债务 = 如实列逾期清单 + 逾期天数 / 程度（轻度≤3天 / 中度≤7天 / 重度>7天），不折算成精确时间**（估不准、不造假）；**有时标任务**（KPI ddl、每日定时）→ 逾期天数自然对应、到期未做=债务；**灵活并行任务**（做一下这个、不行做另一个）→ 只如实标「逾期中 / 逾期天数」、看是否在做/完成，不给时间分；学习目标带时长参考。
  - *原则（温和，⭐）*：B 是**帮你管理时间，不是 push 你**；长期、**慢就是快、打基础**；管理工具**不制造压力**；学生学得慢正常。
  - *结算*：**以周为主**；**不设独立「目标」实体**（**伪需求**，避免过度抽象）——目标=大的任务分组/项目（用 N8 自定义分组涵盖，必要时给任务打**多分组/领域标签**）；投入基准**靠如实记账 + 趋势自判断**，**不硬对标**；**产出量化交给知识管理系统**，本软件只粗颗粒记录。
  - *可扩展*：量化含「学校 KPI / 知识资产」两类，**给知识管理项目留改变空间**（呼应 N35/N36）。
  - *可视化*：债务/储蓄用**曲线 + 时间热力图**；**投入/产出分布可按任务分组（领域）查看**（如主线 / 自媒体 / 财务各投多少）。
  - *版本*：基础记账纳入第一版；完整心智（重规划/债务重组）后置第二版。
- **记账规则（默认值，用户可改）**：
  1. **未绑定专注**也可计投入（如实、轻量，不额外归因）。
  2. **复习完成** = 投入（维持）；**温故知新**（新理解/笔记/灵感）→ 额外计一笔产出（可选）。
  3. **学校任务**：写作业/备考 = 投入（时间）；成绩/综测（达标）= 产出；逾期 = 债务；**成绩/综测 与 知识资产 分开记账、分开展示**。
  4. **团队任务**：分配出去的不计我投入（我没做），只记「协调/分配完成」+ AI 回报单独记。
  5. **债务生命周期**：完成 → 随当天清零；取消 → 按已过天数计完即止；推到 → 债务随天数累计。
  6. **均衡度指标**：显示「投入波动/空档」作参考，**温和不告警、不施压**。
  7. **B 顶部轻量摘要**：今日/本周债务项数 + 投入时长，一行小条。
  8. **跨端去重**：来源标记（设备 id）+ 同 id 去重（LWW 已覆盖）。
  9. **产出评价器接口**：第一版「手动粗颗粒」入口，合同待知识管理对齐再定。
- **N4** 【重新规划】：指标失真时按实际情况重校（后置第二版）
  - *为什么*：计划不合理或能力提高 → 盈余虚高 → 数字误导「好像很久不用做」→ 其实计划与当前能力不符。
  - *衍生*：能标记「指标已失真 + 建议按新基线重校」；重校要可证（证据链），不拍脑袋。
- **N5** 【债务重组】：债务过高导致破罐子破摔时，允许承认失败、从头再来（后置第二版）
  - *为什么*：债务越积越高会让人放弃，系统失去正面意义；需要一条逃生通道。
  - *衍生*：「承认失败 → 吸取教训 → 定更合理计划 → 重组（清零/重新分摊）」，**保留教训记录**。

## C. 任务管理（参考 Microsoft To Do + 自定义规则）
- **N6** My Day 语义：**今天要做的集合**；昨日未完成的自动移入**逾期栏**（自由处理，除非手动移除）；排序 = 截止时间 → 优先级 → 手动拖拽
  - *为什么*：当天焦点清晰可控；未做完不假装消失，也不硬塞回今天。
  - *衍生*：My Day 独立视图 + 「挑选加入」动作 + 逾期栏。
- **N7** 筛选视图：My Day / Important / Planned / Flagged / **逾期栏** + 全局总任务数；**砍掉 Assigned to me**（个人不适用）
  - *为什么*：快速聚焦不同类型任务，不被全量淹没；团队分配语义由管理者模式承接（N46）。
  - *衍生*：侧边栏视图切换 + 全局计数。
- **N8** 自定义分组：按项目/领域分类（主线任务 / 数学视频自媒体 / 财务…）+ 分组计数
  - *为什么*：跨领域任务要分区，避免混在一起。
  - *衍生*：分组管理 + 分组计数。
- **N9** 任务详情与状态机：Add step / Add note、Add to My Day、due date、Remind me、**Repeat**、附件；状态 = 未开始 / 进行中 / 完成 / **逾期** / 取消 / 归档
  - *为什么*：一个任务要能挂子步骤/备注/截止/提醒/周期/附件；状态清晰才能流转。
  - *Repeat 规则（已定）*：到点**自动生成下一次**（基于上次完成时间），可用**时间热力图**管理重复节奏。
  - *衍生*：详情编辑面板 + 状态机流转 + Repeat。
- **N10** 大任务→小任务拆解，不臃肿；**子任务全完成父任务才自动完成**（可手动提前勾）
  - *为什么*：大量任务下分大量小任务，全平铺很乱；父子完成关系要明确。
  - *衍生*：任务树/折叠 + 子任务驱动父任务完成。
- **N11** 【给任务存档】：记录当前状态 + 过去做过的尝试（简版）；详细信息写在本子，任务列表记「笔记名称」
  - *为什么*：历史与尝试要可追溯，但不想在任务列表堆长文本。
  - *衍生*：任务字段「关联笔记名/链接」+ 存档视图；**Obsidian 深联动后置**（见 G）。
- **N45** 逾期处理（全新）：逾期任务**留 My Day 标红**（今天没做完不假装消失）；点开可「推到明天/改 ddl / 标逾期 / 取消」；**学校硬考核逾期 → 强提醒**（会扣分）；**普通任务逾期 → 温和提示**
  - *为什么*：逾期是最常见的状态；学校考核是硬约束，普通任务是软约束，强度要区分。
  - *学校硬考核分类（已定）*：① **有指标类**（我会定的 KPI，如考试目标分/GPA 目标）——进**产出账**（可重规划）；② **逾期不候类**（过时不让交/考）——又分：**作业/考核**（负向，逾期扣分影响加权成绩 → 强债务、**不可重组清零**）、**竞赛/活动**（正向，逾期不扣分，仅错失机会 → 弱债务/机会损失）。
  - *衍生*：逾期提醒分级（强/弱）；与 B 系统联动（逾期=债务，N3），且**强度分档**（负向强债务 vs 正向弱/机会 vs 指标可重规划）。
- **N46** 管理者 / 执行者模式（全新，团队·AI 协作）：分「管理者（建/分配任务）」与「执行者（接收/执行）」两种视角，可切换
  - *为什么*：与 AI 协作执行任务、大学组队比赛都有团队概念；个人自用时可用纯「执行者」视角。
  - *团队原则（已定）*：**不强制执行者装本软件**——只需「我知道谁负责什么、进展到哪」即可；执行者（组员/AI）可不接入，状态**第一版「手动为主 + AI 接口」**；这类数据属于「**现实与 AI 记忆对齐**」部分，**参考 toolkit 笔记做法**（obsidian-vault-notes 的记录/读写，见 N24）。
  - *衍生*：任务可标注「分配给我 / 我分配」；AI 作为执行者之一，通过 N23 接口接收任务 + 回报进展；配合筛选视图（N7）。

## D. 计划与执行的差距 + 习惯 + 自检
- **N12** 每日执行后反馈，反映「计划 vs 执行」差距
  - *为什么*：知道每天实际做多少、差在哪，才能校准。
  - *衍生*：每日复盘录入 + 计划-执行对比；**专注时长（绑定任务）自动计入**。
- **N13** 习惯养成日历（打卡，**时间热力图**）
  - *为什么*：习惯要可视化、连续记录。
  - *衍生*：日历热力图可视化，**纳入 B 系统**（与债务/储蓄同一套可视化）。
- **N14** 定期自检：任务列表是否臃肿、注意力基线是否下滑、方向是否需重新校准
  - *为什么*：工具也要自我体检，防长期偏离。
  - *衍生*：自检提醒/报告（可对接 N4 重规划）。

## E. 计时与专注
- **N15** 计时器：番茄钟 + 普通计时；**可绑定任务**（绑定则时长自动计入该任务 + 每日反馈 + B 系统投入）；**专注被打断可选「暂停 / 放弃 / 记中断」**
  - *为什么*：区分番茄与普通；专注要能归因到任务、计入投入；被打断要能如实处理。
  - *衍生*：两种计时模式 + 任务绑定 + 中断处理。
- **N16** 专注白名单（软件/网站）+ 专注时段勿扰（类似 Windows 勿扰）；**白名单默认「阻止非白名单」**
  - *为什么*：专注时屏蔽干扰源；默认收严，用户再放宽。
  - *衍生*：白名单配置 + 勿扰时段；桌面端/移动端分别配置。
- **N17** 多设备同步专注：电脑或手机开始专注后，另一设备同步进入专注计时
  - *为什么*：在电脑开专注，手机也要跟着进入勿扰/计时；反之亦然。
  - *衍生*：专注状态跨设备同步。

## F. 学业追踪（GPA / 学分 / 学校任务）
- **N18** GPA 与学分追踪，避免自学与学校考核冲突；**期末/成绩出来后手动录入**
  - *为什么*：自学再投入也不能砸了学校考核；学分绩点要看清。
  - *衍生*：GPA/学分手动录入 + 与自学时间线对照。
- **N19** 学校课程「学分 + 考核方式」追踪与提醒（来自学校办公网）
  - *为什么*：每门课学分与考核要求不同，需按课追踪与提醒，防漏考/漏交。
  - *衍生*：课程档案（学分/考核/截至）+ 提醒。
- **N20** 学校任务 KPI 单：完成要求备注 + 跳转到本地文件/网站看清要求
  - *为什么*：光记「要做什么」不够，要能记清「怎么评、去哪看要求」。
  - *衍生*：任务附件「本地路径 + 网站链接」+ 备注。
- **N21** 学校通知监测：网站/公众号/群聊/考试网站 → 抓取/集成/通知
  - *衍生*：可能让主工具过大 → 另起脚本/软件，本工具提供**合作接口**（见 N22）。

## 学校任务处理方案（设计定位）
> 关键：**数据域按课程归类，执行视图合流进每日计划**——同构、无差别，不增加心智负担，保住「今天自由安排」的自由。

- **同构**：和普通任务一样进 My Day/列表，可勾选/排序/拆子步骤；只是多带「课程标签 + 硬约束元数据」（截止、学分、分数、来源）。
- **课程卡片**：`课程档案（学分/考核/任课）` → `考核项（考试/作业/论文/小测）`。这是组织维度，不是执行隔离维度。
- **提醒**：临近（提前 N 天）提醒并**建议**进 My Day（保底防漏）；**不强制**，你可自由安排/推迟。
- **要求跳转**：备注 + 外部链接 + 本地文件路径，点进去看要求。
- **逾期分级**：学校硬考核逾期 → **强提醒**（N45）；计入债务的口径见 N3（硬考核逾期视为债务，但**不可重组清零**——考试不会因重组消失）。
- **课程价值/优先级（已定）**：**用「重要性 / 优先级」机制调整即可**（任务本就有 Important/优先级），**不单独做"价值"标签**；你自定义某课降优先级/豁免，仅作排序提醒，不替你判断。
- **录入**：学期初**手动建档**一次，再按需更新；自动抓取留给通知脚本（N22）。

## G. 外接与数据
- **N22** 与「学校通知监测」等外部脚本/软件合作，通过接口集成（不让主软件膨胀）
  - *衍生*：预留「外部服务接口」契约（spec 层定）。
- **N23** 为 AI 智能体（Hermes）提供读写任务的接口/端口；**第一版只读 + 新增**（不改不删，避免和你手动冲突），结合管理者模式（N46）
  - *为什么*：要和 AI 协作，AI 需能读任务、写任务；第一版保守，避免覆盖你的操作。
  - *衍生*：本地 API（HTTP/端口）可读 + 新增任务/记录；写/改/删留后续。
- **N24** 备忘录：碎片化任务/想法随手记（本地）；**Obsidian 深度联动后置到「知识资产管理项目」处理**，本软件只预留接口 / 记录笔记链接
  - *为什么*：碎片记录重要；Obsidian 联动与知识资产管理强相关，独立项目更干净（避免本软件膨胀）。
  - *知识资产联动（参考 toolkit 6 技能）*：**本软件只存「引用句柄」**——Vault 相对路径 / `KB-...` 资源 ID；**读/写 Obsidian、接 PDF 库交给「知识资产项目」**（obsidian-vault-notes 受控读写 + manage-personal-knowledge 的 KB ID/PDF 库），本软件不直接碰 Vault 文件。
  - *衍生*：备忘录本地存储 + 预留「知识资产句柄」契约（spec 层定）；移动端快速记录进这里。
- **N25** 数据具体怎么存（需设计）：本地优先、可跨端同步、可被 AI 读写、可扩展（习惯/专注/学业/备忘录多域）
  - *衍生*：存储方案是 design 层关键权衡点。**已决（见 `../specification/conventions.md`）**：采用**混合模式**——Markdown（frontmatter+正文）为共享真源，结构化索引供软件高效计算；沉淀型走 Markdown、计算型走结构化。

## H. 复习与间隔重复（spaced repetition）
- **N26** 复习任务的**间隔重复调度**（追踪 + 提醒 + FSRS 曲线）；**可由学习任务「升级为复习任务」或手动建**（相当于特殊子栏目）；**到期多时按算法排序（重要度 + 最久未复习）优先进 My Day**
  - *为什么*：持续背诵/复习要按遗忘曲线才会有效；到期要能聪明地排优先级，不挤爆当天。
  - *算法（已定）*：第一版**用现成 Python FSRS 库**；数据按 FSRS 兼容字段设计，为扩展留口子。
- **N27** 外部工具场景（只记录、不替代执行）：英语单词在「不背单词」app 背诵，本工具只做**调度中枢**——提醒「今天该背这批」，**你手动点「完成」**
  - *为什么*：实际背诵在别的 app，本工具不重复实现，只跟踪 + 提醒；进度只能手动报。
  - *衍生*：复习任务打「执行源」标签（外部 app / 内置），外部执行靠手动完成。
- **N28** 与 Obsidian / 其他工具的**联动**复习：复习材料在 Obsidian（或未来自制复习工具），本工具追踪进度 + 记录历史；**读写交给知识资产项目（参考 toolkit 6 技能），本软件只存复习卡片/笔记的「引用句柄」**
  - *衍生*：复习任务引用笔记/卡片（呼应 N24，用 Vault 路径/KB ID），复习完标记并推进下一间隔。
- **N29** 复习形式多样性（预留）：**挖空（cloze）/ 真题 / 问答卡**等；**FSRS 反馈用三态（记得 / 模糊 / 忘了）**——这是本软件与「复习工具」的联动接口
  - *为什么*：不同内容用不同复习形式；反馈三态是给 FSRS 喂熟练度、也是将来复习工具的接入点。
  - *衍生*：复习任务预留「复习形式」字段 + 扩展口子；反馈三态作为调度接口。

## 核心概念定义（校核后）
- **债务 / 储蓄** = 如实记账：**逾期任务=债务（逾期天数/程度）**、**专注投入=储蓄（时间）**、**完成悬赏=收益/储蓄**。目标是看「单位时间产出稳不稳」；**长期平均投入**是理念，但**不强制拆「均匀投入量」、不硬对标**（已砍目标实体）。不是存钱 app，是「投入 / 产出 / 欠账」的**如实账本**。
- **重新规划** = 账本失真时按真实能力重校指标。**双向**：计划过松/能力提升→盈余虚高→调高；计划过难/能力下降→长期欠账→下调。要有证据（基于近期实际完成量）。
- **债务重组** = 债务压垮人时的逃生通道：承认失败→吸取教训→定合理计划→重组（清零/重新分摊），允许从头再来；**必须保留教训记录**。注意：**学校硬考核逾期虽计债务，但不可通过重组清零**（考试不会因重组消失）。
