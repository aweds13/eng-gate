# SR-F3 计时与专注 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-3 开始专注（扩展）

- 入口：专注页「番茄 / 普通」；任务卡片「开始专注」。
- 前置：无进行中 session；绑定任务存在且未取消/归档。
- 输入：kind（tomato / plain）+ 可选 task_id。
- 后续：落库 status=进行中 → 显示计时 → 标注绑定任务。
- 可逆：可放弃。
- 反馈：计时器可见并走动；按钮切为结束/放弃。
- 边界：重复开始拒绝；非法 kind 拒绝；任务无效拒绝。

## OP-4 结束专注（MVP 最关键）

- 入口：计时态「结束」；中断时「暂停 / 放弃 / 记中断」。
- 前置：存在进行中 session。
- 输入：无（时长自动）；中断选处置方式。
- 后续（正常结束四步全执行）：①落库 ended/duration/status ②发 `focus.finished` ③账本记投入 ④当日反馈自动累加 ⑤绑定任务时长累加 ⑥界面退出计时并刷新。
- 可逆：否；放弃不计入投入。
- 反馈：计时停止；今日专注分钟即时 +N。
- 边界：重复结束幂等；session 不存在报错；0/负时长按 B2；跨午夜按完成日。

## OP-3b 暂停 / 继续

- 入口：计时态「暂停」；暂停态「继续」。
- 前置：进行中 / 已暂停。
- 输入：无。
- 后续：状态切换；恢复后继续累计；不产生投入事实直到正常结束。
- 可逆：可继续。
- 反馈：计时暂停 / 恢复。
- 边界：暂停中再次暂停幂等；暂停跨天按恢复后的完成日归属。

## OP-4b 放弃 / 记中断

- 入口：计时态「放弃 / 记中断」。
- 前置：存在进行中 session。
- 输入：无（记中断可选原因，预留）。
- 后续：放弃 → `focus.abandoned`，不入投入；记中断 → `focus.interrupted`，按实际时长入账 + 标记。
- 可逆：否。
- 反馈：session 结束；摘要按规则变化。
- 边界：放弃幂等；记中断时长 0 可记录不显有效投入。

## OP-3c 白名单 / 勿扰配置

- 入口：**设置页「专注（白名单 / 勿扰）」区**（宽屏左栏最后一格 / 手机端底部 Tab 都能进）。
- 前置：无。
- 输入：`block_by_default`（真布尔）、白名单来源列表、勿扰时段列表。
- 后续：保存到 `app_settings` → 之后的判定（`is_allowed` / `is_do_not_disturb`）按新设置走。
- 可逆：可改回；**空列表 = 明确清空**（与"没传这个字段"是两件事，后者保持原值）。
- 反馈：保存 toast + 当前值就地刷新（chips 增删）。
- 边界：空、重复条目忽略；**非法一律 400**（超长/超量/`25:00-07:00` 这种时段/非布尔开关）——
  **不静默落默认值、不静默清空**（静默清空等于数据丢失）。
- **实现（前端批次③，2026-09-20 / GAP-F3-02 收口）**：
  - `GET /api/focus/guard` → `{block_by_default, whitelist, do_not_disturb, note, window_format, max_items}`
    —— 连**口径说明**一起返回（"只做配置与判定，不做系统级屏蔽"），界面不复述规则；
  - `PUT /api/settings/focus-guard` —— **服务端持有 + 只接受本机页面**（带跨站 Origin → 403，
    与附件打开方式同一套 `require_local_origin`）；
  - **默认值来自 `config.toml` 的 `[focus]`**，本机在界面里改过的以 `app_settings` 为准，
    **逐项独立**（只改了白名单，勿扰仍用配置值）；
  - 时段格式 `HH:MM-HH:MM`（24 小时制，允许跨午夜如 `22:00-07:00`），各限 50 条。
  - 测试：`../../../tests/test_focus_guard_line.py`、`../../../tests/test_web_frontend.py`。

## 多设备同步（B3 细化）

- 任一设备开始 → 其他设备同步进入专注/勿扰；同 id 去重，冲突不静默覆盖。
