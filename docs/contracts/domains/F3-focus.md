# SR-F3 计时与专注 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-3 开始专注（扩展）

- 入口：专注页「番茄 / 普通」；任务卡片「开始专注」。
- 前置：无进行中 session；绑定任务存在且未取消/归档。
- 输入：kind（tomato / plain）+ 可选 task_id。
- 后续：落库 status=进行中 → 显示计时 → 标注绑定任务。
- 可逆：可放弃。
- 反馈：计时器可见并走动；按钮切为结束/放弃。
- 边界：重复开始拒绝；非法 kind 拒绝；任务无效拒绝。

## OP-4 结束专注（MVP 最关键）

- 入口：计时态「结束」（正常结束）；**被打断时三选**「结束（计入投入）/ 记中断 / 放弃」。
- 前置：存在进行中 session。
- 输入：无（时长自动）；中断选处置方式。
- 后续（正常结束四步全执行）：①落库 ended/duration/status ②发 `focus.finished` ③账本记投入 ④当日反馈自动累加 ⑤绑定任务时长累加 ⑥界面退出计时并刷新。
- 可逆：否；放弃不计入投入。
- 反馈：计时停止；今日专注分钟即时 +N。
- 边界：重复结束幂等；session 不存在报错；0/负时长按 B2；跨午夜按完成日。

## OP-4b 放弃 / 记中断

- 入口：计时态「放弃 / 记中断」。
- 前置：存在进行中 session。
- 输入：无（记中断可选原因，预留）。
- 后续：放弃 → `focus.abandoned`，不入投入；记中断 → `focus.interrupted`，按实际时长入账 + 标记。
- 可逆：否。
- 反馈：session 结束；摘要按规则变化。
- 边界：放弃幂等；记中断时长 0 可记录不显有效投入。

## OP-3c 白名单 / 勿扰配置

- 入口：**设置页「专注（白名单 / 勿扰）」区**（宽屏左栏最后一格 / 手机端底部 Tab 都能进）。
- 前置：无。
- 输入：`block_by_default`（真布尔）、白名单来源列表、勿扰时段列表。
- 后续：保存到 `app_settings` → 之后的判定（`is_allowed` / `is_do_not_disturb`）按新设置走。
- 可逆：可改回；**空列表 = 明确清空**（与"没传这个字段"是两件事，后者保持原值）。
- 反馈：保存 toast + 当前值就地刷新（chips 增删）。
- 边界：空、重复条目忽略；**非法一律 400**（超长/超量/`25:00-07:00` 这种时段/非布尔开关）——
  **不静默落默认值、不静默清空**（静默清空等于数据丢失）。
- **实现（前端批次③，2026-09-20 / GAP-F3-02 收口）**：
  - `GET /api/focus/guard` → `{block_by_default, whitelist, do_not_disturb, note, window_format, max_items}`
    —— 连**口径说明**一起返回（"只做配置与判定，不做系统级屏蔽"），界面不复述规则；
  - `PUT /api/settings/focus-guard` —— **服务端持有 + 只接受本机页面**（带跨站 Origin → 403，
    与附件打开方式同一套 `require_local_origin`）；
  - **默认值来自 `config.toml` 的 `[focus]`**，本机在界面里改过的以 `app_settings` 为准，
    **逐项独立**（只改了白名单，勿扰仍用配置值）；
  - 时段格式 `HH:MM-HH:MM`（24 小时制，允许跨午夜如 `22:00-07:00`），各限 50 条。
  - 测试：`../../../tests/test_focus_guard_line.py`、`../../../tests/test_web_frontend.py`。

## OP-51 跨端同步专注（只读镜像，T-G20）

- 入口：**不需要点** —— 任一台设备（电脑 UI / 手机）开着这一页就会看到；
  出现条件是「**别处**有一条进行中的专注」（`GET /api/focus/active` 的 `device_id` 不是我这台）。
- 前置：同一局域网且已配对（跨端那道门）；对面正在计时；我这边**没有**自己的进行中会话。
- 输入：无（只读）。
- 后续：右栏变成「别处正在专注 · 来自手机/另一台设备」+ 秒数（`#clockPeer`），专注页同步换文案；
  **不新建会话、不发事实、不改对面那一行**。
- 可逆：镜像随对面结束自动消失（界面侧靠 10 秒轮询；数据侧不做推送）。
- 反馈：秒数在走；文案写明「这边只看不动：结束请去那边，这里不会重复记一笔投入，也不会打断它」。
- 边界（三条硬规矩）：
  1. **镜像卡里一个 `data-action` 都不许有** —— 加「结束」就是让这台设备去停另一台；
     加「我也开始」就是同一段时间记两笔投入（后端也会 400 拦，但界面不该给这个念想）。
  2. **判定靠 `device_id`**：它是**客户端**身份（手机 = 它自己的 `ph-` 号；电脑 UI = `cl-` 号），
     不是「数据库主人」那个设备号（两个客户端读到的是同一个主人号，区分不了）。
  3. **老数据（`device_id` 为 NULL）算「我开的」** —— 保住「重开页面恢复计时」这条既有行为；
     代价是两台机器各开过一次之后的老会话分不出归属（新会话都带号，属过渡期）。
- **实现（T-G20，2026-09-23；SR-F3.4 收口）**：
  - 后端：`start_session(device_id=)` 落库、`active_session()` 回传（空白 → NULL、超长截断到
    `MAX_DEVICE_LEN = 40`）；**没有新表、没有新接口** —— 镜像只是把既有那一行读出来；
  - 前端：`clientId()` + `FOCUS_POLL_MS=10000` 轮询（页面可见且在线时才问、失败静默、
    指纹变了才重画）+ `renderActiveMirror()`；
  - 结束**不做实时推**（用户口径：结束时再同步）：记录各自入库，之后走同步包（T-G8/T-G10/T-G15）。
  - 测试：`../../../tests/test_focus_mirror_line.py`（数据侧：不重复记账）、
    `../../../tests/test_web_frontend.py::test_cross_device_focus_mirror_is_read_only`（界面侧）、
    `../../../tools/ui_dom_probe.mjs`（镜像真渲染 + 0 按钮 + 老数据回归）、
    `../../../tools/web_live_check.py` 的「跨端专注」5 条（真 HTTP）。

## 多设备同步（B3 细化）

- 任一设备开始 → 其他设备同步进入专注/勿扰；同 id 去重，冲突不静默覆盖。
- **专注这一侧 2026-09-23 定案并落地**（OP-51）：**实时启动 + 结束时再同步** ——
  实时只传「谁在计时」（一条只读查询），数据（`focus_sessions`）不做实时推、事后走同步包。
- **勿扰是「状态可见」，不是系统级屏蔽**：`is_allowed` / `is_do_not_disturb` 只做配置与判定
  （见 OP-3c 的口径说明），主工具不拦系统里的应用 —— 镜像卡只说「别处正在专注」，
  不谎称已经替用户按下了勿扰。
