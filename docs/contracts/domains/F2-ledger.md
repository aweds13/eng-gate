# SR-F2 B 系统记账 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-7 查看今日摘要（扩展）

- 入口：顶部摘要区。
- 前置：无。
- 输入：无。
- 后续：债务 = 逾期项数 + 天数/程度；投入 = 今日 `focus.finished` 事实 sum/3600；任一操作后刷新。
- 可逆：只读。
- 反馈：一行摘要，温和不告警。
- 边界：空账本显示 0；跨午夜按完成日；旧库无 facts 由回填/回退保证。

## OP-13 手动记投入（目标态）

- 入口：投入流水/设置页（第一版可无 UI，API 保留）。
- 前置：无。
- 输入：数值（非负）、可选备注/来源。
- 后续：发 `invest.manual` 事实 → 摘要/周结算重算。
- 可逆：撤销/反向事实。
- 反馈：流水新增。
- 边界：0 值可存不显；负值拒绝。

## OP-14 手动记产出（目标态）

- 入口：产出流水入口（`ledger_entries` 现路径）。
- 前置：无。
- 输入：数值、kind（学校 KPI / 知识资产）、备注、可选引用句柄。
- 后续：产出轴 +1，与投入分开展示。
- 可逆：撤销。
- 反馈：产出流水新增。
- 边界：不做知识资产打分；只存句柄。

## OP-15 周结算

- 入口：统计/账本页（B4 前可无 UI）。
- 前置：有事实数据。
- 输入：周起止（默认本地周一）。
- 后续：聚合投入/产出/债务趋势与波动；温和呈现。
- 可逆：只读。
- 反馈：图表/数字。
- 边界：无数据空态友好；不硬对标、不告警。

## OP-16 逾期债务展示

- 入口：摘要/逾期栏。
- 前置：有逾期任务。
- 输入：无。
- 后续：项数 + 天数 + 程度；学校硬考核加强提示但不施压。
- 可逆：只读。
- 反馈：温和一行。
- 边界：无 due 的 My Day 任务不计债务。
