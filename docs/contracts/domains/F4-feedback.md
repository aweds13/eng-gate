# SR-F4 反馈 / 习惯 / 自检 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-17 保存每日反馈

- 入口：反馈页「保存」。
- 前置：无。
- 输入：plan_note、executed、gap_note；focus_minutes 不由前端决定。
- 后续：写入/更新当日 feedback_logs；自动累加当日专注分钟；刷新自检数据。
- 可逆：再次保存覆盖；可清空备注。
- 反馈：保存 toast + 数值更新。
- 边界：空内容允许；日期非法拒绝；并发 LWW。

## OP-18 习惯打卡 / 取消

- 入口：习惯卡片。
- 前置：习惯存在。
- 输入：无（可选日期）。
- 后续：toggle habit_logs；更新 streak 与热力图。
- 可逆：再次点击取消。
- 反馈：打卡状态即时变化。
- 边界：重复点击幂等；未来日期拒绝/警告；习惯不存在报错。

## OP-19 查看习惯热力图

- 入口：习惯页。
- 前置：无。
- 输入：无。
- 后续：只读查询。
- 可逆：只读。
- 反馈：日历热力图。
- 边界：无习惯空态友好。
- 实现（第 7 步）：`GET /api/habits` 返回**全部习惯**（id/name/streak/近 90 天打卡日期），
  前端逐习惯渲染「53 周 × 7 天」日历热力图（列=周、行=周一→周日，未来格子留白）；
  此前只有按 id 查单个、前端靠 `sessionStorage` 存 id，刷新即丢——列表接口补上后该问题消失。

## OP-20 自检

- 入口：自检页（B4 前可无 UI，API 已有）。
- 前置：无。
- 输入：无（默认本周）。
- 后续：聚合投入/产出/债务/习惯，温和趋势。
- 可逆：只读。
- 反馈：轻量报告，不告警。
- 边界：无数据 0 值；不硬对标。

## FLOW-4 扩展

- 专注结束 → 自动累加 focus_minutes（不靠前端传参）。
- 任务完成/未完成 → 反映在 executed 侧（B2 联动）。
- 用户补录计划/差距 → 保存。
