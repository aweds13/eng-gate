# SR-F8 备忘录与知识资产 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-35 新建备忘录

- 入口：记录页输入区。
- 前置：无。
- 输入：text 必填；可选 ref_handle。
- 后续：落库 → 列表刷新。
- 可逆：可删除（确认）。
- 反馈：列表出现。
- 边界：空内容拒绝；无效句柄只提示。

## OP-36 顺手建任务

- 入口：备忘录卡片「建任务」。
- 前置：备忘录存在。
- 输入：标题（默认取摘要）、到期日、是否进 My Day。
- 后续：创建任务 → 关联 task_id → 刷新。
- 可逆：可取消关联/删除任务。
- 反馈：任务出现并带来源。
- 边界：任务创建失败保留备忘录；重复建任务去重。

## OP-37 关联引用句柄

- 入口：备忘录/任务详情。
- 前置：无。
- 输入：Vault 相对路径 / KB-ID。
- 后续：只存句柄；读写交给外部项目。
- 可逆：可清除。
- 反馈：句柄显示。
- 边界：不直接读写外部文件。

## OP-38 产出评价器接口（第一版手动）

- 入口：产出流水/备忘录产出。
- 前置：无。
- 输入：value、kind、note、ref_handle。
- 后续：产出轴 +1，分开展示。
- 可逆：可撤销。
- 反馈：流水新增。
- 边界：不做打分器；合同待对齐。
