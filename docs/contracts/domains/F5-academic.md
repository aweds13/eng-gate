# SR-F5 学业追踪 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-21 建课程

- 入口：学业页「新建课程」。
- 前置：无。
- 输入：name 必填；credits / teacher / exam_mode 可选。
- 后续：落库 → 列表与看板刷新。
- 可逆：可编辑/删除（删除需确认）。
- 反馈：课程卡片出现。
- 边界：空名/负学分拒绝；重名提示。

## OP-22 录考核项

- 入口：课程详情「添加考核项」（当前在学业页表单：选课程 + 名称 + 截止日 + 权重）。
- 前置：课程存在。
- 输入：name、due_date、weight、note。
- 后续：落库 → 提醒与看板更新。
- 可逆：可编辑/删除。
- 反馈：考核项列表更新。
- 边界：权重非法/负数拒绝；due 过去则标逾期。
- 实现（第 10 步）：`POST /api/assessments`、`DELETE /api/assessments/{id}`（幂等）；
  前端可添加并删除考核项。
- **要求备注 + 要求链接（T-B4，2026-09-18）**：`note`（要求备注，建考核项时可填）+
  `attach`（要求网页/本地路径）——用 `POST/DELETE /api/assessments/{id}/attachments[/{index}]` 维护，
  打开走同一套规则（`POST /api/attach/open`，见 `F1-tasks.md` OP-46）；
  学业页「考核项」区把两者都摆在考核项旁边，临期卡片上也带已挂的链接。

## OP-25 课程提醒

- 入口：系统提醒（临期/逾期）；当前落在**学业页「临期与逾期（14 天内）」区**。
- 前置：有考核项/任务。
- 输入：无。
- 后续：提前提醒并建议进 My Day，不强制。
- 可逆：可关闭提醒。
- 反馈：温和提示，硬考核更强。
- 实现（第 10 步）：`GET /api/assessments/upcoming?days=14` ——
  **只取还没录成绩**的考核项（录了分就不再提醒）；`days_until` 负=已逾期 / 0=今天 / None=无截止日；
  排序「逾期优先 → 无截止日最后」；窗口外（`days_until > days`）不打扰；`days` 限 0~365（越界 400）。
  文案只说事实（「还有 N 天」/「已逾期 N 天」），不施压、不强制。

## OP-23 录成绩 / GPA

- 入口：学业页「录成绩」。
- 前置：可关联课程。
- 输入：score、credits、scale。
- 后续：GPA 重算并展示；scale 可切换。
- 可逆：可修改/删除成绩。
- 反馈：GPA/学分即时更新。
- 边界：分数越界拒绝；非法 scale 回退 4.0；无成绩空态。
- 实现（第 10 步）：`GET /api/grades`（明细，供可视化）、`DELETE /api/grades/{id}`（幂等，GPA 随之重算）；
  前端成绩明细带删除按钮（二次确认）。
- **制式切换与加权平均（第 11 步，用户要求）**：
  - **页面内切换制式**：学业页有「4.0 制 / 5.0 制」按钮，切换即按该制式重算显示（记住所选制式）；
    写死默认值仍由 `config.toml` 的 `[academic] gpa_scale` 决定 —— 前端不偷偷改本地配置文件。
  - **加权平均成绩** = `Σ(单科学分 × 单科成绩) / Σ单科学分`（百分制原始分），
    与 GPA 并存、同屏显示、互不替代；学分为 0/负 的记录不参与。
  - `GET /api/gpa?scale=` 一次返回 `{gpa, credits, scale, weighted_average, weighted_credits}`。

## OP-24 学校任务合流

- 入口：任务详情 →「编辑」→「类型」（普通/作业/考试/论文/小测）+「所属课程」（下拉）；
  学业页课程卡上**反向列出**已挂在该课上的未完成任务，点「打开」直接进任务详情（T-C12）。
- 前置：课程存在（`GET /api/courses` 有货）；**类型不是「普通」** ——「普通」= 与课程无关，此时课程下拉禁用。
- 输入：`task_type` + `course_id`（`POST /api/tasks` / `PATCH /api/tasks/{id}`）。
- 后续：进 My Day/列表，卡片与详情带「课程 · 类型」标识；**改类型/课程不发事实、不动账本**
  （它是任务属性，不是"发生了什么"）；Repeat 继承类型与课程。
- 可逆：可改回「普通」（同时清空课程）或换课程；清空 = 存 NULL。
- 反馈：卡片上一枚徽标（`高数 · 作业`）；课程页可见"这门课挂了哪些任务"。
- 边界：
  - 挂不存在的课程 → 400 并说明（不写进库）；「普通」+ 课程 → 400 并说明（**不偷偷清空**）；
  - 课程删除**不级联**：任务照旧活着，只显示「课程已删」；重复任务回落"不挂课程"继续生成；
  - 与 `course_assessments` 的考核项**不强制互链**（考核项回答"有哪些考核/占比/成绩"，任务回答"我要做什么"）；
  - 硬约束逾期不可重组清零：沿用 R3 的强弱提醒分级（学校硬考核强提醒 = T-C8）。
- **现状（T-C12，2026-09-19）**：已实现（`tasks.task_type` / `tasks.course_id`，schema v11；
  测试 `../../tests/test_task_course_line.py`）。
