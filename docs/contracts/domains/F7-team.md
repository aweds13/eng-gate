# SR-F7 团队 / AI 协作 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-31 分配任务

- 入口：任务详情「分配」。
- 前置：任务存在；管理者视角。
- 输入：执行者、角色、备注。
- 后续：创建/更新 assignment；任务标「我分配」；不计个人投入。
- 可逆：可取消分配/改派。
- 反馈：任务卡片显示负责人。
- 边界：重复分配去重；分配给自己提示；任务不存在拒绝。

## OP-32 回报进展

- 入口：执行者卡片 / AI 接口。
- 前置：存在 assignment。
- 输入：状态（assigned / in_progress / done / blocked）+ 备注。
- 后续：更新 assignment；管理者视图刷新；协调记录。
- 可逆：可修正状态（留痕）。
- 反馈：状态变化即时可见。
- 边界：非法状态拒绝；并发 LWW。

## OP-33 视角切换

- 入口：顶部视角切换。
- 前置：无。
- 输入：管理者 / 执行者。
- 后续：列表与筛选切换。
- 可逆：随时切换。
- 反馈：视图即时变化。
- 边界：无分配时空态友好。

## OP-34 AI 只读 + 新增接口

- 入口：本地 API（供 Hermes）。
- 前置：API 开启 + 本机访问。
- 输入：读取查询；新增任务/记录。
- 后续：只读返回；新增落库。
- 可逆：新增可删除（由用户/后续 AI 写删能力实现）。
- 反馈：结构化响应。
- 边界：改/删返回拒绝；不泄露敏感；不绕过去重与 LWW。
