# SR-F7 团队 / AI 协作 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-31 分配任务

- 入口：任务详情「分配」（当前：任务卡片「分配」按钮 → 填执行者）。
- 前置：任务存在；管理者视角。
- 输入：执行者、角色、备注。
- 后续：创建/更新 assignment；任务标「我分配」；不计个人投入。
- 可逆：可取消分配/改派。
- 反馈：任务卡片显示负责人。
- 边界：重复分配去重；分配给自己提示；任务不存在拒绝。
- 实现（第 10 步）：`POST /api/team/assign` —— 校验**任务存在**（404）与**执行者非空**（400）；
  分配后 `TaskOut.assignments` 直接带回，**任务卡片可见「谁负责 / 进展到哪」**（此前分配出去就沉底）。

## OP-32 回报进展

- 入口：执行者卡片 / AI 接口（当前：任务卡片上的「开始 / 完成 / 恢复」按钮）。
- 前置：存在 assignment。
- 输入：状态（assigned / in_progress / done / blocked）+ 备注。
- 后续：更新 assignment；管理者视图刷新；协调记录。
- 可逆：可修正状态（留痕）。
- 反馈：状态变化即时可见。
- 边界：非法状态拒绝；并发 LWW。
- 实现（第 10 步）：`PATCH /api/team/assign/{id}`（非法状态 400）；前端按钮按当前状态给「下一步」动作
  （已分配→开始→完成；受阻→恢复）。

## OP-33 视角切换

- 入口：顶部视角切换。
- 前置：无。
- 输入：管理者 / 执行者。
- 后续：列表与筛选切换。
- 可逆：随时切换。
- 反馈：视图即时变化。
- 边界：无分配时空态友好。
- **现状（第 10 步）**：未实现独立视角页 —— 分配信息直接挂在任务卡片上（对个人使用更省事）；需要时再补。

## OP-34 AI 只读 + 新增接口

- 入口：本地 API（供 Hermes 等本机程序）——`/api/ai/*`；**开关在设置页「AI 接口」**（默认关）。
- 前置：① 本机来源（跨站来源一律 403）② 设置页把开关打开（**默认关**，关着时整组 403 带原话）。
- 输入：只读查询（任务列表 / 单个任务与步骤树）；新增（建任务；给 `parent_id` = **加一个步骤**）；
  勾完成（**只能勾 AI 自己建的**）。
- 后续：只读直接返回；新增落库并标 `created_by=ai`；勾完成走**与人完全相同**的领域路径
  （账本、联动、重复生成一致），事实的 `source` 记 `ai`（可审计、可撤销 —— 你在界面上撤销即可）。
- 可逆：新增的任务/步骤你在界面上删/取消即可（AI 自己没有删接口）；勾完成可撤销（OP-5）。
- 反馈：结构化 JSON（含 `boundary` 自述；`GET /api/ai/ping` 只报边界与动作表，不读你的数据）。
- 边界：**改/删返回 403 带原话**（明确拒绝，不静默改）；**碰你建的 → 400 带原话**（不静默忽略）；
  多传的字段 400（不静默忽略）；不绕过去重与三层嵌套上限；不泄露敏感（读的是任务，不含日志/配置）。
- **实现（T-G6，2026-09-22）**：口径见 `复盘/口径定案-待定清单.md` §2 的**乙案**
  （判据从"改不改"换成"**动的是不是你亲手写的东西**"）。落地：
  - schema **v16** `tasks.created_by`（`me` / `ai`，老行一律 `me`，**不猜**）；归属**不给人手改**
    （不在 PATCH 白名单里，`test_ownership_field_is_not_user_writable` 钉住）；
  - 规则与措辞**一处**在 `src/timeflow/core/ai.py`（开关 / `require_own` / 自述 / 示例命令），
    `api/app.py` 只做 HTTP 落地；
  - **联动导致的完成算系统行为**：AI 勾掉最后一个步骤会把父任务带完成（父任务是你建的也一样），
    因为那条规则跟谁点的无关；事实如实记 `source=ai`，所以查得出来；
  - 测试 `../../tests/test_ai_line.py`（23 条）+ 真机自检 10 条（`tools/web_live_check.py`）
    + DOM 探针「AI 接口 3/3」（含**反证**：你建的任务不许带「AI 建的」徽标）。
