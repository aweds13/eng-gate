# SR-F9 存储 / 同步 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-39 启动迁移

- 入口：应用启动 / connect。
- 前置：有本地库。
- 输入：目标 schema 版本。
- 后续：逐版本升级；建表/索引/回填；更新 schema_version。
- 可逆：迁移前备份；失败回滚。
- 反馈：日志 + 健康检查。
- 边界：重复启动幂等；残缺库跳过缺表；不丢旧数据。
- 回填口径（v5 / 第 3 步）：只回填**可考证**的事实（历史已完成任务 → `task.completed`，时间取 `updated_at`）；
  缺列/缺值退回 `created_at`；**不伪造时间**，不可考证者（历史复习逐次记录）不回填、记缺口（A-015）。

## OP-40 同步数据

- 入口：同步 API / 跨端触发。
- 前置：两端有数据。
- 输入：记录（id、时间戳、version、来源）。
- 后续：LWW 合并 → 同 id 去重 → 冲突写 sync_logs。
- 可逆：可从日志追溯/回滚。
- 反馈：同步结果摘要（成功/冲突数）。
- 边界：并发冲突不静默覆盖；重复同步幂等。

## OP-41 冲突处理

- 入口：同步结果 / 冲突日志。
- 前置：有冲突。
- 输入：无（自动）或用户选择保留哪版。
- 后续：记录冲突 → 提示/日志；默认较新者胜。
- 可逆：可手动改回。
- 反馈：冲突可见，不静默。
- 边界：时间戳相同按版本/来源决胜。

## OP-42 备份 / 回滚

- 入口：设置 / 命令行。
- 前置：有数据库。
- 输入：备份路径。
- 后续：生成快照 → 校验；回滚用快照恢复。
- 可逆：回滚前再备份。
- 反馈：成功/失败提示。
- 边界：备份损坏不覆盖现状；敏感不入库。

## OP-43 配置加载

- 入口：启动。
- 前置：无。
- 输入：config.example.toml + 本地 config.toml + env。
- 后续：Pydantic 校验 → 注入。
- 可逆：改配置重启。
- 反馈：非法配置明确报错。
- 边界：敏感只存本机；缺失用默认。
