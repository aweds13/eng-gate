# SR-F9 存储 / 同步 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## OP-39 启动迁移

- 入口：应用启动 / connect。
- 前置：有本地库。
- 输入：目标 schema 版本。
- 后续：逐版本升级；建表/索引/回填；更新 schema_version。
- 可逆：迁移前备份；失败回滚。
- 反馈：日志 + 健康检查。
- 边界：重复启动幂等；残缺库跳过缺表；不丢旧数据。
- 回填口径（v5 / 第 3 步）：只回填**可考证**的事实（历史已完成任务 → `task.completed`，时间取 `updated_at`）；
  缺列/缺值退回 `created_at`；**不伪造时间**，不可考证者（历史复习逐次记录）不回填、记缺口（A-015）。

## OP-40 同步数据

- 入口：同步 API / 跨端触发。
- 前置：两端有数据。
- 输入：记录（id、时间戳、version、来源）。
- 后续：LWW 合并 → 同 id 去重 → 冲突写 sync_logs。
- 可逆：可从日志追溯/回滚。
- 反馈：同步结果摘要（成功/冲突数）。
- 边界：并发冲突不静默覆盖；重复同步幂等。

## OP-41 冲突处理

- 入口：同步结果 / 冲突日志。
- 前置：有冲突。
- 输入：无（自动）或用户选择保留哪版。
- 后续：记录冲突 → 提示/日志；默认较新者胜。
- 可逆：可手动改回。
- 反馈：冲突可见，不静默。
- 边界：时间戳相同按版本/来源决胜。

## OP-42 备份 / 回滚

- 入口：**设置页「数据与同步」→ 备份与恢复**；命令行仍是 `tools/serve.py`（启动前自动备份）。
- 前置：有数据库。
- 输入：要恢复到哪个时间点（从备份列表里点一个）。
- 后续：见下面「实现」——恢复是**整库回到那一刻内容**，不是挑表回滚。
- 可逆：**恢复前会先自动再备份一次现库**，所以这一步是可逆的（界面上必须写明，否则用户不敢点）。
- 反馈：成功提示（含"恢复前的现库也留了一份：<文件名>"）；备份比程序新时**如实提示**。
- 边界：**备份名是唯一的安全边界**（不许带路径、不许 `..`、必须是本库的备份）；
  恢复是**不可逆动作** → 必须壳级二次确认（确认按钮写清"恢复到这个备份"）。
- **实现（2026-09-21 用户定：设置页列出最近几个备份、点一下恢复）**：
  - 模块 `src/timeflow/storage/backup.py`（**口径只有一份**，`tools/serve.py` 与 `app/main.py` 共用）：
    `make_backup()` / `list_backups()` / `resolve_backup()`（名字校验）/ `restore()`；
  - **什么时候自动备份**：起服务前（`tools/serve.py`）**与开窗口前**（`app/main.py`）各一次 ——
    都在"首次连接会跑 schema 迁移"之前；
  - **恢复怎么写**：SQLite **在线备份 API**（`Connection.backup`）把选中备份的**内容**写回当前库，
    **不替换文件**（Windows 上替换正被连接打开的文件会失败，且已打开连接的页缓存还是旧的）；
    为此 `storage/db.py` 提供 `raw_conn()`（拿到线程代理背后的真连接）与 `migrate()`（就地升级 schema）；
  - **老备份的 schema** 恢复后就地升到当前版本；备份比程序**新**时（降级场景）不改它，
    但返回值带 `newer_than_app=true`，界面如实提示；
  - API：`GET /api/settings/backups`（最多 20 条，最新在前）、`POST /api/settings/restore`
    （**服务端持有 + 只接受本机页面**，非法名 400）；
  - 测试：`../../../tests/test_backup_restore_line.py`；界面接线见 `../../../tests/test_web_frontend.py`。

## 桌面形态与启动入口（AC-11 / SR-NF16）

- **窗口形态**：`timeflow`（`src/timeflow/app/main.py`）或 `python tools/serve.py --window` ——
  起本地服务 + pywebview 窗口（依赖已在 `pyproject.toml` 的主依赖里，不需要另装）。
- **回退**：`import webview` 失败、或窗口起不来（例如缺 WebView2 运行时）→ **打印原因**后
  退回浏览器。**不许静默回退**（静默会让人以为自己在用桌面版）。
- 两个入口**都先备份**（同一份口径，见 OP-42）。

## OP-43 配置加载

- 入口：启动。
- 前置：无。
- 输入：config.example.toml + 本地 config.toml + env。
- 后续：Pydantic 校验 → 注入。
- 可逆：改配置重启。
- 反馈：非法配置明确报错。
- 边界：敏感只存本机；缺失用默认。
