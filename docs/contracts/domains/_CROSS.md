# 跨域交叉 · 操作与动线契约

> 六要素见 `../interactions.md`；横切行为见 `../../specification/behaviors.md`。

## C1 专注 → 任务

- 触发：专注正常结束且有 task_id。
- 传导：订阅 `focus.finished`。
- 落点：任务累计时长 + duration；任务详情可见。
- 验收：绑定任务后累计时长增加；放弃不计。
- 缺则：P0（当前断，B2 接）。

## C2 专注 → 反馈

- 触发：专注正常结束。
- 传导：订阅 `focus.finished`。
- 落点：当日 feedback_logs.focus_minutes 自动累加（不由前端传）。
- 验收：只做专注不手动填，当日反馈已有值。
- 缺则：P0（当前断，B2 接）。

## C3 专注 → 框架

- 触发：专注正常结束。
- 传导：ledger 读 facts。
- 落点：投入轴 + duration。
- 验收：摘要投入即时 +N。
- 状态：第 1 步已完成。

## C4 逾期 → 债务

- 触发：到期未完成。
- 传导：逾期任务实时查询 + 债务口径。
- 落点：债务项数 + 天数/程度。
- 验收：逾期显示分档且温和；完成清零。
- 缺则：P1（部分实现，B3 补分级展示）。

## C5 完成 → 投入

- 触发：任务完成。
- 传导：发 `task.completed` 事实。
- 落点：投入轴 +1（不估时）。
- 验收：完成后投入账增加；撤销回退。
- 缺则：P0（当前断，B2/B3 接）。

## C6 学业 → 任务

- 触发：学校课程任务建档。
- 传导：任务带课程标签 + 硬约束元数据。
- 落点：进 My Day/列表，不单独隔离。
- 验收：学校任务同构展示；硬考核逾期强提醒。
- 状态：B3 定义，后续接线。

## C7 复习 → 任务

- 触发：复习到期 / 学习任务升级。
- 传导：建议进 My Day。
- 落点：My Day 出现复习项。
- 验收：到期优先出现在 My Day；不强制。
- 状态：B3 定义。

## C8 复习 → 框架

- 触发：复习完成 / 温故知新。
- 传导：发 `review.completed` 事实（+ 可选产出事实）。
- 落点：投入轴（+ 产出轴）。
- 验收：复习完成记投入；温故知新可选产出。
- 状态：B3 定义。

## C9 习惯 → 框架

- 触发：习惯打卡。
- 传导：同一套可视化聚合。
- 落点：习惯热力图与 B 数据同一视图。
- 验收：打卡后热力图更新。
- 状态：B3 定义。

## C10 成绩 → 框架

- 触发：成绩达标录入。
- 传导：产出事实。
- 落点：产出轴 + 分值。
- 验收：成绩与知识资产分开显示。
- 状态：B3 定义。

## C11 协作 → 框架

- 触发：任务分配出去。
- 传导：归属判断。
- 落点：不计个人投入；只记协调/分配。
- 验收：团队任务不计个人投入。
- 状态：B3 定义。

## C12 备忘录 → 任务

- 触发：备忘录顺手建任务。
- 传导：创建任务 + 到期 + 关联。
- 落点：任务进 My Day；备忘录保留链接。
- 验收：转任务成功且可追溯。
- 状态：B3 定义。

## 验收

- C1–C5 纳入 B4 可执行验收；C6–C12 随域接线逐条补。
