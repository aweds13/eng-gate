# 功能规格（SR-F）— 系统「必须做到什么」

> 每条 = 一件系统必须做到的可验证事实。**必须**句式，末尾标注满足的 `N`。**约定层规则见 `conventions.md`**；本文件只收本功能决定细节。**[一版]**/[二版]见 README。

## SR-F1 · 任务管理（N6–N11、N45）

- **SR-F1.1**（N6，一版）～ My Day 排序 = 截止时间→优先级→手动拖拽；昨日未完成自动移入逾期栏（用户可手动移除）。验证：次日打开见逾期栏；拖拽保序。
- **SR-F1.2**（N7，一版）～ 提供视图：My Day / Important / Planned / Flagged / 逾期栏；显示全局总任务数；不提供 Assigned to me。
- **SR-F1.3**（N8，一版）～ 支持按项目/领域自定义分组，显示分组计数；任务可归多分组（多领域标签）。
- **SR-F1.4**（N9，一版）～ 任务支持：子步骤 / 备注 / 加入 My Day / 截止日 / 提醒 / 重复 / 附件；状态可在 未开始/进行中/完成/逾期/取消/归档 间流转。
- **SR-F1.5**（N9，一版）～ 重复任务到点按上次完成自动生成下一次；节奏可用时间热力图管理。
- **SR-F1.6**（N10，一版）～ 大任务可拆子任务；子任务全完成父任务自动完成（可手动提前勾）；任务树/折叠呈现。
- **SR-F1.7**（N11，一版）～ 记录任务当前状态 + 过去尝试（简版）；可关联笔记名/链接；提供存档视图；Obsidian 深联动后置（见 SR-F8）。
- **SR-F1.8**（N45，一版）～ 逾期任务留在 My Day 并标红；可「推到明天 / 改 ddl / 标逾期 / 取消」；学校硬考核逾期→强提醒，普通任务→温和提示。
- **SR-F1.9**（N45，一版）～ 区分三类：①有指标类（进产出账、可重规划）；②逾期不候·作业/考核（负向→强债务、不可重组清零）；③逾期不候·竞赛/活动（正向→弱债务/机会损失）。
  **一版口径调整（2026-09-19 用户决定，见 `../复盘/C批口径定案.md` §四）**：**不做任务分类字段**；
  「哪件事不能拖」用「**优先级（高）** + **学校硬考核强提醒**（SR-F1.8 的强弱提醒分级）」表达；
  分类字段与"指标可重规划"留到二版（N45 的"重规划"本身也是二版项，见 N4/SR-F2.8）。

## SR-F2 · 债务记账 B 系统（N3 + 记账规则；N4/N5 后置）

- **SR-F2.1**（N3，一版）～ 记两轴：投入轴（专注时长为主、习惯保持；完成任务按完成情况记、不硬估耗时）与产出轴（学校 KPI / 知识资产）；记「逾期=债务、专注=投入、悬赏=收益、复习逾期=轻债务」。
- **SR-F2.2**（N3，一版）～ 复习完成=投入（维持）；温故知新（新理解/笔记/灵感）可额外记一笔产出（可选）。
- **SR-F2.3**（N3，一版）～ 债务=逾期清单 + 逾期天数/程度（轻≤3d / 中≤7d / 重>7d），不折算精确时间；有时标任务按逾期天数对应，灵活并行任务只标「逾期中/天数」。
- **SR-F2.4**（N3，一版）～ 学校 KPI（成绩/综测）与个人知识资产增加独立记账、分开展示；写作业/备考=投入、成绩达标=产出、逾期=债务。
- **SR-F2.5**（N3，一版）～ 周结算；不设「目标」实体；不硬对标（不用算法推荐）；衡量单位时间产出稳定性，提供均衡度指标（波动/空档），温和呈现不告警。
- **SR-F2.6**（记账规则1–5/8，一版）～ 默认：未绑定专注也计投入（轻量）；团队分配出去不计个人投入（记协调/分配+AI回报）；债务生命周期（完成→当天清零 / 取消→按已过天数计完 / 推到→随天数累计）；跨端同 id 去重（来源标记+LWW）。
- **SR-F2.7**（N3，一版）～ 曲线+时间热力图呈现债务/储蓄；可按任务分组（领域）查看投入/产出分布；顶部轻量摘要（今日/本周债务项数+投入时长）。
- **SR-F2.8**（N4/N5，二版）～ 后置：重规划（失真时按真实能力重校指标，双向，需证据）；债务重组（承认失败→吸取教训→重组），保留教训记录；学校硬考核逾期不可重组清零。

## SR-F3 · 计时与专注（N15–N17）

- **SR-F3.1**（N15，一版）～ 支持番茄钟与普通计时；可绑定任务（时长自动计入任务+每日反馈+B投入）。
- **SR-F3.2**（N15，一版）～ 专注被打断提供「暂停/放弃/记中断」三选。
- **SR-F3.3**（N16，一版）～ 支持专注白名单（软件/网站），默认阻止非白名单；支持专注时段勿扰；桌面端/移动端分别配置。
- **SR-F3.4**（N17，一版）～ 电脑或手机任一开启专注，其他设备同步进入专注计时/勿扰。

## SR-F4 · 习惯 / 反馈 / 自检（N12–N14）

- **SR-F4.1**（N12，一版）～ 支持每日复盘录入，反映计划 vs 执行差距；专注时长（绑定任务）自动计入。
- **SR-F4.2**（N13，一版）～ 支持习惯打卡，时间热力图呈现，纳入 B 系统同一套可视化。
- **SR-F4.3**（N14，一版）～ 支持定期自检（任务臃肿/注意力基线/方向重校）；自检消费 B 账本数据（投入/产出/债务趋势）。

## SR-F5 · 学业追踪（N18–N20）

- **SR-F5.1**（N18，一版）～ 支持 GPA 与学分追踪，期末/成绩出来后手动录入；与自学时间线对照。
- **SR-F5.2**（N19，一版）～ 支持按课程建档（学分/考核方式/任课），按课追踪与提醒，防漏考/漏交。
- **SR-F5.3**（N20，一版）～ 支持学校考试/课程任务完成要求备注，并跳转到本地文件/网站看清要求。
- **SR-F5.4**（N18–N20，一版）～ 学校任务与普通任务同构（进 My Day/列表、可勾选/排序/拆步骤），多带「课程标签+硬约束元数据」；课程价值用重要性/优先级（不单独做价值标签）；录入手动建档为主。

## SR-F6 · 复习与间隔重复（N26–N29）

- **SR-F6.1**（N26，一版）～ 按 FSRS 做间隔重复调度（追踪/提醒/复习曲线）；第一版用现成 Python FSRS 库；数据按 FSRS 兼容字段设计。
- **SR-F6.2**（N26，一版）～ 可由「学习任务升级为复习任务」或手动建（特殊子栏目）。
- **SR-F6.3**（N26，一版）～ 复习到期多时按算法（重要度+最久未复习）排序，优先计入 My Day。
- **SR-F6.4**（N27，一版）～ 对「不背单词」等外部 app 只做调度中枢（提醒+记录），用户手动点「完成」；复习任务带「执行源」标签（外部 app/内置）。
- **SR-F6.5**（N29，一版）～ 预留「复习形式」字段（挖空/真题/问答卡）与扩展口子；具体工具方案后置。
- **SR-F6.6**（N29，一版）～ 用 FSRS 反馈三态（记得/模糊/忘了）作为与复习工具的联动接口。

## SR-F7 · 团队 / AI 协作（N46、N23）

- **SR-F7.1**（N46，一版）～ 支持「管理者（建/分配）」与「执行者（接收/执行）」两视角，可切换；任务可标注「分配给我/我分配」；跨端集成（桌面+手机）。
- **SR-F7.2**（N46，一版）～ 不强制执行者装本软件；只需「知道谁负责什么、进展到哪」；执行者状态第一版手动为主+AI接口。
- **SR-F7.3**（N23，一版）～ 为 AI（Hermes）提供读写任务的本地 API；第一版只读+新增（不改不删）；写/改/删留后续。
- **SR-F7.4**（N46，一版）～ 分配出去的任务不计个人投入；只记「协调/分配完成」+AI 回报单独记。

## SR-F8 · 备忘录与知识资产（N24、N28、N11）

- **SR-F8.1**（N24，一版）～ 支持碎片化任务/想法本地随手记（含移动端）；可顺手建成任务+加到期。
- **SR-F8.2**（N24/N28，一版）～ 只存引用句柄（Vault 相对路径/KB-ID）；读写 Obsidian/PDF 库交给知识资产项目，不直接碰 Vault 文件；预留句柄契约。
- **SR-F8.3**（N28，一版）～ 复习卡片/笔记可用引用句柄关联（Vault 路径/KB ID），复习完标记并推进下一间隔；深联动后置。
- **SR-F8.4**（记账规则9，一版）～ 预留「产出评价器」接口：第一版手动粗颗粒入口；合同待知识管理项目对齐再定。

## SR-F9 · 存储 / 同步 / 数据（N25、N41）

- **SR-F9.1**（N25，一版）～ 本地优先（SQLite/文件），数据不出本地；可跨端同步；可被 AI 读写；可扩展多域。
- **SR-F9.2**（N25，一版）～ 跨端同步用「修改时间戳+version」LWW（较新者胜），不静默覆盖（冲突给提示/日志）；同 id 去重（来源标记）。
- **SR-F9.3**（N41，一版）～ schema 版本化+升级迁移；重要数据（任务/学业/复习历史）可备份、可回滚。

## SR-F10 · 学校通知监控接口（N21–N22，后置）

- **SR-F10.1**（N21–N22，后置）～ 学校通知监测（网站/公众号/群聊/考试网站→抓取/集成/通知）以独立脚本/软件实现，主工具只提供合作接口（不让主软件膨胀）；接口契约后置定。
