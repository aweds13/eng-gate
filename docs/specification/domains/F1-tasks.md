# SR-F1 任务管理 · 详细规格

> 上游：N6–N11 / N45 + `../functional.md` 的 SR-F1.1~F1.9 + `../conventions.md` + `../behaviors.md`。
> 操作与动线契约见 `../../contracts/domains/F1-tasks.md`；覆盖见 `../../implementation/coverage.md`。

## 1. 实体与字段

- **Task**：id、title（必填）、due_date（可空）、status、is_myday、priority、note、repeat_rule、parent_id、created_at、updated_at、version、source。
- **status 取值**：未开始 / 进行中 / 完成 / 逾期 / 取消 / 归档 / 已删。
- **Group**：id、name（非空、唯一）、created_at。
- **task_groups**：task_id + group_id 多对多。
- 关联笔记：只存引用句柄（Vault 相对路径 / KB-ID），不存正文。

## 2. 状态机

```
未开始 → 进行中 → 完成
   │        │
   ├→ 逾期 ─┤→ 完成 / 取消 / 归档
   └→ 取消 / 归档
（任意状态）→ 已删（软删除）→ 可恢复
```

- **逾期** = 有截止日、当天已过、且未完成/未取消/未归档；按自然日计算。
- **完成可撤销**：回到原状态；子任务/父任务联动一并回退。
- **取消**：可二次确认后执行；默认不参与 My Day 与债务。
- **归档**：保留历史与尝试记录，不再出现在默认视图。
- **已删（第 5 步新增）**：软删除态；默认视图（列表 / My Day / 逾期 / 债务）隐藏，数据与事实保留，可 `restore` 撤销。
- 状态不合法转换要拒绝并提示（例：已归档任务不能直接开始专注）。

## 3. 规则

- **R1 My Day**：新建默认不勾选；昨日未完成自动进逾期栏，不自动回到今天；用户可手动移除。
- **R2 截止日**：可空；过去日期新建即标逾期；到期未完成自动进逾期栏。
- **R3 逾期分级**：轻≤3 天 / 中≤7 天 / 重>7 天；学校硬考核逾期强提醒，普通任务温和提示。
- **R4 逾期处理**：推到明天 / 改 ddl / 标逾期 / 取消；四个动作都留痕。
- **R5 Repeat**：基于上次完成时间生成下一次；未完成不生成；生成任务继承标题/分组/重复设置。
  实现（第 5 步）：完成后自动触发；**只生成一次**（以 `task.repeat.generated` 事实去重）；无截止日不生成。
- **R6 子任务**：子任务全完成父任务自动完成；允许手动提前完成父任务（需提示未完成子任务）。
- **R7 删除**：默认**软删除**（置「已删」+ 留 `task.deleted` 事实）+ 提示条短时撤销；物理清理由 `purge_task` 显式调用；
  删除后列表与摘要同步（已删不计债务、不进 My Day）。
- **R8 存档**：保留当前状态 + 过去尝试的简版记录；详情可关联外部笔记句柄。
- **R9 分组**：任务可归多分组；分组计数实时；删除分组需二次确认，任务不丢失。
- **R10 学校任务**：与普通任务同构合流进 My Day/列表，多带课程标签 + 硬约束元数据，不单独隔离。

## 4. 边界与异常

- 空标题/纯空格拒绝；超长标题截断显示但存储完整。
- 过去日期可接受但建成即逾期；未来日期正常。
- 对已完成任务再次完成：幂等，不重复记账。
- 删除不存在任务：幂等返回成功或明确提示，不抛 500（API 侧对不存在 id 返回 404）。
- 删除已删任务 / 恢复未删任务：幂等，不重复留事实。
- 对已有未完成子任务的父任务直接完成：默认拦截，提示「可仍要完成」。
- Repeat 任务重复完成：只生成一次下一次（按首次完成时间）。
- 删除不存在任务：幂等返回成功或明确提示，不抛 500。
- 分组重名拒绝；删除有任务的分组需确认且任务保留。
- 子任务成环拒绝；父任务删除时子任务按策略处理（默认一并软删除 + 撤销可恢复）。
- 跨端同 id 更新按 LWW；冲突写日志，不静默覆盖。
- 重复点击：加 My Day / 完成 / 删除均幂等。

## 5. 动线

- FLOW-1 把一件事做完（MVP 主链）：新建 → 专注 → 完成 → 摘要变化。
- FLOW-2 逾期处理：看到逾期 → 分级 → 处置 → 债务变化。
- 任务详情/编辑、分组管理、Repeat、子任务为配套动线。

## 6. 验收

- LC-1 新建任务、LC-2 加入/移出 My Day、LC-5 完成任务、LC-6 删除、LC-8 Repeat。
- LF-1 主链、LF-2 逾期处理。
- B1 细节验收：空态、错误、撤销、幂等、边界各自有测试或手动记录。
