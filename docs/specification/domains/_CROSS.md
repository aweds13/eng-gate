## 2. 规则

- 每个交叉必须有：触发 → 传导 → 落点 → 验收；链上任一环断开，整条不成立。
- 同一动作只落一次节点，禁止重复计账。
- 交叉实现优先级：MVP C1–C5 先行；C6–C12 在对应域接线时完成。
- 换心智模型只改解读层：交叉发的是事实，不直接写账。

## 3. 边界与异常

- 触发时目标主体已删除 / 取消：按各域规则处理，不产生孤儿账。
- 重复触发 / 重放：幂等，同 id 去重。
- 部分失败：先保证事实落库，再更新派生；失败可重试。
- 跨端并发：LWW + 冲突日志。
- 未绑定 / 无归属：如实记录，不硬归因。

## 4. 验收

- 主链 LF-1：C1/C2/C3/C5 必须同时成立。
- 逾期 LF-2：C4。
- 其余交叉在对应域验收中逐条补。
