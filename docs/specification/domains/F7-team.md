# SR-F7 团队 / AI 协作 · 详细规格

> 上游：N46 / N23 + `../functional.md` SR-F7.1~F7.4 + `../conventions.md` + `../behaviors.md`。
> 契约见 `../../contracts/domains/F7-team.md`；覆盖见 `../../implementation/coverage.md`。

## 1. 实体与字段

- **team_assignments**：id、task_id、assignee、role、status、note、created_at、updated_at、version。
- **视角**：管理者（建/分配）、执行者（接收/执行），可切换。
- **AI 接口**：本地 API 第一版**只读 + 新增 + 勾自己建的**（见 R4 与
  `../../contracts/domains/F7-team.md` OP-34）。
- **谁建的**（`tasks.created_by`，schema v16）：`me`（你）/ `ai`（AI 接口）——
  **这是 AI 边界的判据**（乙案：动的是不是你亲手写的东西），老行一律 `me`（不猜）。

## 2. 状态与生命周期

```
assigned → in_progress → done
              └→ blocked
```

- 状态第一版手动为主 + AI 回报；不强制执行者安装软件。
- 分配出去的任务不计个人投入；只记「协调/分配完成」+ AI 回报单独记。

## 3. 规则

- **R1 两视角**：管理者 / 执行者可切换；任务标「分配给我 / 我分配」。
- **R2 不强依赖**：执行者可不接入；只需知道谁负责什么、进展到哪。
- **R3 投入归属**：分配出去的任务不计个人投入；协调动作可记录。
- **R4 AI 边界**：第一版**只读 + 新增**；**AI 只能动它自己建的东西**（勾自己建的步骤），
  **不许碰你建的**；其余写/改/删后置。
  - **落地（T-G6，2026-09-22）**：判据是"**动的是不是你亲手写的东西**"（用户 2026-09-21 定的乙案，
    见 `../../../复盘/口径定案-待定清单.md` §2）—— 进展用**子步骤**表达（加步骤本身就是"新增"），
    AI 勾你建的（步骤或顶层任务）一律 **400 带原话**、状态不动、不发事实；
    改/删没有接口，调了 **403 带原话**（明确拒绝）。**默认关**（N16「默认收严、用户再放宽」）。
  - ⚠️ **约定层那一行仍写着"不改不删"**（`../../specification/conventions.md` 第 34 行）：
    "勾自己建的步骤"严格说是"改"。约定层由人维护，**已把差异登记给用户**，等一句话再改
    （见 `../../../复盘/AI接口边界-T-G6.md` §五）。
- **R5 跨端**：桌面 + 手机都可看；同步走 LWW。
- **R6 数据性质**：属「现实与 AI 记忆对齐」，参考知识资产句柄做法。

## 4. 边界与异常

- 分配给自己：允许但提示。
- 重复分配：同一任务同一执行者去重。
- 非法状态流转：拒绝并提示。
- AI 调用写/改/删：返回 403/405 或明确拒绝，不静默改。
- AI 碰你建的任务/步骤：返回 400 + 原话（**不静默忽略** —— 静默会让 AI 以为已经做完了），
  且不留任何事实（没做成的事不该有记录）。
- 执行者不存在：允许自由文本或创建占位人；不强制账号。
- 任务删除后分配记录：保留审计或标记失效。
- 并发更新：LWW + 冲突日志。
- 团队任务与个人账本：绝不重复计个人投入。

## 5. 动线

- 分配 → 回报 → 完成；AI 作为执行者之一通过接口接收 + 回报进展。
