# SR-F10 学校通知接口 · 详细规格（后置）

> 上游：N21–N22 + `../functional.md` SR-F10.1 + `../conventions.md`。
> 契约见 `../../contracts/domains/F10-notify.md`；状态：后置，不阻塞第一版。

## 1. 定位

- 学校通知监测（网站/公众号/群聊/考试网站 → 抓取/集成/通知）由**独立脚本/软件**实现。
- 主工具只提供**合作接口**，不让主软件膨胀。
- 接口契约后置设计；第一版不实现抓取。

## 2. 规则

- 主工具不直接抓取外部网站；不新增对用户数据的外部依赖。
- 外部监测结果可通过合作接口转成任务/提醒（只读或新增，待定）。
- 隐私：本地优先，不上传用户数据。

## 3. 边界与异常

- 外部脚本不可用：主工具不崩、不报错；只提示未接入。
- 非法/重复通知：去重、来源标记。
- 接口契约未定：字段保持扩展位，不写死。
