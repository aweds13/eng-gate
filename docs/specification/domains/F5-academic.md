# SR-F5 学业追踪 · 详细规格

> 上游：N18–N20 + `../functional.md` SR-F5.1~F5.4 + `../conventions.md` + `../behaviors.md`。
> 契约见 `../../contracts/domains/F5-academic.md`；覆盖见 `../../implementation/coverage.md`。

## 1. 实体与字段

- **courses**：id、name、credits、teacher、exam_mode、created_at。
- **course_assessments**：id、course_id、name、due_date、weight、note。
- **grades**：id、course_id（可空）、score、credits、scale、created_at。
- 学校任务：与普通任务同构，额外带课程标签 + 硬约束元数据。

## 2. 状态与生命周期

- 课程：手动建档 → 可编辑/归档；删除需确认。
- 考核项：考试/作业/论文/小测；可关联截止与权重。
- 成绩：手动录入 → GPA 重算；支持 4.0 / 5.0 制切换。

## 3. 规则

- **R1 建档**：课程可录学分 / 考核方式 / 任课；学期初手动建档一次。
- **R2 考核项**：按课追踪与提醒，防漏考漏交；可跳转外部要求（本地路径 / 网站）。
- **R3 GPA**：加权计算；4.0 / 5.0 可切换；分段绩点封顶不越界。
- **R4 同构合流**：学校任务进 My Day/列表，不单独隔离；只多课程标签 + 硬约束。
- **R5 价值判断**：用重要性/优先级，不单独做「价值」标签。
- **R6 逾期分级**：学校硬考核逾期强提醒并计债务，但不可重组清零。

## 4. 边界与异常

- 无成绩：GPA 0 或空态，不报错。
- 非法 scale：回退 4.0 并提示。
- 学分 0 / 负：拒绝或警告；权重和不为 1 允许但提示。
- 课程重名：允许但提示；删除课程需确认，考核项/成绩按策略处理。
- 成绩越界（<0 / >100）：拒绝。
- 考核项截止已过：标逾期并强提醒（硬约束）。
- 并发编辑：LWW + 冲突日志。
- 课程删除后关联任务：保留任务，课程标签置空或标记。

## 5. 动线

- 学业闭环：建档 → 录考核项 → 任务合流 → 录成绩 → GPA/学分看板。
- 漏考提醒：临期提醒并建议进 My Day，不强制。

## 6. 验收

- AC-18 课程档案、AC-19 GPA 切换。
- 补充：学校任务合流、考核提醒、硬约束逾期分级。
