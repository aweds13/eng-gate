# SR-F8 备忘录与知识资产 · 详细规格

> 上游：N24 / N28 / N11 + `../functional.md` SR-F8.1~F8.4 + `../conventions.md` + `../behaviors.md`。
> 契约见 `../../contracts/domains/F8-memo.md`；覆盖见 `../../implementation/coverage.md`。

## 1. 实体与字段

- **memos**：id、text、ref_handle、task_id、created_at。
- **引用句柄**：Vault 相对路径 / KB-ID；只存句柄，不存正文、不读写外部文件。
- **产出评价器接口**：第一版手动粗颗粒，合同待知识管理项目对齐。
  第 5 步物化：手动产出同时落 `ledger_entries` 与 `output.manual` 事实（撤销发 `output.retracted`）。

## 2. 状态与生命周期

- 新建备忘录 → 可顺手建任务 + 加到期 → 可关联引用句柄。
- 备忘录删除/编辑（第一版可仅新增 + 列表）。

## 3. 规则

- **R1 本地随手记**：桌面 + 移动快速记录。
- **R2 转任务**：可顺手建成任务并加到期；任务与备忘录互相关联。
- **R3 句柄边界**：只存 Vault 路径 / KB-ID；读写交给知识资产项目。
- **R4 产出**：产出评价器接口第一版手动；不做打分器。

## 4. 边界与异常

- 空内容拒绝；超长文本可存但列表截断。
- 无效句柄：只提示，不阻断保存。
- 转任务时任务创建失败：备忘录保留，提示重试。
- 删除备忘录：需确认；关联任务不自动删除。
- 并发编辑：LWW + 冲突日志。
- 不直接读写 Obsidian / PDF 库。

## 5. 动线

- 随手记 → 转任务 → 进 My Day；知识资产引用 → 外部项目读写。
