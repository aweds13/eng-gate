# CONVENTIONS（稳定约定）— 实现任何 SR 前必读

> 本文件是**约定层**：只收长期适用、横切多处、违反即错的**简短规则**。
> 不写解释、背景、示例（那些按需各放到对应功能/文档处）。
> ⚠️ 由人维护，AI 不得自行增删。功能层细节见 `functional.md` / `nonfunctional.md`。

## 全局约束（横切，违反即错）

- 数据存储（混合）：**结构化索引为权威，Markdown 是产物**——人/AI/Obsidian 可读、可版本化、可与知识系统联动；**md 里手改的内容不读回、下次导出覆盖**（权威归属 2026-09-21 用户定，见 `../../复盘/口径定案-待定清单.md` §7）。结构化索引供软件高效计算（聚合/FSRS/结算）；数据本地、离线可用、可被 AI 读写。（N1）
- 数据分流：内容/沉淀型（任务完成记录、任务信息、备忘录、温故知新产出、任务存档、复习材料引用）→ Markdown，沉淀至知识资产、与 AI 对齐；计算/核心型（任务状态机、债务天数、专注时长、FSRS 参数、学分/GPA、统计）→ 结构化索引供软件计算。（N24/N25）
- 数据边界：沉淀型 Markdown 数据放独立共享目录（frontmatter 带 type+命名空间），与 Obsidian 笔记分目录；知识系统/Obsidian 可索引并沉淀为知识资产。（N24）
- 温和不施压：呈现/提醒默认温和、可关闭、无强制红点，不因逾期天数放大焦虑。（N3）
- 长期均匀投入：关注单位时间产出稳定性，防突击、防拖延。（N2）
- 逾期提醒分级：学校硬考核→强提醒；普通任务→温和提示。（N45）
- 学校任务与普通任务同构合流（进 My Day/列表，多带课程标签+硬约束元数据），不单独隔离。（N18–N20）

## 固定口径（语义契约，避免一词两义）

- 债务 = 逾期天数/程度（轻≤3d / 中≤7d / 重>7d），不折算精确时间。（N3）
- 投入 = 专注时长为主；储蓄 = 完成悬赏 / 复习完成（维持）。（N3）
- 产出 = 学校KPI 与 知识资产，独立记账、分开显示。（N3）
- 任务状态 = 未开始/进行中/完成/逾期/取消/归档/待定。（N9；「待定」为 2026-09-21 用户定案：闲置/挂起、不计债）
- 复习轴：复习完成=投入（维持）；温故知新（新理解/笔记/灵感）可额外计一笔产出（可选）；复习逾期=轻度债务（由 FSRS 自愈）。（N3/N26）
- 债务生命周期：完成→当天清零 / 取消→按已过天数计完即止 / 推到→随天数累计。（N3 记账规则5）
- FSRS 反馈三态（记得/模糊/忘了）= 本软件与「复习工具」的联动接口。（N29；SR-F6.6）
- 事实/解读分离：事实层只记「发生了什么」（kind + value + 时间）；解读层（ledger）按当前心智模型算成账目。换心智模型只换解读层、事实不动。计算型事实落结构化事实表（facts），沉淀型内容落 Markdown（数据分流见全局约束）。（N3/N35/N36）

## 红线（不得 / 默认 / 后置）

- 不得：设独立「目标」实体 / 用算法推荐 / 折算精确时间 / 知识资产打分器 / 直接写外部知识资产库（Obsidian 笔记、知识管理系统的 PDF/KB）——外部知识资产一律只存引用句柄。（N3/N24/N28）
- 学校硬考核逾期：计债务，但不可重组清零。（N5/N45）
- 默认：白名单「阻止非白名单」；重复到点按上次完成自动生成下次。（N16/N9）
- 后置：Obsidian 深联动、平台载体、复习形式工具、学校通知脚本、AI 写/改/删。（N4/N5/N21/N22/N23/N24）
- AI 接口（N23/N46）：第一版**只读 + 新增**（新增含「记一条事实」）；**不改不删用户的数据** —— AI 的进展以**事实**回报（`source=ai`、只追加、可撤销），状态由解读层算；写/改/删用户数据仍后置。（N23/N46）
- 课程价值用重要性/优先级，不单独做「价值」标签。（N18–N20）
- 复习调度：用现成 Python FSRS 库；数据按 FSRS 兼容字段设计（留扩展）。（N26；SR-F6.1）
- 外部 app：只做调度中枢（提醒+记录，用户手动点「完成」）；复习任务带「执行源」标签（外部/内置）。（N27；SR-F6.4）
- 可回退（N34）：删除可撤销；删分组/债务重组/清空等不可逆操作须二次确认；债务重组前存快照可恢复。
- 可维护·隔离（N35）：模块化分层、功能独立；局部错误隔离（出错不崩全局）；数据与逻辑分离；配置驱动。
- 可测试·不谎报（N37/N44）：模块单测+回归；敏感改动 shadow+一键回退（默认不改现状）；测试隔离、不谎报通过；合入前 checklist（ruff/mypy/pytest+手动+文档）。
  - **口径开关的边界（T-D11 收紧）**：只有**可重算的派生口径**（天数怎么算 / 谁排前面 / 什么算基线）能进这张表 —— 换套算法重算即可回退；**动数据的改动**（schema 迁移 / 改状态 / 删）旧口径算不回来，走**备份与恢复**，**不假装能一键回退**。
- 配置·隐私（N43）：config.example.toml 入库→本地 gitignore；Pydantic 校验+env 覆盖；敏感信息只存本机（不入 Git/PR/日志/截图）。
- 数据·备份回滚（N41）：schema 版本化+迁移；重要数据（任务/学业/复习历史）可备份、可回滚。
