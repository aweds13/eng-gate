# 行为细则（横切）— 用户逻辑的通用细节

> 本文件补足各域共用的用户逻辑细节；域内专有规则见 `domains/`。
> 每条编号 B-x；域规格与操作契约应引用；与 conventions 冲突时以 conventions 为准。

---

## B1 状态与反馈

- 每个操作必须有进行中 / 成功 / 失败 / 空态反馈；语气温和、不告警。
- 失败要说明原因并给出可重试动作；不吞异常、不使用恐吓式弹窗。
- 成功给轻量 toast 或界面变化，不强迫用户确认。

## B2 输入校验

- 必填去空格后非空；不合法就地提示、不提交。
- 日期必须合法；数值非负；长度上限合理；错误信息中文、具体。
- 不静默丢弃用户输入。

## B3 可逆与确认

- 删除 / 完成 / 取消等可逆操作优先提供短时撤销。
- 不可逆操作二次确认；破坏性操作前存快照。
- 撤销必须回退派生数据（账目 / 摘要），不能只回退显示。

## B4 时间与日期

- 一律本地时区、本地日期；日界 00:00。
- 跨午夜专注按完成日归属。
- 逾期天数 =（今天 - 截止日）自然日；轻≤3 / 中≤7 / 重>7。
- 周起点为周一；周结算按本地周。

## B5 幂等与防重复

- 重复点击 / 提交必须幂等；in-flight 禁用按钮。
- 同一操作的重复事实不重复计账；同 id 去重。
- 已存在进行中的专注时，再次开始应拒绝。

## B6 并发与同步

- LWW：修改时间戳较新者胜；冲突记录不静默覆盖。
- 同 id 去重并带来源标记；跨端异步对齐。
- 多设备同时专注按约定合并或拒绝，不产生两条并行会话。

## B7 错误隔离与恢复

- 单模块异常不崩整个 app；记录日志并给用户可操作提示。
- 数据库忙 / 锁冲突可重试；失败不得留下半截数据。

## B8 空态与首次使用

- My Day / 任务 / 复习 / 习惯等空态给简短引导，不出现恐吓式空白。
- 首次使用引导：建任务 → 开专注 → 记反馈。

## B9 主题 / 可访问性 / 低门槛

- 亮 / 暗双主题；强调色可自定义；状态色可跟随主题。
- 键盘可达、对比度合理、动效可减弱。
- 默认 My Day；重信息点进去才有。

## B10 性能与即时反馈

- 本地操作即时反馈；列表与摘要操作后刷新。
- 多年数据仍保持流畅；查询走索引。

## B11 数据一致与事实优先

- 先落事实，再更新派生 / 显示；崩溃可恢复。
- 事实不因心智模型改变而改；解读层可重算。
- 重要数据可备份 / 回滚。

## B12 隐私与配置

- 数据本地存储；敏感信息只存本机；配置模板 + 本地覆盖。
- 不新增对用户数据的外部依赖。

## B13 可观测

- 关键路径留日志 + 计数；提供健康检查 / 调试开关。
