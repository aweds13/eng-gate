# 非功能规格（SR-NF）— 质量契约

> 质量属性：体验/性能/隐私/可靠性/可维护/可扩展/可观测/配置/测试/跨端。每条「必须」+ 满足的 N。**约定层规则见 `conventions.md`**；本文件只收本类质量细节。

## SR-NF1 · 视觉美感（N30）——一版
- 界面必须：中性底色+单一强调色；支持亮/暗双主题；强调色可自定义（预设+调色盘，默认兜底）；状态色（完成/到期债务/专注/复盘差距）可自定义或跟随主题；字体/间距/圆角/阴影统一。
- **落地**（2026-09-18）：双主题与强调色已接通——`app.css` 令牌区 + `[data-theme="dark"]`，
  设置页可选「亮 / 暗 / 跟随系统」与预设强调色（本机记住；默认值来自 config.toml）；
  状态色（`--danger`/`--ok`）与间距统一仍在收尾（前端 R5）。护栏：`tests/test_web_frontend.py`。
- **判据（2026-09-23，T-G26）**：本条此前只有"中性底色 + 单一强调色 + 素雅克制统一"这种**形容词**，
  没有可判定的标准。现钉住 **workbench 风格包**（SHELEG Design Skill，工具类产品 UI 的默认包）
  作为这条线的判据：一个强调色（+ 浅底 + 它上面的字）／状态色只表状态**且不许只靠颜色**／
  层次用 1px 边框而非阴影／圆角 6·10·999／间距 4px 网格／字号成令牌／数据用等宽字体＋`tabular-nums`／
  亮暗同源／动效上限 0.12–0.18s 且**禁止滚动驱动与循环**／禁忌表（渐变·装饰性阴影·毛玻璃·emoji·
  第二个强调色·衬线显示体·没动作的徽标·有实时状态还转圈）。**组件层已答**：本项目不引 `shadcn/ui`
  （前端零依赖是既有约定，`app.css` + `emptyState()/toast()/card` 就是我们的组件层）。
  完整记录与实测见 `复盘/设计基线-workbench与去AI味-T-G26.md`（含**亮色 9 对不达 AA 的实测数字**——
  那 9 对属**缺陷**、不属审美，是这条线开工的第一批工单）。
- **可自动验的一半（2026-09-23，T-G27）**：对比度进了门禁 —— `tools/contrast_audit.py`
  从令牌区现读颜色算 **42 条「字/底」组合**（亮/暗各 21，含强调色预设与徽标合成底），
  **亮色 18 条**不达 AA 逐条登记在 `tools/contrast_baseline.toml`（分三条根因，带 why/fix）。
  判定是**棘轮**：登记的不算通过，只拦**没登记过的新欠账**与**变差**；修一条删一条，
  删空后加 `--strict` 即成为硬门。**它是本项目第一条不需要浏览器的审美门槛。**
  详见 `复盘/审美门-对比度-T-G27.md`。

## SR-NF2 · 交互低门槛（N31）——一版
- 必须：打开即 My Day 今日清单；新建一键回车/加入 My Day 一键/完成点一下；提供新手引导（建任务→开专注→记反馈）；操作可撤销；空状态友好。

## SR-NF3 · 信息可视化（N32）——一版
- 必须：对不同数据用最合适呈现——债务/储蓄曲线+热力图、习惯日历热力图、复习卡片+进度条+到期列表、计划-执行柱状对比、GPA 卡片/雷达、今日完成度进度环。

## SR-NF4 · 一屏到底、不淹没（N33）——一版
- 必须：My Day/学校/复习/计时同属一个逻辑视图（不割裂）；渐进式聚焦、按需展开；布局「左导航+中列表+右详情（可折叠）」；默认聚焦 My Day；重信息点进去才有；信息密度低、留白足。

## SR-NF5 · 反馈与可回退（N34）——一版
- 必须：完成划线动画/保存 toast；删除可撤销；删分组/债务重组/清空等不可逆操作二次确认；债务重组前存快照可恢复。

## SR-NF6 · 可维护（N35）——一版
- 必须：模块化分层、功能独立；局部错误隔离（某功能出 bug 不崩整个 app）；数据与逻辑分离；配置驱动。
- **并发正确性（2026-09-18 修）**：HTTP 服务多线程共享一个 `conn` 变量时，底层必须**每线程一个
  `sqlite3.Connection`**（`storage/db.thread_local()`），否则一个请求的 `commit()` 会打断另一个请求的事务
  —— 真机表现为「快速点击顶部导航 → 操作未完成」。回归守卫：`tests/test_concurrency.py`。
- **前端交互约定**：视图渲染必须**可取消、后点优先**（渲染序号 + AbortController）；
  取消不是错误，不得弹提示。

## SR-NF7 · 可扩展（N36）——一版
- 必须：提供插件/自定义机制（加功能/字段/复习形式/可视化/集成，不改核心）；预留扩展点+「如何加一个功能」模板。

## SR-NF8 · 可测试、可回退（N37）——一版
- 必须：模块单测+回归；敏感改动（改基线/排序）shadow+一键回退（开关默认不改变现状）。
- **落地（2026-09-21，D 批 · T-D11）**：`core/behavior.py` = 口径注册表 + 开关 + 影子对比，
  设置页「口径与回退」可切、可一键回默认位；样板口径 = T-F8 的计债口径（真跑对比，不是空架子）。
  **边界（用户选 B 案时一并定）**：**只有"可重算的派生口径"进这张表**；**动数据的改动**
  （schema 迁移 / 改状态 / 删数据）旧口径算不回来 → 走既有的**整库备份与恢复**（SR-NF12），
  **不假装能一键回退**。默认位 = **现状位**（口径引入时正在生效的那一侧）。

## SR-NF9 · 开源文档完整（N38）——一版

- DESIGN.md（know-why）/ LEARN.md（零基础定制）：**经用户决定撤回、暂不建**（当前优先保证软件闭环；决策见 `../../复盘/DESIGN-LEARN撤回与闭环验收恢复.md`）；开源文档由 README / 架构文档 / CODING_GUIDELINES 承载。

## SR-NF10 · 零基础定制友好（N39）——一版
- 必须：常见定制做成「改配置/填模板」；2–3 个由浅入深扩展示例；代码注释中文。

## SR-NF11 · Git 工作流（N40）——一版
- 必须：新功能用 Worktree 独立分支；提交按 Conventional Commits；PR 说明含变更摘要+测试命令与结果。
  - **落地（2026-09-20）**：`.github/pull_request_template.md`（合入清单，逐条对应**机器检查**：
    `Task:/Refs:/Ledger:/Gates:` trailer、`run_gates.py` 的阻断门（**项数以 `gates/last.json` 为准**）、`gates/last.json` 入库、
    台账证据与 `[exceptions]` 留痕、约定层红线、前端零依赖护栏）。Worktree 按用户 2026-09-18 的决定是**可选**。

## SR-NF12 · 数据迁移与备份（N41）——一版
- 必须：schema 版本化+升级迁移；重要数据可备份、可回滚。（落点见 SR-F9.3）
  - **落地（2026-09-20）**：`src/timeflow/storage/db.py` 的 `SCHEMA_VERSION` + 幂等迁移链、
    `tools/serve.py` 启动前**自动备份**（`.bak-<时间戳>`）。
  - **回滚入口已落地**（2026-09-21，口径见 `../../复盘/口径定案-待定清单.md` §4）：
    设置页「备份与恢复」列出最近几个备份 → 点一个 → 二次确认 → 用 SQLite 在线备份 API 写回
    （**恢复前再自动备份一次现库**，选错了能回去）。
  - **迁移的判据是"结构在不在"，不是"版本号写到几"**（2026-09-22，缺陷 T-G9）：
    老 `_upgrade` 漏了 `if current < 14 / < 15`，而它结尾就把版本号写成 15 ——
    于是 v12 的库升级后缺 `groups.parent_id`，**版本号却已经开始撒谎**（详见
    `../../复盘/迁移漏档缺陷-T-G9.md`）。现在每次连接都跑一遍 `_ensure_schema()` 做**结构补齐**
    （幂等、便宜，"从任何历史版本升上来 = 与新建库结构一致"这条不变式有测试钉着），
    补齐了记一条 `schema_healed` 日志（不静默）；`schema_version` 只用来决定**数据回填**跑没跑过。

## SR-NF13 · 可观测/日志审计（N42）——一版
- 必须：关键路径留日志+计数；提供健康检查/调试开关（坏了能定位）。
  - **落地（2026-09-20）**：`src/timeflow/logs.py` —— 日志**一行一条 JSON**（`logs/timeflow.jsonl`，
    本机产物、gitignore）；**关键路径** = 改动类请求（POST/PATCH/PUT/DELETE，记方法/路径/状态/耗时）
    + 启动事件；**调试开关** `TF_DEBUG=1` 或 `tools/serve.py --debug`（**只改日志级别，不改业务行为**）。
  - **隐私最小化**（守 SR-NF16）：**不记请求正文/备注/标题**等用户写的内容（有单测钉住）。
  - `/api/health` 报能自证的事实（`database_ok` / `schema_version` / 任务与事实条数 / 日志路径），
    库坏了如实报 `degraded` + 原因，**自己不许 500**。

## SR-NF15 · 测试闭环（N44）——一版
- 必须：单测默认同功能补；真实/外部调用拆成可 mock 单测+integration marker；覆盖率门槛；合入前 checklist（ruff/mypy/pytest+手动验证+文档）；测试隔离（不谎报通过）。

## SR-NF16 · 本地优先、隐私最小（N1）——一版
- 必须：数据本地存储、不出本地（不上云）；复杂外部监测不硬塞进主工具；不新增对用户数据的外部依赖。
  - **放宽也要显式**（2026-09-23，T-G10b）：唯一的"出本地"是可选开关 `[net] allow_lan`
    （**默认关**，且只有**同一个 WiFi** 可达、不涉及公网）；放开的代价（同 WiFi 其他设备也可能访问到、
    明文、配对码不是加密）在**界面上与起服务时都当面说**，不默认打开、不静默打开。

## SR-NF17 · 移动端(跨端)（N1）——一版
- 必须：PWA（加到主屏）+IndexedDB 本地缓存→离线能记/看/提醒；回电脑网络异步对齐（LWW 不静默覆盖，见 SR-F9.2）；响应式（底部 Tab「今日/记录/专注/设置」+单列卡片，手机出精简核心版）；首版不做公网远程实时。
  - **落地（2026-09-23，G 批 · T-G10 = 跨端场景 ①）**：**IndexedDB 离线队列**（`src/web/offline.js`）——
    断网时记下的东西入队（新建任务 / 勾完成与撤销完成 / 习惯打卡 / 备忘 / 每日反馈），
    导出成与电脑↔电脑**同一个格式**的同步包（`timeflow-sync` v1），回电脑用 SR-F9.2 那套合并导入。
    「看」= 读过的那几份清单缓存在 IndexedDB（离线能看到**上次同步的样子**，不是实时）；
    「提醒」= 只在界面上标出（与 T-B5 同口径：移动端不发系统通知，如实标注）。
    **这一版不做**：离线删除 / 离线改字段 / 从电脑回传到手机 / 离线专注计时（各自的理由见复盘 §六）。
    **诚实边界**：手机要**打开**这个应用仍需场景 ②（服务对局域网可见，默认关，未做）——
    在此之前用电脑浏览器的 Offline 模式验收路线；`sw.js` 预缓存应用壳（含离线引擎）所以断网能开页面。
    复盘：`../../复盘/手机离线记-T-G10.md`；契约 OP-49。
  - **② 已落地（2026-09-23，T-G10b：局域网访问 + 配对码）**：`[net] allow_lan`（**默认 false**，
    或 `python tools/serve.py --lan`）→ 服务绑 `0.0.0.0` + 装**配对码那道门**
    （非本机请求要带 `X-Timeflow-Pair`，否则 401 带原话；静态壳与 `/api/lan/pair` 免检）。
    ★ **配对码只在本机（回环）响应里出现** —— 局域网设备能读数据，读不到"钥匙"；
    换码也只允许本机（`PUT /api/settings/lan`）。
    **诚实边界**（界面上、起服务横幅里、`core/lan.py` 里都写着）：只在**同一个局域网**里管用
    （同一个 WiFi，**或你自己开的热点**）、不涉及公网；配对码防的是"同一网段下别人随手扫到你的地址"，
    **不是加密、也不挡同 WiFi 抓包**；真实机器上首次绑非回环地址可能弹一次防火墙允许框。
    ⚠️ **校园网 / 公共 WiFi 常开客户端隔离**（同一个 WiFi 也可能设备之间不通，属网络策略）——
    所以界面上给**热点优先**的排查顺序（电脑开移动热点 → 手机热点/USB 共享 → 用「离线记」导文件），
    并提供 `POST /api/lan/selfcheck` 本机自检（只报"能在电脑上查的那一半"，隔离**查不出来**、直说）。
    复盘：`../../复盘/局域网访问与配对码-T-G10b.md`；
    契约 OP-50。**至此跨端 ③（走文件）/ ①（手机离线记）/ ②（同一 WiFi 直连）三步全部落地。**

## SR-NF18 · 性能/轻量（N1、N2）——一版
- 必须：轻量——启动快、内存低、交互响应即时；数据量增长下（任务/习惯/复习多年积累）查询与可视化仍流畅。
  - **落地（2026-09-20）**：`tools/bench.py`（跑在临时库上，**不碰真实数据**）——测**启动**（含 schema 迁移）、
    读路径（列表/今天/摘要/周结算/热力图/今日完成明细）、写路径（建任务/完成），并用 `tracemalloc`
    报 **Python 侧峰值内存**；`--json` 机器可读、`--check` 超护栏退出码 1。
    阈值是**回归护栏，不是产品指标**（故意定得松，只抓"某条路径慢了一个数量级"）。
