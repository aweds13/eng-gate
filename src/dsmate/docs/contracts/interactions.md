# interactions.md — 单个操作的闭环（六要素）

> 判据：**每个操作都要能回答这六问**，缺一项就是「做一半」。
> 六要素 = 触发 / 前置 / 输入 / 反馈 / 失败 / 持久化。

---

## IX-1 发一条消息

| 要素 | 内容 |
|---|---|
| **触发** | 点发送 / 回车 / 点建议条（`suggestion_prompt_*` 那类） |
| **前置** | 已配置 key；已选模型；当前会话已绑定教材（未绑定则走「无书模式」，仍可聊） |
| **输入** | 文本（可含 `#p12`、可含图片附件） |
| **反馈** | ① 用户消息立刻上屏 ② 模型思考折叠条出现（开思考时） ③ 正文流式长出来 ④ 完成时显示耗时与 token |
| **失败** | 网络错/4xx/5xx：消息留在原位、标红、给「重试」；**不丢消息**（C12）；思考模式被拒（400）时提示关思考或换模型 |
| **持久化** | 消息写入 DB（含 `reasoning_content`、usage、模型 id、时间） |

**边界**：上下文超限 → 先弹三种处置，不自动裁。
**反例（不做）**：失败后把用户消息塞回输入框——那会丢失「我发过」的事实。

---

## IX-2 从一条消息分叉

| 要素 | 内容 |
|---|---|
| **触发** | 消息上的「从这里分叉」（官方 App 叫 Edit to branch） |
| **前置** | 该消息有后继；当前在某个分支内 |
| **输入** | 可选：改一下用户消息内容 |
| **反馈** | ① 输入框上方出现「分叉自 <某条消息>」的提示条 ② 新分支创建后，版本切换器显示「第 2 支 / 共 2 支」 ③ 顶部出现「回主干」入口 |
| **失败** | 父分支已删除 → 拒绝并提示「分支点已不存在」；循环引用 → 写入前拒绝 |
| **持久化** | 写 `branch(branchFromMessageId, parentBranchId)`；**分支不复制消息体** |

**边界**：分叉时不自动发送；要用户确认再发（避免误触把主干搞乱）。

---

## IX-3 输入 `#p12` 唤图

| 要素 | 内容 |
|---|---|
| **触发** | 输入框出现 `#` → 弹页码候选；或直接打全 `#p12` |
| **前置** | 当前会话已绑定教材；该书第 12 页已录入 |
| **输入** | `#p12` / `#12` / `#第12页` |
| **反馈** | ① 输入框里 `#p12` 变成一个小胶囊（点开可预览该页） ② 发送后，该页图像随消息送出 ③ 消息气泡里显示缩略图 |
| **失败** | 页码不存在 → **不发请求**，当场提示「这本书没有第 12 页，现在拍？」并给拍照入口 |
| **持久化** | 消息记录「引用了哪些页」，之后重开这条消息仍能还原图 |

**边界**：一页多图 → 一起送（保持录入顺序）。
**反例（不做）**：把 `#p12` 当纯文本发给模型让它自己理解——那等于让模型猜图。

## IX-4 点核验条

| 要素 | 内容 |
|---|---|
| **触发** | 含公式的 assistant 消息下的「核验这条推导」 |
| **前置** | 该消息含可解析的式子；SymPy 运行时可按需加载 |
| **输入** | 抽取到的式子列表（用户可取消勾选其中几条） |
| **反馈** | ① 加载中骨架 ② 逐条出结果 ③ 一致=绿、不一致=橙并展开三方视角 ④ 无法解析=灰并给「手动框选」入口 |
| **失败** | 超时 20s / 运行时加载失败 / 式子无法解析 → **如实说**「算不完 / 加载失败 / 这条解析不了」，**不许**显示为通过（C8） |
| **持久化** | 核验结果缓存在该消息下，重开不重算（可手动「重算」） |

**边界**：只验算与化简，不自动解题。

## IX-5 开联网并搜索

| 要素 | 内容 |
|---|---|
| **触发** | 输入框「联网」开关；或模型给出搜索意图时用户点确认 |
| **前置** | 已配置 key；搜索额度够（余额可见） |
| **输入** | 查询词（模型生成或用户改） |
| **反馈** | ① 「正在搜：<query>」 ② 结果条列表（标题+域名+摘要，`rerank_score`<1.5 折叠） ③ 正文里出现可点引用 ④ 结束显示「本次搜索 N 次，约 $X」 |
| **失败** | 端点不可用 / 超额 → 降级为「没搜到，原因：…」，对话继续 |
| **持久化** | 存查询词、结果快照、计次（用于花费统计） |

**边界**：「搜外网」与「搜我的资料」是两个按钮（D12）。

---

## IX-6 切换模型

| 要素 | 内容 |
|---|---|
| **触发** | 顶部模型名 → 弹出清单（来自 `list-models`） |
| **前置** | 清单已拉取（失败则允许手填） |
| **输入** | 点选一个模型 |
| **反馈** | ① 顶部立即显示新模型名 ② 若该模型不收图，附着的图片旁出现警告 ③ 设置页显示「清单最后刷新时间」 |
| **失败** | 清单拉不到 → 显示「用上次的清单」+「手动填」两个出口 |
| **持久化** | 会话级配置；新会话沿用 |

---

## IX-7 导出备份

| 要素 | 内容 |
|---|---|
| **触发** | 设置 → 导出 |
| **前置** | 有数据 |
| **输入** | 选择范围（全部 / 单本书 + 它的会话） |
| **反馈** | ① 进度条 ② 完成后给分享面板（保存到文件 / 发给自己） ③ 显示归档大小与内容清单 |
| **失败** | 空间不足 → 明确提示需要多少；中断 → 临时文件清理，不留半截归档 |
| **持久化** | 导出物含 `manifest.json`（版本号、计数、导出时间） |

**边界**：默认不含密钥（C10）。
