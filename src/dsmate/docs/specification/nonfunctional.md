# nonfunctional.md — 非功能规格（SR-NF）

> 每条都要**可测**。写不出测法的，就是没想清楚。

---

## SR-NF1 离线可用

| 项 | 判据 |
|---|---|
| 除 API 调用外的功能 | 飞行模式下：打开历史会话、看公式/代码/表格、按页码找图、看树视图，**全部可用** |
| 无 CDN 依赖 | 前端 bundle 打出后，源码里 `https://cdn.` / `unpkg` / `jsdelivr` 出现次数 = **0**（门禁脚本查） |
| 无外部字体/图标请求 | 网络面板在离线时无 pending 请求 |

## SR-NF2 性能

| 场景 | 目标 | 测法 |
|---|---|---|
| 冷启动到可输入 | < 2.0 s（中端机，含 WebView 初始化） | 打点日志，取 10 次中位数 |
| 首字到达（不含网络） | 收到第一块到渲染出字 < 100 ms | 打点 |
| 1000 条消息的会话滚动 | 无白屏，滚动掉帧 < 20% | DevTools FPS + 手测 |
| 单条 50 KB 回答（含 20 个公式）渲染 | < 300 ms | 打点 |
| 流式追加不整段重排 | 已渲染区域不闪（用 `requestAnimationFrame` 增量更新） | 录屏比对 |

> 未实测项：WebView 里 KaTeX 长会话性能（`evidence.md` §5）。**这条要在写代码前补测**，测不过就换方案。

## SR-NF3 隐私与安全

| 项 | 判据 |
|---|---|
| 数据不出本机 | 除 `baseURL` 指向的 API 外，无任何第三方域名请求（抓包验证） |
| 密钥存储 | 存 Keystore 加密区；`adb` 拉出 App 数据**看不到明文 key** |
| 导出 | 归档默认不含密钥；若含，必须用户显式勾选且归档加密 |
| 日志 | 日志里 key 一律打码为 `sk-****`；请求体默认不落盘 |

## SR-NF4 大数据与内存

| 项 | 判据 |
|---|---|
| 单本书 500 页照片 | 可正常录入与浏览，不 OOM（图按需解码，列表用缩略图） |
| 图片体积 | 入库前自动压缩到长边 ≤ 2048（vision 每图只算 1024 token，更大只是浪费） |
| 700 MB+ PDF | **第一版不导入**（D14）；若用户误选，必须给出明确拒绝语，不许卡死 |

## SR-NF5 可更新（热更新）

| 项 | 判据 |
|---|---|
| 前端 bundle 与壳分离 | `assets/web/` 下的 bundle 有独立版本号，`version.json` 可读 |
| 替换 bundle 后生效 | 放新 bundle → 重启 App → 版本号变化且功能生效，**不需要重装 APK** |
| 回滚 | 保留上一版 bundle，失败可回退 |

## SR-NF6 可观测

| 项 | 判据 |
|---|---|
| 错误面 | 每次失败有：发生在哪个端点、HTTP 码、错误码、可重试提示 |
| 本地日志 | 滚动保留最近 7 天；可从设置页导出 |
| 关键打点 | 首 token 时延、流总时长、token 用量、搜索次数（**只落本机**，不上报） |

## SR-NF7 依赖与许可证

| 项 | 判据 |
|---|---|
| 红线 | 无 AGPL-3.0 / GPL-3.0 代码进发布物（`conventions.md` C9） |
| 清单 | 依赖清单带 SPDX 标识，脚本可跑出全表 |
| 体积 | 首装 APK ≤ 40 MB（含 KaTeX 字体与 Shiki 常用语言；SymPy 走按需下载或内置分卷） |

## SR-NF8 兼容性

| 项 | 判据 |
|---|---|
| 系统版本 | Android 8.0（API 26）起；WebView 内核可独立更新 |
| 屏幕 | 360 dp 宽起可用；折叠屏/平板不崩 |
| 输入法 | 中文输入法下 `#p12` 不被打断（composition 事件不误触解析） |

## SR-NF9 成本可控

| 项 | 判据 |
|---|---|
| 搜索计次 | 每次搜索在 UI 里可见；单会话累计可见 |
| token 用量 | 每条回答显示本次花费（低/高峰价不同，按北京时间判定） |
| 上限提醒 | 单次请求预估超过设定阈值时先提示（默认关，可开） |

> 价格口径见 `intention/evidence.md` §1.1——**只用于估算展示，不参与任何逻辑**。
