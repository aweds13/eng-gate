# 逻辑审视与衔接分析（补充缺口）

> 这份文档是意图层的一次深度体检，聚焦三件事：① 继续挖掘**逻辑缺失**；② 考察**各环节衔接断点**；③ 重点回答「**资产如何在 B 系统中发挥作用**」（本软件与知识管理项目的接口点）。
> 作者注：大部分是"缺口 + 建议设计"，供拍板后回填 `needs.md`。**标 ⭐ 的是我认为最关键、必须先定的。**

## 〇 核心洞察（⭐ 最重要）：B 系统必须拆成「投入轴 / 产出轴」

**这是"资产如何在 B 中起作用"的答案。**

现在 B 系统把「专注 = 储蓄」当**投入**，但这里藏着一个深层失真：**时间投入 ≠ 产出增长**。你可能专注了 3 小时却没产出任何东西。

一个健康的"投入均衡"账目应该是有**两条轴**的：

```
【投入轴】你控制的（过程）
  专注时间 / 完成任务耗时 / 习惯保持
        ↓
【产出轴】你努力换来的（结果）
  学校 KPI（加权/综测）· 个人知识资产增加（笔记/技能/成果）
```

- **投入是过程，产出是结果，二者必须对照看。**
- 要防两种病：
  - **假努力（低效）**：投入高、产出低 —— 专注很久没成果，账本应该"预警"。
  - **突击（不均衡）**：产出靠临时爆发 —— 违背"长期平均投入"。
- 而且光看"平均值"会掩盖"忙一阵、歇一周" → 需要**均衡度指标**（每周投入的方差 / 最大空档天数）。

> **结论**：B 不是"记我在身上花了多少时间"的钟，而是"**投入能否稳定转化为产出**"的体检账。**资产（产出轴）正是让这个账有意义的另一半**——没有产出轴，投入轴只是一串时间数字。
>
> **量纲问题（已解决）**：不像之前想的那样强行统一"投入=小时、债务=小时"——现在**投入随时间（专注时长），债务按「逾期天数/程度」显示（不折算时间）**，两者**分开呈现**（配合"投入/产出按分组分布"），不强求同一量纲；「有时标任务」用时间、「灵活并行任务」不量化，见 needs.md N3。

## 一、资产如何在 B 中发挥作用（重点）

- **资产 = 产出轴**，与"学校 KPI"并列，但语义不同：
  - **学校 KPI**：外部硬指标（加权成绩 / 综测成绩），被动达成，强债务口径。
  - **知识资产增加**：内部成长（主动积累：笔记 / 技能 / 成果），**由未来「知识管理项目」量化**。
- **本软件 ↔ 知识管理项目的交接点（留扩展空间）**：
  - B 系统定义 **「资产入口」**：记录一条"资产增量"流水，如 `产出：数学笔记 #3 → +1 单元`。
  - B **不自己评价"资产值多少"**，而是调用 **「产出评价器」接口**：
    - 第一版 = 你**手动**给产出打"量 / 重要度"；
    - 知识管理项目落地后 = **自动**（按 KB 资源 ID / 笔记数 / 完成度等）。
  - 数据通过**引用句柄**关联（Vault 相对路径 / `KB-...` 资源 ID，见 N24 / N28），**B 不直接碰 Vault 文件**。
- **⚠️ 需和知识管理项目对齐**：资产的"**具体形态**"到底是数学笔记？脚本？知识库条目？还是广义技能？——接口字段要跟知识管理项目对齐，否则接不上。建议**先定"产出评价器"接口的输入/输出合同**，资产形态先做的宽一点（可容纳多种）。

## 二、各环节衔接断点（系统内部协同）

| 环节             | 断点                                                  | 建议                                                    |
| -------------- | --------------------------------------------------- | ----------------------------------------------------- |
| **任务 → B**     | 任务在 My Day，但**没有「任务 → 投入量」映射**。完成一个任务计多少储蓄？逾期计多少债务？ | 每个任务带**预估/计划投入量（时间）**，决定它的债/储额度                       |
| **专注 → B**     | 只有**绑定任务**的专注计储蓄；**未绑定**的（临时/普通计时）计不计？              | **任何专注都计"基础投入"**（进投入轴）；绑定任务则额外归因到任务                   |
| **复习 → B**     | 复习逾期=轻债务+FSRS自愈。但**复习完成计什么**？复习是"维持已有资产（抗遗忘）"，非新增   | 复习完成计**投入（维持投入）**，不计产出增量；FSRS 补上（重新复习）→ 该轻债务清零        |
| **学业 KPI → B** | 学校 KPI 是产出（成绩/综测）。但"写作业/备考"是**投入**，"提交/成绩"是**产出**   | 区分「执行投入（时间）」vs「KPI 达成（结果）」；现在把学校任务都当成债务，**正常完成的投入没计** |
| **团队/AI → B**  | 分配给别人（含 AI）的任务，**不算我的个人投入**（我不做）                    | 团队任务**单独记账归属**（算"协调/管理产出"，可选）；AI 回报进展 → 折算            |
| **习惯/自检 → B**  | 习惯打卡=行为投入，但**自检（N14）没消费 B 数据**                      | 自检应该用 B 账本（投入/产出/债务趋势）作为体检依据                          |
| **知识资产 → B**   | 资产=产出轴（见第一章）                                        | 通过「产出评价器」接口接入                                         |

## 三、新发现的逻辑缺失

1. **「目标」实体**（已评估 → **用户判定为伪需求，不做**）：目标 = 大的任务分组/项目（用 N8 自定义分组涵盖，必要时给任务打多分组/领域标签），**不设独立实体**；投入基准靠如实记账 + 趋势自判断，不硬对标；**产出量化交给知识管理系统**。
2. **债务生命周期**：逾期任务最终被"推到明天 / 取消 / 完成"后，它欠的债务怎么处理？
   - 取消 = 一笔勾销？完成 = 债务转储蓄？——需定义，否则债务会越欠越糊。
3. **均衡度指标**："长期平均投入"要有**波动度量**（周投入方差 / 最大空档天数），否则平均值掩盖"忙一阵歇一周"。
4. **跨设备记账去重**：同一次专注/任务在手机 + 桌面各记一笔 → 需**来源标记 + 去重**（呼应移动端 LWW，N25）。
5. **B 顶部轻量摘要（⭐）**：B 是贯穿核心，但 N33"渐进式聚焦"要求"点进去才有"。→ **建议在 My Day / 顶部给轻量摘要**（本周债务 +3、投入 12h、距目标 +4h），否则账本看不见、记了也白记。

## 四、建议补丁（供拍板）

- ~~新增「目标」实体~~（**已否定→不做**）：目标用任务分组/项目涵盖（N8），投入基准靠如实记账 + 趋势自判断，不硬对标；产出量化交知识管理系统。
- **B 拆投入轴 / 产出轴**：投入 = 专注时间 / 习惯；产出 = 学校 KPI / 资产增加，两轴对照看效率。
- ~~新增「投入量映射」~~（**已调整**）：任务**不硬估时间**、**产出导向**；债/储按「逾期=债务 / 专注=投入 / 悬赏=收益」直接记，不依赖预估时间。课程价值用**重要性/优先级**（不单独做价值标签）。
- **新增「产出评价器」接口**：第一版手动、知识管理项目落地自动（先定输入/输出合同）。
- **新增「均衡度/波动」指标**：周投入方差 + 最大空档。
- **新增「B 顶部摘要」**：轻量，不被 N33 隐藏。
- **明确**：未绑定专注也计投入；团队任务单独记账归属；债务生命周期；跨端去重。
