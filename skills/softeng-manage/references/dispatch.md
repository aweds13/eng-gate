# dispatch —— 派活细则（缺口回填）

> 来源：`复盘/INDEX.md` §5.2（P0/P1 缺口清单，结论为原文）。
> 这里只写「什么时候看哪里、跑哪条命令」；判据在 `tools/wb_dispatch.py` / `tools/pool/` 里。

## 派活前必读（核四样）

1. **核预声明**（缺口 PO2）：队列登记会漏（写卡不写预声明 / 台账漏一笔）：一卡一号，派活前必须核预声明在不在。
   操作：先跑 `python -X utf8 tools/pipeline_view.py --json` 看 `cards` 块里这张卡在不在；缺登记先补队列条目，不许先派后补。
   证据：`复盘/卡/卡157-写卡必须同写预声明.md`、`复盘/问题清单-组5.md`、`复盘/卡/卡188-域细化为符号级.md`
2. **核基点**（缺口 PO5）：卡树基点会过期：派活时的 base 已被主树推进 ⇒ 落地前必须比基点，算不出就拒。
   操作：落地时显式给 `python -X utf8 tools/pool/landing.py ... --changed-from <基点>`；算不出基点就停手报主控，别硬落。
   证据：`复盘/backlog扩建-T-G100.md`、`复盘/并发架构-T-G99.md`、`复盘/外包卡-012b-集成.md`
3. **核域到符号级**（缺口 PO3）：域要细化到符号级（不是文件级），收批时按卡树实际改动重算越界，不按工人自报。
   操作：写卡时域声明细化到符号（判据库在 `tools/domain_symbols.py`，排班器 `tools/pool/plan.py` 消费）；收批越界以卡树 `git diff` 实际改动重算。
   证据：`复盘/卡/卡188-域细化为符号级.md`、`复盘/域与串行-符号级细化.md`、`复盘/文档重整方案.md`
4. **核域没被占**（缺口 PO9）：攒批固定进工作流：同一波按域分批、批内并行、批间串行；临时拼的并行会撞域。
   操作：同一波先按域分批再派；派前用 `python -X utf8 tools/pipeline_view.py --json` 的 `leases` / `fences` 块确认域空闲。
   证据：`复盘/卡/卡212-攒批固定进工作流.md`、`复盘/并行与攒批模型.md`、`复盘/卡/卡184-收口增量门禁.md`

## 派活五步里的三个坑

1. **白名单两份真源合一**（缺口 PO11）：模型白名单两份真源合一（tools 的 MODEL_WHITELIST 与 infra/pool 注册表），否则一个允许一个拒。
   操作：指定模型前看 `tools/pool/model-registry.toml` 该池条目；对不上就停手对账，别各改一份。
   证据：`复盘/合并白名单-决策单.md`、`复盘/卡/卡146-合并模型白名单.md`、`复盘/问题清单-组5.md`
2. **对账只报告不改名**（缺口 PO4）：两份白名单（`tools/wb_dispatch.py` 的 MODEL_WHITELIST 与 `infra/pool` 注册表）必须对账，不一致只报告不改名。
   操作：撞「一边允许一边拒」时在回报里点名两边读数，改名对齐是主控的活。
   证据：`复盘/问题清单-组5.md`、`复盘/合并白名单-决策单.md`、`复盘/问题清单-组2.md`
3. **effort / 模型名要透传**（缺口 PO12）：CLI 的 effort / 模型名要透传进工人，否则派活时写的等级不生效、读数全是默认值。
   操作：派活显式带 `--model` / `--effort`（参数面见 `python -X utf8 tools/wb_dispatch.py --help`）；默认 dry-run，先核切片里这两个值再 `--execute`。
   证据：`复盘/卡/卡167-派活器effort透传.md`、`复盘/反空转三道-T-G88.md`、`复盘/问题清单-组4.md`

## 派活器的两条环境铁律

1. **不许依赖 cwd**（缺口 PO10）：派活器不许依赖 cwd：main_tree_root 从脚本位置反推，否则换个目录起就派到别处。
   操作：工人落点必须显式给 `--cwd <卡树>`；切片第一行写死「cd 进卡树再干活」。
   证据：`复盘/卡/卡114-main_tree_root不许依赖cwd.md`、`复盘/文档重整方案.md`、`复盘/卡/卡117-registry相对路径与MCP机器块.md`
2. **不靠人轮询**（缺口 PO1）：派活不许靠人轮询：队列 + 定时巡检（每日一批）让该派的自己派，人只做判断。
   操作：每日一批看 `python -X utf8 tools/wb_daily.py` 的「待派」分区；盯在飞卡用 `python -X utf8 tools/wb_watch.py --cards <卡号>`（只读轮询 + 心跳 + 硬超时），别手刷日志。
   证据：`复盘/卡/卡215-派活不该靠人轮询.md`、`复盘/并行波复盘-20260927.md`、`复盘/看门狗护栏补强-T-G96.md`

## 派活后必须挂看守

- **`--detach` 没有回推通道**：`tools/wb_dispatch.py --detach` 派完就退，工人收工不会自动通知主控。派活器自己打印的提示原文是「--detach 派活没有回推通道（完工不会自动通知主控）—— 请轮询」。
- **挂看守命令**：`python -X utf8 tools/wb_watch.py --cards <卡号>`（阻塞到收工，输出结论）。它把那句「请轮询」变成默认动作——挂一次，收工自动出结论。
- **派活和挂看守是同一步，不是两步**：派活命令起完，紧接着在另一个终端起 `tools/wb_watch.py`；别等「想起来再看」，否则活租约白挂着、工人早收工了也没人收。
- **实例**：A289 昨天 19:24 就收工了，今天巡检才发现——中间那几个小时是「白挂的活租约 + 没人收」。`tools/wb_watch.py` 头部就记着这条。

## 额度与收口

1. **额度按钟表算**（缺口 QU1）：额度按钟表算（记录时刻 vs 现在），不按「上次探测 + 固定间隔」；否则会判成「还在限流」并空转等待。
   操作：看额度用 `python -X utf8 tools/pool_quota.py status`；别自己估间隔。
   证据：`复盘/卡/卡201-额度按钟表算.md`、`复盘/交接.d/T-G305.md`
2. **429 要四态判**（缺口 QU2）：429/限流要四态判（限流中 / 已过期需重探 / 余额耗尽 / 未记录），不许一个「限流中」盖住全部。
   操作：429 后先 `python -X utf8 tools/pool_quota.py status` 分清是哪一态，再决定重派 / 换号 / 停手；回报里写清是哪一态。
   证据：`复盘/问题清单-组5.md`、`复盘/卡/卡029-派活器三合一.md`、`复盘/派活器三合一-T-G114.md`
3. **收口按增量门禁跑**（缺口 PO7）：收口按增量门禁跑（只跑受影响的输入面），跳过的必须记账，否则等于没跑。
   操作：收口给 `python -X utf8 tools/pool/landing.py ... --affected <路径>`；跳过的门会进 trailer 的「非全量」字样，回报照实写，别当全量读数。
   证据：`复盘/卡/卡184-收口增量门禁.md`、`复盘/收口-增量门禁.md`、`复盘/框架-并行改同一件.md`
