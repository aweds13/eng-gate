# 写 / 改 / 补文档：四个问题答完再落笔

> 给 `softeng-manage` 用的按需参考。这一页只讲**怎么用才不出错**：
> 什么算死指针、什么算漂移、门怎么退码 —— 判据真源在 `scripts/` 与 `skills/nails/`，本页不抄。
> 换一个仓用这套技能，只换 [本仓绑定](repo-bindings.md)，本页不动。

## 一句话

写文档出错几乎都不是文笔问题，而是**没先回答这四个问题**就开始敲字。
按顺序答完再写第一行，比「改一处 → 跑一遍 → 再改一处」省一个数量级。

## 1. 定层：这份属于哪一层？

四套分层在本仓并存，**选一套并说清是哪一套**，别混着用：

- 内容分层（意图 / 规格 / 契约 / 实现 / 品味）：[文档五层](doc-layers.md)
- 读者分层（新窗口先读哪份）：`docs/文档系统导航.md`
- 技能内部三层（元数据 / 正文 / references）：`docs/reference/agent-skills-spec.md`
- 技能职责分层（索引 / 操作 / 判据）：[技能三层](skills-layers.md)

答不出属于哪一层，多半是**两层混在一页**：拆开，一层只留一处。

## 2. 改还是加注：读者会拿它当「现在的事实」吗？

- **会**（reference / how-to）⇒ **就地改成当前真值**。旧值、为什么改、谁改的，
  留在卡规格 + 变更记录 + 台账证据里，**不进正文**。
- **不会**（explanation / 历史复盘）⇒ **保留原文 + 顶部加注**「已被哪张卡推翻」，
  加注要带日期与推翻它的卡号 / 台账号。

一句话：**删掉原文等于毁证据，留着旧值等于放假话** —— 二选一，别两样都干。

## 3. 引用怎么给

- **反引号里的路径必须此刻就存在**。计划中 / 本卡才新建的，去掉反引号，或同句里写明「（计划建）」。
- **会漂的数不进正文**：门数、篇数、行数这类计数一律写「带日期的读数 + 算它的命令」。
- **一条事实只留一处投影**。同一串数字 / 路径在别处还出现，就一次把全部投影列出来一起改。
- 跨层关联走**索引**，不走正文（一层只引用上一层，不反向引用）。
- 机器生成的文件不手改：改生成器，再重跑生成器。

## 4. 写完跑哪句

改的是普通文档：

```bash
python -X utf8 scripts/check_docs.py --mode report
python -X utf8 scripts/check_layers.py
```

改过 `skills/` 再加两句：

```bash
python -X utf8 tools/check_skills_claims.py --check --mode report
python -X utf8 skills/nails/check_skills.py
```

退出码与「判不出」的口径：**各脚本文件头的注释就是真源**，别在这里记数字。
只记一条：**「判不出」不是绿**，回报里要如实写出来。

只想看几份文档的读数：给 `scripts/check_docs.py` 传 `--file`（可重复）。
它只收窄逐份文档的那两条腿，漂移那条仍全量；输出会写明「只看几份（全仓几份）」——
**别把收窄后的读数当全仓结论**。
