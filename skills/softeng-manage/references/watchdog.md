# watchdog —— 看门狗与锁租约（缺口回填）

> 来源：`复盘/INDEX.md` §5.2（结论为原文）。判据在 `tools/wb_watch.py` / `tools/pool/locks.py` / `tools/pool/lease.py`，这里只写操作顺序。

## 判活：看「工人还在不在动」

1. （缺口 WD1）看门狗判活要看「工人还在不在动」（每次工具调用刷心跳 + 滑动窗口），固定超时会把正在跑长命令的工人误杀。
   操作：盯工人用 `python -X utf8 tools/wb_watch.py --cards <卡号>`（心跳 + 滑动窗口）；判活看 `gates/diag/wb-<卡>.jsonl` 的事件间隔，不看墙钟总时长。
   证据：`复盘/看门狗护栏补强-T-G96.md`、`复盘/看门狗误杀-T-G94.md`、`复盘/看门狗独立化-T-G112.md`
2. （缺口 WD2）看门狗误杀的真根因是「空转判死 / 阈值衰减 / 只看 stdout 不看进程」，不是「工人太慢」；修法是判据改成看进程树。
   操作：判「卡死」前先看进程树还在不在动（面板 `python -X utf8 tools/wb_dash.py` 的「在跑什么与卡死阈值」一栏）；stdout 沉默不等于死。
   证据：`复盘/看门狗护栏补强-T-G96.md`、`复盘/看门狗误杀-T-G94.md`、`复盘/卡/卡024-看门狗独立化.md`
3. （缺口 WD3）看守要能区分「在等长命令」与「真卡死」：长命令期间不许判死，否则杀掉的正是干活的人。
   操作：派活时按卡的负载给足 `--stall-seconds` / `--timeout`（参数面见 `python -X utf8 tools/wb_dispatch.py --help`）；门禁、长测试场景单独放大阈值，别用默认值一刀切。
   证据：`复盘/面板口径对齐-T-G97.md`、`复盘/并发两卡-T-G92T-G93.md`、`复盘/索引-台账号到复盘.md`

## 锁与租约：四条退出路径同一处释放

1. （缺口 LS1）掐工人必须还租约：正常退出 / 超时 / 强杀 / 异常四条路径都落到同一处释放，否则下一张卡撞幽灵锁。
   操作：任何一条退出路径走完，都用 `python -X utf8 tools/pipeline_view.py --json` 的 `leases` 块确认租约已还；残留用 `python -X utf8 tools/pool/lease.py release --card <卡号>` 还掉（`--card` 是必填，漏了 rc=2）。
   证据：`复盘/卡/卡141-掐工人要还租约.md`、`复盘/卡/卡163-锁与租约接线.md`、`复盘/坑总账.md`
2. （缺口 LS2）强杀（taskkill / kill_tree）之后要清孤儿进程 + 清租约，只 kill 主干会留下占着门的子进程。
   操作：强杀后两步缺一不可：按 PID 树清孤儿进程；再核 `leases` 块确认租约已还。
   证据：`复盘/卡/卡141-掐工人要还租约.md`、`复盘/卡/卡163-锁与租约接线.md`、`复盘/坑总账.md`
3. （缺口 LS3）门禁锁要分把并有并发上限：不同门可并行、同一门必须串行，否则并行派活等于自己撞自己。
   操作：跑门前确认同一道门没有第二趟在跑（锁文件在 `gates/diag/`）；并行波里门禁串行排，别两趟门禁同时压。
   证据：`复盘/集成八张并行卡-T-G170.md`、`复盘/门禁锁分把与并发上限-T-G169.md`、`复盘/外包工具-需求与架构.md`
4. （缺口 LS4）锁要带 TTL + 接管留痕（租约制）：文件在不算占着，锁永留会让后续所有 claim/waive/land 一律 rc=2。
   操作：撞 rc=2 先看锁的租约时间与接管记录（`gates/diag/` 的锁文件 + `python -X utf8 tools/pool/lease.py`）；过期锁按租约制接管留痕，不许直接删锁文件。
   证据：`复盘/问题清单-组5.md`、`复盘/卡/卡128-栅栏六处判据.md`、`复盘/审计-GLM53-外包系统对抗审核.md`
