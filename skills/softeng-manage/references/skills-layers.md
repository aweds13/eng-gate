# skills-layers —— 技能三层与登记表（缺口回填）

> 来源：`复盘/INDEX.md` §5.2（结论为原文）。判据在 `skills/nails/` 与门里，这里只写「分哪三层、登记表在哪、什么时候去登记」。

（缺口 SK1）技能要三层（索引 / 操作 / 判据）并维护技能登记表；技能只放操作知识，判据留在库里。

## 三层各是什么

| 层 | 落点 | 放什么 |
|---|---|---|
| 索引 | `skills/README.md` | 技能清单（§3 登记表）：哪个技能覆盖哪个动作、走哪条真命令 |
| 操作 | 各技能的 `SKILL.md`（+ 按需 `references/`） | 只有「怎么用才不出错」：顺序、前置检查、常见错、该看哪个产物 |
| 判据 | 库与门（`scripts/` `tools/` `tests/`） | 判据本身；技能里一个字的判据都不许留 |

## 登记表怎么维护

- 技能登记表 = `skills/README.md` §3 那张清单；**新增 / 改名 / 退役技能，先登记再用**，不许先写技能后补登记。
- 自证：`python -X utf8 skills/nails/check_skills.py`（格式 + 卡 209 加严）与 `python -X utf8 skills/nails/check_commands.py`（命令名对账）。
- 自检口径：删掉整个 `skills/` 目录，框架仍要完整可用；做不到就是判据漏进了技能层。

证据：`复盘/卡/卡A292-技能登记.md`
