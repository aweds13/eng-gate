> 本仓的落地路径、现读取数、看守退出码与历史证据：见 [本仓绑定](repo-bindings.md)。

## 1. 四件套

| # | 工具 | 干什么 | 关键参数 | 产物 / 读法 |

## 2. 数据从哪来（别自己重读）

| 块 | 源 |
|---|---|
| `cards` | `docs/workbacklog.toml` |
| `gates` | `gates/last.json` |
| `verdicts` | `gates/diag/` 下的判决文件 |
| `leases` | `gates/diag/pool-registry.json` |
| `fences` | 任务栅栏的状态 |
| `worktrees` | `git worktree` + 本仓 `.wt/*` |

块 id 与源文件的那张表在 `tools/pipeline_view.py:97-125`。

缺源的正确表现：**该块 `null` + `*_note` 写原因**。把缺源洗成空数组 = 把「没读到」伪装成「没有」。

## 3. 「空」与「没读到」的区别

| 看到 | 意思 |
|---|---|
| `[]` | 读到了，真的是空的 |
| `null` + note | 没读到（文件缺 / 坏 / 路径不对） |

这一条是四件套最常被读反的地方：**租约为空 ≠ 没人干活**。先确认注册表读没读到。

## 4. 面板的边界

- 只报「在不在动」：卡号、最近活动时间、当前在跑什么、判决。
- 「可能卡死」只在**有在更新心跳**时才允许出现；没判决又没心跳的，如实显示「已停（无判决）」。
- 它**不判内容对错** —— 内容看判决文件与主控复核。
- 从某棵 worktree 里起，看不到兄弟树；要全视野就回主工作区起。

## 5. 什么时候别用这层

- 派活 / 申报 / 落地 —— 那是写操作，走 `wb_dispatch` / `wb_task` / `wb_land`。
- 跑门禁与读三值判决 —— 走 `pipe-gate`。
- 想加一个新读数入口 —— 先加块到 `pipeline_view`，别在外面开第二份。
