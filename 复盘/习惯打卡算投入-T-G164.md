# 复盘 · 习惯打卡直接算投入（卡 070 · `T-G164`）

> 底座 `b90c4e4`（集成十一张并行卡之后）。2026-09-27。派活模型 `--model deepseek-v4.1-flash`。

## 为什么有这张卡

用户 2026-09-27 原话：

> 「习惯里面习惯打卡只记次数，想要算投入去「今日手动投入」补记，**这个是废话吧**。」

实情：界面把**设计缺口写成了使用说明**。`habits` / `habit_logs` 只有「那天做没做」没有时长，
但 `ledger_entries.kind` **本来就有 `habit` 取值**（`focus / habit / task_done / kpi / asset / review`）——
「打卡算投入」设计上走得通，只是没接上。

## 改了什么

- **后端**（`src/timeflow/api/app.py` 打卡路由）：`POST /api/habits/{id}/toggle` 加可选 query 参数
  `invest_minutes`。留空（默认）= 与老行为**逐字相同**：只写 `habit_logs`；填 N（>0）且打卡为 done 时，
  走**现成的** `memo.add_invest_entry` 另写**一条** `ledger_entries(axis=invest, kind=habit)`（秒口径，
  value = 分钟×60）——与「今日手动投入」同表、同统计入口（`invest.manual` 事实）、同撤销路
  （`invest.retracted` 反向事实）。**没有新造第二套投入口径，零迁移**。
- **界面**（`src/web/index.html`）：打卡行加可选分钟输入（placeholder「投入分钟（可选）」，
  必要语义用输入框自己表达，不留解释句）；那句「习惯打卡**只记次数**；想算投入，去「今日手动投入」补记。」
  **整句删掉**。前端 `toggleHabit` 只在「打卡且分钟>0」时带 `?invest_minutes=N`；离线排队场景投入分钟
  记不上，toast 如实提示联网后在「今日手动投入」补记。
- **测试**（`tests/test_habit_memo_line.py`）：新增三条钉子（见下）。

## 口径记录（如实写）

- 卡 §2.2 点名删后半句；实测把**整句**删掉。理由：前半句「只记次数」在本卡之后**也不再为真**，
  留着就是新的假话；且界面不解释（T-G142/T-G144）不许留解释句。必要语义（可选）由 placeholder 表达。
- 取消打卡不自动撤销已写的投入流水（撤销走「今日手动投入」既有撤销路）；再打卡再填分钟会再写一条——
  每条流水独立、可撤销，与手动投入行为一致。

## 先红后绿 / 互补读数

钉子（`tests/test_habit_memo_line.py`，三条）：

1. `test_habit_toggle_blank_writes_no_ledger` —— 留空打卡：`habit_logs` +1、`ledger_entries` 零新增，
   且响应恰为 `{"done": true, "entry_id": null}`。
2. `test_habit_toggle_with_minutes_writes_one_invest` —— 填 30：`ledger_entries` 恰多一条
   `axis=invest / kind=habit / value=1800.0`（秒口径），且 `/api/ledger/invests` 流水合计 30.0 分钟。
3. `test_habit_invest_retractable` —— 走既有 `DELETE /api/ledger/invest/{id}` 撤销后合计回退 0。

（留空那条不受影响，符合预期——突变只杀投入路）；还原后三条全绿（本文件测试段 13 passed）。

## 没动什么

- `scripts/**`、其余 `tools/**`（`ui_flow_check.mjs` 无需换向：习惯页断言只有导航，没有针对那句话的断言）；
- `src/timeflow/core/**`（复用现成 `toggle_habit_log` / `add_invest_entry` / `retract_invest_entry`，零改动）；
- `src/timeflow/storage/db.py`（表结构禁改，diff 为空）；
- 设置页那两处「习惯打卡」字样（讲的是手机同步缓存，与投入口径无关）；
- `data/` 与真实库、`.wt/**`、主树外来未跟踪文件。

## 边界

- 离线（手机断连）打卡队列只含 `habit_logs` 行，投入分钟不会随队列补写——toast 已如实提示；
  联网场景不受影响。
- done 的数字以集成者跑 `sync_counts.py --check` 的实测输出为准（本卡不写死）。
