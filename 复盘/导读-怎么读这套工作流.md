# 导读：怎么读这套工作流（想学习的话，从这里开始）

> **为什么要这份**（用户 2026-10-03 16:5x）：「**假如我以后想通过你的工作流来学习点东西的话会影响吗？**」
> ⇒ 答案：**会话（对话记录）会被换窗口/重启切成两段；但"能学的东西"全在磁盘上**。
> 本文件就是**那条学习路径的入口** —— 它把「散在几十份文件里的过程」编成一条**能按顺序读的线**。

---

## 一、先分清两样东西（这决定了重启/换窗口的代价）

| | 住在哪 | 换窗口 / 重启会怎样 | 能不能学 |
|---|---|---|---|
| **会话记录**（我们的对话） | DSH 的会话库（磁盘） | ★ **旧窗口留在磁盘、能切回去读**；新窗口是**新线程**（读不到旧的） | 能读，但**长、散、不结构化** |
| ★★ **过程产物**（文书/台账/复盘/日志） | 仓库与 `gates/`（**git 管着**） | **一个字都不丢** | ✅ **这才是教材** |

★ 结论：**重启/换窗口不影响学习** —— 影响的是「还能不能一口气读完一条线」。⇒ 所以**学习要用教材，不要用会话记录**。

## 三、★ 一次收口的全过程（照这个骨架回放，任何一笔都能读懂）

```
① 写卡（复盘/卡/卡NNN-*.md）        ← 规格：为什么做 / 产出什么 / 验收 / 禁区 / 交成送申请
② 注册预声明（gates/diag/_B-*.toml） ← 域 = 这批活能碰哪些文件（★ 猜错会在收工时被域守卫拦住，见 §26）
③ 派活（wb_dispatch.py --detach）    ← 五个前置：树没被占 / 域不相交 / 不越项目 / 门禁没在跑 / 内存够
④ 工人干活（在卡树 .wt/<树> 里）      ← 只看不写主树；产物**不 commit**
⑤ 工人交成送申请（wb_task.py claim）  ← ★ 成功申请**必须带证据**（判据：证据能不能被机器复核）
⑥ 主控复核（独立复跑测试 / 看 git status / 查域）
⑦ 收口落地（wb_land.py）             ← ②文书 → ③同步 → ④门禁（**红着不提交**）→ ⑤封存 → ⑥提交 → ⑦审计 + ff 合流
⑧ 标 landed（wb_task.py landed）     ← 队列转 done
```

★ **每一步都有产物**（这就是为什么它可学）：卡的规格、预声明、worker 日志、成送申请、门禁日志、封存指纹、提交信息（`Task:/Refs:/Ledger:/Gates:`）、审计结论。

## 四、★ 读的时候盯三件事（这三件才是「这套流程想教你的」）

1. **判据 vs 人话**：哪一条是**机器能判的**？哪一条只是**一句人话**？
   ★ 本仓一直在做的是「把人话变成判据」（例：`复盘/不变量台账.toml` 的每一条都要有**判据 + 反例钉子**）。
2. **「我没看」与「我看了且没问题」**：这条判据分得清吗？
   ★ 分不清就会「**空集绿灯**」「旧判决冒充当前」「部分跑冒充全量」—— 这三种我们全咬过。
3. **「实际发生的」有没有被「声称」**：改了的文件有没有人说？跑了的门有没有记？
   ★ 反向判据（`audit_progress.py` ⑫）就是干这个的。

## 五、★ 想自己动手时的最短路径

```bash
# 1) 看一眼现在有什么活、能不能一起跑
python -X utf8 tools/wb_plan.py check           # 队列自洽：域冲突 / 依赖 / 必填
python -X utf8 tools/wb_plan.py plan --concurrency 2

# 2) 派一张卡（默认 dry-run；真跑加 --execute；★ 要跨窗口活着就加 --detach）
python -X utf8 tools/wb_dispatch.py --card <号> --spec 复盘/卡/卡<号>-*.md --cwd .wt/<树> --execute

# 3) 工人收工后：写文书（三段）→ 落地
python -X utf8 tools/wb_land.py --batch <批> --tree .wt/<树> --task T-G<号> \
       --title "<一句话>" --evidence <裸路径…> --allow <裸路径…>
```
★ **三条最容易踩的**（照 `_HOLD.md` 抄）：`--evidence` **只给裸路径**（`file:` 前缀由收口链加）；
文书 `=== changelog ===` 那节**不许放 trailer**；**要提交的文件必须同时在卡树与它的索引里**。

## 六、★ 换窗口 / 重启之前必须做的一件事

★ **把交接写到最新**（`复盘/交接-重构进度.md` 顶部 + `gates/diag/_HOLD.md`）——
**否则新窗口的我读不到今天的细节，会明显变笨**。

★ 这也是「这套工作流可学」的**前提**：**能交接，才说明过程是可复现的**；
交接写不清的地方，就是**这套流程还没做好的地方**（这正是可改进的入口）。
