# 复盘 · 派活器「额度检测」误判与无限续跑（卡 045 · T-G136）

> 卡规格：`gates/diag/卡045-额度检测误判与循环.md`。本卡只碰 `tools/wb_dispatch.py`、
> `tests/test_wb_dispatch.py` 与本复盘；没跑全量门禁（按 §0.3，轻门见 §4）。

## 1. 为什么有这张卡（真撞现场，我按 §1 复核过）

2026-09-26 19:45 主控真撞：只读复核卡 R029 第 1 轮**成功收工**（89 行 log /
`pytest 104 passed` / 报告已交付），但它的**回话正文提到过「429」**（复核清单第 5 条
就是「429 当成功」），log 里还有 `git log` 打出的提交信息（卡 029 自己的提交信息写着
「+429 三拍+」）。旧的 `quota_error()` 把 `result`（= 回话正文）一起扫、名单里有裸
`"429"` → 判「余额耗尽」→ 等 300s → **探针真调模型、通过** → 仍「同一模型接着干」
→ 带同一会话续跑 → 新回话又提 429 → 再判 → 无界循环，发现时已白跑 3 轮
（`wb-R029.jsonl` + `.r2` + `.r3`）。

我复核旧代码确认了机制：`quota_error()`（改前 658–680 行）把
`("errors", "errors_info", "result")` 三个字段 `json.dumps` 进同一个 blob，
再用 `QUOTA_STATUS_NEEDLES = ("429", "6004", "quota")` 扫整块 —— **成功回话只要
正文含「429」这个字符串就中招**；且主循环的额度分支不看 `--retry`、探针通过就
`attempts += 1; continue`，**没有任何界**。

## 2. 落了什么（对着卡 §2 逐条）

1. **候选闸门**（`tools/wb_dispatch.py:683-686`）：只有
   `subtype == "error_during_execution"` / `is_error` 为真 / 回话全空白，三种
   `result` 事件才进入额度判定；**正常成功 + 非空回话一律不算额度错**。
2. **判据只认结构化字段**（`tools/wb_dispatch.py:688-699`）：`errors` / `errors_info`
   用状态 needle（429/6004/quota）+ 完整中文短语；**回话正文只允许完整中文短语**
   （「额度已用尽」「使用量已超出频率限制」），裸 429/quota/6004 不许扫正文。
   原有行为保留：真额度错（errors 带 status 429）照抓、限流与余额耗尽照旧分开记。
3. **续跑封顶**（`tools/wb_dispatch.py:1662`）：`if attempts > args.retry:` ——
   额度续跑与中断续跑**共用 `--retry` 这一个界**；到界写判决（含每个模型撞了什么 +
   这次烧的 token）、**退出码 7**、不再自动重试。界就在这一行，无别的隐藏重试计数。
4. **探针优先**（`tools/wb_dispatch.py:1680-1685` + `round_is_normal_success`
   `tools/wb_dispatch.py:708`）：探针通过而这一轮是「正常成功 + 非空回话」→
   打 `[额度] 误判？（探针通过但判别器报额度）→ 按成功收下`，按成功收下、不再续跑。
   （闸门修好后真判别器对正常成功不会再开火，这条路是兜底；测试里用假判别器钉住它。）
5. **可观测性**（`tools/wb_dispatch.py:704`）：`quota_error()` 返回值多一个 `why`
   （命中哪个 needle、在哪个字段），检出时随 `[额度]` 那行一起打出 ——
   下次再误判，一眼看出是谁骗了它。

## 5. 没动的 / 界线

- 没动：`tools/wb_dash.py`、`tools/wb_status.py`、卡 037 的滑窗逻辑
  （`stall_threshold_seconds` 一行没碰）、`scripts/**`、`src/**`、`docs/**`、
  `gates/**`、`复盘/` 其它文件、主树那三个外来未跟踪文件。
- 界线：额度续跑的界 = `--retry`（默认 1），与中断续跑**共用**；到界 →
  判决（每个模型撞了什么 + token 读数）+ 退出码 7。全挂（白名单走完且探针都挂）
  → 原有退出码 7 路径不变。
- 边界（如实写）：`round_is_normal_success` 只看**最后一条** `result` 事件 ——
  多轮 log 逐条喂 `quota_error()` 的老行为没变（任何一条候选事件中招就报），
  这是故意保守：宁可多看一眼，不许漏真额度错。
