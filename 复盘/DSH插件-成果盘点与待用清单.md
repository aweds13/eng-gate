## 三、★ **还没用上**的（按性价比排；这些才是"其他成果"的价值）

### A 级（与我们的门禁/收口直接相关，建议马上做）
1. ★★ **成送申请的证据要"读时重算哈希"**（防篡改）：`tools/pool/task.py` —— claim 时若 `--evidence` 指向文件，登记**路径 + sha256**；收口读申请时**重算比对**，不一致 ⇒ 判 `tampered`、挡收口并点名。
   - 出处：第二批 §三.1；依据 `dsh-research-report` 的 `readContent` 三态（`ok | tampered | missing`）✓
2. ★★ **被证伪口径的**墓碑表**：新增机器可读 `docs/tombstones.toml`（每条：id + **被证伪口径的 sha256** + 原文 + 证伪出处 + `revoked` 撤销标记 ✓），并在**派活前置检查**里比对：命中且未撤销 ⇒ **拒派**并给出墓碑条目与撤销方法。
   - 出处：第二批 §三.2；**这条正对我们踩过的坑** —— 我们真出现过"把 README 描述当正文"、"228 不翻"、"口径坑"这些事 ✓ ⇒ 墓碑表就是把"**别再重报**"变成机器挡 ✓
3. ★★ **收口前的"交付重审计"**（防漂移）：claim 成功申请时**顺手记该卡域内被跟踪文件的 sha256 快照**；收口时重算比对，任一文件自成送后变更 ⇒ 该申请失效、收口被挡并点名 `drift: <path>`。
   - 出处：第二批 §三.3；依据 `provider-local.ts:671-673` 的 drift-into-blockedReasons 形状 ✓

### B 级（把"门禁/裁定"做得更可审）
4. ★ **非证据码成对列出**（gating-hub）：我们的门禁现在只报"**没通过**" ✗，不报"**查过 X、因为 Y 所以没禁**" ✓ ⇒ 给门禁/裁定输出加一栏**"为什么没挡住"**，让**沉默的通过也可查** ✓。
   - 出处：第一批 §2.1（`EVIDENCE_CODES` vs `NON_EVIDENCE_CODES` ✓）
5. ★ **解析不确定 ⇒ 整批只报告、绝不写盘**（gating-hub `:76-80`）：我们的批/落地遇到"口径不确定"时要**只报告不动手** ✓（现在部分路径会动手 ✗）。
6. ★ **动作留痕 + 每条自带一键回滚命令**（gating-hub `:186-200`）：我们的 `stack-actions.log`（卡 253 ✓）可以再进一步：**每条禁用/起停记录里带上"怎么撤销"的原话命令** ✓。
7. ★ **运行期冒烟当判据**（gating-hub `compat.js:100-107`）：启用/落地前在**独立子进程**里 `import` 一次（8 秒超时，失败/超时按**不通过** ✓）—— 我们现在是**手工**裸导入验一次 ✓ ⇒ 可钉成判据 ✓。

### C 级（形态/能力扩张，看你要不要）
8. ★ **让 agent"点着走"禅道**（`dsh-pilot` 的 CDP 驱动 + cockpit 信息架构）：禅道现在只能"看" ✓；`dsh-pilot` 那条路能让 agent **点菜单/填表单/截图当证据** ✓（且它的会话池 + "防认错浏览器"（校验 `/json/version`）值得我们抄 ✓）。
9. ★ **深链：每个界面都有自己的链接**（`dsh-url-router`）：`#/panel/<panelId>` → `selectPanel(id)` ✓ ⇒ 我们那三行/页签也能"贴一条链接就回到那个界面" ✓（纪律：**地址栏唯一写者 + 只用 `replaceState`** ✓）。
10. ★ **跨会话共享任务板 + 消息总线**（`dsh-team-rooms`）：我们的台账是文件 ✓；它的"持久房间 + 共享任务板"是另一条形态（★ 注意该仓**已 archived** ✗，只抄形状不抄依赖 ✓）。
11. ★ **只读展示不再开 HTTP 服务**（架构层的更省内存法）：我们三行开的是"真实页面" ✓（需要服务 ✓）；如果只想看数字，其实**插件面板自己就能渲染** ✓ ⇒ 可省掉 board/timeflow 两个常驻服务（~93 MB ✓）。取舍：真实页面能交互、面板渲染省内存 ✓。

## 四、我的建议（等你一句话就开卡）
- **立刻做 A 级三件**（1+2+3）—— 它们**直接补在我们最要命的地方**（证据可不能假、被推翻的口径不能再报、成送后不能偷改 ✓），而且**都在框架层**、不动面板 ✓；
- **B 级挑 4 与 7**（"为什么没挡"可查 + 冒烟当判据 ✓）—— 都是**小改大收益** ✓；
- **C 级**里 **8（让 agent 点着走禅道）** 最有新意 ✓，但它要新起一个能力面（CDP 驱动 + 会话池 ✓），建议**排在 A/B 之后** ✓。
