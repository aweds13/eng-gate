## ① 一句话

**禅道 22.6 是一款以 PHP 自研框架（ZenTaoPHP）实现的、覆盖需求-任务-缺陷-用例全链路的项目管理软件；这个便携版用 ZenPanel（Qt 控制面板）把 Apache + PHP + MariaDB + Redis + RoadRunner + XXD + GitFox 七个组件打进一个 894 MB 的目录，双击 `ZenTao.exe` 即可起服务访问，面向不想折腾 LAMP 环境的 Windows 团队。**

证据：
- `app/zentao/VERSION` → `22.6`
- `app/zentao/config/config.php:19` → `$config->version = '22.6';`
- `app/zentao/config/config.php:27` → `$config->edition = 'open';`（开源版；注释写 `open|biz|max`）

- `zbox/config.yml:6` → `title: 禅道集成运⾏环境`

### 便携化（怎么变成双击就能用）

1. **ZenTao.exe**（74 MB，Qt 应用，即 ZenPanel）— 控制面板，读 `zbox/config.yml` 管理服务
2. **nssm.exe**（`zbox/nssm/win64/`）— 把 Apache/MySQL/XXD 注册成 Windows 服务
3. **config.yml** 声明每个服务的端口、路径、启停命令、账号密码：
   - Apache `:80`（`config.yml:12`），账号 `zentao/123456`（`:23-24`）
   - MySQL `:3306`（`:28`），账号 `root/123456`（`:42-43`）
   - XXD `:11444`（`:57`）
4. **端口冲突规避**：`autoPorts: [80, 8999]`（Apache）、`[3306, 3999]`（MySQL）
5. **配置重写**：`bin/apache/conf/httpd.conf` 和 `bin/mysql/my.ini` 里硬编码了构建机路径 `C:/Users/Administrator/Desktop/ZenTaoPMSmax34zboxwin64/zbox/...`，运行时由 ZenPanel 按实际解包路径重写（推断，未实测运行）

## ⑥ 对我们的启示（最多 5 条，每条指证据）

1. **一套代码 + extension 分层做多版本变现**，比 fork 多份代码省力——证据：`extension/{biz,max,ipd,lite,xuan}/` 共用 `module/` 主体，`config.php:27` 用 `edition` 一行切换。（启示：若做多档产品，优先 extension 模式而非多仓）

2. **升级链用 `update<version>.sql` 串起来，282 个脚本跨 0.1→22.5**——证据：`db/update*.sql` 282 个。说明它把"每次发版改了哪些表"当成第一公民资产。（启示：schema 迁移脚本应版本编号、不可篡改、连续可回放）

3. **便携版靠控制面板（ZenPanel/Qt）+ nssm 把多服务变成双击可用**，config.yml 声明每个服务的端口/账号/启停命令——证据：`zbox/config.yml`、`zbox/nssm/win64/nssm.exe`。（启示：给非技术用户的交付物，需要一个"服务编排面板"层，不能只给 docker-compose）

4. **框架自研而非用 Laravel**，router/control/model/zen/tao 五层，URL 即 `module-method-params`——证据：`framework/router.class.php:1` 自述、`module/bug/control.php:12` `class bug extends control`。代价是生态隔离，收益是零依赖、全可控。（启示：当目标是"打包成单目录可移植"时，自研轻框架的依赖优势显著）

5. **同一入口支持三种运行时**（Apache+mod_php / RoadRunner / FrankenPHP），靠 `php_sapi_name()` 分支——证据：`www/index.php:97` 判断 frankenphp、`www/.rr.yaml` 配 RoadRunner。说明它把"运行时可替换"当架构红线。（启示：PHP 应用的性能升级路径，可先留 worker 入口再逐步切运行时）

## ⑦ 老实说（没查到 / 只是推断 / 目测的）

### 没查到

1. **Apache 实际版本号**：config.yml 声明 `2.4.25`，但在 `httpd.exe` 二进制里没匹配到 `2.4.x` 字符串（可能版本串被编译期去掉或格式不同）。**未实测运行 `httpd -v`**，所以 2.4.25 是声明值，未独立证实。

2. **Redis / XXD / RR / GitFox 的实际版本**：仅 config.yml 声明，未从二进制提取版本串，也未实测 `--version`。
