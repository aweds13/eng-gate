## 6. ★ 429 / 额度三拍（§2.5）：等 → 按序换 → 全挂就停

- **认出它**：`quota_error()`（:658）读 `result` 事件的 `errors` / `errors_info` / 正文，
  认 `429` / `6004` / `quota` 或「额度已用尽」「使用量已超出频率限制」；
  **限流（带「将在 <时间> 重置」）与余额耗尽（没有）分开记**（正则抓重置时间）。
  位置在判决落盘之后、`should_resume` **之前** —— 所以 429 **不可能**走 `--retry` 自动续跑。
- **先等**：`--quota-wait`（默认 300 秒）→ **探**：`quota_probe_ok()`（:683）发一条
  「只回复四个字：连接成功」的极小请求（**不拿整卡重跑当探测**）。
- **按序换**：探仍挂 → `next_whitelist_model()` 取下一个重派（**同一会话续跑**、
  换白名单内的模型）；探通过 → 同一模型接着干。
- **全挂就停**：白名单耗尽 → 判决文件**追加**「★★ 额度判决」块（每个模型的额度状态 +
  这次共烧的 token 数）、退出码 **7**、不再自动重试（`--retry` 给多大都没用）。
- **三种情形怎么验的**（全部桩级端到端、真走 `main()` 循环）：
  1. 限流：`test_quota_run_waits_probes_then_switches_to_the_next_whitelisted_model`
     —— ①429（带重置时间）→ 探挂 → 换 `glm-5.3-flash` 重派成功，重置时间原样透出；
  2. 余额耗尽：`test_quota_error_tells_rate_limit_from_exhaustion`
     —— 无重置时间 → 记「余额耗尽」；健康 log 不误报、畸形 log 不炸；
  3. 全挂：`test_quota_all_exhausted_stops_with_exit_7` —— 两个模型各一轮后**退 7**，
     判决带两个模型与「input tokens 2,000」；`--retry 5` 也拦不住（不许空撞）。
  另有探测通过不换模型的对照（`test_quota_probe_ok_continues_the_same_model`）。
