# T-G86 · 修 T-G79 的「幂等也在写库」—— 今天清单的空转不再整表重写

> **卡**：外包卡 002（`复盘/外包卡-002-修T-G79幂等写库.md`），第一张**真写代码**的外包卡。
> **发现人**：卡 001 的独立复核（`gates/diag/wb-review-T-G79.md`），主控独立复现
> （`gates/diag/probes/myday_noop_write_check.py`）。
> **一句话**：`T-G79` 的文档与提交信息写着"拖到自己前面 / 已在头尾按 ↑↓ …**也都不写库**"。
> **那句是错的** —— 那三种空转把今天清单**每一行**都写了一遍（`version + 1`），
> 还把"没拖过 = `NULL`"这个语义冻成显式 `1..N`。这一卡把它修掉。

---

## §1 事实：怎么证明它真的在写（两处独立证据）

**主控探针**（`python -X utf8 gates/diag/probes/myday_noop_write_check.py`，改之前）：

```
① 调用前：3 行 myday_rank 全是 None
② 拖到自己前面 → HTTP 200，3/3 行被改写：v1→2，rank None→1 / None→2 / None→3
③ 已在最前按 ↑ → 同样 3/3 行被改写
结论：『幂等 = 不写库』站不住（幂等动作确实在写库）
```

卡 001 的探针（`gates/diag/wb001_probe.py`，33 条 check）里也是同样三条 FAIL。
**改完之后**同一条探针跑出来：

```
被改写的行数：0 / 3
被改写的行数：0 / 3
=== 结论：『幂等 = 不写库』站得住（幂等动作一行都没写） ===
```

**为什么这是真缺陷**（不是"多写几行无所谓"）：

- 「没拖过 = `NULL`、排在后面」这个语义**被一次空转抹掉** —— 之后你已经分不清哪些是"没拖过"；
- 跨端合并按 `version` 判谁新（`syncpack`）：空转把 `version` 抬高却**不改 `updated_at`**，
  真实改动更容易**输给**这些空写（卡 001 的边界 C 指出的那类风险）。

## §2 根因（读代码确认，不是猜）

`place_myday()` / `move_myday()` 的**第一句**都是

```python
items = _myday_sequence(conn)
```

而 `_myday_sequence()` 当时会把今天清单**每一行**都 `_write_myday_rank(conn, item.id, i)`
（`version + 1`）。于是**任何**调用（包括空转）都会整表重写一遍，并把 `NULL` 变成显式 `1..N`。
那条注释自己写着理由（"序号不连续时往前挪一格会挪不动"）—— 但它解决的是一个**不存在**的问题：
`myday_rank` 只用于**相对**排序，读回来时 `_MYDAY_ORDER_BY` 本来就不要求连续。

## §3 修法（只动 `core/tasks/manager.py`）

| 改前 | 改后 |
|---|---|
| `_myday_sequence()` = 读出顺序 **+ 每行写一次号** | `_myday_sequence()` = **只读出顺序**（`return myday_tasks(conn)`） |
| `_write_myday_order(order)` = 把 `1..N` 全写一遍 | `_myday_rank_plan(items, order)` = 只算出**该写哪些号**；`_apply_myday_order()` 先比"顺序变没变"，没变**一个字节都不写** |

**`_apply_myday_order` 的两条判据**：

1. **顺序没变就返回**（`order == [it.id for it in items]`）→ 空转 0 写。这是本卡的正题。
2. 变了才写，且**只写"排过号的那一截"**。哪一截？从 `order` 的**尾巴**往前找**最长的一段**，
   要求它 ① 全是不带号的行（带号的行必须留在头里 —— 我们从不把号清掉）、
   ② 在里面**仍是老口径次序**（否则读回来就不是 `order` 了）。这段尾巴**一个都不写** ——
   这就是「**不许把没动过的 `NULL` 冻结成序号**」。头里的行重排成 `1..m`，本来就等于目标号的跳过。

★ **边界（如实写，不假装做到"只写换位的那一行"）**：一次**真拖**仍是把
**排过号的那一截**（头）整截重排成 `1..m` —— 只写"真的换位置的那一行"要把序号改成
**有间隙**的（sparse index），那是另一张卡的事。本卡消除的是**空转整表重写**与**冻 `NULL`**
（探针量到的那两件事），以及"真拖也把没排过号的尾巴一起写"。

## §7 教训（进 `复盘/视觉线地图.md` §6 的那类）

- **"原地不动"不等于"没写库"**。T-G79 把"结果看起来一样"直接写成了"什么都没发生" ——
  同 T-G67/T-G68/T-G75 那族：**状态/行为的描述字段没人复查就会漂**，而这次漂的是一句结论，
  不是字段。判据要**量**（前后两份快照逐行比），不能"看顺序没变"就下结论。
- **归一化写在读路径上最隐蔽**：`_myday_sequence()` 名字像"读"，干的却是"读 + 写整表"。
  读函数不许有副作用 —— 这条被这次踩了个正着。
