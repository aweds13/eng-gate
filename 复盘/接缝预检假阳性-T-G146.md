# 复盘 · 收掉 seam_check 的字符串/注释假阳性（T-G146，外包卡 054）

> 卡规格：`gates/diag/卡054-接缝预检假阳性.md`；底座 = 卡 048 的提交 `aa90547`。
> 只改 `tools/seam_check.py` + `tests/test_seam_check.py` + 本复盘（白名单三文件）。

## 1. 为什么有这张卡（RC 复核卡 048 找到的）

只读复核实测出一条假阳性方向：`extract_symbols` 的「被桩替换的对象」判据是
纯文本正则，**注释里**写 `# see monkeypatch.setattr(w, "egg.spam", x)`、
**字符串里**写 `log("patch('egg.spam')")`，都会把 `spam` 收成"符号"。
两张只共享这种词的卡 → 假交集 → `exit 1`（假串行）。而工具 docstring 自述
「字符串里的词一概不算」—— 自相矛盾。假阳性会毁掉工具的可信度：要么白串行，
要么干脆没人再信它。

改前复现（RC 反例，真跑）：

```
A(注释): [('spam', 'stub')]   ← 注释行被收成符号
B(字符串): [('spam', 'stub')] ← 字符串行被收成符号
交集: {'spam': ['A', 'B']}    ← 假交集 → 假串行
```

## 2. 判据：代码还是文本，由 tokenize 说了算

选了卡 §2.2 的方向一（tokenize），**没有**选手写剥引号。理由：

1. **口径只有一个真源**：注释/字符串/f-string/三引号/转义的定义交给
   `tokenize`，不自己再写一份剥引号状态机 —— 手写的那份迟早跟 Python
   词法漂移（f-string 在 3.12 拆成 FSTRING_* 三段就是现成的例子）。
2. **锚点在"关键字"而不是"实参"**：`setattr(`/`patch(`/`def`/`class`
   必须落在**代码位置**上才算符号；此时跟在后面的字符串实参才是真对象。
   这样既收掉假阳性，又不用碰真阳性（桩对象本来就住在字符串实参里）。
3. **解析不了的整行跳过**（宁可少、不可滥）：多半是跨行三引号的内容。

实现（`tools/seam_check.py`）：

- `_textual_spans(line)`：tokenize 求该行注释/字符串字面量的区间；失败 → None。
- `_balanced(line)`：行尾没闭拢的 `(`/`[`/`{` 补齐后再 tokenize —— diff 里
  大量 `def NAME(` 跨行签名，不补会把整行当"解析不了"跳过（真撞过，见 §4）。
- `_tq_close` / `_tq_open` / `_line_analysis`：跨行三引号状态机；hunk 起点
  假定不在字符串里（状态不跨 hunk 带）。
- `extract_symbols`：四处判据全部先过「区间过滤」—— 关键字区间撞上
  注释/字符串区间就不算；不可解析的行不抽符号、也不推进参数表状态。

## 4. 碰到的坑

- **行尾未闭合的 `(` 让 tokenize 报 `EOF in multi-line statement`**：
  第一版只处理了「未闭合的三引号」，`def _write_myday_rank(` 这种跨行签名
  开头行被整行跳过 → 参数表状态永远打不开 → 022 侧符号全丢、真阳性测试红。
  修法 = `_balanced` 补括号（补的只在行尾，不影响行内区间）。
- 本会话的 shell 是 Git Bash 不是 PowerShell：规矩里 `*> 日志` 的写法会把
  `*` 当通配符展开进 pytest 命令行（报 not found）。改用 `> log 2>&1`，
  其余口径不变。

## 5. 边界（如实写）

- **已知残留（同病根的尾巴，本卡只点名不顺手改）**：三引号状态**不跨 hunk**
  （hunk 起点假定不在字符串里）。反例形状：docstring 在上一个 hunk 打开、
  下一个 hunk 里有一行内容恰好是合法 Python 且以 `def fake():` 开头 →
  仍会被收成定义符号。要收掉得把字符串状态跨 hunk 接起来（或整段重建），
  是另一张卡的活。
- **解析不了且无三引号开头的行整行跳过** → 理论上会漏报（宁可少、不可滥，
  与工具既有口径一致）。
- docstring 只对齐了「代码还是文本」那一段自述；`--card` 解析、退出码语义
  （有交集=1 / 无交集=0 / 用法错=2）、报告三段格式、卡 048 其余行为**没动**。
- 没跑全量门禁（卡 §0.3 明令）；台账没写（条目在本文件末尾供集成者粘贴）；
  `docs/changelog.md` 不在本卡白名单，留给集成者收口。
- 其余假阳性方向（若有）未系统排查，本卡只收 RC 点名的这一条。
