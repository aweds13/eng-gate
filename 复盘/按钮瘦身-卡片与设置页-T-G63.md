## 2. 判据从哪来（三处，都不是我发明的）

1. **项目自己的包**（`sheleg-design/workbench`，这条线的 core contract）：
   - `DataTable.md`：行 hover 只是 `--panel-2` 底色，**nothing else moves**；
   - `Button.md`：primary 是"这一屏存在就为了让**那一个**动作好按"，其余动作穿 secondary/ghost；
     `workbench.md` 追加 **primary max one per view**；
   - `DestructiveButton.md`：删除 = **红边小 ghost + 两步确认**；"需要它又大又安静，是上游的设计问题"；
   - `workbench.md`：**keyboard-first**（每个主要动作键盘可达 + ⌘K）。
2. **第三方 UX 库**（`ui-ux-pro-max`，本地 119 条）：`Hover vs Tap`（High）——**"Don't rely only on hover for
   important actions"**；`icon-only buttons without labels` 属反模式。
3. **同类产品的机制**（Things 3 / Apple 提醒：行上只剩勾选，动作在详情面板；Todoist/Linear/GitHub：
   hover 一个 `…` 或固定槽位的 1–3 个小图标；批量动作走"选中后出工具条"）。

★ **我自己上一轮的方案（A+B：悬停显形）是被预演否掉的**：鼠标扫过时动作行会从一行变两行、卡片长高 ——
正是包明令禁止的位移（"nothing else moves"）。**先出图**这一步就是为了让它当场暴露，而不是上线后被人抱怨。

## 3. 做了什么

**① 任务卡（`taskCard`）**
- 常显：勾选圈（完成/撤销）+ `在做/开始` + `专注` + **`…`**；
- `…` 点开 = **行内展开**（与分组管理里「看任务/收起」同一套做法，不新造浮层）：
  推到明天 · 取消 · 加入/移出 My Day · 标记 · 分配 · 详情 · 记录 · **删除**；
- **删除**是 `.danger`（红边 + 红字，悬停也不变回正文色）+ 照旧二次确认；
- **「详情」按钮消失** → 改成**点标题**打开右栏（动作绑到已有元素上）；
  ★ 键盘那条路留在 `…` 菜单里（"收起来"不等于"键盘到不了"）；
- 菜单状态 `cardMore`：**同一屏重渲染不清**（在菜单里点一下不会把它关上），切视图才清。

**② 设置页（`renderSetting` + `foldSettingSections`）**
- 每节 = 「标题 + **现状**（当前值）+ 展开」；现状摘要优先取"当前选中的那个按钮"（分段控件本身就是答案），
  关键几节有人写过的短摘要（`setSummary`），截 12 字；
- 展开/收起 = **真按钮**（`set-fold` + `aria-expanded` + `aria-controls`，Tab 可达）；
- **就地切 DOM**（不重跑那一页的 15 个请求）；
- 「常用」那排链接会**叫开**目标节（`openSettingSection`）；
- 折叠状态 `setOpen`：同一屏重渲染保留（点一下"加上时段"不会自己折回去），切视图重置。

## 5. 边界（不许假装验证过）

- **不做悬停显形**（用户原本想要的 B 那一半）：包禁止 hover 位移，所以只保留"点开"这一条路。
- **删除仍在菜单里而不是"藏起来"**：它一直是两步（`…` → 红色按钮 → 确认框），这一步只是把前两步合成了"一眼看得见"。
- **手机端**：没有悬停，所以「…」是唯一入口 —— 手机那一列本来就是"动作挤到 128px"最严重的地方，
  现在一张卡只剩 2 个按钮 + 「…」，标题从 128px 拿到 ~200px（`squeeze_scan` 复扫 0 处）。
- **设置页的现状摘要**是"扫一眼"用的：超过 12 字截断；导出目录那种长路径只显示最后一段。
  少数节的摘要是通用兜底（抓第一节正文），不如手写的那几节准 —— 这是**已知的粗糙处**，不值得为它加后端字段。
- **「常用」与「入口」两节不折**：它们是导航，不是动作列表（判据：没有 `set-*` id）。

## 6. 教训（已进地图 §6）

1. **"悬停显形"在有一行放不下的动作时必然带来位移** —— 判据是"hover 只动 background/border/color"，
   而换行会改高度。要做这类交互，得先把动作**压到一行放得下**（图标化），否则就是位移。
2. **折叠的边界规则要把"没有 id 的标题"也算边界**：第一版只把带 id 的当边界，
   于是「数据与同步」（标题没有 id）被上一节连卡片一起吞进折叠体 → 它下面每一节都变成点不到的隐藏元素
   （流层当场报"元素是 0×0"）。**在真实浏览器里点不到**比"页面长得不对"更难自查。
3. **"渲染完再整理 DOM"要先把假 DOM 的桩补齐**：`querySelectorAll` / `after` 这些真 DOM 都有的方法，
   桩里缺一个就整页抛错。
