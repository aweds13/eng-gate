## 三、关键决策（新对话必须知道）

1. **方向：修复，不重写。** 后端 90% 可用（60 项测试全绿），问题在「缺联动 + 前端薄」。

2. **架构核心：事实与解读分离。**
   - **事实层**（已建）：只记「发生了什么」，与心智模型无关
   - **解读层**（= ledger）：按当前心智模型算成"账目"
   - **换心智模型 = 只换解读层，事实不动**（这是用户最关心的能力）

3. **表设计三原则**：
   - `kind` 自由字符串（加新事实类型**不改表**）← 真正的扩展点
   - 高频值放 `value_num`/`value_text` 公共列；`extra` JSON 只作兜底
   - `revision`/`supersedes` **预留但不实现**（MVP 不做修正机制）

4. **事件驱动用「同步执行」**（非异步队列）：本地单机无性能压力，强一致、易调试。

5. **实测确认的断点**（重要，别再凭读代码猜）：
   | 项 | 实测 |
   |---|---|
   | 专注结束 → 摘要投入 | ✅ **没断**（0.42h 真进账了，实时聚合） |
   | 专注 → 当日反馈自动累加 | ❌ 断 |
   | 专注 → 累加绑定任务时长 | ❌ 断 |
   | 完成 → 记投入账 | ❌ 断 |
   | Repeat 触发 | ❌ 死代码（无端点） |
   | 产出轴 | ❌ 断（无写入） |

6. **MVP 范围** = 框架（账本）+ 2 条线（任务、专注）+ 全部交叉。
   其余（复习/学业/团队/备忘录/分组/习惯/同步/PWA）**延后**。

7. **事实语义（第 0.1 步已修）**：只有正常结束记 `focus.finished`；暂停/放弃/记中断分别记 `focus.paused/abandoned/interrupted`，避免第 1 步误计入投入。

8. **历史数据（第 0.1 步已修）**：schema v4 幂等回填历史 `focus_sessions` → facts；保证第 1 步改读 facts 后旧数据不归零；其余域仍按第 3 步迁移。

9. **存储边界**：按 conventions 数据分流——计算型事实（专注/完成/复习等）走 SQLite facts；沉淀型内容（任务/备忘录/产出）走 Markdown（目标态，第 3 步定契约）。

## 六、工作约定（用户偏好 · 重要）

### 协作方式
- **先出方案 → 给 diff → 等用户确认 → 才写入**（不许静默覆盖）
- 用中文交流
- 改动前说明「不改什么、可逆、风险」，用户对"会不会破坏现有系统"敏感

### 判据
- ★ **「这件事是否直接推动软件能用」** —— 不满足的先不做
- 别把"自己列的选项清单"当成"用户的任务"；用户说"按 2-3"时先确认那两项当前是否值得做
- **不为假想的未来过度设计**（派生层、修正逻辑，都是 MVP 之后的事）

### 质量门（每步必跑）
```bash
python -m pytest                          # 全绿
python -m ruff check src/ tests/ scripts/  # 0 错误
python -m mypy src/                       # strict，0 错误
python -X utf8 scripts/check_layers.py    # 五层对齐 PASS
python -X utf8 scripts/test_check_layers.py  # 护栏脚本自测 PASS
```

### 铁律
- **能跑就实测** —— 别凭读代码推测（本轮实测纠正过一处误判）
- **一次只做一步** —— 每步保持测试全绿
- 报告进度时给**状态快照**（到哪了 + 卡点 + 下一步），不要长报告

### 环境备忘
- Python 包用 editable 安装；**项目搬过家**，若 `import timeflow` 失败：
  ```bash
  python -m pip install -e ".[dev]" --no-build-isolation -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```
- 启动服务：`python -m uvicorn timeflow.api.app:create_app --factory --port 8520`
- 受限沙箱 / TEMP 不可写时，pytest 可能报 `tmp_path` PermissionError（`mkdtemp` 目录被 ACL 拒绝）——是环境问题，不是项目代码；换普通终端或把 `--basetemp` 指向可写目录。
- 详细说明见 `复盘/check_layers修复与验证复盘.md`（含环境问题诊断与修复命令）
