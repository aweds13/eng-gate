### 2.2 `docs/LEARN.md`（零基础定制，7 节）

**定位**：写给**没有编程基础**的人，目标"改配置就能用"。

**结构**：
1. 先记住：大部分定制只需改 `config.toml`
2. 第一步：复制模板生成配置
3. **五个可马上改的配置**（逐个解释，附实例）
   - 数据路径 / 主题颜色 / 专注白名单勿扰 / 债务等级阈值 / GPA 制式
4. 改配置的通用步骤（5 步 + 备份建议）
5. 进阶：环境变量临时覆盖（`TIMEFLOW_DATABASE__PATH`）
6. 常见问题（改了没生效 / 启动报错 / 想改功能 / 怎么确认对）
7. 想改的还没配置项 → 扩展清单 + 加配置项的 3 步

**特点**：
- 全部基于**真实配置项**（读 `config.example.toml` + `config.py` 确认，未编造）。
- 每项都有**具体实例**（如"想换绿色写 `#22c55e`"）。
- 特意提醒 Windows 隐藏扩展名的坑（`config.toml.txt`）。

## 六、教训

1. **"被引用但不存在"是文档体系的常见病** —— 靠 `check_layers.py` 的引用完整性检查可自动发现（本次正是它抓出来的）。
2. **写 know-why 要写"代价"** —— 只说好处是宣传，说了代价才是决策记录。
3. **验收标准必须与契约层对齐** —— 契约层说"怎样才算做完"，验收标准却只看"有没有"，必然漏。
4. **升级标准时保留旧标准** —— 归档而非删除，可追溯历史交付范围。
5. **写面向零基础的文档，必须核实真实配置项** —— 不能凭印象写（本次读了 `config.example.toml` + `config.py` 才动笔）。
