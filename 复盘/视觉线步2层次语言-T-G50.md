> 状态：**候选已出、数字与截图都在、还没动 `app.css`**。选哪个由用户定（`T-G30 §5` 的口径：

## 1. 诊断（要解决的是什么，不是审美形容词）

- **66 张卡权重完全相同**：白底 + 同圆角 + 同内距 + 一条 4% 黑的阴影。阴影在近白的页面上
  **几乎看不见**（这就是"平"的直接来源），而它同时还是**唯一**的层次手段。
- 包对这件事有明文，而且我们只抄了一半：`.wb-card` = `--panel` 白底 + **1px `--border`**；
  阴影只有一条，注释写着 **`overlays only`**。另有 `.wb-stat` = `--panel-2` 静音面（"读数"）。
- 尺度：包 6 档间距（4/8/12/16/24/32）+ 3 档圆角（6/10/999）；我们 **11 档 / 5 档**，
  多出来的全是"差一点"（6 与 8、10 与 12、14 与 16、18 与 20）。

## 2. 三个候选（嵌套：A ⊂ B ⊂ C，所以是"走多远"的选择）

| 候选 | 做什么 | 依据 |
|---|---|---|
| **A 边框做层次** | 卡片/面板补 1px `--border`、阴影归位成"浮层专用"、两对同义卡片类先表现一致 | 包明文（`.wb-card` / `overlays only`）——**最小、也最没争议** |
| **B 尺度收敛** | A + 间距 11 档 → 包的 6 档、圆角 5 档 → 3 档（就近并档） | 包明文（4px 网格）；这是"缺少呼吸"那一条 |
| **C 静音层** | B + **读数卡**（环/条形/大数字/雷达）退到 `--panel-2` + `--muted` 跟包（更深） | 包 `.wb-stat`；两级卡片才叫"层级" |

映射（就近并档，逐条列出，不藏着）：间距 `4→4 6→8 8→8 10→12 12→12 14→16 16→16 18→16 20→24 24→24 30→32`；
圆角 `6→6 8→6 10→10 12→10 999→999`。

## 3. 预演怎么做的（**没动真文件**）

`tools/candidate_shots.mjs`：起一个真后端 + 真浏览器，往**真界面**注入候选 CSS（覆盖层），
3 档宽度 × 14 个视图截图 + 量数；数字表落 `gates/render/candidates/NUMBERS.md`。
候选 CSS 与截图都不入库（`.gitignore`：`gates/candidates/`、`gates/render/candidates/`）——
它们是"选定那一刻就过期"的东西，决策本身记在这里与 `app.css` 的注释里。

★ **预演当场抓到一个真缺陷（这就是它存在的意义）**：候选 C 里"读数卡"变成浅底之后，
**完成度环的轨道与雷达的网格线直接消失** —— 因为它们本来就靠 `--panel-2`（同一档浅色）画形状。
修法照包：`.wb-progress__track` 就是"浅底 **+ 1px 边框**"，SVG 里等价物是把那一笔换成 `--border`。
**补完重拍才拿来给你看**（`gates/candidates/step2/C-静音层.css` 末尾那条注释就是这段）。

## 4. 对比度也不靠猜

`tools/candidate_contrast.py` **用门自己的算法与组合清单**（import `contrast_audit` 的函数）
在候选令牌上预演：A/B 在"候选新造的那一对"（`--muted` 落在 `--panel-2` 上）是 **4.23（不过 AA）**，
C 跟了包的值（`#5b6472`）之后是 **5.32** —— 也就是说 **C 的静音层与"muted 跟包"是一件事的两半**，
不能只做一半。真判定仍是 `run_gates.py --fast` 里的 `contrast` 一步。
