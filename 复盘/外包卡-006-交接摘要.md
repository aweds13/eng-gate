# 外包卡 006 · 紧凑交接摘要（台账号 `T-G95`）

> 八条铁律在你的系统提示里（以卡规格为准）。卡号 006。**这一轮只有你一个工人在主工作区
> `line/impl-v1` 上干活**，所以**你要自己提交**。干完按 §6 回报。

## §1 背景（主控为什么提这个需求）

主控（我）每收一张卡，最大的开销**不是复核**（那是 `wb_review.py` 一条命令、5 秒的事），
而是**读工人那一轮的原始事件流**：卡 005 那轮是 `gates/diag/wb-005.jsonl`，
**264 行 / 316 KB**，而我要的东西（工人的六项回报、判决、计数）**只压在它末尾**。
主控为此**读了整段渲染**，一次上万 token —— 这是纯浪费。

**所以要你做一件事：让派活器自己在收工时落一份 1~2 KB 的摘要文件**，
让主控只读它，**永远不必再碰原始 jsonl**。

## §2 口径（要做什么）

### 2.1 新增 `write_report(log, *, card, code, reason, scene, sid, attempts, lines, started_at)` → `gates/diag/wb-<卡>.report.md`

内容（顺序固定，主控按标题读，别花哨）：

```markdown

- 尝试：第 <n> 次   退出码：<code>   判决：<reason 或「正常收工」>

- 开始 / 结束：<ISO> / <ISO>   用时：<x.x> 分钟
- 回合 <turns> | 工具调用 <tool_calls> 次 | 碰过文件 <files> 个 | 工具报错 <errors> 次
- log：wb-<卡>.jsonl（<行数> 行 / <x.x> KB）

## 工人的回话（`result` 事件原文）
<把 `result` 事件的 `result` 字段**原样**贴进来；没有 result 事件就写「整段 log 里没有 result 事件
（被打断 / 被杀 / 还在跑）」。>

## 最后 10 次工具调用
<每行一条：序号 + 工具名 + 参数前 120 字符 —— 让主控不必翻 log 就知道它最后在干什么>

## 主控下一步（机械读数，不是判断）
- `git -c core.quotepath=false status --porcelain` 的未提交文件数：<n>
```

★ **口径复用现成的，不许写第二份**：回合数用 `turns_seen()`、工具签名用 `tool_signatures()`、
log 摘要用 `wb_status.parse_events()`（它已经算了工具调用/文件/报错）。别自己再解析一遍事件流。

### 2.2 每一条退出路径都要落这份摘要

正常收工、被看门狗掐、超时、撞 `--max-turns`、重试中的每一轮，**都要落一份**（重试的第 2 轮覆写或
落成 `wb-<卡>.r2.report.md`，你定，但要在复盘里说明并**钉一条测试**）。

### 2.4 ★ 顺手修那个块缓冲的坑（T-G93 记录在案）

## §5 自检 + 真机证据

```powershell
python -X utf8 -m ruff check tools/wb_dispatch.py tests/test_wb_dispatch.py
$env:PYTHONPATH = "$PWD\tools\sandbox_shim"
python -X utf8 -m pytest tests/test_wb_dispatch.py -q --no-cov
```

**单测至少覆盖（先红后绿）**：

1. 摘要文件真的被写出来，且**包含工人 `result` 事件里的回话原文**（造一段假事件流）；
2. **没有 `result` 事件**时（被打断/被杀）摘要照样落盘，且写明"没有 result 事件"；
3. 被看门狗掐 / 超时 / 撞上限这几条路径**也落摘要**（至少钉住其中两条）；
4. 摘要里 **CJK 不被转义**（不能出现 `\u4e2d` 这种）；
5. `detached_argv()` 里 `-u` **恰好一个**，且 T-G92 的既有断言（脚本自己、`--no-preflight` 恰好一个、
   `--detach` 已去掉、以 `--detach-done` 收尾）**全都还绿**；
6. 事件流缺字段 / 半截时**不许炸**（退回"没有数据"）。

★ **真机证据**：用 `--detach` 真派一张**很小的**只读卡（例如 `--read-only` + 一张一页的卡，
或干脆用 `--card R-smoke --spec <本卡> --no-preflight`），跑完**贴出**：

（证明 `-u` 生效）；③ `--status` 里那一行 `[摘要]`。
（★ 真派会花钱在 CLI 上但积分免费；**也可以**用桩命令替你跑一轮，只要如实写清你怎么造的。）

## §7 已知的坑

1. 一律 `python -X utf8`；pytest 要 `$env:PYTHONPATH="$PWD\tools\sandbox_shim"`。
2. 事件时间戳键是 **`__timestamp`**（两个下划线）；回合数用 `turns_seen()`，**别自己数**。
3. **别写"真睡几百秒"的测试**：构造假事件流即可。
4. TOML 里**不许出现裸 ASCII 双引号**（台账 `gaps` 最容易踩）—— 用「」。
5. 提交消息用 `git commit -F gates/diag/msg-T-G95.txt`（PowerShell heredoc 会搞坏反引号）。
6. 读 `gates/diag` 里的文件一律**显式 UTF-8**（否则中文乱码，看着像文件坏了）。
7. **块缓冲**这个坑你不一定复现得出来（TTY 下不缓冲）—— 铁证是"`--detach` 之后 dispatch.log 是
   0 字节"，用 §5 的真机那一步验。
