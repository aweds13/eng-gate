## §2 要逐条判的四条硬主张（本卡的核心）

对每一条给出 **站得住 / 站不住 / 无法判定**，并且**必须附你实际跑过的命令与输出摘要**
（只读代码就下结论 = 不算证据）：

1. **落点语义**：`place_myday(task_id, before_id)` 的语义是"放到 `before_id` 那一条的**前面**"，
   `before_id=None` 放到**末尾**；拖到自己前面、已在头尾按 ↑↓ 都是**原地不动且不写库**。
2. **两条入口同一份顺序**：拖拽（`place_myday`）与键盘（`move_myday`）写的是**同一份** `myday_rank`，
   所以"拖过之后再按 ↑↓"结果一致；不是两套各排各的。
3. **进/出「今天」的语义**：进今天 = `NULL`（新来的排**最后**，不抢手动摆好的位置）；
   离开今天 = **清空** rank；没拖过的（`NULL`）排在拖过的**后面**并按老口径（截止日 → 优先级 → 创建时间）。
4. **接口次序与错误语义**：两个键**要么给一个要么不给**（都给/给空 → **400**）；
   **任务不存在 → 404**，且这一步**先于**"不在今天"那一步；`myday_rank` **不是 PATCH 可写字段**。
