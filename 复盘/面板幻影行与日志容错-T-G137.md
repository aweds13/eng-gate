# 面板幻影行与日志容错（T-G137，卡 046）

> 一句话：面板把派活器的**用量账本** `wb-usage.jsonl` 当成一张叫 `usage` 的卡，永远显示
> 「静默 N 分钟（可能卡死）」—— 9 棵树 9 行幻影把真卡挤下去；顺带修掉第二个坑：
> PowerShell `*>` 写出的 UTF-16 log 被显示成 `? 非 JSON 行：\x00`、整张卡变「说不清」。

## 1. 为什么有这张卡 / 怎么发现的

用户 2026-09-26 19:5x 看着面板问「怎么好多静默的工人」。主控拉 `wb_dash.api_state()` 看到
`usage@.wt/doc44   静默 9.4 分钟（可能卡死）` 等一排幻影行（卡 §1）。根因两层：

1. **账本不是卡**：卡 029（`T-G114`）给派活器加了用量落账，每棵树一份
   `gates/diag/wb-usage.jsonl`（只有 token 计数、**没有事件流**）；而
   `wb_dash.discover_logs()` 用 `wb-*.jsonl` 一网打尽 → 账本成了「一张叫 usage 的卡」，
   没有事件流 → 永远「静默」→ 还被盖了「可能卡死」的帽子。
2. **读日志不容错**：`card_state()` 用 `read_text(utf-8, errors="replace")`，UTF-16 的
   NUL 字节全变成 `\x00` 文本 → `wb_status.parse_events` 只能把它标成
   `? 非 JSON 行：\x00` → 看起来像一张「说不清/卡住」的卡。

**修的方向（主控裁定，卡 §2）**：面板适配账本 —— 账本不改名、`wb_dispatch.py` 的落账逻辑
一个字不动；读不懂的日志如实标「日志不可解析」，不许推断成「卡死」。

## 2. 做了什么

只改 `tools/wb_dash.py`（+ 测试）：

1. **排除判据收拢成具名常量 + 小函数**（tools/wb_dash.py:111-114）：
   ```python
   NON_CARD_LOGS = frozenset({"wb-usage.jsonl"})

   def is_card_log(name: str) -> bool:
       """gates/diag/ 里这个文件名算不算一张卡的 log —— 用量账本等非卡文件排除。"""
       return name not in NON_CARD_LOGS
   ```
   `discover_logs()` 的 `wb-*.jsonl` 循环里 `is_card_log(log.name)` 不过就 `continue`
   （tools/wb_dash.py:158-160）。以后再有别的非卡文件，往 `NON_CARD_LOGS` 加一项就行。
2. **日志容错**：新增 `_read_log_lines(log)`（tools/wb_dash.py:118-139）——
   - 真 UTF-8（无 NUL 字节）→ 整份 `decode("utf-8")` + `splitlines()`，**与从前一字不差**；
   - 有 NUL 或整份解不出 → 退到按行救：非 UTF-8 行、含 NUL 行**跳过**，好行照常解析；
   - 整份一行都读不进来 → 返回空列表，`card_state()` 里 `st_size > 0` 且空 →
     状态如实标 **「日志不可解析」**（tools/wb_dash.py:186-189、199-202），
     **不参与**「静默/可能卡死」的推断。好行混坏行的情况只丢坏行、回合/模型照常读出来。
3. **行序一个字没动**：`discover_logs()` 的排序键照旧（030 的「组按最新 mtime 降序 +
   同卡轮次新的在前」），既有用例
   `test_newest_activity_group_first_and_rounds_new_on_top` / `test_newest_card_on_top_overall`
   / `test_equal_mtime_is_stable_by_tree_then_card` / `test_round_suffix_sorted_numerically_not_lexically`
   全部原样通过（26 passed 里有它们）。

## 3. 反证（先红后绿）

新钉子 4 条（tests/test_wb_dash.py:351-422）：`usage` 排除、UTF-16 →「日志不可解析」、
坏行跳好行留、真 UTF-8 行为不变。

- **红（改前）**：`python -X utf8 -m pytest tests/test_wb_dash.py --no-cov` →
  `2 failed, 24 passed`：
  - `test_usage_ledger_is_not_a_card`：`assert ['042.r2', '042', 'usage'] == ['042.r2', '042']`
    —— 改前 `usage` 真在 `discover_logs` 结果里；
  - `test_utf16_log_is_unparseable_never_stalled`：`'静默 10.0 分钟（可能卡死）' != '日志不可解析'`。
- **绿（改后）**：同命令 → `26 passed in 0.50s`；`ruff check tools/wb_dash.py tests/test_wb_dash.py`
  → `All checks passed!`（exit 0）。
