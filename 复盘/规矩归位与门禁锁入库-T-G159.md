## 三、`gate_lock.py` 入库：`.gitignore` 精确取反

`.gitignore` 里 `gates/diag/` 那一行**不动**，在它下面加**精确取反三步**：

```gitignore
# 例外（T-G159）：门禁串行锁是**每棵树都会调用**的工具，改它必须能进提交
# （卡 062 踩过：改好却进不了提交，只能手工拷）。**只放这一个文件** ——
# 卡规格、诊断日志、活文档（自动推进表/队列）仍不入库。
!gates/diag/
gates/diag/*
!gates/diag/gate_lock.py
```

★ **为什么必须三步**：`.gitignore` 里「忽略目录」再「取反文件」是**不生效**的
（git 不会进入一个被忽略的目录找例外）—— 必须 `!gates/diag/`（让 git 进目录）→ `gates/diag/*`
（把里面全忽略）→ `!gates/diag/gate_lock.py`（只把那一个文件取回来）。
★ **只放这一个文件**：`git add gates/diag/gate_lock.py`（**绝不** `git add gates/diag/` 整目录、
绝不 `git add .`）—— 那会把**几百个**一次性日志/卡规格/活文档带进仓库。
★ `gate_lock.py` **内容一个字没动**（进提交用）。
