## 2. ★ 四件事逐处改了什么

### 2.1 学业页撤掉 GPA 制式卡（用户：「放在设置就行」）

- 删 `src/web/index.html` 原 `2821-2827` **整块**（说明句 + 两颗 `set-gpa` 按钮 + config 说明）。
- 同处原 `2820` 的 sub「切换制式：另 X 制为 Y」**一并删**（它指向刚删掉的按钮）；
  依据：`2819` 的 GPA 大卡自带「GPA（4.0 制，N 学分）」，制式名不丢。
- 顺带删因之变成死代码的 `const otherScale=...`（原 `2814`）。
- ★ **设置页那一份原样保留**（现 `3440-3444`）—— 唯一入口。`git grep -n 'set-gpa'` 读数见 §3。

### 2.2 学业概览加设置开关（用户：「学业概览可以设置开关」）

- 概览区 = 顶部两张读数大卡（加权平均 / GPA）+ 多维 radar。新建两个模板变量 `acadCards` / `acadRadar`，
  `m.innerHTML` 里按 `academicOverviewOn` 决定是否插入。
- **关掉只隐藏概览**：硬考核 / 课程 / 成绩明细 / 两张录入表单照常显示（开关不包它们）。
- 偏好键 `tf_academic_overview`（localStorage，**只存本机**），读写都包 `try{}catch(e){}`（照 `RAIL_KEY`）；
  **默认显示**（用户只说"要个开关"，没说默认关）。
- 开关落点：设置页「学业」节（`set-academic`，现 `3446-3448`），一颗按钮、文案随状态变（`隐藏概览`/`显示概览`）。
- 状态变量 `academicOverviewOn` 与键常量放在原 `let gpaScale` 旁（现 `99-103`）；动作 `academic-overview-toggle`
  在 `ACTIONS` 学业块注册（现 `1033`）；`toggleAcademicOverview()` 紧跟在 `renderAcademic` 后（现 `2880-2886`）。

### 2.3 录入成绩绑课程（后端早有，本卡只接前端）

- 录入表单在「成绩/学分」前插课程下拉 `#gCourse`，选项复用现成 `courseOpts`，写法抄「添加考核项」那颗
  （`2850-2851`）；**空选项 = 不绑课**。
- `addGrade()` 请求体加 `course_id:courseId||null`。
- 「成绩明细」meta 前置 `${esc(courseName(g.course_id))}`（兜底串已是「未关联课程」）。
- ★ GPA 数值不许变：`gpa()`／`weighted_average()` 只读 `score`/`credits`，**不读 `course_id`** —— 读数见 §3。
- ★ 绑的是「课程」（`courses` 表），不是「科目/学科」；本仓没有 subject 实体。

### 2.4 压密度（折叠，**没动 app.css**）

- 两张表单标题加 `set-` 前缀 id（`set-acad-assessment` / `set-acad-grade`），`renderAcademic` 末尾调用
  仓内既有的 `foldSettingSections(m)` —— 折成「标题 + 现状 + 展开」，默认收起。
- 复用的是设置页那套（`.set-head` / `.set-body[hidden]`，`app.css:452-459`），**没有新增任何全局样式**，
  也没碰 `.card` / `.section-title` 的间距令牌。
- ★ 硬考核区（含「硬考核：临期与逾期」「未录成绩」「逾期不候」三串字）与两张表单的**内容一字未改**，只是收进折叠体。
