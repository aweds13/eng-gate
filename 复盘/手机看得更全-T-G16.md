# 复盘 · 手机上更完整的"看"（跨端延伸 / G 批 · T-G16）

> 触发：用户 2026-09-23「全做」——交接文档里最后一条："手机上更完整的看/提醒
> （离线缓存已有；提醒仍只在界面标注，与 T-B5 同口径）"。这是本批最后一张卡。

## 一、这一卡在说什么

手机侧原来只能**记**：离线页有一份"缓存里最近看到的那份清单"（可勾完成/撤销）、习惯打卡、
一句备忘、每日反馈。但"今天该做什么、欠了什么、什么时候该动"这些**看**的东西，
手机上要么没有，要么要翻到别的地方。

这一卡把"看"补齐：离线页多一段**「上次看到的（只读）」**，四份清单 + 一行摘要：

1. **该提醒了**（带提醒时间）；
2. **今天该复习**（到期日 + 已复习几次）；
3. **逾期**（逾期几天 + 截止日）；
4. **今日摘要**（债务 / 完成收益 / 投入 / 复习 / 习惯 —— 与电脑端**同一句**措辞）。

## 二、口径：看的是"上次联网时的样子"，提醒仍然只标不通知

三条都**承接既有口径**，没有新增需要拍板的东西：

1. **不是实时**：手机没有库，能看的只有缓存。所以段标题就叫「上次看到的（只读）」，
   段尾明写"这几份是**上次联网时看到的样子**（不是实时的）"。宁可直接说破，
   也不要让人以为"手机上看到的就是现在的"。
2. **提醒只标出来、不发系统通知**：这就是 T-B5 当初定的移动端口径（"移动端只标不通知"）。
   手机浏览器里也确实发不出系统通知（没有推送通道），所以这不是"还没做"，是**口径如此** ——
   界面上照抄这句话，免得用户以为是坏了。
3. **只读区里没有写动作**：手机上能改数据的仍然只有三样（完成 / 撤销完成 / 习惯打卡），
   它们都在可写区。只读区**一个 `data-action` 都没有** —— 提醒是"标出来"，不是"点掉"；
   逾期也不是"就地处理"。这条有护栏（测试 + 探针各查一遍）。

## 三、落地

| 层 | 落点 |
| --- | --- |
| 缓存 | `OFFLINE_CACHE_PATHS` 从 4 条扩到 9 条：加 `/api/mydays`、`/api/overdue`、`/api/reminders/due`、`/api/review/due`、`/api/summary`（键名与清单一一对应，`OFFLINE_CACHE_KEYS` 一处声明） |
| 界面 | `renderOffline` 新增 `const seen=…` 一段（四份清单 + 摘要）+ 可写清单里补上**提醒时间** |
| 数字 | 摘要直接用后端 `summaryLine()` 那份字段拼（**不在手机上另造一套口径**）；逾期天数/提醒状态都是后端算好的字段（`overdue_days` / `reminder_state`），手机不拿"今天"去减 |
| 验证 | `tests/test_phone_view_line.py`（6 条）+ 真机自检 3 条 + 探针「手机离线记」那一档扩了一倍断言 |

★ 一条值得单独说的护栏：**"要缓存的接口必须真的存在"**。
缓存路径写错一个字，手机不会报错 —— 它只是**什么都看不到**，而且多半是在断网时才发现。
所以有条测试拿 `app.routes` 对账：界面声明要缓存的每一个 `/api/...` 都必须在真路由表里。

## 四、探针是怎么"真跑一遍"的（这一档的价值所在）

假 DOM 探针里这一档不是查字符串，而是**把整条链子跑一遍**：

1. 临时把 `mydays` / `overdue` / `reminders` / `summary` 换成有内容的桩；
2. 渲染**今日页** —— 这一步会真的发那几个请求，`rememberForOffline()` 把响应写进
   （内存版）IndexedDB，**这就是手机上"联网时看过一遍"的那个动作**；
3. 渲染**离线页** —— 它从 IndexedDB 读回缓存，四段应当有东西；
4. 反证：只读区里**不许**出现任何写动作（`offline-done` / `offline-habit` / 任何 `data-action`）；
5. 跑完把桩还原，别的档不受影响。

于是"缓存键写错""渲染时读错键""只读区混进按钮"这三类错都会当场红 —— 它们都是**真机才看得出来**
的那一类。

## 五、遗留（如实写）

- **提醒仍然不会响**（手机上只标）；要真响得走推送（需要公网 + 服务端），
  那与"本地优先、不涉及公网"的基调冲突，不在这一版。
- 手机上看的是**上次联网时**的样子：断网久了就是旧的。界面上说破了，但**没有做"这份缓存有多旧"**
  的标注（缓存里其实存了 `at`）—— 想做的话是下一张卡的事（把 `at` 显示成"看到于 …"）。
- 还是没有"手机上直接改字段 / 删除"：那是 T-G10 就定下的边界（手机上判不准电脑那边有没有更新过）。
