## 3 · 判据（★ 选了哪条、写在页面上让人能自查）

- **已集成** = 该卡台账号在主树 `docs/traceability.toml` 里且 `status = done`
  —— **选台账这条**，不选 git log trailer（台账是唯一真源，trailer 可能先落而台账未收口）。
- **在跑** = 最新一轮的心跳在更新（052 判据，`_heartbeat_fresh`，300 秒内）。
- **已交付待复核** = 有判决文件或 `result` 收工、且台账号不在主树 done 里；
  **没有台账号（或台账读不到）＝没法查集成 → 不猜**，写「无法判断」。
- **已停** = 无判决 + 心跳不在更新 + 静默超过本次阈值（052 终态，阈值复用派活器口径）。
- **无法判断** = 其余（有规格无日志、日志还新但无心跳无判决等），**一律不猜**。
- B 行的「还剩 R 张卡」= 认出的卡总数 − 已集成（含在跑/待复核/已停/无法判断/未派）。
