# 复盘 · 跨卡接缝：T-G126 的桩签名接住 T-G110 新增的 `bump_version`（T-G138 · 卡 047）

> 作者：外包工人（卡 047）。底座 = 主树 HEAD `277cf49`（含 `T-G126`，不含 `T-G110`）。
> 只改测试桩；产品代码一个字没提交。

## 一、为什么有这张卡（出处）

- 集成者 I-2 把 022（`T-G110`，myday 稀疏序号）收进主树时全量门禁红 1 例：
  `tests/test_myday_conflict_409.py:82` `assert 500 == 409`。
- 根因（本卡复核实锤）：`git show 5f51806 -- src/timeflow/core/tasks/manager.py` 命中
  `+    bump_version: bool = True,` 与调用点 `+                conn, task_id, rank, by_id[task_id].version, bump_version=bump`
  —— 022 真的给 `_write_myday_rank` 加了 keyword-only 参数；而 `T-G126`（卡 035）的桩
  `always_conflict(conn, task_id, rank, expected_version)`（`:58-60`）接不住 `bump_version=bump`
  → `TypeError` → 无人接 → 500，根本没走到 `src/timeflow/api/app.py` 的 409 映射。
- 为什么两位作者都没撞到：022 的作者树建在 `T-G126` 合入之前（那份树里没有这个测试文件）；
  035 写卡时 022 还没落地。跨卡接缝只有集成时的全量门禁能抓到。

## 二、做了什么、为什么这样做

桩签名加显式第 5 参（`tests/test_myday_conflict_409.py:58-69`）：

```python
def always_conflict(
    conn: object,
    task_id: str,
    rank: int,
    expected_version: int,
    bump_version: bool = True,
) -> None:
```

- 卡给了两条路（`**kwargs` 或显式），我选**显式 `bump_version: bool = True`**：
  ① 卡建议保留显式（读代码的人一眼看到产品真的会传这个参数）；
  ② 默认值取 `True` 而不是卡文示例里的 `False`，是与产品签名**逐字同形**
  （`5f51806` 里产品的默认就是 `True`）—— 桩的价值是「长得像被替换的那真函数」，
  同形以后产品再改默认值时 diff 会直接撞到这一行。
- 断言与意图一个字没动：`:82` 的 `assert resp.status_code == 409`、detail 人话断言、
  顺序断言全部原样（它钉的是「撞车必须回 409」，不是签名本身）。

## 四、★ 过程里撞到的一个环境坑（如实记，值得主控知道）

本机 `timeflow` 是 **editable 安装**（`site-packages/__editable__.timeflow-0.1.0.pth` 内容就是
主树的 `D:/repo/engineering\src`）。后果：

- 在 **worktree** 里跑 pytest，若 `PYTHONPATH` 不含**本树** `src`，`import timeflow` 拿到的是**主树的代码**
  —— 我第一轮「底座绿 / 接缝红」就是这么跑失真的（接缝现场竟然也绿：因为跑的根本不是 022 的 manager）。
- 修法：`PYTHONPATH` 用 **Windows 风格**路径把本树 `src` 放最前
  （`d:/.../.wt/seam/src;d:/.../.wt/seam/tools/sandbox_shim`；Git Bash 的 `$(pwd)` 给的
  `/d/...` 风格 Windows Python 不认，压不过 `.pth`）。上面第三节的三贴读数全部是
  **修正之后**、`import timeflow` 已确认指向本树 `src\...` 的读数。
- 边界：I-2 是在主树里跑全量门禁（editable 正好指向主树）所以能抓到接缝；
  但任何在 worktree 里跑的测试（包括此前各作者卡的轻门）都可能测的是主树代码 ——
  这条的波及面本卡**没查**（超出白名单允许的动作），留给主控裁定要不要另立卡。
