> 所以按 T-G47 的「按主题批量」一次做完、一轮门禁覆盖（L1）。教训一律进 `复盘/视觉线地图.md` §6。

## 1. 图标系统（T-G54）：15 处字形 → 内联 SVG

**先量后改**：全仓只有 **15 处真图标字形**（14 种），全在 `src/web/index.html`：
底栏 7 个 emoji（📅🗂️⏱️👥🔥📈⚙️）+ 标记 ⚑ + 删除 ✕×4 + 折叠 ▸▾ + 上移下移 ↑↓ + 分组勾选 ✓。
**没有任何测试或工具断言过这些字形** —— 会动的只有渲染黄金的**文字列**。

**换的理由（不是"emoji 不好看"）**：emoji 是**彩色字体**、不吃 `currentColor` ——
选中态改不了它的颜色，也看不出"这个图标现在是次要色还是强调色"；而且它随系统字体变样子
（同一个界面在三台机器上三种气质）。描边 SVG 24 网格、单 path、`stroke: currentColor`、`stroke-width: 1.75`。

四条规矩（都写进了 `index.html` 的注释）：
① 尺寸与颜色**只在 CSS 定**（底栏 20px / 行内 16px）；② **不给 `svg` 加 class**（加了会被黄金当"有名字的容器"多采一行）；
③ **不加 `<title>`**（与按钮标签重复，还会把文字塞进 `span.ic` 的 textContent）；④ svg 在 `button` **内部**、自己不注册动作 ——
点击靠 `ev.target.closest('[data-action]')` 冒泡命中。

三个**踩过的坑**（当场修掉，见地图 §6）：
1. **底栏是静态壳**，`${icon('today')}` 写在 HTML 里只会当字面文字渲染出来 → 改成启动时一次性填槽位；
2. 把 `⚑ 已标记` 换成 `${icon('flag')} 已标记` 时忘了那对是**单引号字符串** → 引号被提前闭合，
   页面整片起不来（`ui_dom_probe` 一句 `Unexpected identifier 'flag'` 就指到了）；
3. **底栏矮了 3px**（65 → 62）：emoji 的字形行盒 24px、20px 描边图标是 21px —— 这是**想要的**
   （图标不该撑高行盒），没有为了维持 3px 去写 `line-height: 24px` 那种裸值。
底栏那 7 个按钮同时补了 `aria-label`（渲染黄金对"有真元素孩子的容器"取 aria-label 当文字列 ——
不加的话那 7 行的文字列会变空，"今日/任务/…"这些标签就从黄金里消失了）。

## 2. 图表规范（T-G55）：让一致性门**看得见图表**

**关键结构事实**：一致性门（`tools/style_audit.py`）**只读 `app.css`** —— 它**结构上看不见任何 SVG**，
所以图表里写死的 `stroke-width` / `r` / `rx` / `font-size` / `opacity` 一直没人管。规范要能被门看见，
就必须**下沉成类**。做了 8 个：`.chart-grid` / `.chart-axis` / `.chart-label` / `.chart-line` /
`.chart-area` / `.chart-mark` / `.chart-cell-off` / `.chart-cell-on` / `.chart-fill-soft`（+ 环的 `.chart-ring`）。
颜色一律用**已有令牌**（`--border` / `--muted` / `--accent` / `--panel-2`）；标记里只留**几何**
（`x/y/d/points/w/h/cx/cy` —— 那是数据不是样式，T-G43 定的口径）。顺带把那个**已 0 引用**的死类
`.cell-off` 收编成"空格"的语义类。

**一处有意的 1px 变化**：雷达/热力图的轴标签 10px → `var(--fs-xs)`（11px）—— 10px 不在字号档位上，
"多出来的一档"就是这类东西。

## 3. 真缺口（本卡最值钱的一件）：习惯热力图"画 53 周、只给 90 天"

前端按 **53 周 × 7 天**铺日历、文案写「近一年打卡」，而后端 `core/feedback/feedback.py` 的
`list_habits` 只回**近 90 天**（13 周）→ **左边 3/4 永远没有数据**，看着像"这个人三个月前才开始打卡"。

修法：`HABIT_HEATMAP_DAYS = 371`（= 53×7，与前端铺的格子逐个对齐），**只放窗口** ——
算法、接口形状、`streak` 一个都不动；上界与 `core/insights.py` 的 `MAX_HEATMAP_DAYS = 400` 兼容。
**机器证明**（`tests/test_insights.py::test_list_habits_logs_window_matches_the_53_week_heatmap`）：
200 天前的打卡**要在**、370 天前的**也要在**、400 天前的**不给** —— 窗口两端都钉住了。

## 4. ★ 一处**回落**：子任务把三句数字口径"删了"，而用户选的是「≤8 字」

图表那张卡在"空态/口径统一"里顺手删掉了三句**数字口径解释句**（环下那句、分组图那句、学业 vs 自学那段），
并把测试改成"这三句不许出现"。**这跟用户的选择相反**：2026-09-24 用户在「也全删 / ≤8 字 / 留着」里
选的是 **≤8 字**（`复盘/新窗口交接卡.md` 记着）。落地时改成短句：

| 位置 | 原来是 | 现在 |
|---|---|---|
| 今日完成度环下 | 只统计今天的清单与今天完成的，不翻旧账。 | **只算今天** |
| 统计页「学业 vs 自学」 | 手动投入不参与这张图。这里只如实对照，不做「学业该占多少」的建议。 | **手动投入不计入** |
| 统计页「投入分布（按任务分组）」 | 任务可属多个分组，各组之和可能大于总投入；未绑定任务的专注不计入分组。… | **任务可属多组** |

同步改了三处钉着长句的地方：`tools/ui_flow_check.mjs` 第 ⑥ 条流（改认短句 + 保留"不替人下判断"那条反向断言）、
`tests/test_web_frontend.py`（长句进"不许出现"清单、短句进"必须在"清单）、以及 6 份黄金。
**这条教训进地图 §6**：换人（或换 agent）做同一张卡时，"删掉"与"改短"是两条不同的路，
**用户选过的那一档要写在卡的 gaps 里**，不然下一只手会替他做另一个决定。

## 6. 没做（如实记）

① **不给折线图/热力图新增网格线与刻度** —— 那是"看得见的变化"，要单独出预演图给人看（候选机制现成）；
② 热力格子的 `rx: 2.5` **没并进圆角档位**（最小档是 6px；11px 的格子上 6px 会变成药丸）——
   它现在至少住在 CSS 里、一致性门看得见（"格子的圆角"是一条**有意的例外**，不是漏网）；
③ 暗色主题仍没有渲染基线（渲染层只采亮色，老账）。
