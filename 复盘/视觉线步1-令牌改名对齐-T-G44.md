> `T-G39` 已经替用户定了「**改**」，但把它排在"视觉线第 1 步、要用到这张表的时候一起做"。

## 1. 一句话结论

**颜色令牌改用 workbench 的名字（118 处替换），值一个没动；尺度令牌刻意不跟，理由写进映射表。**
唯一的例外是 `--accent-soft` **并进了 `--panel-2`**（它名不副实，T-G26 就记过）。
证明：42 份渲染清单**逐行一致**，只有 24 行（进度条槽）的颜色从 `#f1f5f9` 变成 `#eef2f7`。

**为什么值得做这一步**（它本身看不见任何变化）：后面每一步都要照 workbench 的规矩写
（`--panel-2` 当 hover 底、`--accent-weak` 当选中底、`--border` 做层次），
名字对不上就得在脑子里做一次翻译 —— 而"翻译"是漂移的开始。改完这一步，
**照着包的规则读我们的 CSS，读到的就是同一批名字**。

## 2. 映射表（进 `docs/specification/nonfunctional.md` 的 SR-NF1，不另立文档）

| 我们（新名） | workbench | 说明 |
|---|---|---|
| `--bg` / `--panel` / `--panel-2` | 同名 | 页面底 / 卡片 / 更浅一档（原 `--card` / `--surface-2`） |
| `--border` / `--border-strong` | 同名 | 原 `--line` / `--line-strong` |
| `--ink` / `--muted` | 同名 | 正文 / 次级（原 `--text`） |
| `--accent` / `--accent-ink` | 同名 | 强调色 / **它上面的字**（原 `--accent-on`） |
| `--accent-N` / `--accent-N-ink` | 包无预设 | 6 个预设 + **各自**的 ink 色（原 `--accent-N-on`） |
| `--ok` / `--danger` | 同名 | 状态色，值跟包（T-G42） |
| `--toast-bg` / `--toast-ink` | 包不管 toast | 唯一一处包没覆盖的语义（原 `--text-on-dark`） |
| 尺度 `--sp-*` / `--r-*` / `--fs-*` | 包：6 档间距 / 3 档圆角 / 6 档字号 | **刻意不跟**：我们是包的超集（11/5/9 档），且 `--sp-2`=6px 这类值包没有对应。收敛到包的网格属步 2/3 |
| `--shadow` / `--shadow-rgb` | 包只有 `--shadow-1`（**只给真浮层**） | **待定**：我们把阴影用在卡片上，而包的规矩是"层次=1px 边框"。留到步 2「层次语言」定 |

**为什么"尺度不跟"不是偷懒**：把 11 档间距砍成包的 6 档、把 5 档圆角砍成 3 档、
把 9 档字号砍成 6 档 —— 那是**改视觉**（而且是改得很狠），必须与"层次语言/排版节奏"
一起做、一起给你看。把它们塞进一次"改名"里，就变成"顺手改了版式还不说"。

## 3. 机械活怎么保证不出错

1. **长的先换**：`--text-on-dark` 必须在 `--text` 之前换，`--line-strong` 必须在 `--line` 之前，
   否则前者会被后者咬掉一半（脚本里写死顺序 + 正则加 `(?![\w-])` 右边界）。
2. **构造出来的名字单独抓**：`f"--accent-{idx}-on"` 这种**拼出来**的名字不会被字面替换抓到 ——
   它是靠跑测试抓出来的（`contrast_audit：令牌区里没有 --accent-1-on`）。
   教训：**"全仓替换"永远要配一次真跑**，替换脚本自己说"干净了"不算数。
3. **证据指针一起改**：台账里两条 `text:src/web/app.css::…` 断言指着旧名（T-G27 的
   `--toast-bg: var(--surface-2)`、T-G39 的 `--accent-2-on: #000`）—— 不改成新名，
   `audit` 门会红（这就是"证据会烂"那条铁律在起作用）。
4. **历史文本不改**：`复盘/` 与台账里的**历史叙述**、两份 baseline 的销账记录，
   保留旧名（它们记的是当时的事），并在 `contrast_baseline.toml` 顶上写明
   "这里用的是当时的名字 + 映射表在哪"。

## 4. 唯一一处有意的变化：`--accent-soft` 并进 `--panel-2`

`--accent-soft` 的值是 `#f1f5f9` —— **一个中性灰**，名字却写着"强调浅底"
（T-G26 §4-2 当场记过"名不副实"）。T-G42 之后它只剩一个用处：**进度条的槽**。
而 `--surface-2`（`#eef2f7`）干的正是同一件事（更浅一档的底），包那边这一档就叫 `--panel-2`。

→ 合并成 `--panel-2`（值取 `#eef2f7`），**同一件事不留两种写法**。
代价：进度条槽的背景色淡一档（`#f1f5f9` → `#eef2f7`，24 行黄金）。这是**改动**，
所以逐行点名（见 §5），不混在"改名零变化"里。
