# 复盘 · 长任务执行协议（自动执行 + 步骤级 checkpoint）

> 时间：2026-09-18
> 来源：本窗口与用户的对话要求。
> 性质：工作协议 + 能力边界记录；不是产品规格。
> 结论：采用**模式 A**——单线程主控 + 执行，自动执行已授权；**不采用**「我直接 spawn sub agent」。

---

## 一、用户原始要求（对话还原）

1. 为支持长任务，执行时必须按工程管理文件走：`specification/conventions.md` → `contracts/` → `ACCEPTANCE.md` → `CODING_GUIDELINES.md`，并维护 `复盘/` 与 `交接-重构进度.md`。
2. 最初要求：「上下文超过 500K 时自动检测并更新复盘/交接」。
3. 后续讨论替代方案：改为**步骤级 checkpoint**；或「我作为主控，把任务分发给 sub agent」。
4. 最终授权：**先执行第 1 步重构，授权自动执行**；执行任务前先写复盘记录本次对话要求；走完第 1 步后说明第 2 步是什么。

---

## 二、能力边界（诚实声明）

| 事项 | 能力 | 说明 |
|---|---|---|
| 步骤级 checkpoint | ✅ | 每完成一个契约级操作 / 一次提交即写快照 |
| 本回合内自动执行 | ✅ | 读文件 → 改 → 跑质量门 → 提交 → 回写复盘/交接 |
| 跨回合 / 后台自唤醒 | ❌ | 回合结束即停止；需要用户或外部调度器发下一条 |
| 真实 spawn sub agent / 新窗口 | ❌ | 本环境只有 PowerShell 工具，无 Task/Agent/API；不能创建会话 |
| 实时监控其它窗口/子代理 | ❌ | 无调度接口；只能接收它们回传的分支/提交/测试结果并验收 |
| 自动检测 500K 上下文 | ❌ | 拿不到自身 token/字符计数；平台截断/压缩不由我控制 |
| 工作区外写入 / worktree | ❌ | 沙箱写权限仅限工作区内；可考虑工作区内 `.worktrees/` |
| 联网 | ❌ | 工具无互联网 |

> 因此：**「500K 自动检测」由「步骤级 checkpoint」替代**；主控/子代理的真实分发需要外部执行器，本文档先把接口与协议定好。
---

## 三、模式 A：单线程主控 + 执行循环

```
① 读工程管理入口（协议 + 交接快照 + 当前任务卡）
② 读当前任务相关的 conventions / contracts / ACCEPTANCE / implementation
③ 实现（最小侵入、不改范围外）
④ 跑质量门：pytest / ruff / mypy / check_layers / 护栏自测
⑤ 提交（Conventional Commits）
⑥ 写步骤级 checkpoint（复盘 + 交接快照）
⑦ 判断下一步；若跨窗口，输出新窗口开场白
```

---

## 四、停止条件（只在这些点请示用户）

- 破坏性 / 不可逆操作（删数据、破坏性 schema 变更、force push、改历史）。
- 需要产品决策或改 `conventions.md` / `contracts/` / `ACCEPTANCE.md` 的横切规则。
- 超出当前任务卡范围，或需要引入新依赖 / 联网 / 外部服务。
- 质量门红且原因不明确、修复方案有分叉。
- 发现与工程管理文件冲突、或文档与代码出现新的不一致。
