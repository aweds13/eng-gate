## B 件：`tools/wb_status.py` 对畸形 log 的防御

**为什么**：台账 `T-G96.gaps` 边界①：「`wb_status.parse_events()` / `turns_seen()` / `tool_signatures()` 在 `message` 不是 dict 时仍会抛……本卡白名单不许碰 `tools/wb_status.py`」；`复盘/看门狗护栏补强-T-G96.md:146`：「真要修得动 `wb_status.py`（另立卡）」→ 本卡就是那张卡。

**改法**：新增 `_message_of(event)`：`message` 缺失 / `None` → 空对象（**老口径不变**，当没有）；是 dict → 原样；是字符串 / 列表等 → 返回可渲染的坏行「`message 不是对象（str/list）…`」并计 `unknown_events`（认不出来的一行也不丢）。`parse_events()` 的 assistant / user 两分支改用它 —— 不再抛 `AttributeError`。

**真机证据（先红 → 后绿 → 突变 → 还原）**：四条新用例（用真实事件形状 `{"type": ..., "message": ...}`）：

① `test_message_is_a_string_does_not_crash` ② `test_message_is_a_list_does_not_crash`
③ `test_message_none_behaves_like_before` ④ `test_message_missing_behaves_like_before`
