# 复盘 · 界面缺陷：静态文案里的 `**重点**` 原样显示成星号（T-G11）

> 时间：2026-09-23。任务卡：**T-G11**（做 T-G10 时顺手查出并登记的界面缺陷）。
> 提交：见 `git log`（`fix(web): …`）。
> 一句话：**界面上写了 30+ 处 `**重点**`，但它们一个都没变成粗体 —— 用户看到的是字面的星号。**

---

## 一、缺陷是什么，为什么一直没人发现

`noteHTML()` 会把文字里的 `**x**` 转成 `<b>x</b>`，**但它只用在"后端给来的文字"上**
（`${noteHTML(sync.note||'')}` 这类）。而 `index.html` 的**静态模板文案**里，
大家习惯性地也写了 `**x**`（因为同一份约定：`**` = 重点）—— 那些没人转，
浏览器就把星号原样画出来了。

**为什么测试没抓住**：字符串护栏只查"片段在不在"，`**不计债**` 在不在源码里是**在**的；
假 DOM 探针只查"渲染有没有抛错 / 关键片段在不在"——`**` 是 HTML 里的普通文本，谁都不觉得它有问题。
**为什么我也没一眼看出来**：本轮之前它已经躺在代码里很久了（多条卡片陆续加的），
而且每一处单独看都很"顺眼"（写文档的人以为那是强调）。

**怎么发现的**：做 T-G10（手机离线记）时，我给离线页写新文案，
顺手在假 DOM 探针里加了一段**临时诊断**（把渲染结果里的 `**…**` 数出来打印），
结果发现**不是我新加的那些**：`today` / `tasks` / `planned` / `habit` / `setting` 五个视图里
早就有 —— 于是登记成 T-G11，**没有混进 T-G10**（那次自己新加的文案全部用 `<b>`）。

## 二、修了什么

- **按"渲染结果"定位**：临时诊断列出了每处星号，逐个定位到源码里的模板/字符串，改成 `<b>…</b>`。
  共改 **19 处**（18 处整段可扫 + 1 处被 `${afterDays}` 打断的「完成满 N 天自动收入」）。
- **注释里的不动**：`**` 在 JS / HTML 注释里大量出现（那些不影响界面），保持原样 ——
  这也是本次的教训之一：**按行 grep 会把注释和文案混在一起**（我第一次写的行级分类器就判错了，
  见 §四）。
- 新增的两处之外没有动任何逻辑、样式、接口。

## 三、护栏（这一节是本次真正的产出）

**两层查，都进 `tools/ui_dom_probe.mjs`（门禁里跑）：**

1. **按源码查**（`scanBoldInSource`）：用状态机把脚本里的**字符串字面量**（含模板串）扫一遍，
   出现 `**` 就报 **行号 + 片段**。它不依赖桩数据，注释天然被跳过。
   - 为什么不用 grep：注释里也有 `**`；
   - 为什么不用"行级判断"：块注释跨行，我第一版就判错过（详见 §四）；
   - 为什么不用正则一把梭：`/…/` **正则字面量里也有引号**（`esc()` 里的 `/[&<>"']/g`），
     会把扫描带进字符串态再也出不来 —— 所以状态机里要**判断 `/` 是除号还是正则**（看前一个有效字符）。
2. **按渲染结果查**：把 13 个视图 + 详情（只读/编辑态）+ 今日明细展开都渲染一遍，
   扫输出里有没有 `**…**`。这一层查的是**用户真正看到的东西**，
   能覆盖"源码里被 `${}` 打断所以扫不到"的情况（比如那个「完成满 N 天自动收入」）。

两层都红了才算问题；**任何一层红了 → 门禁红 → 不许提交**。

## 四、踩的坑（都记下来，免得下次重复）

1. **"grep 整个文件"不可靠**：`**` 共 96 行，绝大多数在注释里。
   我第一版写的行级分类器把**跨行块注释**判成了代码 → 报了 95 处假阳性。
2. **写状态机比想象的容易翻车**：模板串（`` ` ``）里的 `${…}` 要**回到代码态**、
   表达式里还有对象字面量（`${{a:1}[k]}`）—— 我第一次用"见到 `}` 就回模板"，
   被对象字面量提前弹栈，后面整段错位（报出 102 处假阳性）。
   最后用**一个统一的栈**（`'{'` 与 `${` 都压栈，`}` 看栈顶决定弹哪个）才稳。
3. **正则字面量里有引号**：`esc()` 的 `/[&<>"']/g` 会让朴素扫描器把后面的代码当成字符串 ——
   必须判断 `/` 是除法还是正则起始。
4. **行号漂移**：扫描器给的行号和编辑器行号差十几行（因为按"字面量内偏移"回推行号），
   所以修的时候我是**按片段 grep 定位**的 —— 教训：**报片段比报行号更有用**。

## 五、做不到 / 边界

- 两层护栏覆盖的是**当前探针桩数据能渲染到的分支**；如果有分支在探针里不渲染
  （例如「正在做」栏为空时那段文案），只靠第 2 层会漏。
  第 1 层（源码字符串）能补上大部分 —— 它不依赖桩，但它对**被 `${}` 打断**的 `**…**` 会漏。
  **两层合起来仍有缝**（目前已知的那处已经被这次一并修掉）。
  真要 100% 覆盖，得给模板串做 AST 级解析（`node` 里没有现成的解析器可用）——
  这属于"成本明显大于收益"，**如实写在这里**，不做。
- 界面好不好看、粗体是不是该粗 —— **只能人眼过**（本环境没有浏览器）。
  这一处改动只影响"星号有没有画出来"，不影响任何数据与逻辑。
