| # | 缺口 | 它怎么复现的 |
|---|---|---|
| 1 | ★★ **两个假护栏**：`run_worker` 里那两行**接线**（`lines=snapshot` 喂看门狗、`inflight=` 喂心跳）**单测覆盖 = 0** —— 删掉它们，**全套 50 条仍全绿** | 报告 §2.2 的 M5 / M6 |

## §2 口径（要改成什么）

### 2.1 把"接线"钉进单测（★ 本卡最重要的一条）

现状：`tests/test_wb_dispatch.py` 里那条"真掐"用例用的 `_stub()`（约 302–315 行）吐的 `tool_use`
**既没有 `id` 也没有 `__timestamp`** → 它走的是"认不出在飞"的保守路径，**恰好绕开了新判据**。

**你要做的**：新增用例**经过 `run_worker`**（不是只调纯函数）证明接线真的生效：

- **对偶两条**：① 桩吐**带 `__timestamp` 的 `tool_use`** + 静默超过 `--stall-seconds` → **不许被掐**；
  ② 桩吐"已配对完成、无在飞" + 静默超过阈值 → **必须被掐**。
- ★ **验收的硬标准**：把 `run_worker` 里 `lines=snapshot` 删掉 → **用例①必须红**；
  把 `inflight=` 删掉 → 心跳那条**必须红**。**这两个突变的原始输出必须贴进回报**
  （红 = 判据有牙；不红 = 你还没钉住）。
- **不许真睡**：用例总时长控制在几秒内。用 `--stall-seconds` 小值（如 2~3 秒）+ 一个会短暂
  sleep 的桩命令即可（`python -X utf8 -c "import time; time.sleep(3)"` 这种 1~3 秒的桩可以接受，
  **别写 500 秒**）。卡 §7.3 那条"别把真睡写进 tests"指的是**长睡**，几秒的桩是本卡要求的。

### 2.2 畸形 log 不许让看门狗失效（两层防御，都要）

- **第一层**：`_tool_use_blocks` / `_tool_result_blocks` 里对 `message` 做**类型判断**
  （不是 dict 就当没有 `content`）；同理 `content` 不是 list、`input` 不是 dict 等既有守卫**保持**。
- **第二层（更重要）**：在 `run_worker` 的**轮询循环**里给判据调用加兜底 ——
  **判据自己抛异常时，不许让看门狗失效**：最坏也要"当成没有在飞 / 没有耗时数据"继续盯，
  并把这次异常**如实记进心跳或判决**（别静默吞掉）。
- **用例**：把报告 §3.2 那 10 种畸形形状做成**参数化**用例，逐条断言"不抛异常 + 退回保守行为"。
  ★ 其中至少两条要**经过 `run_worker` 的循环路径**（证明第二层兜底真在）。

### 2.3 自适应阈值**封顶**

新增常量 `ADAPTIVE_MAX_SECONDS`，值 **3600**（60 分钟），然后
`stall_threshold_seconds()` 的返回改成 `min(max(base, FACTOR * longest), ADAPTIVE_MAX_SECONDS)`。

★ 注意两个边界：
- `BUSY_STALL_SECONDS = 1800` **必须仍生效**（封顶 3600 > 1800，别把在飞那条压下去）；
- **没有历史长调用时老口径 480 秒一字节不变**（报告 §2.1④ 验过，别破坏）。

**用例**：历史最长 3600 秒 → 阈值**恰好 3600**（不是 9000）；在飞 + 无历史 → 1800；
无在飞 + 无历史 → 480；历史最长 240 秒 → 600（2.5 倍仍生效）。
★ 在复盘里写清**封顶值 3600 是主控定的口径**（可被质疑），理由：实测三份真 log 最长一次调用是
**389.3s / 81.2s / 69.1s**，60 分钟已是本项目最长门禁的约 5 倍。

### 2.4 `kill_tree()` 的乱码（小，顺手）

`subprocess.run(..., encoding="utf-8")` 读 Windows `taskkill` 的 **cp936** 输出 → 乱码。
改成**按系统区域编码解 + `errors="replace"`**（别让它抛），语义仍是"掐完返回一句人话（原因照实说）"。
（**只动解码这一处**，别改掐进程的逻辑。）

### 2.5 ★ 每轮留痕不许互相覆写（主控在复核卡自己那一轮撞到的）

复核卡 `R-1969b46` 跑了**两轮**：第 1 轮 log 有 **221 行、没有 `result` 事件、末事件是 `user`**
（CLI 中途死了），`finish_verdict()` 判成"被打断" → `--retry` 带**同一会话**续跑 → 第 2 轮
`subtype=success` 正常收工。**安全网生效了**，但事后**查不出第 1 轮为什么断**：

- `wb-R-1969b46.verdict.txt` 只有**一份**，写的是第 2 轮的判决 —— **第 1 轮的判决被覆写了**；
- `wb-R-1969b46.stderr.txt` 是 **0 字节**；log 里也没留"最后事件类型 / 退出码 / 断在哪一行"。

**你要做的**：让每一轮**各自留痕、不互相覆写**，并且断流时**留下能查的线索**：

- 判决文件按轮落（第 2 轮起落成 `wb-<卡>.r2.verdict.txt` 这种，或统一带轮次后缀）——
  ★ 注意：`--status` 要**仍能读到最后一轮**的判决（别改成主控读不到）；
- 摘要文件（如果另一张卡已经落了 `wb-<卡>.report.md`，就用同一套命名口径）同样按轮落；
- 每轮要能查到：**那一轮的退出码 / 是不是有 `result` 事件 / 末事件类型 / log 行数 / stderr 末 5 行**。

**用例**：钉住"第 2 轮的判决**不覆写**第 1 轮的判决"+"`--status` 仍指向最后一轮"。

### 2.6 ★ 别在 Windows 上留下"看着像还在跑"的空控制台窗口（用户实际被它迷惑过）

**用户实测反馈（2026-09-26）**：他看到任务栏里有一个窗口，标题是
`C:/Users/example\.workbuddy\binaries\node\versions\22.22.2-3\node.exe`，**里面什么都没有**，
于是问"这是什么、怎么没内容"。主控查证：

- 那个窗口是 `WindowsTerminal.exe -Embedding`（Windows 11 的**默认终端宿主**），**没有活着的子进程**；
- 它显示的是**最后一个跑完退出的控制台程序** —— 而那个程序正好是 WorkBuddy 带的 node.exe
  （= 我们派活/前置检查时跑的 CLI），跑完就走了，所以**标题留着、内容是空**。

**为什么这是要修的问题**（不是纯审美）：这套东西是给"**过夜无人值守**"用的 ——
一个**空窗口配着一个工人进程的名字**，会让人（和下一个主控）以为"它还在跑"或"它卡住了"。
而且 `--detach` 用的是 `DETACHED_PROCESS`，**没有** `CREATE_NO_WINDOW`，
Windows 11 会把控制台程序转交给默认终端宿主 → 该弹的还是会弹。

**你要做的**（都很小）：

- 派活器自己发起的那些 `subprocess`（前置检查里的登录自检 `auth_ok()`、`node --version` 之类的探测）
  加 `creationflags=CREATE_NO_WINDOW`（Windows 上），别借终端宿主弹窗；
- `spawn_detached()` 在 Windows 上把 `DETACHED_PROCESS | CREATE_NO_WINDOW` **一起**给
  （★ 确认这**不会**影响它脱离窗口后继续跑 —— 这正是 `--detach` 的命根子，**必须真机验一次**：
  用 `--detach` 派一张极小的只读卡，确认子进程**照样活过父进程退出**且**没有新窗口**）；
- **控制台真跑不出窗口**是不好单测的，所以这条以**真机证据**为准：贴出"没弹窗 + 子进程仍活着"的实测。

★ 边界：**不许**为了让窗口不弹而改坏 `--detach` 的"活过主控窗口"语义（那条比窗口重要）。

## §7 已知的坑

1. 一律 `python -X utf8`；pytest 要 `$env:PYTHONPATH="$PWD\tools\sandbox_shim"`。
2. ★ 本仓 `pyproject.toml` 的 `addopts` **自带 `-q`** —— 命令行再叠一个 `-q` 会把**末尾统计行吃掉**
   （复核报告 §2 踩过）。要看 `N passed` 就别叠第二个 `-q`。
3. 事件时间戳键是 **`__timestamp`（两个下划线）**；回合数用 `turns_seen()`，别自己数。
4. `print` 在非 TTY 下是**块缓冲**（另一个卡正在修）—— 后台 job 输出看着空，**别据此下结论**。
5. 读 `gates/diag` 里的文件一律**显式 UTF-8**（`-Encoding utf8`），否则中文乱码、看着像文件坏了；
   ★ 顺带：**`gates/diag/复核-1969b46.md` 是复核报告，务必完整读**（它是你这一卡的输入）。
6. TOML 里**不许出现裸 ASCII 双引号**（台账 `gaps` 最容易踩）—— 用「」。
7. 提交消息用 `git commit -F gates/diag/msg-T-G96.txt`（PowerShell heredoc 会把反引号搞坏）。
