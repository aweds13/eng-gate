# 外包派活脚本（T-G82）—— 把"派活"这件事变成**一条有护栏的命令**

> 一句话：派活 = **别人替我改工作区**。手工敲命令有三个坑（脏工作区、没登录白等一轮、
> log 被覆盖），所以 `tools/wb_dispatch.py` 把四道检查放在**真跑之前**，任何一道不过就**不派活**、
> 并说清原因；默认还是 **dry-run**（只打印将要执行的命令）。
> 2026-09-26；分支 `line/impl-v1`；台账 `T-G82`；**`src/` 一行没改**。

---

## §1 它解决的问题（三个坑都是真的）

| 坑 | 后果 | 现在怎么办 |
|---|---|---|
| 在**脏工作区**里派活 | 工人和我的未提交改动混在一起，事后分不清谁动了什么 —— 「一写一读」当场失效 | `git status --porcelain -uno` 非空 → **拒绝**，并把是哪几个文件说出来（未跟踪文件不算：那两个是别的窗口放的） |
| **没登录**就派活 | 白等一轮，只拿到一句 `Authentication required`（T-G80 实测） | 真发一条极短请求做**登录自检**，认出那句就拒绝并提示「去 TUI 敲 `/login`」 |
| 派活不留痕 / 覆盖上一轮 log | 之后没人说得清它到底干了什么 | 输出固定落到 `gates/diag/wb-<卡号>.jsonl`；已存在就**拒绝**，要覆盖得显式 `--force` |

第四道：`--spec` 指的**卡规格文件必须存在** —— 不许凭记忆派活（本项目的规矩：任务先落成文件）。

## §2 用法

```powershell
# 默认 dry-run：四道检查照跑 + 打印将要执行的命令（不派活）
python -X utf8 tools/wb_dispatch.py --card 001 --spec 复盘/外包卡-001-独立复核T-G79.md

# 真派活：跑完自动用 tools/wb_status.py 把时间线印出来
python -X utf8 tools/wb_dispatch.py --card 001 --spec 复盘/外包卡-001-独立复核T-G79.md --execute
```

- `--model` 默认 `deepseek-v3-2-volc`（用户 2026-09-26 定的那一档）；
- 派活命令固定带 `--output-format stream-json`（实时留痕）、`--no-session-persistence`、`-y`；
- 开场白**写死在脚本里**：读三份协议文件 + `复盘/外包-卡表与规矩.md` + **这一张卡的规格** ——
  不是"随便一句提示词"；
- 退出码：`0` 过（dry-run 或工人正常结束）/ `2` 前置检查没过 / `4` 工人自己失败（这一轮不算数）。

## §3 边界（不假装）

- ★ **`--execute` 那条路还没在真登录下跑过**（CLI 未登录，见 T-G80）—— 被验证过的是
  **四道前置检查与命令拼装**（`tests/test_wb_dispatch.py` 9 条），跑完渲染那条用假 runner 钉的。
- 它不管工人的**内容质量**（那是主控复核的事），也不替工人写卡规格。
- 它不检查工人有没有偷偷提交（那要靠复核：`gates/last.json` + `git log` + audit）。

## §4 一句话教训

> 凡是**把工作区交给别人**的动作，护栏都要放在**动作之前**：
> 事后发现"工作区脏了 / 白等一轮 / 痕迹被盖了"，代价都比提前检查一秒大得多。
