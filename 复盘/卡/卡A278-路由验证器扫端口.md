# 卡 A278 —— 路由验证器扫端口：200 但非 JSON 的端口要跳过

## 现象

`tools/verify_panel_routes.py` 不带参数扫本机所有 LISTENING 端口，取**第一个回 200** 的
`/dsh-panel/stack-status` 当 GUI，然后断言三条路由。本机同时开着别的 DSH 实例（端口
9012 等），它也对未知路径回 200（HTML 兜底）⇒ 脚本拿它当 GUI，三条全报「200 但解不出
JSON」，把真 GUI（54325/50124）判成红的。

## 根因

判据写的是「第一个 200 就 `break`」，而 200 并不代表「这是面板」——面板的判据是
**回的那份 JSON 里 `ok` 是 true**。

## 改法

扫端口时逐个探 `/dsh-panel/stack-status`：200 还要能 `json.loads` 且 `ok is True` 才认；
认不出就接着扫下一个。显式给端口时只探它，认不出就点名报红（不静默降级）。

## 判据

- `python tools/verify_panel_routes.py 50124` → 三条 200 + `[OK ] 运行时路由全绿`
  （`gates/diag/_routes_50124.txt`）。
- 无参扫全端口同样能命中真 GUI，不再被 9012 骗。
