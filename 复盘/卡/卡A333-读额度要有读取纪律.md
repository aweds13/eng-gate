## 判据（8 条）

1. **首次才等，且只等 3 秒**：`tools/pool_quota.py::read_policy(*, first: bool, last_read_at: float | None,
   now: float) -> str` 回三值之一 —— `first and last_read_at is None` ⇒ `"wait"`；
   `last_read_at is None or now - last_read_at >= REREAD_AFTER_S` ⇒ `"reread"`；
   其余 ⇒ `"use_cached"`。常量 `FIRST_WAIT_S: float = 3.0`（照 `routing.go:191`）、
   `REREAD_AFTER_S: float = 60.0`（照 `:589`）。`"wait"` 的含义是「**最多**等 3 秒，到点无论如何继续」，
   调用方不许把它当阻塞失败。
2. **`REFRESH_GAP_S` 沿用，不重定义**：`tools/pool_quota.py:66` 已有 `REFRESH_GAP_S = 30`（F93/A328 落的），
   本卡**只加注释**说明它与 `REREAD_AFTER_S` 是两套语义（一个「用户手动刷新抑制」、一个「后台重读阈值」），
   **不许**再写一个同名常量，**也不许**把 `REREAD_AFTER_S` 改成 `REFRESH_GAP_S` 的倍数而不写注释
   （设计稿明说混用会重演 magpie `#1295`）。
3. **时钟倒流按缓存**：`now - last_read_at < 0` ⇒ `"use_cached"`。既**不**当 `"reread"`（倒流的真因
   通常是时区/夏令时，重读会打穿供应商速率限制），也**不**当「刚读过所以永久缓存」（下次正常时间到了照样 `reread`）。
4. **作废一次只作废一条，且留痕**：`tools/pool_quota.py::mark_stale(card: str, model: str, *,
   now: datetime | str | None = None, root: Path = ROOT) -> None` —— 删掉 `gates/diag/quota-state.json`
   里 `cards[card][model]` 那一条（删完 `read_record(card, model)` 必须回 `None`），并在**既有的**
   `gates/diag/quota-refresh.json`（`REFRESH_REL`，`:59`）里落一条 `stale` 时间戳，
   key 用既有 `refresh_key(card, model)`（`:315`）。**不新增文件**；写盘走 `tmp` + `os.replace`。
5. **晚到的读数被丢弃且说话**：`tools/pool_quota.py::merge_latest(kept: dict, got: dict, seq: int) -> dict`
   —— 只有 `got` 的 `read_seq >= kept` 的 `read_seq` 才替换；`got.read_seq < kept.read_seq` ⇒
   **保留 `kept`** 并往 stderr 打一行「晚到的读数被丢弃」。两边的 `read_seq` 缺失时按「`got` 无序号 ⇒ 不替换」处理
   （缺证据就不许改事实）。
6. **探测必须留痕，且只留该留的**：`tools/pool_accounts.py::record_probe_result(ledger_path: Path,
   data: dict, rows: list[dict], *, now: datetime | None = None) -> None` —— 只写每个 `[[account]]`
   的 `[account.quota]` 的 `observed_at` 与 `samples`（`samples` 追加 `{"at": stamp, "kind": row["kind"]}`，
   **无 `reset_at`**，上限继续由 `save_ledger()` 的 `SAMPLES_CAP = 20`（`:48`）截）；
   **不写** `state`（`STATES` 是人工判定的五行，`:49`）、**不写** `approved_models`；`cmd_probe()`
   在 `--json` 与非 `--json` 两条出口**都要**调它一次。
7. **没探测过就还是不许填数**：`source == "unknown"` 的行若带 `amount` ⇒ `record_probe_result()` **拒写**
   并抛 `LedgerError`（照 `_check_account():166-170` 原话「没探测过就不许填数」；设计稿写 `:165-170`，
   实测 if 在 `:166`、报错串在 `:168` —— 已核），账本**一个字节都不变**。
   六结论码（`ok / skipped / uncertain / failed / not-supported / unknown-platform`，`probe_account():439-443`）
   **原样**进 `samples`，一条都不许压平。
8. **反向钉子**：在 `status()` 开头插一行 `probe_account(...)` 调用 ⇒
   `tests/test_quota_read_policy.py::test_reverse_status_never_touches_network`（`monkeypatch` 替
   `pool_accounts._get_json` 计数，断言调用数为 **0**）必须**变红**。`status()` 现在零网络、零 sleep
   （`grep -n "socket\|urllib\|requests\|httpx\|time.sleep" tools/pool_quota.py` 只回 `447: time.sleep(nap)`，
   在 `wait_until` 的循环里 —— **已核**），这条钉子就是防止「顺手让它去探一下」。

## 不许做

- 不许让 `status()` 发网络或 sleep —— 它的口径就是「四态（每次现算）」（`tools/pool_quota.py:189`
  小节标题；设计稿写 `:172`，实测是 `:189` —— 已核）。
- 不许把 `probe_account()` 的六结论码压成三分（`ok / failed / other`）：`uncertain` 与 `not-supported`
  是「不敢当结论」的两种不同原因，压平就丢了证据。
- 不许给 `probe` 加隐式节流而不告诉调用者：抑制时必须往 stderr 明说读了多少秒前的那一份
  （magpie 逐字 `"read %s ago: not asked again before %s have passed, shown as it was read\n"`，
  设计稿引 `:62-63`），静默返回旧值等于骗人。
- 不许把 `REREAD_AFTER_S` 设成 `REFRESH_GAP_S` 的倍数关系而不写注释（两套语义，混用重演 `#1295`）。
- 不许改六份 `PROTECTED_FILES`（`tools/pool/plan.py:45-52`：`docs/traceability.toml`、`docs/changelog.md`、
