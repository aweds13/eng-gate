## 你要做的

### 1. `tools/pool_mcp.py` 新增**两个写工具**（★ 只加这两个；既有六个只读工具的**语义与输出形状一个字都不许改**）

**`pool_dispatch(card, tree, spec?, model?, pool?, note?)`** —— 顺序**固定**：

1. **干跑**：`pool.guards` 三条 + `pool.registry` 的租约判据（**import 调用**，别 shell 出去）→ 有咬就**不派活**，
   把逐条原因**原样**回给调用方（`isError=true`），并附"怎么才能通过"。
2. **先占位**：`pool.registry.reserve(...)` → 占不上就停（★ 这一步是**并发安全**的关键：不能"先派活后登记"）。
3. **起工人**：`wb_dispatch.py ... --cwd <树的绝对路径> --lean --detach --execute`
   ★ **必须 `--detach`** —— MCP 工具调用不能阻塞几十分钟；派完立刻返回。
4. **起不来就回滚**：释放刚占的租约（`pool.registry.release`），如实报错。

参数**写死、不许透传危险项**：**不许** `--force`、**不许** `--allow`、**不许** `--no-preflight`、**不许** `--resume`；
`--model` 只许取 **`wb_dispatch.MODEL_WHITELIST`** 里的值（不在就拒），不给就用默认。
`spec` 不传时按 backlog 里登记的路径给（**仓库相对**即可 —— `--cwd` 那套会自动转绝对，见卡 103/T-G204，**别自己转两遍**）。
返回：`log` / `dispatch.log` / `pid` / **前置检查原文** / 租约 JSON / 一句"用 `job_status` 看进度"。

**`pool_cancel(card, reason?)`** —— 只取消**本机登记里那一条租约**的 pid：

- ★★ **先核对 pid 身份**：`tasklist /FI "PID eq <n>" /FO CSV` 拿到的**映像名**必须是 `node.exe` / `python.exe` 之一，
  否则**拒绝动手**，并把"人工怎么做"的**确切命令**印出来（pid 会被复用 —— 杀错树 = 杀掉别人的东西）。
- ★★ **绝对不许**用 `os.kill(pid, 0)` 探活：Windows 上 CPython 的 `os.kill` 走 `TerminateProcess`，
  那不是探活、那是**把人杀了**（见 `复盘/口径坑.md` 第 27 条）。判"还在不在"只许 `tasklist` 或日志心跳。
- 成功后：写 `gates/diag/wb-<卡>.cancel.txt`（谁 / 什么时候 / 为什么），并 `pool.registry.release`。

### 1.5 ★ 现成的 API（卡 108 / T-G205 **已落地**）—— 照它调，别另发明

```
pool.registry:  registry_path()                      # 主树的 gates/diag/pool-registry.json（TF_POOL_REGISTRY 可覆盖）
                reserve(card, tree, files, ...)      # ★ 先占位（并发安全就靠这一步）
                release(card)                        # 放租约（只放本卡）
                list_reservations(now=None)          # 活租约（死租约先被清掉）
                prune(now=None)  load()  save()
pool.guards:    tree_guard(tree, reservations, now=None)        # 一棵树一个写者
                domain_guard(files, reservations, now=None)     # 冲突域相交就拒（点名文件）
                lock_guard(card, tree, lock_body, *, root=None) # 门禁还在跑就不动手
                log_guard(path)                                 # 目标已存在 ⇒ 拒
pool.locks:     status_argv()  is_empty(body)  parse_entries(body)   # 锁的原文 → 结构化
tools/wb_registry.py:  list / check / reserve / release   （退出码 0=全过、1=被咬、2=用法错）
```

★ 用法（卡 108 §9 的交代）：**先 `reserve` 再起进程**；被咬就**逐条把 problems 报给调用方、不许绕**。
★ **同一张卡要重派**：先 `release(card)` 再 `reserve`（卡 108 裁定**不加隐式续租**）。
★ 门禁锁原文怎么拿：`pool.locks.status_argv()` 起进程（**只列不拿**）—— 这是本模块**唯一**可保留的
subprocess 之一（另一处是起工人）。

### 2. **六条不变量逐条对上**（在 `pool_mcp.py` 的模块 docstring 里列一张表："哪条谁判"）

| # | 不变量 | 谁判 |
|---|---|---|
| ① | 一棵树同时一个写者 | `pool.guards.tree_guard` |
| ② | 冲突域不许相交（域从 backlog 读，**查不到就拒**，别猜空域） | `pool.guards.domain_guard` |
| ③ | 门禁还在跑就不动手 | `pool.guards.lock_guard` |
| ④ | 内存闸 | **委托** `wb_dispatch.py` 的前置检查（★ **不许**在本模块再写一份内存判据 —— 那就是第三份真源） |

| ⑥ | 模型白名单 | `wb_dispatch.MODEL_WHITELIST`（硬闸门）+ `pool.models`（批准 ∩ 可用） |
