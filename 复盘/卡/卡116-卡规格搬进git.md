## 来路（用户当面问出来的缺口）

用户问：「**用 pool 工具处理任务 —— 为什么会处理你的任务，不是另一个 AI 的任务？你不应该把自己的记录放出去吗**」。

主控查实的**事实**：队列 `docs/workbacklog.toml` 在 git 里 ✅，规则（长任务协议 / 外包规矩 / 口径坑）与台账也在 ✅ ——
**但每张卡登记的 `spec` 指向 `gates/diag/卡NNN-*.md`，那个目录是 gitignore 的** ❌：

```
卡 108 … 文件在=True 进了git=False  gates/diag/卡108-号池写面①作业登记与守卫.md
卡 115 … 文件在=True 进了git=False  gates/diag/卡115-封存未跟踪清单判据.md
```

⇒ **队列不自洽**：另一个窗口 / 另一台机器拿到这份仓库，看得到队列，却**读不到"这张卡要干什么"**。
只能"处理主控这台机器的记录"。`gates/diag/` 下现存 **128** 份卡规格，**一份都没进 git**。
