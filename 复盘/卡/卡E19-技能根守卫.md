1. 2026-10-24 21:54 那次 `cordis.patch.yml` 被重写后，9 个软工技能（8 个 `pipe-*` + `softeng-manage`）从
   会话目录里整体消失；查下来是**预设切换**把 `skill-filesystem.customSkillDirs` 换成了另一个根
   （默认预设在 `:805` 用 `@dsh-agent-preset/skills`，`preset-softeng` 在 `:886` 用 `C:/Users/example/.dsh/skills-softeng`）。
2. 主控 2026-10-24 手工给默认预设那段追了一个根（`C:/Users/example/.dsh/skills-softeng`，62133 → 62181 字节），
   但**没有任何机器判据**守着它 —— 下次谁再应用一次策略，同样的静默丢失会重演。
3. `@michengai/dsh-skills-manager` 每次应用策略都会重排 profile 补丁，所以「人记得改」不是解法。

## 要做的事
新增 `tools/dsh_skills_guard.py`（只读，不去写别人的 profile）：
- 定位 profile 补丁：`%USERPROFILE%/.dsh/profiles/desktop/cordis.patch.yml`（可用 `--profile` 指定别的）。
- 解析出**每一段** `skill-filesystem` 的 `customSkillDirs`（含 `!!js …` 表达式那种，原样记下来，不展开）。
- 判据：**默认预设**（`customSkillDirs` 里出现 `!!js` 的那段）必须包含仓库 skills 根 `C:/Users/example/.dsh/skills-softeng`；
  其余预设若声明了自己的根，也报出来（只报不判）。
- `--check`：全绿退 0；缺就退 1，逐条打印「哪一段、当前根、缺哪一个」。
- 退出码与文案要和 `tools/check_skills_claims.py`（卡 G1）一致：不用 emoji 之外的花样，`[OK ]` / `[FAIL]` 前缀。

## 判据
1. `python -X utf8 tools/dsh_skills_guard.py --check` 在**当前** profile 上退 0。
2. 把 `--profile` 指到一份**删掉仓库根**的副本上，必须退 1，且报行里点名「默认预设」与缺的目录。
3. 文件不存在 / 解析失败：退 2，打印一句「判不了」——**不许**当成绿。
4. 只读：跑完 `git status`（或文件 mtime）不许变，profile 文件字节数不变。
5. 不写 `~/.dsh` 下任何文件；不自作主张改预设。

## 钉子（`tests/test_dsh_skills_guard.py`）

- 缺仓库根的副本 ⇒ 1 且报行含「默认预设」+ 路径；

- `!!js` 表达式原样保留（不许被当成路径展开成报错）。
