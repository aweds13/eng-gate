# 卡 E15 · 体检第 12 条：文书里反引号包住的 `.md` 必须解析得到（T-AG466）

## 现在疼在哪（实测）

1. `check_layers` 的 `check_link_integrity()`（`scripts/check_layers.py:166`）把 `docs/**/*.md` 里
   **反引号包住、以 `.md` 结尾**的每个 token 当引用核对（三基准：片段所在目录 / `docs/` / 仓库根 + 裸名 rglob）。
2. 我写的 `gates/diag/_text_TAG453.md` 的 changelog 段里，有一行把四处技能写成短路径
   （`README.md` / `pipe-card/references/dispatch.md` / `pipe-workbench/SKILL.md` / `pipe-land/SKILL.md`）。
   ② 的 `tools/pool/stage_card.py:296` 把这一段**原文照搬**成 `docs/changelog.d/T-AG453.md`，
   于是 `check_layers` 与 `check_layers_selftest` 双双红：
   `[FAIL] 引用断裂: docs\changelog.d\T-AG453.md 引用了不存在的 pipe-card/references/dispatch.md`（共 6 处）。
3. 代价：E7（T-AG453）**多烧了一趟全量门禁**（≈15 分钟），而这条错在文书写下的**那一秒**就能查出来。
4. `check_layers_selftest` 的「干净仓库应 PASS」样例因此也红，报 `实际: [info] 引用完整性：这次实际检查了 928 条引用（断链 6 处）` —— 它读的是真树，所以一条文书错会同时打红两道门。
