# 卡 121 —— 把任务栅栏接到外包面（MCP 的任务类工具）（T-G218）

**树**：`.wt/mcptask` ｜ **base**：`ac5968d` ｜ **提交**：★ **你不要 commit**（主控复核后提交）

## 来路（用户原话）

> 『然后呢，我在**外包程序的某个地方给一个板块的数个复数个任务**他们。**注册一个任务**，然后任务需要这些板块
> 下面的多张卡都完成了，并且发送了那个成功申请，然后集齐所有的成送申请再写。』

栅栏本体已经进 git（`tools/pool/task.py` + `tools/wb_task.py`，卡 119），但**外包面（MCP）里一个任务工具都没有**
—— 别的窗口 / 别的 AI 现在只能敲命令行，等于"**注册任务**"这件事还没接到外包程序上。本卡就补这一段。

## 做法（复用，不许另写一套）

1. **只读三个**（**不需要** env，永远列出；每条输出都要带机器可读块 —— `JSON_MARKER` 规矩见卡 117）：
   - `task_list`：所有任务一行（任务号 / 状态 / 成送申请进度 / 一句话 why）；
   - `task_status`：一个任务的详情（每张卡的**层**与**域**、交没交、history 尾部）—— 参数 `task`；
   - `task_pool`：待办登记表（还没定卡的活，按层）。
   ★ **一个字节都不许写**（卡 105 那条"跑一遍工作区不多出一个文件"的判据要能过）。
2. **写两个**（★ 只在服务端 `POOL_MCP_WRITE=1` 时**列出来** —— "存在性即授权"，卡 111 的规矩；
   每次调用还要 `arguments.confirm` **等于任务号**）：
   - `task_register`：给 `manifest_text`（整段预声明 TOML）**或** `manifest_path`，
     `confirm` 必须等于 TOML 里的 `id`；★ **复用 `pool.task` 的函数**（**不许 shell 出去**——卡 106 的规矩）；
   - `task_claim`：参数 `task` / `member` / `claim`（`success`|`failed`）/ `evidence` / `files` / `why`，
     `confirm` 必须等于 `task`；★ **域守卫照走**（`pool.task` 那条逐卡域检查），越界 ⇒ 回话里**点名**，绝不静默。
3. **钉子 `tests/test_pool_mcp_task.py`**（正反都要）：
   - 只读三个：回话带机器可读块 · **工作区不多一个文件**；
   - `tools/list`：**不设** env = 只读那些（9 个）· 设了 `POOL_MCP_WRITE=1` 才多出这两个写工具；
   - 写工具：`confirm` **不等于**任务号 ⇒ **拒**（回话说清为什么）· 没设 env ⇒ 当"没有这个工具"；
   - ★ 反例：`task_claim` 带**域外的文件** ⇒ **拒并点名**（守卫在 MCP 这条路上也不能绕）；
   - ★ 反例：`task_register` 的 `confirm` 与 TOML 里的 `id` 不一致 ⇒ **拒**；
   - ★ 反例：`task_status` 传一个**不存在**的任务 ⇒ 说清（不崩、不带假数据）。
