# 卡 A283 · 面板可用性（参数可写 / 禅道反代 / 号池派活 / 技能页子目录）

## 缺口

`tools/dsh_panel.py` 是挂在 Web GUI 上的只读面板（`--check` 断言三个座位都只 GET）。
用下来五处"看得见但用不上"：

1. **参数页只读**：能看到 `~/.dsh/settings.json` 的键值，但改不了 —— driver 只能开编辑器手改。
2. **禅道座位是空壳**：`zentao_gantt` 座位只给一个外链，内网禅道页带 `X-Frame-Options`，
   塞进 iframe 直接被浏览器拒掉；页面里的绝对路径（`/zentao/...`）也不落在面板前缀下。
3. **号池按钮不落地**：派活 / 放租约只有一个按钮，点了不发任何请求（`pool_plan` 只读面看得到、
   派活面走不通）。
4. **技能页只认顶层**：`listSkills()` 只扫 `skills/*.md`，`skills/<名>/SKILL.md` 这种子目录形态
   （本仓 `skills/` 里就有）整块漏掉。
5. **主题与排版各写一份**：颜色/字号散在模板字符串里，明暗两套对不上。

## 变更

只动 `tools/dsh_panel.py` 一个文件（其余是台账/changelog/交接三处记账）：

- **参数页可写**：新增 `writeSettings(updates)` —— 已知键白名单 + 逐键 clamp（数值夹到区间、
  字符串截断），写盘走 `.tmp` → `fs.renameSync(tmp, file)` 原子替换；面板侧新增
  `POST {SEAM_PREFIX}/settings`，`serveAction` 里只在这个路由上放行写。
- **禅道只读反代**：新增 `/dsh-panel/proxy/z/` 段 —— 转发 `zentao_gantt` 座位时抹掉
  `X-Frame-Options` / CSP 响应头、把页面里的绝对路径改写成面板前缀、cookie 原样透传。
  `zentao_gantt` 的 `url` 由外链改为反代地址（`tools/dsh_panel.py:1549`）。
- **号池派活/放租约**：新增 `POOL_ACTION_ROUTE = SEAM_PREFIX + "/pool-action"`，按钮走
  `POST /dsh-panel/pool-action?op=dispatch|release&card=<数字>`（`tools/dsh_panel.py:1729`），
  只透传 `op` / `card` 两个参数。
- **技能页子目录**：`listSkills()` 改扫 `skills/*.md` **加** `skills/<名>/SKILL.md`（`tools/dsh_panel.py:918`）。
- **主题令牌与排版**：颜色/字号收成一组 CSS 变量，明暗两套共用。

## 陷阱

- **写盘面只能走白名单**：`_strip_settings_writer()`（`tools/dsh_panel.py:2474`）在 `--check` 里
  会把 `writeSettings` 整段剥掉再断言只 GET；新增写路由必须同时满足「在白名单内」和
  「`.tmp`→`renameSync`」，否则自检要么漏检要么直接红。
- **反代不是转发**：只抹两个头 + 改写绝对路径，不缓存、不重试；禅道侧 5xx 原样透给 iframe。
- **派活只透两个参数**：`op`/`card`，其它查询串一律不往下传 —— 免得面板变成能改号池状态的通用入口。

## 影响面

单文件（`tools/dsh_panel.py`）+ 台账条目。面板仍是只读的三个座位 + 两条受白名单约束的写路由；
不动库、不动门禁判据、不动 `framework/`。
