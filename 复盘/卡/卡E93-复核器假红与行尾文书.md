# 卡 E93 —— 复核器两类「假红」+ E92 文书里的行尾事实更正（T-AG601）

> 台账号 `T-AG601` ｜ 分区 E ｜ 树 `.wt/E93` ｜ 层 判据层
> 依据：卡 198（⑧ 复核必须拿到收口链自己那份 `--allow`）、卡 210（放行集 = `allow` ∪ 派生物清单）、
> 卡 E92（云门禁泛用化落成 `2ede0fef`，它的 `gates/review/T-AG600.json` 恰好两条 problems 都在这两类里）。

## 要解决的问题

E92 落成后，`gates/review/T-AG600.json` 报了两条 problems。两条都不是本笔伪造，是**复核器自己的两类假红**：

1. **短 sha 字面比**（`tools/wb_review.py:check_gates_trailer_truth()`）：`matched = ok is True and rev == parent_short`
   直接比字面量。门禁在提交前跑 ⇒ `last.json` 的 `rev` 是**父提交**的短 sha，而这个仓 `git rev-parse --short`
   的长度会随仓库变大而变长：T-AG600 实测 `last.json.rev = "7194eaf4d6"`（10 位）vs `parent_short = "7194eaf4"`（8 位），
   两者 `git rev-parse` 都解析到 `7194eaf4d67b1bd9fb965081ecaab03440efb966`。同一笔提交被判成「伪造门禁结论」。
   同文件 `check_gate_evidence()` 早就有 `_resolve_commit()` 双向解析并写了注释说明这个坑，这条没跟上。
   同族假红在 `gates/review/T-AG431.json` / `T-AG443.json` 也有（全仓 `gates-trailer` 类 3 条、`gate-rev` 类 2 条）。

2. **派生物清单漏三个收口链自己造的文件**（`tools/wb_review.py:DERIVED_GLOBS` 只有 8 条）：
   收口链（`tools/pool/landing.py`）还会写 `docs/INDEX.md` 与 `docs/subsystems/pool/README.md`
   （`RECOUNT_DOCS`，由 `recount_derived()` 用 `scripts/gen_doc_index.py` / `scripts/gen_pool_readme.py` 重算）
   与 `docs/workbacklog.toml`（`flip_card_status()` 翻账；分片启用后是 `docs/backlog/*.toml`）。
   它们不在 `a.allow` 里（用户给的 `--allow` 只列本卡的交付面），于是每笔都报
   「有 N 个改动不在白名单里」。全仓统计 26 条同型：`['docs/workbacklog.toml']` 15 条、
   三件套 1 条（就是 T-AG600）、旧片段族 8 条、另一形态 1 条。

顺带一处**文书与现状不符**（E92 那笔自己写错的）：E92 落地时 `scripts/cloud/run_gate.sh` 被 Python 字节级脚本重写，
索引侧从 `i/-text` 变成 `i/lf`（工作区仍 `w/crlf`）。三处文书却写死「全 CRLF（`i/-text w/crlf`）」。
`i/-text` 本来就是「无属性 + blob 含 CRLF」的**推断态**（`.gitattributes` 至今没有任何 `*.sh` 规则），
改成 `i/lf` 是 `core.autocrlf=true` 下的正常态、与同目录 `profile.py` / `profiles/*.toml` 一致 ⇒ **行为零变化**。

## 判据（5 条，逐条可执行）

1. **短 sha 双向解析**：`check_gates_trailer_truth()` 在字面不相等时，用 `_resolve_commit()` 解析两边再比；
   解析出来同一个提交 ⇒ 不报 problem。`tests/test_wb_review.py` 里有一条用例覆盖「10 位 rev vs 8 位 parent」。
2. **清单对齐 `landing.RECOUNT_DOCS`**：`test_derived_globs_are_pinned_and_match_landing` 除了逐字钉住新清单，
   还断言 `landing.RECOUNT_DOCS` 的每一条都在 `DERIVED_GLOBS` 里（landing 换了派生物、复核这侧漏了要红）。
3. **反向钉子仍在**：不是收口链产物、也不在 `--allow` 里的文件（docs/rogue.md 一类，故意不存在的反例，故不加反引号）**仍然**被判「不在白名单里」——
   证明清单扩充没有把「什么都放行」写进来。
4. **不改 `tools/pool/landing.py`**：卡 198 的「传同一份 `--allow`」口径不动，`tests/test_wb_land.py::test_review_cmd_gets_landing_allow` 仍绿。
5. **三处文书与实测一致**：`复盘/交接.d/T-AG600.md`、`复盘/交接-重构进度.md`、`复盘/卡/卡E92-云门禁骨架与profile.md`
   里关于 `run_gate.sh` 行尾的句子不再声称 `i/-text`，且 `tools/sync_docs.py --check` 仍退 0（片段与汇总一致）。

## 直做

`tools/wb_review.py` 与三份文书都是 `i/lf w/crlf`（索引 LF、工作区 CRLF）：
改它们按文件自身 EOL 适配（`read_bytes()` → 判断 `\r\n` → 按行切 → 断言旧锚点命中恰好一次 → 替换 → 回写），
改完断言裸 LF = 0（`b.count(b"\n") - b.count(b"\r\n") == 0`），否则 `git diff` 会变成全文。
