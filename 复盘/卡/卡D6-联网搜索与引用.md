# 卡 D6 · 联网搜索与引用（走官方 tools/search + fetch，计次可见）

- task: T-DG006
- tree: `.wt/D6`
- risk: mid
- depends: D1, D4

## 问题

用户明确「联网搜索功能呢。这个还是要有的」。官方已给专用接口（`POST /v1/tools/search`、
`POST /v1/tools/fetch`），返回里 `snippet` 给 UI、`summary` 给模型、`rerank_score` 判质量，
按 **$0.75 / 1000 次成功请求** 计费。本卡要把它接好，并且守住一条切分：
**「搜外网」与「搜我的资料」是两个工具，不能合成一个按钮**。

## 改法

1. `ToolsClient.kt`：`search(query, count, need_content)` 与 `fetch(url)`；独立超时与重试；
   失败不冒泡到对话。
2. `SearchBar.ts`：输入框「联网」开关；模型给搜索意图时**弹确认**再执行（不静默搜索）；
   结果条列表（标题 + 域名 + `snippet`，`rerank_score < 1.5` 默认折叠）。
3. `Citations.ts`：回答里的引用角标 → 可点开（标题 + 域名 + 原文）；对不上时显示原始 URL。
4. 计次：每次成功搜索记一次；会话内累计显示「本次搜索 N 次，约 $X」（C11，< $0.01 显示「< $0.01」）。

## 判据

- 开「联网」问一个时效性问题 → 拿到答案且带可点引用；点引用看到原文标题与域名。
- 关掉「联网」重问 → 不产生任何 search 请求（抓包证明）。
- 界面上能看到「本次搜索 N 次，约 $X」。
- 断网下点搜索 → 「没搜到（网络不可用）」，对话继续，不弹崩溃。
- 余额不足/接口 5xx → 降级提示，消息不丢。
- 界面上「搜外网」与「搜我的资料」是两个不同入口（截图）。

## 证据

- 一次带引用回答的录屏 + 抓包（search 请求与响应摘要）。
- 计次显示截图。
- 断网降级的截图。

## 不做

- 不做「自动每轮都搜」（花钱，且多数问题不需要）。
