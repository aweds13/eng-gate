# 卡 F2 —— 索引机器化：`docs/INDEX.md` 与 `复盘/INDEX.md` 由脚本生成

> 台账号 T-AG450 · 分区 F（文档治理）· 依据 `docs/文档架构.md` 计划 v2 期 1
> 外部依据：`docs/research/文档治理-best-practice-调研.md` §Q11（"判不出来要报 skip 而不是 pass"）

## 要解决的问题

两份索引现在都是手写的：`复盘/INDEX.md` 自述"587 篇、约 284 万字"，一篇都没法核对；
`docs/` 根本没有索引，新窗口只能靠 `AGENTS.md` 的路由 + `ls` 瞎猜。
手写的索引必然过期 —— 这是调研里被反复点名的失败模式。

## 判据（五条）

1. `python -X utf8 scripts/gen_doc_index.py --check` 在索引与文件一致时退 0、不一致时退 1 并**点名哪几行不一致**。
2. 索引内容只来自文件头 frontmatter：`title` / `mode`（tutorial·howto·reference·explanation）/ `status`（active·superseded·draft）/ `owner` / `supersedes`；**没有 frontmatter 的文件归入「未标注」段**并在索引里如实计数（不猜、不补）。
3. 生成物带 `<!-- generated by scripts/gen_doc_index.py; do not edit -->` 首行；人改了但没跑脚本 ⇒ `--check` 必须红。
4. `复盘/INDEX.md` 的 L0 主题表与"历史与被推翻"段也由脚本算（按 frontmatter + 文件路径前缀），不复用手写数字。
5. 不许把索引当唯一入口：`AGENTS.md` 仍只做路由，索引是**第二层**（薄入口 → 索引 → 具体页）。

## 交付

- `scripts/gen_doc_index.py`（`--check` / 默认写盘 / `--stats` 打印各段计数）
- `docs/INDEX.md`、`复盘/INDEX.md`（生成物）
- `tests/test_gen_doc_index.py`（4 条：一致退 0 / 手改退 1 / 无 frontmatter 计入未标注 / 计数稳定）

## 验收

```
python -X utf8 scripts/gen_doc_index.py --check          # 退 0
python -X utf8 -m pytest tests/test_gen_doc_index.py -q  # 全绿
```

## 不许做

- 不许给 500 篇文档批量加 frontmatter（那是另一张卡的事，且容易做成形式主义）。
- 不许把索引做成"全仓 md 清单"——只收 `docs/**` 与 `复盘/**`，`gates/diag/**` 与 `.wt/**` 一律排除。
- 不许在索引里内联正文摘录（会立刻过期）。
