**判据 = 「两条 rev 解析成同一个提交」这一个布尔。** 它只有两种结局：相等 ⇒ 一个字都不说；不相等 ⇒ 一律出上面那句话。

所以「`f833d006` 与 `ebd39871` 差三个文件、全在台账」与「`f833d006` 与 `ebd39871` 差了整个 `tools/`」在复核器眼里是同一件事。

`_resolve_commit`（`tools/wb_review.py:178-192`）的注释写得很清楚：「判据比的是提交不是字符串长度」—— 它治的是**同一笔的两种短写法**（卡 A319 / T-AG433），不是「两笔不同提交」。

### 8. 结论：**真问题 —— 红对了，理由错了**

**红对了**（不能当假红放过）：

- 门禁确实没验过 `ebd39871` 那棵树上的 pytest / docs 结论；那三个文件确实在这两道门的输入面上（§7）；
- 落地链 ⑦ 确实**一步都没问**（§5）—— 就算这次差异无害，这个洞对下一次「插进来的是一笔源码」完全同样地敞开；
- 复核器是**唯一**会把这件事说出来的地方（`scripts/audit_progress.py:779-793` 只查「产物时间比父提交新不超过 120 秒」，不查差异集合）。

**理由错了**（两句文案都在说一件没发生的事）：

- 「★ 一次门禁跑完提交两笔？第二笔没验过」—— 现场是**基线前移**（`merge-base --is-ancestor` rc=0，反向 rc=1），不是一次门禁两笔提交；
- 「伪造门禁结论」—— `Gates:` 那行是 `landing.py:1352` 的**模板**自动出的，没人伪造；指控不成立；
- 而且它**没说**最该说的那句：「`R..P` 只动了 N 个台账 / 派生物文件，但 pytest / docs 属永远跑 ⇒ 结论未被复验」。

一句话：**这是真问题，但现在的红把「没复验」说成了「伪造」，把「基线前移」说成了「一次门禁两笔」；而且它并不能区分「R..P 只动台账」与「R..P 改了源码」。**
本卡要的不是把红洗绿，是**把红说对**：台账差异 ⇒ 出「未复验」这一档（留读数、不声称绿）；源码差异 ⇒ 照红，且文案点名路径。

## 判据（4–6 条，每条一个钉子）

### 判据 1 · 基线前移必须能被分类，而不是与「一次门禁两笔」共用一句话

在 `tools/wb_review.py` 里新增**唯一一份**分类器（名字建议 `gate_base_drift`，返回 `(分类, 差异文件, 读数)`），三分支：

- **同提交**（`rev` 解析后 == 父提交）⇒ `MATCH`，行为与今天完全一样；
- **真祖先 + 差异 ⊆ 台账 / 派生物 / 卡规格**（`git merge-base --is-ancestor <R> <P>` 为真，且 `git diff --name-only <R> <P>` 每一条都命中「台账族」名单）⇒ `LEDGER_ONLY`；
- **其余**（堪称源码差异 / 非祖先 / 任意一方解析不出）⇒ `DRIFT`。

`LEDGER_ONLY` 的处置是**如实标注**，不是放行：`check_gate_evidence` 不再往 `problems` 里塞「门禁不是为这一笔跑的」，改为把读数放进 note；
词必须带全：`last.json.rev=R 是父提交 P 的真祖先；R..P 只动了 N 个台账/派生物文件（列表）；pytest / docs 属「永远跑」⇒ 结论未经复验`。

- 钉子：`tests/test_wb_review.py::test_base_drift_ledger_only_is_not_red`

### 判据 2 · 差异里只要有一条落进 {lang} / {product} 档路径，照红，且点名路径

分档真源只有一份：`gates/defs/domains.py:26-42` 的 `REQUIRED_PROFILES`（`src/` `examples/` `harness/` → {lang,product}；`tools/` `scripts/` `tests/` `gates/` → {lang,audit}；`docs/` `复盘/` `skills/` → {audit}）。
**不许**在复核侧另抄一张新的路径表 —— 由分类器 import 它（或直接读 `required_profiles_for_paths` 同源的函数）。
`DRIFT` 分支的文案要升级为：`门禁基点 R 与父提交 P 之间改了源码：<逐条路径> ⇒ 必须重跑门禁`，并**保留**原来那句「门禁不是为这一笔跑的」作为兜底。

- 钉子：`tests/test_wb_review.py::test_base_drift_touching_source_is_still_red`（中间插一笔改 `tools/foo.py` 或 `src/a.py`，必须仍出红，且文案里出现该路径）

### 判据 3 · 解析不出 ⇒ 不放过（今天的两条钉子不许变绿）

`_resolve_commit` 两边都解析不出（合成 sha / 浅克隆 / 仓外树）⇒ 分类器必须回 `DRIFT`，且**不许**因为「查不到差异」就当成 `LEDGER_ONLY`。
这条是判据 1 的**否决权**：任何「拿不准」都退回今天的红。

- 钉子：`tests/test_wb_review.py::test_base_drift_unresolvable_stays_red`（沿用现有合成 sha 形状）；
- 既有钉子不许动：`tests/test_wb_review.py:78-81`（`_payload(rev="oldc0de")` vs `"abc1234"` ⇒ 必须含「不是为这一笔跑的」）、`tests/test_wb_review.py:733-749`（真仓里 `~2` 那笔 ⇒ 必须红）。

### 判据 4 · trailer 真伪跟**同一个**分类器走，不另写一份

`tools/wb_review.py:494-506` 改两处：

1. `matched` 的 rev 比较换成与 `:229-235` **同源**的解析（补上卡 A319 漏掉的这处字面量）；
