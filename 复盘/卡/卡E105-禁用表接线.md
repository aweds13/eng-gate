# 卡 E105 · 禁用表装好了判据，却没人问它：三处派活入口都当它不存在

> 台账号 `T-AG614`｜分区 E（门禁与可信度）｜树 `.wt/E105`｜层 判据层｜基准 `b8545049`｜
> 依据：用户 m92988「把 pool 的使用打磨好，不计代价与 token」；m93503「之前的任务记得做完」。

## 要解决的问题（逐条实测，不是推测）

卡 A353（`T-AG566`）把 magpie 的「禁用模型」判据搬进了 `tools/pool/model_registry.py`：
`load_disabled` / `match_disabled` / `model_disabled` / `assert_not_disabled`，18 条钉子。
它自己在 docstring 里承认了缺口：

```text
$ grep -rn "assert_not_disabled(" tools/ scripts/ | grep -v model_registry.py
（0 命中，rc=1）
$ ls tools/pool/model-disabled.toml infra/pool/model-disabled.toml
No such file or directory（两份都不存在）
$ echo "$TF_POOL_DISABLED"
（空）
```

于是今天：**用户在禁用表里写一行，一个请求都不会被拒** —— 判据存在、有 18 条钉子、也全绿，
但生产链上一次都没被调用。三处派活入口各自只问「批没批」：

| 入口 | 现在问什么 | 缺什么 |
|---|---|---|
| `tools/wb_dispatch.py` main() 模型闸（:3411-3426） | 注册表 + 白名单（`model_rejected`） | 没问禁用表 |
| `tools/pool/gateway.py::_model_block`（:322-338） | 批准集 + 快照新鲜度（全回 404） | 没问禁用表；且「禁用」该是 403（原件口径） |
| `tools/pool_mcp.py::tool_pool_dispatch`（:1771） | `MODEL_WHITELIST` + caller 收窄 | 没问禁用表 |

原件 `_ext/magpie-main/internal/gateway/disabled.go` 的口径是逐字写死的：

```text
a model the user turned off is refused on every route before anything is sent upstream,
with a 403 in the API's own shape
```

—— 两件事本卡都要满足：**每一条路都问**（不是只有 CLI 主路径），以及**回 403 而不是 404**
（404 的含义是「没有这个模型」，403 才是「有这个模型，但你现在不许用」）。

## 判据（五条）

### 判据 1 · 派活主路径：模型闸里先问禁用表，拒单仍是零副作用

`tools/wb_dispatch.py` main() 的模型硬闸门（:3411-3426 的 `try` 块）里，在
`rejected = model_rejected(args.model, pool)` 之后加 `assert_not_disabled(pool, args.model)`，
靠**既有**的 `except (ModelRegistryError, ...)` 兜住（`DisabledUnknownError` 是它的子类）：

- 命中禁用模式 ⇒ 退 2，stderr 点名「被禁用」+ 命中的模式 + 禁用表路径；
- 表读不到 / 读不懂（`unknown`）⇒ 退 2，STDERR 点名「不知道 ≠ 空表」；
- 两种都必须**零副作用**：一个子进程都不起、不建 `gates/diag/wb-000.jsonl`、不写判决。

**钉子**（`tests/test_wb_dispatch.py`，本卡追加）：

- `test_disabled_model_is_refused_with_zero_side_effects`（`TF_POOL_DISABLED` 指 tmp 表，禁 `deepseek*` ⇒ rc 2 + 文案 + `record == []` + 无 log/判决）；
- `test_unknown_disabled_table_refuses_every_model`（写坏 TOML ⇒ rc 2 + 「不知道」+ `record == []`）；
- `test_absent_disabled_table_changes_nothing`（指向不存在的路径 ⇒ 白名单模型照常派出，`record` 非空 —— 证明不是「一律拒」）。

### 判据 2 · 网关：禁用 / 不知道回 403，未批 / 快照过期仍回 404

`tools/pool/gateway.py`：

- `_model_block` 返回值从 `str` 改成 `tuple[int, str]`（`(0, "")` = 放行；非 0 = 该回的状态码 + 原因），
  末尾加禁用判定：`pool_model_registry.assert_not_disabled("", model)`，命中或 unknown ⇒ `(403, str(exc))`；
- `route_once` 改成按返回的状态码回（`:488-490`），其余四支仍是 404（**不许**顺手改成 403）。

**钉子**（`tests/test_pool_gateway.py`，本卡追加）：

- `test_disabled_model_is_403_not_404`（禁 `MODEL` ⇒ status 403 + body 含「被禁用」+ `forward.calls == []`）；
- `test_unknown_disabled_table_is_403`（坏 TOML ⇒ 403 + 「不知道」+ 一个字节都不出网）；
- 既有 `test_unapproved_model_is_404_not_429` / `test_stale_snapshot_is_404` **一个断言都不许改**。

### 判据 3 · MCP 干跑面：同一个判据，拒单不起工人

`tools/pool_mcp.py::tool_pool_dispatch`：在 `MODEL_WHITELIST` 判定之后、`resolve_account` 之前加禁用闸，
`except wb_dispatch.ModelRegistryError` ⇒ `_result(f"模型被禁用，已拒绝派活：{exc}", {...}, is_error=True)`。

**钉子**（`tests/test_pool_mcp_write.py`，本卡追加）：

- `test_disabled_model_is_refused_before_spawning`（白名单模型 + 禁用表禁它 ⇒ `isError` + 文案含「禁用」+ `no_spawn == []`）。

### 判据 4 · 判据只有一份：三处都调 `model_registry.assert_not_disabled`

不许在网关 / MCP 里各写一份 glob 或各读一次表。钉子用 AST 钉死：

- `tools/wb_dispatch.py` main() 体里出现 `assert_not_disabled` 调用；
- `tools/pool/gateway.py::_model_block` 体里出现 `assert_not_disabled` 调用，且 `route_once` 按 `_model_block` 返回的状态码回；
- `tools/pool_mcp.py::tool_pool_dispatch` 体里出现 `assert_not_disabled` 调用；
- 三处调用都**没有**出现第二份判据（不许出现 `glob_match`、`load_disabled`、`match_disabled` 的直接调用）。

**钉子**（`tests/test_pool_disabled_wiring.py`，本卡新建）：

- `test_every_production_entry_asks_the_same_judge`（AST 取三个函数体，各恰 1 次 `assert_not_disabled`，0 次 `glob_match/load_disabled/match_disabled`）；
- `test_gateway_forwards_the_status_code_not_a_fixed_404`（AST 核 `route_once` 里 `if blocked` 分支用的是 `status` 变量而非字面 `404`）。

### 判据 5 · 文案与地图跟着改（「零生产调用方」不再成立）

- `tools/pool/model_registry.py:730-731` 的 docstring 改成「已接线：三处入口（wb_dispatch / gateway / pool_mcp）」；
- `tests/test_pool_disabled.py:18` 模块 docstring 的「本卡只提供判据、不接线」改成历史注记 + 指向本卡；
- `docs/subsystems/pool/modules.toml` 的 `model_registry.py` 条 duty 补「禁用表与三处生产接入」；
- **不许**顺手改与本卡无关的零调用声明（`tools/pool/usage_ingest.py:44`、`modules.toml` 的 pricing 条、`tools/domain_symbols.py:24`）。

**钉子**（`tests/test_pool_disabled_wiring.py`）：`test_docs_stop_claiming_zero_production_callers`
（读两份源文件与 modules.toml，断言不再出现「零生产调用方」这句话，且出现「wb_dispatch」「gateway」「pool_mcp」三个名字）。
