# 卡 E14 · 起子进程的钉子用例遇 PermissionError 要重试（T-AG465）

## 现在疼在哪（实测）

1. 落地链全量门禁里，`tests/test_wb_review.py::test_chinese_paths_are_not_escaped` **连续两趟**报同一句失败：
   `PermissionError`（在 `plain("config", "user.name", "test")` 那一行起 `git` 子进程时抛出），
   而同一条用例**在主树单跑 4 次全过**（`pytest tests/test_wb_review.py::test_chinese_paths_are_not_escaped -q --no-cov` → 4 个点）。
2. 同一趟里其余 **2987 条**全过、覆盖率 93.70%、`acceptance`/`mypy`/`ruff`/`audit` 全绿 ⇒ 不是被测代码的问题，
   是 **Windows 上临时目录里起进程偶发 WinError 5**（杀软/句柄/临时目录回收竞争）。
3. 代价：E7（T-AG453）为这一条**多烧了两趟全量门禁**（每趟 ≈16 分钟）。

## 你要做的事

把「起子进程」这一动作在测试夹具里**做成可重试**，让偶发 WinError 5 不再把整趟落地判红；
**不许**为了变绿而删掉或跳过这条用例。

## 判据（机器可判）

1. 在 `tests/conftest.py` 里新增一个共享助手（名字自定，例如 `run_git()` / `run_with_retry()`）：
   - 内部分支：`subprocess.run(...)`；捕获 `PermissionError`（以及 `OSError` 里 `winerror == 5`）后**最多重试 3 次**，间隔 50 ms；
   - 三次都失败 ⇒ 把**原异常**抛出（不许吞掉、不许 `pytest.skip`）；
   - 返回值/`returncode` 语义与 `subprocess.run` 一致（`capture_output=True, text=True, encoding="utf-8"` 由调用方给）。
2. `tests/test_wb_review.py::test_chinese_paths_are_not_escaped` 里的 `plain()` 改用它；该用例的**断言一条都不许改**。
3. 同族夹具里凡是用 `subprocess.run(["git", ...], cwd=<临时目录>)` 起进程的地方（`tests/test_wb_review.py` 内其余、`tests/test_wb_plan.py` 里若有）一并换过去。
4. **报行可查**：重试发生时打印一行 `[retry] git … PermissionError（第 N 次）`（`-q` 下不刷屏即可）。
5. 不许改 `tests/test_wb_review.py` 的判据逻辑（`wb_review.py` 一行不动）。

## 钉子（≥3 条）

1. `monkeypatch` 让 `subprocess.run` **第一次抛 PermissionError、第二次成功** ⇒ 用例通过，且 `[retry]` 行出现一次。
2. 让 `subprocess.run` **三次都抛** ⇒ 用例**失败**（不是 skip），异常里带原始 `PermissionError`。
3. 正常路径：`subprocess.run` 一次成功 ⇒ **零**重试（断言调用计数 == 1）。

## 不许做

- 不许 `pytest.mark.skipif` / `xfail` / `try: … except: pass`。
- 不许改 `wb_review.py` 的判据或用例断言。
- 不许把重试次数写成无限循环。
