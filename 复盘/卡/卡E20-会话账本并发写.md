# 卡 E20 —— 会话账本并发写：临时文件名必须唯一

## 现在疼在哪（实测）

2026-10-24 23:43，F3 落地门禁在本机 **4 个 worker** 下红了唯一一条：

```
FAILED tests/test_wb_dispatch.py::test_execute_auto_resumes_an_interrupted_run
FileNotFoundError: [WinError 2] 系统找不到指定的文件。:
  '.../.wt/F3/gates/diag/session-leases.tmp' -> '.../session-leases.json'
```

栈：`tools/wb_dispatch.py:2884` → `wb_session.claim` → `tools/wb_session.py:107 _save` → `:59 tmp.replace(LEDGER)`。

根因在 `tools/wb_session.py:52-66`：`_save()` 的临时文件名**写死**成 `LEDGER.with_suffix(".tmp")`。
两个 worker 同时写账本时，先完成的那次 `replace` 把 `session-leases.tmp` 换成了 `session-leases.json`，
后完成的那次再 `replace` 就找不到源文件。而现有重试**只捕 `PermissionError`**（`:63`），
`FileNotFoundError` 直接抛。

后果：**这套测试在 `-n≥2` 下必偶发红**——本机 `-n 4` 全量 341 s、云机 `-n 4` 336 s 都踩到过，
「云门禁机多 worker 跑门禁」这件事在修好之前不可信。

## 要做的事

1. 临时文件名唯一：把 `LEDGER.with_suffix(".tmp")` 换成
   `LEDGER.with_name(LEDGER.name + "." + str(os.getpid()) + "." + uuid4().hex[:8] + ".tmp")`
   （同目录，保证 `replace` 仍在同一卷上、是原子换名）。
2. 重试条件放宽成 `except (PermissionError, FileNotFoundError)`：目标被别的进程挡一下、
   或自己的 tmp 被别人换走，都算「再试一次」，别直接抛。
3. 末次失败仍要清掉自己的 tmp（沿用 `contextlib.suppress(OSError)`），别在 `gates/diag/` 留垃圾。
4. 钉子：`tests/test_wb_session.py` 加一条并发用例——两个线程各自 `_save`（或起两个子进程），
   断言都不抛、且最终 `session-leases.json` 可被 `json.loads`。

## 判据

- `python -m pytest tests/test_wb_session.py -q` 全绿；新增用例在**旧实现上必红**（反向验证一次）。
- `python -m pytest -n 4 -q` 连跑两次，不再出现任何 `session-leases` 相关红。
