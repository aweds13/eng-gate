## 来路（外部审查 GLM-5.3，四条原文要点）

- **2.3（重）**：「`spin_lock` 用 `O_CREAT|O_EXCL`、10 秒超时、**没有任何陈旧判定/接管** —— 持有进程一死，
  锁永留，此后所有 `claim/waive/advance/expire/landed` 全部 rc=2，**直到人手工删锁文件**。
  而 `cmd_claim` 在**锁内**跑 `gate_cmd`（全量门禁 ≈5~6 分钟）⇒ 持锁窗口被放大到门禁时长。」
  ★ 同族教训本仓早吃过：**门禁锁**从"按 pid 判活"进化到**租约制**，**这把没吃到**。
- **2.5（中）**：「`cmd_advance` 对非 `awaiting-commit` 状态一律重置成 `collecting` 再 `_maybe_advance`
  ⇒ 它**实测复现**了：对 **`landed`** 跑 `advance` ⇒ 变回 `awaiting-commit`（`landed` 字段还挂着 commit，
  自相矛盾）；对 **`timeout`** 跑 `advance` ⇒ timeout 被抹掉。配套：`cmd_expire` **不校验 deadline 是否真到**。」
- **2.6（中）**：「`task.py` 以 `shell=True` 执行 manifest 里的 `gate_cmd`；`task_register` 又开在 MCP 写面上
  ⇒ 有 env 的任何客户端可注册**带任意命令**的任务并在集齐时触发执行。」
- **2.12（轻）**：「`selftest()` 把 `TF_BATCH_DIR` 指进临时目录，结尾**不复原**。」
- **三.1（最重，本卡只做其中一半）**：域检查吃的是"交申请一方自己填的 `--files`" ⇒ 本卡治**其中的
  `PROTECTED_FILES` 缺口**（受保护的共享文件谁都不许声明进自己的域）；"拿卡树实际改动与域比对"那半
  在**集成/复核侧**（另一张卡治）。

## 要做什么（六件，都在 `tools/pool/task.py` + `tests/test_pool_task.py`）

1. **`spin_lock` 改租约制**（当前 `:165-192` 附近）：
   - 锁文件里**写清楚**：谁拿的（卡号 / owner / pid）+ 拿到的时间（ISO）；
   - **按时间判陈旧**（锁内 `at`，退化到 mtime）+ TTL（默认 **3600 秒**，`TF_BATCH_LOCK_TTL` 可覆盖）；
     ★ **不许用 pid 判活**（pid 会重用、跨机器不可信 —— `gates/diag/gate_lock.py` 的现成口径照抄）；
   - 陈旧 ⇒ **接管**并在该任务 `history` 里**留一行**（"接管了谁留下的陈旧锁、已 N 秒"）；活锁 ⇒ 照样拒。
2. **`_run_auto` 的 `gate_cmd` 移出锁外**：拿锁 → 状态推 `gating` + history 写"开始跑门禁" → **放锁** →
   跑门禁 → **再拿锁** → 写读数与骨架。**幂等**：第二个投递者看到 `gating`（门禁还没记账）⇒
   **不许重复跑**（等 / 回一句"门禁在跑"都行，★ 在回报里写明你选了哪种、为什么）。
   ★ **不许**破坏"最后一名投递者当场关门"（没有守候进程、没有轮询）。
3. **`selftest` 复原 `TF_BATCH_DIR`**（`try/finally`）。
4. **状态机判据收紧**：`advance` 对 **`landed`** 与 **`timeout`** **必须拒**（提示"要重开就用 `extend`/重新 register"），
   **不许**把状态改回 `collecting`；`expire` **必须校验 `now > deadline`**（没到期 ⇒ 拒）。
   ★ 并且**统一 deadline 的口径**：**每个会改状态的入口（claim/advance/expire/extend/waive/landed）先检查一次 deadline**，
   过期即判死（`timeout`，**只判死、绝不放行**）—— 这样"到 deadline ⇒ timeout"这条**不再依赖有人记得手动跑 `expire`**。
   （★ 你不改文档 —— 文档不在白名单；口径由主控在收口时对齐。）
5. **`gate_cmd` 白名单化**：`register` 时校验（拒并**点名那条命令**），`claim` 时**再校验一次**（防手改 manifest）：
   - 只认**仓库内脚本**、且必须是 `python -X utf8 scripts/…` 或 `python -X utf8 tools/…` 形态；
   - **不许**含 shell 元字符（`;` `|` `&` `$` 反引号 `>` `<` 换行）；
   - 执行时用 `shlex.split` + **`shell=False`**。
6. **`check_domain` 补 `PROTECTED_FILES`**：`pool.plan.PROTECTED_FILES` 里的**受保护共享文件**，
   **任何卡都不许**写进自己的 `paths` ⇒ **`register` 时就拒**（更早更好），`claim` 时也拒。

## 验收（照这个报，数字要真）

- ★ **反例钉子**（每条要"故意坏掉会红"）—— 前五条 + 后四条：
