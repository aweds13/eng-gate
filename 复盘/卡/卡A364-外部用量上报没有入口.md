# 卡 A364 —— 外部用量上报没有入口：给它开一个 MCP 写工具（T-F43 接线）

> 台账号 `T-AG578` ｜ 分区 A（magpie 移植）｜ 树 `.wt/A364` ｜ 层 接线层
> 依据：卡 A347（T-AG550）已把 F43 的**判据层**整块落地（`tools/pool/usage_ingest.py`，`ingest()` / `parse_batch()` / `merged_tokens()` 全部真实现、反向验证 9/9、验收全绿），但**入口一个都没有**：`grep -rn "usage_ingest" tools/ --include=*.py` 除自己之外**零命中**。模块文件头自己写着「入口是函数，不是 HTTP」。
> 基准提交 `76d3c9e5`（主树 HEAD）。

## 要解决的问题

`usage_ingest.py` 的 docstring 逐字：「**不经过派活器的调用，今天完全不进账。**」有人直接拿供应商的 key 调一次模型，那笔 token 一个字节都没有 —— 而 F43 的判据层已经写好了，只是没人能叫到它。

本卡**只开入口**，不动判据：给 MCP 加一个写工具 `usage_report`，把外部记录收进 `gates/diag/usage-reported.jsonl`。这样「外部调用也进账」这件事第一次真的可用，而判据仍只有 `tools/pool/usage_ingest.py` 那一份。

## 判据（7 条，逐条可执行）

1. **工具存在且只写时才可见**：`POOL_MCP_WRITE=1` 时 `tools/list` 里有 `usage_report`，没有时**不在**（照 `WRITE_ENV` 的「存在性即授权」）。
2. **`confirm` 必须等于批号自证量**：`arguments.confirm` 必须等于**记录条数**的十进制串（本卡选它当防手滑，理由：这一批的规模就是最该先看一眼的东西）。不等 ⇒ 拒，且错话里点名「收到 N 条、confirm 给的 M」。
3. **判据仍只一份**：`usage_report` 的正文**只调** `usage_ingest.ingest()`，**不许**在 `pool_mcp.py` 里重写校验（`grep` 不许出现第二份 `FIELDS` / `MAX_RECORDS` / `rid` 判据）。
4. **拒单有原话**：`IngestRefused`（或 `IngestRefusedError`）抛出时，回话里必须带**逐条 faults 原文**（哪一条、哪个字段、为什么），不许吞成「失败了」。
5. **回包字段与 magpie 一致**：成功回 `{"accepted": n, "skipped": m, "records": [...]}` 原样（判据层已产出，本卡不许翻译字段名）。
6. **`is_error` 语义**：判据层拒单 ⇒ `isError: true`；写成功 ⇒ `false`。断言两条各走一遍。
7. **不碰派活器自己的账**：断言 `gates/diag/wb-usage.jsonl` 一个字节都不变（外部记录进的是 `usage-reported.jsonl`）。

## 不许做

- **不许**动 `tools/pool/usage_ingest.py` 的任何判据（它是卡 A347 的交付物，反向验证 9/9 已咬住）。若验收入口需要它多暴露一个名字，**先说，别自己改**。
- **不许**开 HTTP 口（magpie 的 `POST /v1/magpie/usage/requests` 在 pool 侧没有对应物，卡 A347 已定案「入口是函数」）。本卡只开 MCP stdio 那一个入口。
- **不许**把上报行写进 `wb-usage.jsonl`（判据层明确分了两本账，理由是「这一行是派活器写的还是外面报的」必须永久可判）。
- **不许**给 `usage_report` 加 `readOnlyHint: true`（它写盘）。
- **不许**碰六份 `PROTECTED_FILES`。

## 缺口（如实写在卡里）

1. **传输层三条判据仍未落地**（415 / 413 / 403）：卡 A347 已如实记「HTTP 面没有对应物」。MCP stdio 也没有 Content-Type，所以 415 仍无对应物；413 那半（`MAX_BODY = 32 << 20`）判据层已有，本卡不重造。
2. **只开了一个入口**：`merged_tokens(include_reported=True)` 仍**没有生产调用方** —— 谁在什么界面上看「含上报的总量」是本卡范围之外的事。
3. **`rid` 幂等的两段式不加锁**：判据层自己写着「第二段只是尽量缩小窗口，不是互斥」。本卡不改。
4. 只在本机 win32 验过。
