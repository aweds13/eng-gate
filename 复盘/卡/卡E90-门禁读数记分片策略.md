# 卡 E90 —— 门禁读数要记「按哪种分片跑的」，并清掉一条指向不存在文件的注释（T-AG598）

> 依据：卡 E30（T-AG484）判据 2 与 E31（T-AG485）的收口结论；
> 卡 E30 已被用户 2026-10-25 裁定并入 E50（落地笔 `b659e2df`），本卡只收它剩下的两件尾巴。

## 要解决的问题

`scripts/run_gates.py` 的 `gates/last.json` payload 记了 `"workers": pytest_workers()`，
**没记** `"pytest_dist": pytest_dist()`。于是同一份产物里能读出「开了几个 worker」，
却读不出「这一趟按哪种分片策略跑的」—— 而 `worksteal` 与 `loadfile` 在慢机器上的墙钟差
正是 E30 判据 2 要度量的量。读数缺一维，事后复盘就只能猜。

同一文件里还有一条**指向不存在文件**的注释：`:317-319` 写「读数见 gates/diag 下的
bench-e30-summary.txt」，该文件在本仓从未存在（gates/diag 是 gitignored 的运行时目录）。`scripts/check_docs.py` 会把反引号里的路径当引用算，
死了就记一条 `dead_refs` 欠账。

## 判据（4 条，逐条可执行）

1. **payload 记分片策略**：`scripts/run_gates.py` 构造 `last.json` payload 处
   （现 `:2789` 的 `"workers": pytest_workers(),` 之后）新增 `"pytest_dist": pytest_dist(),`。
   键序必须在 `workers` 之后；`pytest_dist()` 复用既有的那个函数，**不新写一份**。
2. **悬空注释清掉**：`:317-319` 那段不再点名任何不存在的文件（bench-e30-summary.txt
   全文件零命中），改写成「三档墙钟读数已并入卡 E50 的验收记录，本仓不保留单独的
   bench 摘要文件」这一层意思。
3. **两条钉子钉住**（新文件 `tests/test_run_gates_payload.py`）：
   - 源码里 `"workers": pytest_workers()` 出现在 `"pytest_dist": pytest_dist()` **之前**
     （两条都在 ⇒ 顺序也在）；
   - `TF_PYTEST_DIST` 未设时 `run_gates.pytest_dist() == "worksteal"`
     （与 `tests/test_run_gates_workers.py:175` 同口径，不另立默认值）。
4. **文档欠账收口**：`docs/traceability.d/T-AG484.toml` 的 `status` 由 `deferred` 改 `done`，
   `evidence` 三条（**不许为空**，否则 `scripts/audit_progress.py` 红）；`gaps` 只追加、
   不改写既有文字，追加段写明「哪些落成了、哪些没落（判据 2 的三档对照表与 E31 覆盖率段）」。
   顺带把 `docs/doc-debt-baseline.toml` 的 `dead_refs` 按实测从 148 降到 147
   （基线是地板，**只能降不能升**）。

## 直做

`scripts/run_gates.py` 是 2991 个三重 `\r\r\r\n` 的文件，改它必须字节级保形：
`read_bytes()` → 归一成 LF → 断言旧锚点命中**恰好一次** → 替换 → 回写时还原 `\r\r\r\n`
→ 再读回来归一、与预期逐字节比对自检。其它文件是普通 CRLF，回写后 `lf-only` 必须是 0。
