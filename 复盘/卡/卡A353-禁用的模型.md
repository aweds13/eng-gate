## 要解决的问题

pool 今天**没有禁用表**这一维：`grep -n "DisabledUnknown\|disabled_unknown" tools/ scripts/` 零命中，`tools/pool/model-registry.toml` 文件头三条纪律里也没有它。

更糟的是，`tools/pool/model_registry.py:377-388` 的 `_glob_re` docstring 里有一句**与源码不符**的来处描述：

> ★ 与 magpie 的唯一差别：本实现把 `*` 之外的字面片段 `re.escape()` 掉。magpie 直接把片段拼进正则，所以 `(` / `.` 这类字符在那边是正则元字符（能编译就直接当正则用、编不过就 panic）……

而 magpie `internal/access/models.go:99-105` 的 `compileGlob` **全文逐字**是：

```go
func compileGlob(p string) *regexp.Regexp {
	parts := strings.Split(p, "*")
	for i, s := range parts {
		parts[i] = regexp.QuoteMeta(s)
	}
	return regexp.MustCompile("(?is)^" + strings.Join(parts, ".*") + "$")
}
```

⇒ **magpie 同样 `QuoteMeta` 转义**。「那边编不过就 panic」这句在 `compileGlob` 里不成立。`_glob_re` 的实现本身对，错的只是注释把自己说成「更严的一方」并给了一个源码里没有的理由 —— 后面每一波都会有人照它推理，必须顺手改掉。

## 判据（18 条，逐条可执行）

**本卡的判据就是设计原件 §F84「判据逐条」那 18 条**，逐字照做：

1. `glob_match(pat, s)` 是自写**单星号回溯**（逐字照 `provider/disabled.go:105-130` 的 `globMatch`）：`'"*?" not in pat'` 时退化成 `pat == s`；`glob_match` 自己**不转大小写**（转大小写在 `match_disabled` 里，与原件 `matchDisabled` 里 `strings.ToLower` 的位置一致）。
2. `glob_match("*", "a/b/c") is True`（`*` 跨斜杠）。
3. `glob_match("?", "x") is True`；`glob_match("?", "") is False`；`glob_match("a?c", "abc") is True`。
4. `glob_match("[abc]", "[abc]") is True` **且** `glob_match("[abc]", "a") is False` —— `[` 是字面，不是字符类。
5. `glob_match("a*b*c", "aXbYc") is True` 且 `glob_match("a*b*c", "aXbY") is False`（多星号回溯）。
6. `names_of("anthropic", "claude-fable-5") == ("claude-fable-5", "anthropic/claude-fable-5")`（两档）。
7. `names_of("openrouter", "anthropic/claude-fable-5")` 含**三段**：`("anthropic/claude-fable-5", "openrouter/anthropic/claude-fable-5", "claude-fable-5")`（第三段是 `LastIndex("/")` 之后）。
8. `id_names("openrouter/anthropic/claude-fable-5")` 含 `"openrouter/anthropic/claude-fable-5"` / `"claude-fable-5"`（LastIndex）/ `"anthropic/claude-fable-5"`（`Cut` 第一刀之后）三段 —— 与 `names_of` **不是同一个函数**。
9. `match_disabled` 返回**原样的 pattern**（不是小写版）：`match_disabled(["Claude-Fable*"], ["claude-fable-5"]) == "Claude-Fable*"`。
10. `match_disabled` 跳过空 pattern 与空名字：`match_disabled(["", "  "], ["x"]) is None`。
11. `normalize_disabled([" a ", "A", "", "b"])` ⇒ `("a", "b")`（trim、丢空、**忽略大小写去重**、保序）。
12. `normalize_disabled` 超 `MAX_DISABLED_PATTERNS` 抛 `ModelRegistryError`；单条超 `MAX_DISABLED_CHARS` 也抛（**两条上限分开**，不许合并）。
13. `load_disabled()` 文件**不存在** ⇒ `Disabled(patterns=(), unknown=False)`（与 magpie「没配过 = 没禁用」一致）。
14. `load_disabled()` 文件**存在但解析失败** ⇒ `Disabled(patterns=(), unknown=True)` —— **不是空表**。
15. `Disabled.unknown is True` 时 `model_disabled(...)` 返回非 None 的哨兵值（`UNKNOWN = "?"`）**或**抛 `DisabledUnknownError`，**绝不放行**。
16. `assert_not_disabled` 在 `unknown=True` 时抛 `DisabledUnknownError`，消息里必须含「不知道」与「不许当成没禁用」两句。
17. `assert_not_disabled` 命中时抛异常，消息里必须含**原样的 pattern** 与被打的 `id`。
18. `model_disabled` 与 `id_disabled` 是**两个入口**，判据顺序不同；pool 没有「组」概念 ⇒ `id_disabled` 只能搬 `idOff` 十步里的 6 步（第 1/2/3/4/8/10 步），**必须在 docstring 里写明缺哪四步**。

**常量逐字**：`DISABLED_ENV = "TF_POOL_DISABLED"` / `DISABLED_FILE = "model-disabled.toml"` / `MAX_DISABLED_PATTERNS = 500` / `MAX_DISABLED_CHARS = 300`（后两个是**借** `access/models.go:26/31`，禁用表本身没有上限判据 —— 注释里必须写明「这是设计决定，不是原件事实」）。
