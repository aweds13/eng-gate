# 卡 F10 —— 一行判不了就把整行扔掉：同一行里成对的引用也没人判

> 台账号 `T-AG527` ｜ 分区 F（文档治理）｜ 树 `.wt/F10` ｜ 层 文档层
> 依据：2026-10-29 现读 `python -X utf8 scripts/check_docs.py --json` ⇒ `dead_refs 145 / skip 1059`，
> 其中「行内反引号不成对，这一行判不了」**102 条**；成因在 `scripts/check_docs.py:529-530`
> `if line.count("`") % 2: return [], True`，主循环 `:718-721` 见到 `unparsable` 就 `continue`。

## 要解决的问题

1. **一行判不了，整行都不判**。`refs_in_line()` 只要发现这一行反引号个数是奇数，就
   `return [], True`；主循环拿到 `True` 直接 `continue` —— 于是同一行里**成对**的引用
   （`` `docs/ghost.md` `` 这种）一条都不判，却只记一条「这一行判不了」。这是**判据自己制造的盲区**：
   它诚实地承认「判不了」，但顺手把本来判得了的东西也丢掉了。合成树已证：一行
   「见 `docs/ghost.md`，尾 `docs/nothere.md」⇒ 旧实现报 **0** 条死指针（真断链没人看见），
   探针 `gates/diag/_probe_v6.py` 合成树那节就是这条证据。
2. **102 条里绝大多数并不是「判不了」**。逐行看过：多数是正文里把一段代码折行、或者
   写着 `` `
` `` 这类记号，成对反引号其实完好，只是行尾多了一个。把它们记成
   「这一行判不了」既不准确（判不了的是**尾巴那一段**，不是整行），也让 `skip` 这个数
   长期虚高（1059 条里 102 条属于此类）。

## 判据（5 条）

1. **成对引用不许被同行游离反引号连累**：合成树里造一行「成对引用指向不存在的
   `docs/ghost.md` + 行尾一个游离反引号」⇒ 必须报**死指针 1 条**（旧实现报 0 条）。
   反向用例写在 `tests/test_check_docs.py`，用 `tmp_path` 合成树，不碰真仓。
2. **判不了的那一段仍要如实报**：行尾游离反引号后面**真的像引用**（过 `is_pointer()`）
   ⇒ 仍记一条 `skip`，理由改成「行尾反引号不成对，这一段判不了」（口径从「这一行」
   收窄到「这一段」）；后面只是代码原文 / 纯标点 ⇒ 不记 `skip`。
3. **真仓 `dead_refs` 不许涨**：改后 ≤ 145（现读 145，基线 152）。
4. **`skip` 要真降**：`python -X utf8 scripts/check_docs.py --json` 的 `skip` 从 1059
   降到 ≤ 970（探针 `gates/diag/_probe_tail5b.py` 实测 969），且剩下的「反引号不成对」
   条数 ≤ 8，每条都能指出反引号跨到了哪一行。
5. **三处自述同步改**：`scripts/check_docs.py:36` 文件头、`refs_in_line()` docstring、
   `check_dead_refs()` docstring（`:689` 那句「反引号不成对的行整行 skip（判不了）」）
   —— 不许留「整行 skip」的旧说法。

## 交付

- `scripts/check_docs.py`：`refs_in_line()` 改成「成对照解 + 尾巴按词判」；主循环不再
  因 `unparsable` 丢引用；三处自述同步。
- `tests/test_check_docs.py`：新增判据 1、2 的正反用例（合成树）。
- `复盘/卡/卡F10-判不了的那一段不许连累同行.md`：本卡规格。

## 验收

```bash
python -X utf8 scripts/check_docs.py --json                               # dead_refs ≤ 145，skip ≤ 970
python -X utf8 scripts/run_gates.py --only docs,audit_titles,check_layers  # 三门绿
```

## 不许做

- 不许为了让 `skip` 变小去放宽别的判据：gitignored 产物 / 模板占位 / 别仓扩展名三条一律不动。
- 不许把 `skip` 写进 `docs/doc-debt-baseline.toml`（文件头已明写：把不确定当合格等于自欺）。
- 不许改历史台账里「`skip` 1532 条未收敛」（`docs/traceability.d/T-AG493.toml`）与卡规格里
  「判不出 1380 条」（`复盘/卡/卡E39-文档欠账基线.md`）这两处读数 —— 那是**当时**的快照，
  改了就篡改历史；本卡只在卡规格里记一句「已被 F10 刷新」。
- 不许顺手把 `dead_refs` 基线/地板从 152 下调到 145（那是另一张卡的事，混进来会让
  「本卡到底改了什么」说不清）。
