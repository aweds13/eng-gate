# 卡 A321 · 门禁分层：core / product / audit

**task**：T-AG434　**risk**：low　**tree**：`.wt/A321`

## 为什么

19 道门是一锅煮：5 道是通用工程门（pytest / ruff / mypy / 验收 / 检查器自测），
10 道是 **timeflow 产品门**（五层文档、对比度、风格、界面文案、命令表、DOM 探针、
代理指标、台账标题、真机 LF1/Web）。改一个 `tools/wb_*.py` 也要跑全量 13 分钟，
而且 timeflow 组件没起来时那几道真机门的结果与本次改动无关。

## 判据（怎么算做完）

1. `scripts/run_gates.py` 有 `GATE_PROFILES`：`lang` / `audit` / `product` / `all`，
   **每个门 id 恰好属于一档**（联合 = 全量，互不重叠）。
2. 新开关 `--profile {all,lang,audit,product}`；**默认 `all`，行为逐字不变**。
3. `build_jobs(quick, fast, profile="all")` 仍是纯函数；`--fast` / `--quick` 语义不变。
4. 钉子 `tests/test_run_gates_profiles.py`：
   - 三档联合 == 全量门名集合（漏一个就红）；
   - 任一档之间无交集（重叠就红）；
   - `--profile lang` 不含 `product` 的门；`--profile all` 等于不筛选。
5. `skills/pipe-gate/SKILL.md` 加一段：什么时候用 `--profile`（内循环 / 只动工具时），
   并写明**收口链仍然跑全量**。

## 不做什么

- 不改任何门的判据与退出码；
- 不让 `wb_land` 默认改用 profile（收口仍全量，防止「按档跑」被当提交闸）。

## 分层落到文件（不是只加个开关）

```
gates/defs/lang_python.py      语言门 5 道（pytest/验收/ruff/mypy/检查器自测）
gates/defs/contract.py         契约门 3 道（证据/不变量/标题对账）
gates/defs/product_timeflow.py 产品门 11 道（五层/对比度/风格/文案/命令表/DOM/代理/真机/渲染/行为流）
```

- `scripts/run_gates.py` 只负责**拼表 + 跑**，不再写字面门表；`GATE_PROFILES` 由模块现算。
- **换语言**：只换 `lang_python.py`（`lang` 不是「通用门」，是「本语言的门」——用 Go 的仓换成 `lang_go.py`，runner 不动）。
- **换产品**：整份替换 `product_timeflow.py`；删掉它框架仍能跑 core/audit。
- **换仓**：`contract.py` 的判据形状照抄、实现按新仓的台账重写。
