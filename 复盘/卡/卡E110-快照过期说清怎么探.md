> 台账号 `T-AG619`｜分区 E（门禁与可信度）｜树 `.wt/E110`｜层 判据层｜基准 `10f9ac61`｜

## 要解决的问题（逐条实测，不是推测）

### 问题 1 · 「先重新探测再派活」这句话在三处出现，三处都**不给入口**

全仓实测（`grep -rn 先重新探测 --include=*.py . --exclude-dir=.wt --exclude-dir=gates`）只剩三处生产文案：

```text
tools/pool/models.py:96   note = "快照时间戳读不出来 ⇒ 当过期处理（先重新探测再派活）"
tools/pool/models.py:98   note = f"快照已过期 {age} 小时（上限 {STALE_HOURS}h）⇒ 先重新探测再派活"
tools/pool/gateway.py:349 return 404, f"模型快照不可信：{note} ⇒ 先重新探测再派活"
tools/pool_mcp.py:1232    " ⇒ 不当成新鲜，也不当成过期；要派活先重新探测"
tools/pool_mcp.py:1236    f"快照新鲜度：已过期 {age} 小时（上限 {stale_hours}h）⇒ 先重新探测再派活"
```

五句（三处）没有一处给出**命令**或**脚本路径**。真的重新探测只有一条路：跑仓外的
`infra/pool/pool_models.py --check`（它 `subprocess` 起 `bash codearts.sh models`，联网、
再把结果写回 `models.live.json` 并盖 `at` 时间戳）。这一步读者拿不到。

### 问题 2 · 网关那句**把同一句话叠了两遍**

真机实测（`gateway._model_block('codearts', 'huaweicloud-maas/GLM-5.2', base, now=…)`）：

```text
404 模型快照不可信：快照已过期 379.9 小时（上限 24h）⇒ 先重新探测再派活 ⇒ 先重新探测再派活
```

`models.py:98` 的 `note` 里已经带了「⇒ 先重新探测再派活」，`gateway.py:349` 又接了一遍。

### 问题 3 · 同一个「过期」，网关硬拒、派活器只提示 —— 没有一处说清这件事

| 面 | 过期时怎么办 | 出处 |
|---|---|---|
| 号池网关 | **404 硬拒**（一个字节不出网） | `tools/pool/gateway.py:347-349` |
| 派活器 | 只往 stderr 打一行 `★★ …`，**不拦** | `tools/wb_dispatch.py:2701-2725`、调用点 `:3132-3133` |
| MCP 读面 | 只说「已过期 N 小时」 | `tools/pool_mcp.py:1234-1237` |

于是同一个 `snapshot_stale=True`，读者在不同面拿到两种相反的处置，却没有任何一句话
说明「为什么这里拒、那里放」。

### 问题 4 · 仓内**没有**探测入口，而且这一点也不写明

`tools/pool_mcp.py:2953 main()` 只认 `--help` 与 `--http`（没有「探一次快照」的 CLI 面）；
`tools/pool/models.py:7-9` 的模块 docstring 只说「现场拉取既要联网又会写快照文件，两样都不在这里做」，
**不说那份脚本在哪儿**。`docs/subsystems/pool/模型与号池.md:14` 是唯一给了命令的一处，
但它给的是裸文件名 `pool_models.py --check`，没路径 —— 在仓内任何目录下都跑不起来。

## 判据

### 判据 1 · 「怎么探」只有**一处**真源，且路径**现算**

`tools/pool/models.py` 新增：

```python
PROBE_SCRIPT_NAME = "pool_models.py"
PROBE_ARGS = "--check"

def probe_command(pool: Path) -> str | None:
    """重新探测那条命令（绝对路径现算）；目录里没有那份脚本 ⇒ None（不猜命令）。"""

def probe_hint(pool: Path) -> str:
    """人话：「重新探测：<命令>」；没有脚本就明说没有 —— 两种情况都必须能读。"""
```

**钉子**（`tests/test_pool_models.py`）：

- `test_probe_hint_computes_the_path_instead_of_hardcoding_it`：把号池造在 `tmp_path`，
  断言 `probe_hint(pool)` 含 `(tmp_path/…/pool_models.py).as_posix()`、含 `--check`，
  且**不含** `D:/` 与 `infra/pool/pool_models.py` 这种写死片段。
- `test_probe_hint_says_so_when_the_script_is_missing`：目录里没有 `pool_models.py` ⇒
  返回的一句必须说明「这个目录里没有它」并且**不**给命令（不给假命令比给错命令好）。

### 判据 2 · 三处文案**都**带上它，且网关不再叠两遍

- `models.load_pool_models()` 的两个 `note` 分支（读不出来 / 已过期）末尾接 `probe_hint(pool)`；
- `gateway._model_block()` 改成只用 `note` 一句话（**不再**在末尾接一遍「⇒ 先重新探测再派活」），
  且必须保留这四个 marker 原文：`找不到号池目录` / `批准集是空的` / `不在批准集里` / `模型快照不可信`
  （`tests/test_pool_disabled_wiring.py:107-114` 钉的就是它们）；
- `pool_mcp.tool_pool_models()` 的两个「要探」态（`at` 缺失 / 已过期）人话段带上 `probe_hint`。

**钉子**：

- `test_stale_note_carries_the_probe_command`（`tests/test_pool_models.py`）：过期与坏时间戳两态，
  `snapshot_note` 都含 `--check` 与现算路径。
- `test_stale_gateway_message_carries_the_command_once`（`tests/test_pool_gateway.py`）：
  用测试自己的假号池（`_pool_dir(env, stale_at=…)`，里面有一个空 `pool_models.py`）⇒ 404 文案含
  `--check` 与那个假目录的 posix 路径，且 `body.count("先重新探测再派活") == 1`。
- `test_pool_models_stale_line_says_how_to_probe`（`tests/test_pool_mcp.py`）：人话段（`_human`）含
  `--check` 与现算路径；`at` 缺失那态同样。

### 判据 3 · 说清「过期在这儿拒、在那儿只提示」

`tool_pool_models` 的过期那一行后面补一句：网关会**拒**（404，一个字节不出网），
派活器只**提示**不拦（`wb_dispatch.snapshot_stale_problem`）。**不许**把这句话各写一份判断，
只写在读面这一处文案里。**钉子**：

- `test_pool_models_says_who_blocks_and_who_only_warns`：人话段同时含「网关」与「派活器」与「不拦」；
- `test_the_two_sides_really_differ`（`tests/test_pool_gateway.py` 或本钉同文件）：
  同一个过期号池，`gateway._model_block(...)` 返回 `(404, …)`，而
  `wb_dispatch.snapshot_stale_problem.__doc__` 里那句「不拦派活」仍在 —— 两半都是实测，不是文案对文案。

### 判据 4 · 反向变异 ≥4（真改真跑真还原）
