## 判据

### 判据 1 · 两档分类器：`gate_basis_verdict(...)` 是唯一判据

- 在 `tools/wb_review.py` 新增**纯函数**（无 IO，git 读写由调用方注入或本函数内只读一次）：
  ```python
  def gate_basis_verdict(payload_rev: str, parent_short: str, recorded_tree: str,
                         commit_sha: str, files: list[str]) -> tuple[str, list[str], str]
  ```
  返回 `(档位, 差异路径, 读数)`，档位 ∈ `{"BASIS_DRIFT", "TRUE_MISMATCH"}`。
- **BASIS_DRIFT 的四个必要条件（缺一即 TRUE_MISMATCH）**：
  1. `payload_rev` 与 `parent_short` 双向解析都成功（`_resolve_commit`，`:197-211`），
     且 `git merge-base --is-ancestor <payload_rev> <parent>` rc=0（**真祖先**）；
  2. 差异集合 `D − (payload_rev..parent 的改动 ∪ 本笔改动 files)` **为空**（残差 0 才叫漂移）；
  3. `recorded_tree` 在对象库里存在：`git cat-file -t <tree>` 成功（否则是**旧口径产物**，
     见判据 2 的例外档）；
  4. `D` 里**没有**任何路径落 `{lang}` 或 `{product}` 档（`gates.defs.domains.required_profiles(D)`，
     现读，不写死表）。
- 钉子：`tests/test_wb_review.py::test_basis_drift_classifies_one_middle_commit`（用临时仓造
  「门禁 → 插队提交 → 本笔」三段链，断言档位 = BASIS_DRIFT、差异路径恰好是插队笔那几条）。

### 判据 2 · 真不一致照红，且文案不许再诬告

- TRUE_MISMATCH 照旧进 `problems` 并**点名路径**；分支四类分别点名：
  非祖先 / 残差 X 条无法解释 / 落被测代码档（列出档名）/ tree 对象不存在（旧口径产物）。
