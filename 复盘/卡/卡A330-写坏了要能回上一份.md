# 卡 A330 —— 写坏了要能回上一份：magpie lastgood 移植进 pool（T-AG532）

> 台账号 `T-AG532` ｜ 分区 A（历史线 / 号池 pool）｜ 树 `.wt/A330` ｜ 层 判据层
> 依据：magpie 的 `internal/steady`（原子 `Rename`）、`internal/lastgood`（`Write` / `Read` / `Fallback`）、
> F77 的 `caller-keys.json` 纪律（「撤过的凭据不许复活」）；设计原件
> `_ext/_port_design_quota_routing.md`（F77 节）与 `_ext/_magpie_features.md` 的 F77 条。
> 实测现场（基准 `d262052d`）：五处写盘各写一套 `tmp` + `os.replace`，**`.bak` 一处都没有**；
> `tools/pool/registry.py:131 load()` 读到坏 JSON 就抛 `RegistryError` 且不清空 —— 没有「上一份好的是什么」。

## 要解决的问题

三本账（租约 / 任务 / 账号）里任意一份被写坏，冷启动就只能整条链停摆，因为**不知道上一份好的长什么样**：

```python
# tools/pool/registry.py:131（修前）
def load(path=None) -> list[dict]:
    """读登记文件的全部条目；文件不存在 → `[]`；**坏文件 → 抛错，不清空**。"""
    target = Path(path) if path is not None else registry_path()
    if not target.exists():
        return []
    text = target.read_text(encoding="utf-8")
    try:
        data = json.loads(text)          # ← 坏了就只剩抛
    except json.JSONDecodeError as exc:
        raise RegistryError(f"登记文件坏了，**不清空**：{target}（{exc}）…")
```

五处写盘（`tools/pool/registry.py:149 save` / `tools/pool/task.py:179 write_json_atomic` /
`tools/pool/queue.py:95 _save` / `tools/pool_accounts.py:216 save_ledger` / `tools/gate_pool.py:165 PoolQueue.save`）
**都有** temp + `os.replace`（读者看不到半截），但**都没有** `.bak`，于是「写到一半机器断电 / 磁盘写坏」
之后，恢复全靠人手。

magpie 的答案很短：`.bak` **故意落后一次写**（写新的之前先把旧的顶成 `.bak`），冷启动读不了正式文件就读 `.bak`，
**但恢复要记日志**；而「撤过的凭据」这类文件**从不**读 `.bak`（读不了就拒，fail-closed）—— 否则撤掉的 key 会复活。

## 判据（11 条）

1. **`write_atomic()` 不留渣**：同目录临时文件 + `os.replace`；写完 `glob("*.tmp")` 必须为空。
2. **`.bak` 落后一次写**：写 B 之前把 A 顶成 `<文件名>.bak`（不是写完再备份新的）；冷启动至多丢**一次**写。
3. **坏文件不许当 lastgood**：正式文件解析不了（`validate` 抛）⇒ 它的字节**不进** `.bak`
   —— 否则「上一份好的」被坏字节顶掉，兜底就是假的。
4. **`read_with_fallback()` 冷启动能救**：正式文件坏了 / 不在 ⇒ 读 `.bak`；两边都坏才抛，且消息里写明 `.bak` 也坏了。
5. **恢复必须留痕**：从 `.bak` 读成功**必须**调 `log(...)` —— 静默恢复等于把「账本被写坏过」藏起来。
6. **`read_strict()` 从不读 `.bak`**：给「撤过的凭据不许复活」这类文件用；读不了就拒（fail-closed）。
7. **`registry.load()` 走兜底但语义不变**：文件不存在 ⇒ `[]`；**空文件 ⇒ `[]`**（空 ≠ 坏，不走兜底）；
   坏文件 ⇒ 先读 `.bak` 并往 stderr 打一行；两边都坏才抛 `RegistryError`；**坏文件一个字都不动**。
8. **账号账本不从 `.bak` 复活**：`tools/pool_accounts.py` 的凭据/状态读失败就拒，不许拿 `.bak` 顶上
   （撤掉的号不许自己回来）。
9. **只用标准库**；换行走内建 `open()` 的 `newline=`（`Path.write_text(newline=)` 是 3.13+，云机跑 3.12）。
10. **既有行为一字不改**：五处写盘的对外语义（返回值、异常类型、落盘格式）不变；`tests/test_wb_land.py`
    的 `_NEW_TOOLS` 最小仓库清单要加进这一个新模块（**沙箱契约也要跟着长**，否则那份沙箱一 import 就 ImportError）。
11. **`registry.load()` 的异常类型归一**：`json.JSONDecodeError` → `ValueError` 之后才能用单参复刻
    （`JSONDecodeError` 要三个参数），兜底失败时才能把「`.bak` 也坏了」拼进消息里而不丢异常类型。

## 不许做

- 不许让 `.bak` 保存**新的**内容（那就成了「写完再备份新的」，冷启动会读到和正式文件一样的字节，兜底无意义）。
- 不许把坏文件当 lastgood（判据 3 咬的就是这个）。
- 不许在**账号账本**上开兜底（撤掉的凭据不许复活，判据 8）。
- 不许把恢复做成静默（判据 5）。
- 不许动多进程互斥语义（`O_CREAT|O_EXCL` 自旋锁「等满照样往下写」是既有约定，改它要另开卡）。
- 不许改任何既有测试的断言（`tests/test_wb_land.py` 只准往 `_NEW_TOOLS` 清单里**加**一行）。
- 不许加 `noqa` / `# type: ignore` 蒙过门禁。
- 不许改六份 `PROTECTED_FILES`（`docs/traceability.toml` / `docs/changelog.md` / `复盘/交接-重构进度.md` /
  `复盘/新窗口交接卡.md` / `gates/last.json` / `gates/reuse.json`）。
