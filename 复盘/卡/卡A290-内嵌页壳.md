# 卡 A290 · 内嵌页壳：服务停了也不出白框（T-AG404）

## 问题

- 禅道 / timeflow 走 iframe 直连真服务；服务没起或首答慢 ⇒ **白框**，用户看不出是「没起」还是「在加载」。
- 右栏不可用时客户端只抛原话 `sidebarRight: no session surface is mounted`，不降级到内嵌/新窗。
- 实测（桌面实例 59137）：禅道 iframe 白屏；工具箱里才有「一键启动」。

## 改法

1. iframe **先画工具条**（标题 + 状态点 + 「一键启动 / 刷新 / 右栏打开」），iframe 区域给骨架，8 s 未 `load` 显示「还在加载…重试」。
2. 服务 down（`stack-status` 里该组件不是 running）⇒ 不加载 iframe，画空态：一句原因 + 「一键启动」按钮。
3. 右栏不可用 ⇒ 自动降级为内嵌（本页 iframe），并在工具条上标明「已退回内嵌」。

## 判据

- 服务全停时三个入口**都不白屏**：可见状态点 + 原因 + 一键启动。
- 服务起来后 8 s 内 iframe 出内容；超时有可点重试。
- `python -X utf8 tools/dsh_panel.py --check` 绿；`pytest tests/test_dsh_panel.py -q --no-cov` 全绿；零颜色字面量。
