## 你要产出什么（**一个真零件 + 一份设计**，都不碰现有共享文件）

### ① `tools/domain_symbols.py`（**新模块**，纯函数、无副作用）
- `symbols_of(path) -> set[str]`：把一个 Python 文件里的**顶层符号**（函数 / 类 / 常量）列出来，
  并给出**行区间**（`def x` 到下一个顶层定义之间）。
- `declared_symbols(decl) -> set[str]`：解析队列里那种**声明**（形如 `tools/wb_dispatch.py::main`；
  **不带 `::` 就是「整个文件」**）。
- `overlap(a, b) -> Overlap`：判两份声明**是否落在同一个符号/行区间**；
  返回值要能区分四种：**文件不相交** / **同文件不同符号** / **同文件同符号** / **同一整个文件**。
- ★ **不许** import 项目业务代码；不许读网络；不许改任何现有文件。
