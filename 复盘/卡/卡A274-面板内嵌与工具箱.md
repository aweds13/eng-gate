# 卡 A274 —— 面板：三行就地渲染 + 工程工具箱

## 为什么
用户要「点开就在 DSH 里看到真实页面」，而不是先看状态卡再点按钮切窗口；同时要一个
统一入口看号池、技能、参数。旧版只有「打开 http://…」+ 状态文字，用户评「丑、反人类」。

## 改什么
1. `QuickEntry`：主体改为 `<iframe src={target.url}>`；顶部只留 `标题 · 状态点 ·
   一键启动（没起时）· 右栏打开 · 刷新`；没起时才显示命令与 `<details>` 服务细节。
2. 新增第 4 行 `sidebar.panellist`「工程工具箱」（main 座 `/panel/toolbox`），
   五个标签页：
   - 总览：`/dsh-panel/stack-status` 逐件在跑/没起/RSS + 全部起 + 起/停 + 三入口打开；
   - 看板：`workbench_board.reading.cards` 分四列（待办/在跑/已完成/其它）；
   - 号池：筛选（未收口/全部/已完成/失败）+ 表格（#卡/状态/任务，最多 60 行）；
   - 技能：宿主只读路由 `/dsh-panel/skills` 列 `skills/*.md`；
   - 参数：只读展示 `tools/settings.toml` 现值（**不给写口子**，见下）。
3. 宿主半：`serveSettings` 只接受 GET（405 明说「参数缝只读」）；新增 `serveSkills`。
4. 座位判据放宽（`check` + 单测）：前 `len(SEAT_KEYS)` 行必须与 `SEAT_KEYS` 逐项一致，
   尾部额外行只许是登记过的 `toolbox`。

## 判据（为什么这么定）
- **面板不许写仓库**：`--check` 的 `FORBIDDEN_WRITE_TOKENS` 咬 `writeFile/mkdirSync/
  writeFileSync`。参数页因此**只读**；要 GUI 可调需落用户级配置并另开卡放宽判据。
- 失败必须可见：两处 `data-wb-error=""` 分支保留（空响应/非 JSON 都要说出来）。

## 证据
- `python tools/dsh_panel.py --check` → `[OK ] 三座位…；只读 + 失败可见 + 只 GET`
- `pytest tests/test_dsh_panel.py -q --no-cov` → 111 passed
- `node --check lib/client.js` / `lib/index.js` OK
