# 卡 A304 —— 技能层补全（命令漂移 / 新建 / 接手 / 文档层 / 资产边界）

- 任务号：T-AG418
- 类型：docs（只动 `skills/`）
- 工作树：`.wt/A304`（分支 `card/A304`）

## 要解决的问题

技能层现在有四处不成立：

1. **教错命令**：11 个技能文件里共 24 处教 `python framework/cli/main.py …`，而本仓没有根级 `pipeline.toml`，这条命令在本仓跑不起来；真正在用的是 `tools/wb_*.py`。
2. **缺新建方向**：没有一个技能讲「从空目录/新仓起一条能跑的工作链」。
3. **接手方向断在半路**：`pipe-takeover` 讲了判类和最小骨架，没讲怎么接到 `wb_*` 链上。
4. **共用知识没落地**：五层文档怎么写、timeflow/pool/infra 三层资产边界，只存在于对话里。

## 七项改动

1. 新增 `skills/softeng-manage/references/doc-layers.md`：五层（意图/规格/契约/实现/品味）各放什么、不放什么；最小可行两层是什么时候；升级时机；指向 timeflow 41 篇实例（只给路径，不复制内容）。≤150 行。
2. 新增 `skills/pipe-takeover/references/attach-to-chain.md`：六步接链（只读勘察 → 不动原结构 → 最小骨架 → 首张卡 → 首笔落地 → 回滚点），每步给命令与验收。
3. 新增 `skills/pipe-new/SKILL.md`（≤120 行）+ `references/first-landing.md`（空仓第一次落地的完整命令 + 三个最常见的红）+ `NOTES.md`（人读版，含「失败过什么 / 脚本接口」两节）。
4. 新增 `skills/softeng-manage/references/asset-layers.md`：timeflow（产品）/ pool（谁来做）/ infra（在什么机器上）三层边界 + 本仓 15 处引用 `infra/pool` 的耦合点。
5. **命令漂移修正**：24 处逐条判。`pipe-init` 保留 pipe CLI（它就是铺框架骨架的），并写明「框架层 vs 本仓工作链」；`pipe-forensics`、`pipe-gate`、`pipe-land`、`softeng-manage`（含 `mapping.md`）、`GLUE-harness.md` 改成 `wb_*` 或显著标注层归属。
6. `skills/README.md` 索引补 `pipe-new` 一行，并给 `spec-grill` 留占位说明（后续卡补）。
7. 三处登记 + 校验：`~/.dsh/skills` 与 `<仓>/.dsh/skills`、`.codeartsdoer/skills` 都要 10/10；`npx skills-ref validate ./skills/pipe-new` 与 `./skills/pipe-takeover` 必须 Valid。

## 硬约束

- 只动 `skills/`；不碰 `tools/`、`gates/`、`docs/workbacklog.toml`（本卡登记除外）；
- `SKILL.md` ≤120 行；`references/` 只深一层；`name` 必须等于目录名，小写连字符；`description` ≤1024 字符且写清「做什么 + 何时用」；

- 每个新增/修改文件都要能被 `git ls-files` 认到。
