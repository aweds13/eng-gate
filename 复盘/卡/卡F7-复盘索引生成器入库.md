# 卡 F7 —— 复盘索引的生成器入库：让 769 篇的索引可重算

> 台账号 T-AG511 · 分区 F（文档治理）· 批号 F-20261027-1（与 F6、G5 同笔落地）
> 依据：`gates/diag/` 被 `.gitignore:76` 的 `gates/diag/*` 忽略，而它产出的
> `复盘/INDEX.md`（1160 行）**入库**。生成器不入库、产物入库 ⇒ 索引**不可重跑**。

## 要解决的问题

`复盘/INDEX.md` 是全仓 769 篇复盘唯一的指路牌，但它自己的生成链在仓外转不起来：

1. **生成器躺在一个被 gitignore 的目录里**。六个脚本原本在 `gates/diag/retro_*.py`，
   而 `.gitignore:76` 写着 `gates/diag/*`（`:75` 只放行 `!gates/diag/` 目录本身、
   `:77` 放行 `!gates/diag/gates.last.json`）。后果：产物入库、生成器不入库 ——
   下一个窗口拿到索引却复算不出来，只能手改。
2. **`INDEX.md` 里写的复算命令是假的**。`复盘/INDEX.md:13` 声称可复算：
   `retro_extract.py --extract` → `retro_themes.py` → `retro_gaps.py` → `retro_index.py --write`。
   实测六个脚本**没有一个**认 `--extract` 或 `--write`（只有 `--show` / `--only` /
   `--id` / `--all` / `--full` / `--top` / `--grep` / `--sample` / `--preview`）。
   照着这行敲必然什么都不发生，而且**不会报错** —— 它只在 `--preview` 之外的分支
   直接把 `INDEX.md` 写出去。
3. **中间产物入不了库**，链就跑不起来：`retro_extract.json` / `retro_theme.json` /
   `retro_lines.json` / `retro_gaps.json` 四个都在 `gates/diag/` 下。

外加 `INDEX.md` 的读数本身落后：标题写「587 篇」，盘上 769 篇；
主题表里 `handoff 144`（盘上 220）、`misc 1`（盘上 13）。

## 判据（四条）

1. **生成器在入库目录里**：六个脚本落在 `scripts/retro/`（`git ls-files` 看得见），
   不再依赖 `gates/diag/`。
2. **`INDEX.md` 里写的复算命令能照抄执行**：四步链每一步都是真能跑的命令；
   跑完之后 `INDEX.md` 字节不变（幂等）。
3. **读数当场算，不写死**：篇数、目录分布、主题计数一律从盘上算，
   手写的 587/268/176/143 这类数字必须消失（`retro_index.py` 里已有
   「段表三数一律当场算，不许写死」的注释，判据是让它对全体读数成立）。
4. **中间产物有落处且可重建**：四个 json 能重新生成，`INDEX.md` 只由它们产出。

## 交付

- `scripts/retro/retro_extract.py` / `retro_themes.py` / `retro_lines.py` /
  `retro_gaps.py` / `retro_phrases.py` / `retro_index.py`（从 `gates/diag/` 搬进入库目录）
- `复盘/INDEX.md`（按盘上 769 篇重新生成；读数与主题计数当场算）
- `复盘/INDEX.md:13` 那行复算说明改成**真命令**

## 验收

```
python -X utf8 scripts/retro/retro_extract.py
python -X utf8 scripts/retro/retro_themes.py
python -X utf8 scripts/retro/retro_gaps.py
python -X utf8 scripts/retro/retro_lines.py
python -X utf8 scripts/retro/retro_index.py
git -c core.quotepath=false status --porcelain -- 复盘/INDEX.md   # 期望：空（幂等）
```

## 不许做

- 不许改 `复盘/` 下任何一篇正文 —— 这一张卡只动索引与生成器。
- 不许把 `INDEX.md` 里的读数字段手改成「看起来对」的值：要么当场算，要么不写。
- 不许为了让四步链跑通去改 `.gitignore:75-77` 那三行（那是 `gates/diag/` 的放行
  规则，动它会把 150+ 个诊断产物一起放开）。
