# 卡 A324 · 卡归窗口（DSH 会话指纹绑定）

- task: T-AG437
- tree: `.wt/A324`
- risk: low
- depends: A321

## 目标

一张卡默认只归**一个 DSH 对话窗口**。别的窗口要动它，必须显式换手；工人/定时任务（没有会话指纹）一律放行。
动机：多窗口并行时，两个窗口同时对同一张卡落地会互相回退对方的树（这轮 A321 落地里真实发生过）。

## 判据（写死在 `tools/wb_session.py`，别处不许再判）

1. **没有指纹就放行**：`DSH_SESSION_ID` 缺失（号池工人、cron、纯终端）⇒ 不拦、不记账。
2. **首次接触即认领**：卡没有租约时，谁先动谁认领，租约写进 `gates/diag/session-leases.json`（gitignored 运行态）。
3. **换手要明说**：卡归别的窗口时拒（退出码 2），除非带 `--take-over`；换手后旧窗口进 `history`（留痕，不静默抢）。
4. **租期 24 小时**：过期即视为无主，避免卡被一个死掉的窗口永久占住。
5. **释放**：`python tools/wb_session.py --release <卡号>` 任何窗口都能放。

## 交付

- `tools/wb_session.py`：`session_id()` / `owner()` / `claim()` / `release()` / `listing()` + CLI（`--list` / `--claim` / `--release`）。
- `tools/wb_land.py`：落地前过闸（`_session_gate`），`--take-over` 透传。
- `tools/wb_dispatch.py`：派活前认领，`--take-over` 参数。
- `tests/test_wb_session.py`：四条钉子（无指纹放行 / 首次认领 / 别人窗口要换手 / 释放后可再认领）。

## 不做

- 不做「每窗口同时持有几张卡」的配额（另开卡；需要 `--limit` 时再加）。
- 不做面板上的释放按钮（面板只读，等它拿到写口子再谈）。
- 不改号池租约（那是另一套 `gates/diag/leases`）。

## 验收

- 树内 `pytest tests/test_wb_session.py tests/test_wb_land.py tests/test_wb_dispatch.py` 全绿。
- 两个不同 `DSH_SESSION_ID` 对同一张卡：第一个认领成功、第二个被拒并给两条出路、`--take-over` 后换手成功、`--release` 后第三个窗口可再认领。
- `wb_land --help` 不报错（脚本方式运行时 `sys.path` 不含仓根，靠 try/except 回落）。
