## 要解决的问题（已实测，不是推测）

云门禁第二趟（卡 A366 的树，端口段 9520）**22 门真跑完了**，18 门绿、`render` 按设计
`EXCLUDED`（金样本在采集机 `DEV-HOST`，云机是 `gates-runner-host`），**唯独 `pytest`
门一条红**：

```
1 failed, 4405 passed, 7 skipped, 2 warnings in 855.87s (0:14:15)
FAILED tests/test_gate_port_isolation.py::test_two_runs_at_once_do_not_collide
```

证据三份（都已 scp 回本机）：`gates/diag/cloud-last-A366.json`（`ok False`、`gates 22`）、
`gates/diag/cloud-pytest-A366.log`（14565 B，失败单 + 逐字末段）、
`gates/diag/cloud-gate-A366.log`（4/5 段外壳输出）。

红的地方是**正路**那半截（`tests/test_gate_port_isolation.py:302`）：

```
assert codes == [0, 0]
AssertionError: 两条各自 10600 / 10603 并行居然有红的：[1, 1]
    第一条末段：…
        - div.shell>main#main>div.new>button	添加	16,332,58,35	13/normal/400	#ffffff/#2f6feb	10;8px 16px
        …（共 202 行差异，上面 10 行是有文字内容的）
    若这次改动**是有意的**：node tools/render_check.mjs --update --reason "一句话为什么"
```

**这不是端口打架，是显示栈不同**：两条各自用 10600 / 10603，互不干扰，各自都跑完了
（15.2 s / 16.1 s），只是 `tools/render_check.mjs` 拿本机字形度量与采集机的黄金逐字节比，
必然差 202 行。同一个「金样本主机专用」的事实，`scripts/run_gates.py` 早就认了
（`:657 golden_host_reason()`，`:2637` 据此把 `render` 记 `EXCLUDED`），
`tests/test_only_selector_parity.py:150` 也早就照它 `pytest.skip` 了 ——
**只有这一条钉子还在拿「逐字节一致」当自己绿的条件**，于是它把「这台机器做不到这件事」
记成了回归，把整趟云门禁打成 `ok=False`。

★ 为什么不能简单 `pytest.skip` 掉（那是最省事也最坏的做法）：这条钉子的**反证**那半截
（同端口必须被拒）在任何机器上都成立，跳过整条等于把「两条并行不许踩」这条判据一起丢掉；
而且判据一旦能整条跳过，将来谁把端口逻辑改坏也不会有人喊。所以本卡要的不是「跳过」，
而是**把「红」分成两类**：金样本不一致（这台机器上允许）与踩上了（任何机器都不许）。

## 判据（6 条）

1. **判据只有一份**：本文件里的「金样本主机专用」判断**必须**调
   `scripts/run_gates.py:golden_host_reason("render")`（照
   `tests/test_only_selector_parity.py:150` 的体例包一层同名 helper）。
   ★ 判据：文件里**不许**出现 `CAPTURED_ON`，也**不许**出现 `platform.node()` ——
   出现任何一个就说明有人另写了一份比较逻辑。
2. **正路分两档，且档位由那唯一一份判据决定**：
   - 在采集机上（`golden_host_reason()` 回 `None`）⇒ 仍然**严格**要求 `codes == [0, 0]`，
     一个字都不放宽；
   - 在别的机器上（回理由）⇒ 每条要么退 0，要么**失败的证据必须是金样本不一致**
     （输出里有 `渲染与黄金不一致`）。退非零但**说不出**是金样本不一致 ⇒ 判红。
3. **踩上了永远判红**：任何一档下，输出里出现 `分组「高数」已存在`（两条并行重复 seed 的
   原文话术）都判红 —— 不许因为「这台机器金样本对不上」就顺带放过真踩踏。
4. **判定逻辑是纯函数，可被钉子直接驱动**：新增一个把 `(codes, outs, why)` 映射成
   「问题清单」的函数，真跑那两截只负责起进程与断言清单为空。这样上面两档才有确定性钉子
   （不必真起浏览器就能把四个分支各咬一遍）。
5. **反证那半截一字不动**：同端口必须被拒 + 点名端口 + 一次 `POST /api/groups` 都不发，
   四条断言保持原样；`test_busy_port_is_refused_not_seeded` 与其余五条钉子保持原样。
6. **纯 CRLF + ruff 干净**：改动后该文件仍是纯 CRLF（`bareLF == 0`），两者必须给出读数。
