## 要解决的问题

1. **写文档没有入口**：`AGENTS.md` 的路由表已有「跑门禁 / 读懂门禁结果」一行（实测 `AGENTS.md:16`），
   但**没有**「我要写 / 改 / 补文档」这一行；于是新窗口只能照着「改一点、看一点」的方式改，反复往返。
   缺的是一页「写前四问」，不是再写一份规范总纲。
2. **改文档的反馈成本差 159 倍**：`scripts/check_docs.py` 只有全仓模式（15 s），
   而 `docs/INDEX.md` 新鲜度检查挂在 `pytest` 那道门里（1320 s）⇒ 改一行字要等十几分钟才知道错。
3. **会漂的数字写死在文档里**：`tools/pool_mcp.py` 五处还写「六个只读工具」（真值 13 只读 + 5 写）；
   `tools/wb_land.py` 三处写「11 条判据」（真值 12，判据真源 `tools/pool/landing.py` 已写 12）。
4. **照抄即失败的命令**：`docs/presets/softeng.patch.yml` 第 21 行让人跑 `pipe doctor`，
   而本仓没有 `pipe` 命令、也没有 `pipeline.toml`（实测两条路都失败，见判据 5）。

## 判据（6 条）

1. **写文档有入口且只有一页**：`AGENTS.md` 的路由表新增一行「我要写 / 改 / 补 文档」，
   目标只指向 skills/softeng-manage/references/doc-write.md（本卡新建，**≤80 行**）；
   该页只写**四问**（定层 / 改还是加注 / 引用怎么给 / 写完跑哪句），**一个字判据都不抄** ——
   判据仍只在 `scripts/check_docs.py` / `scripts/check_layers.py` / `skills/nails/` 一处。
   钉子：该页里不许出现「阈值 / 上限 / 条数」这类判据常数（用 `grep` 断言）。
2. **单文件有反馈**：`scripts/check_docs.py` 加 `--file <路径>`（可重复）：只扫这几份，
   死指针 / 已废弃两腿只看命中文件；`drift` 腿仍全量（它不是按文件算的）。
   输出里要写明「只看 N 份（全仓 X 份）」——**不许**让人误当全仓结论。
   钉子：给一个**故意坏**的单文件 ⇒ 退非零且只报那一份；给一份**好**的单文件 ⇒ 退 0；
   不给 `--file` 时行为与今天逐字节一致。
3. **会漂的数字删掉**：`tools/pool_mcp.py` 五处「六个」改成与 `:563` 一致的「十三个」，
   并在 `:47` 补一句 confirm 的三种语义（`task_register` = TOML 的 `id`、`task_claim` = `task`、
   `usage_report` = 这一批的记录条数）；
   `tools/wb_land.py` 三处「11 条判据」改成「条数现读」措辞（不写死数字）。
   钉子：`grep -c 六个 tools/pool_mcp.py` 必须为 0；`grep -c "11 条" tools/wb_land.py` 必须为 0。
4. **去掉会骗人的示例命令**：`docs/presets/softeng.patch.yml` 第 21 行的 `pipe doctor`
   换成**不假设 `pipeline.toml` 存在**的措辞（例如「先读 `AGENTS.md`；工具入口是 `python -X utf8 tools/<tool>.py`」）。
   钉子：该文件里不再出现 `pipe doctor`。
5. **CX-01 的判据要能证它自己那句话**：`tools/contract_audit.py` 里 CX-01 现在挂的是
   `skills/nails/check_skills.py`（只核格式，证不了「删掉 `skills/` 框架仍可用」）。
   本卡**不新增门**（加第 23 道门要同步改 `GATE_PROFILES`、`gates/gate-selfproof.toml`、
   `tests/test_gate_selfproof_product.py` 的 22、`docs/subsystems/ci/` 三份表，代价远大于收益），
   只把 CX-01 的 `judge` 换成**合成形态**：一条 pytest，把 `skills/` 临时改名后跑 audit 档的门表构建。
   钉子：删掉/改名 `skills/` 后该判据仍绿；`skills/` 在时也绿。
6. **反向变异 ≥4 条**：`--file` 变成不过滤（全量扫）/ `--file` 命中空集仍退 0 /
   CX-01 的 judge 改回只核格式（合成测试红） / `pool_mcp` 的「六个」改回 —— 四处各自能让对应钉子红。
