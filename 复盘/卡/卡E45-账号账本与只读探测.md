# 卡 E45 —— 账号账本与只读探测（T-AG496）

> 目标：把散在五个平台目录里的账号收成**一份账本 + 一张能力表 + 一组只读命令**，
> 让「我现在有哪些号、各自什么状态、能不能签」一句话问得出来，且**凭据一个字节都不进 git**。

## 1 现状（为什么做）

- 账号散落：`~/codebuddy-accounts/`（`ACTIONS.log` + `tongxue3` 快照）、`~/.codebuddy`、
  `~/.workbuddy`、`~/.codeartsdoer`（`pool.env`，2026-09-30 09:38）、`~/.trae` —— 五个位置、四套凭据形态。
- 仓外 `infra/pool/` 已有七个部件（`dispatch.py`、`codebuddy_accounts.py`、`rotate_credentials.py`、
  `usage_report.py`、`models.whitelist.toml`、`models.live.json`、`model-switches.toml`），
  但**没有一份跨平台的账号清单**：`codebuddy_accounts.py` 只管 codebuddy 一家。
- `quota_status`（卡 201）只回答「某张卡 × 某个模型的额度四态」，回答不了「我有哪些号、哪个能签」。
- 结果：每次要问「还有哪个号能派活」，都得临时翻目录，且翻的时候有把 `refresh_token` 抄进日志的风险。

## 2 要做成什么样（四件）

1. **`tools/pool/platforms.toml`（进 git、可审、无凭据）** —— 平台能力表：每个平台一节，
   字段 `id / label / supported（claim|quota|both|none）/ auth_kind / base_urls / claim_flow / quota_flow / pitfalls / source`。
   `source` 必须写清「哪份参考实现、哪个文件、哪一行」，不许写「凭经验」。
2. **`tools/pool_accounts.py`（进 git、有钉子）** —— 四个**只读**子命令：
   - `list [--platform X] [--json]`：账本里所有号，一平台一行；列 `id/platform/label/state/quota/last_probe`。
   - `show <id>`：单个号的全部账本字段 + 凭据**位置指针**（`locator/kind/expires_at`），**绝不打印凭据值**。
   - `discover`：扫五个已知目录，报告「发现候选账号」的路径与文件 mtime，**只报路径与时间戳，不读内容**；
     已入账的标 `known`，未入账的标 `candidate`（不自动导入）。
   - `probe [--platform X] [--json]`：对每个号跑**只读探针**（今天领没领 / 还能不能领 / 余额多少），
     **不发任何领取请求**；结果回写 `[account.quota]` 的 `samples`（保留最近 20 条）与 `[account.health]`。
3. **账本 `infra/pool/accounts.toml`（仓外，永不进 git）** —— 路径解析与 `tools/pool/projects.py` 同口径：
   `TF_ACCOUNTS_TOML` 覆盖 → 否则从本树逐级向上找 `infra/pool/accounts.toml` → **找不到就抛错，不猜路径**。
4. **MCP 只读工具 `account_status`（`tools/pool_mcp.py`）** —— 参数 `platform?`/`id?`，
   返回与 `list --json` 同形的摘要；**只读账本文件，不发起任何网络请求**（与现有十一个只读面同性质）。

## 4 账本 schema

```toml
[[account]]
id = "codearts-3"                     # 稳定 id，进日志/台账
platform = "codearts"                 # 必须是 platforms.toml 里的 id
label = "同学3"                        # 人看的名字
owner = "me"
added_at = "2026-10-25T16:00:00+08:00"
state = "active"                      # active|rate-limited|exhausted|expired|retired
approved_models = ["huaweicloud-maas/deepseek-v4.1-flash"]   # 与 models.whitelist.toml 求交后才是真能派活的

[account.credential]
locator = "~/.codeartsdoer/pool.env"  # 只存位置
kind = "env-file"                     # env-file|cookie-store|json|keychain
expires_at = "2026-11-30T00:00:00+08:00"   # 不知道就 null，不许编
refreshable = "one-shot"              # one-shot|rotating|manual

[account.quota]
unit = "credits"                      # credits|tokens|requests
amount = 800.0                        # 不知道就 null
observed_at = "2026-10-25T16:10:00+08:00"
source = "probe"                      # probe|manual|report|unknown
samples = [{ at = "2026-10-25T16:10:00+08:00", amount = 800.0 }]

[account.health]
last_probe = "2026-10-25T16:10:00+08:00"
consecutive_failures = 0
state = "ok"                          # ok|degraded|quota-exhausted|auth-expired|unknown
```

三条硬规矩：**只存指针不存明文**；**`source = "unknown"` 时 `amount` 必须是 null，不许填 0**
（参考 `dsh-credit-hub` 的口径：上游没返回就是 `null`，服务端明确返回的 0 才是 0）；
**删除只打墓碑（`state = "retired"`）不删行**，否则 `discover` 会把同一个号当候选重新导进来。

## 5 判据（每条都要有钉子）

1. `pool_accounts.py list --json` 在测试账本上输出**稳定排序**（platform, id），字段集与 schema 一致。
2. **凭据零泄漏**：`show <id>` 与 `--json` 全量输出里不得出现账本里 `locator` 之外的任何凭据样字符串；
   钉子用一组**假凭据形状**（`sk-…`/`AKIA…`/40 位 hex/`eyJ…` JWT）注入账本，断言输出里一个都不出现。
3. **仓内零凭据**：`tools/pool/platforms.toml` 与 `tools/pool_accounts.py` 里不得出现上述形状
   （钉子扫文件文本），`source` 字段必须非空且形如 `path:line` 或 `repo/path`。
4. `discover` **只读目录项**：用 monkeypatch 断言实现里没有任何 `open()` 读到 `locator` 指向的文件内容
   （只 `stat()`）；输出里只有路径与 mtime。
5. 账本找不到时**抛错退出 2 并打印解析过程**（`TF_ACCOUNTS_TOML` 指了不存在 ⇒ 报「指了但不存在」，不回落）。
6. `probe` 在 `--dry-run` 之外的实现里**不得出现领取动词**：钉子静态扫源码，断言不含 `/claim`、`check_in`、
   `daily-checkin` 字面量（只允许出现在 `platforms.toml` 的 `claim_flow` 文本里）。
7. `probe` 的网络失败分类：连接失败/超时 ⇒ `uncertain`（不判 `failed`）；HTTP 404 ⇒ `not-supported`；
   `base_resp.status_code != 0`（HTTP 200）⇒ `failed(code)`。
8. 账本写回是**原子替换**（tmp + `os.replace`），并发两个 `probe` 不互相截断（钉子用两个进程并发，断言结果可解析）。
9. `samples` 保留最近 20 条，超出丢最旧；`amount` 为 null 的样本不入 `samples`。
10. MCP `account_status` 只读：给一个会抛异常的网络层 monkeypatch，断言工具仍返回账本摘要（即不联网）。
11. 反向验证：把 `platforms.toml` 里 `codearts` 段删掉 ⇒ `list` 对着该平台的号必须报
    「平台不在能力表 ⇒ 未知平台，state=unknown」，而不是崩或静默跳过。
12. `python -X utf8 -m pytest tests/test_pool_accounts.py -q` 全绿；`ruff` 全清；`check_layers` PASS。

## 6 不许做

- **不许把账本放进 git**，也不许把 `accounts.toml` 路径写进 `docs/`（写「仓外 `infra/pool/accounts.toml`」即可）。
- **不许 `probe` 顺手签到**（探针与领取严格分文件/分函数，E48 才做领取）。
- 不许自动发现即导入；`discover` 只报候选。
- 不许为「好看」把未知额度填 0 或按倍率估算（`dsh-credit-hub` 的 usage 账本明确：缺字段就是 null）。
- 不许把凭据写进日志、异常栈、`gates/diag/*.json`。
