## 做法（七件，每条都要有反例钉子；★ 别扩大）

1. **新增 `tools/pool/projects.py`**：读 `infra/pool/projects.toml`
   （**允许 `TF_PROJECTS_TOML` 覆盖** —— 测试要用它造临时索引；找不到文件 ⇒ **报错，不猜**）。
   提供 `load()` / `get(name)` / `find_by_tree(rel_tree)` / `memory_entries(name)`；并**校验索引本身**：
   - 每个项目 `root` **必须真实存在**（不存在 ⇒ 拒并点名）；
   - **两个项目不许同一个 root**（撞了 ⇒ 拒并点名两个名字）；
   - `tree_prefixes` **非空**（空 ⇒ 拒并点名）—— 空的树前缀等于"哪儿都能派"，那就没有守卫了。
2. **`tools/pool/guards.py` 新增 `project_guard(tree_rel, project=None)`**（**纯函数**，与同模块另三条同一风格）：
   - **没登记过的项目 ⇒ 拒**（"存在性即授权"，和 MCP 写面同一个思路）；
   - `tree` **不落在**该项目 `tree_prefixes` 里 ⇒ 拒，并**点名允许哪些前缀**；
   - 不给 `project` ⇒ 用 `find_by_tree` **反查**；反查不到 ⇒ 拒（"这棵树不属于任何已登记项目"）。
   ★ **不许**为了接这条而放宽任何**既有**守卫（树 / 域 / 锁 / 日志）。
3. **`tools/pool/registry.py`**：租约里**加 `project` 字段**（占树时定下来），`tools/wb_registry.py` 打印带上它
   （面板/CLI 要看得见"这棵树属于哪个项目"）。
4. **`tools/wb_dispatch.py`**：派活前置检查里**接上 `project_guard`**（放在**既有树守卫/域守卫之后**）；
   `--project` 可显式给，不给就反查。★ **不许**放宽既有前置（内存 / 登录 / 白名单 / 日志 / 树 / 域 / 锁）。
5. **新增 `tools/wb_project.py`**：`use <项目>` / `show` / `memory`：
   - `use` 写 `<主工作树>/gates/diag/current-project.json`（**带 `TF_WINDOW_ID`** —— 窗口级：一个窗口一个当前项目）；
   - `show`：没选 / 没登记 ⇒ **说清并退非 0**（别静默）；
   - `memory`：照索引里的 `memory` 列表**打印该项目的最小记忆入口**（主控照着读；**别的项目一份都不读** ——
     这就是"避免脏 token"的正解）。
6. **`tools/pool/task.py`（收批栅栏）**：任务状态里加 `project` 字段（反查得到就写；拿不到就留空
   并**在 `history` 里记一行**说清为什么）—— ★ **不许**因此改变任何既有放行判据。
7. **钉子 `tests/test_pool_projects.py`（正反都要）+ 既有测试补几针**：
   - 索引坏：缺 `root` / `root` 不存在 / **两个项目同 root** / `tree_prefixes` 空 ⇒ **报错并点名**；
   - `project_guard`：**别的项目的树 ⇒ 拒** · 未登记项目 ⇒ 拒 · **正常树 ⇒ 放行**；
   - ★ **反例**：`--project 码道`（索引里只有注释）⇒ **拒**（**不许猜路径** —— 这是用户亲口定的口径）；
   - 租约里**真的写了 `project`**（写进去再读回来核）；
   - `wb_project.py memory` 对 `engineering` 打印的那三份与索引**逐字一致**。
