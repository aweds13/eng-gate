## 要做的事

### 1. 三个座位（`tools/dsh_panel.py` 从「单面板」扩成「多面板」）

| 座位 key（= `main` key = 左栏行 id） | 左栏 label（zh / en） | order | 数据源 |
|---|---|---|---|
| `workbench_board`（已有） | 工作台看板 / Workbench board | 0 | `pipeline_view.py --json` |
| `zentao_gantt` | 禅道迭代甘特 / ZenTao gantt | 1 | `zentao_gantt.py --json` |
| `timeflow_inbox` | timeflow 待办 / timeflow inbox | 2 | `timeflow_inbox.py --json` |

每个座位都要：`main` 一座 + `sidebar.panellist` 一行 + 一个 glyph（沿用卡 221 的做法）。

### 2. 宿主半：**三个只读工具** + **一条只读缝**

- 路由（同源、**只 GET**、只本机、只读、**不写盘、不起工人**）：
  `/dsh-panel/workbench-board`、`/dsh-panel/zentao-gantt`、`/dsh-panel/timeflow-inbox`。
  每个 handler 起对应**只读**工具（`spawnSync`，`windowsHide: true`，带超时），把它的 JSON **原样**回给浏览器。
- 缺数据（工具不在 / 非零退出 / 超时 / 输出不是 JSON / 顶层不是对象）⇒ 回 `{ ok: false, error: "<原话>" }`
  —— ★ **绝不许用空数据冒充成功**（卡 221 已立的口径，照旧）。
- 会话内三个只读工具也注册：`workbench_board`（已有）+ `zentao_gantt` + `timeflow_inbox`，说明里写清「缺什么说什么」。

### 3. 浏览器半：三块渲染（纯 DOM/SVG，不引第三方库）

- 用 `fetch("/dsh-panel/…")` 取数（同源）。
- `workbench_board`：六块，原样（已有实现，搬过来即可）。
- `zentao_gantt`：按模型画**条**（任务名 + 起止 + 迭代分组，画得出来就够，不求漂亮）。
- `timeflow_inbox`：列表。
- 失败可见：失败 ⇒ `data-wb-state="error"` + 原话；某块缺 ⇒ `data-wb-state="missing"`（**不许白屏**）。

### 4. 判据（扩 `tests/test_dsh_panel.py`；每条都要**先红后绿**读数）

1. 三个座位的 `main` key **与** `sidebar.panellist` 行 id **一致**（两个列表逐项比，写死不许手抄）；
2. 三条路由**只 GET**（不许出现 `post`/`put`/`delete`/写盘 API）；
3. 缺数据 ⇒ 必须回 `ok:false`（造一个"工具不在"的目录，调 handler，断言 `ok is False` 且有 error 原话）；
4. 复用既有 `FORBIDDEN_WRITE_TOKENS`（源码里不许出现写仓库 / 起工人的词）；
5. 装法文档必须写 `file:` 且写明**不许 `link:`**（今天实测：`link:` ⇒ 宿主半裸导入 `ERR_MODULE_NOT_FOUND` ⇒ 整行 Loader 条目起不来 ⇒ 界面里什么都没有）。
