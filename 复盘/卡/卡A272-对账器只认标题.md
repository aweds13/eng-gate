# 卡 A272 —— 对账器**只认标题** + **终态不判红**（T-AG390）

**树**：`.wt/A272`（或主树）｜ **成员号**：`B-DOCS` ｜ **层**：工具层
★ 只改 `tools/wb_reconcile.py` + `tests/test_wb_reconcile.py`。

## 为什么有这张卡

卡 A269 立的对账器（`tools/wb_reconcile.py`）在真仓上**误报**过一次：

- 卡 146 状态是 `failed`（2026-10-03 主控裁定：**被卡 166 取代**，`.wt/onemodel` 的旧工作故意留着），
  却被报成 `stale-pending` —— 因为 `git log --grep T-G246` 命中了 **A269 自己的提交正文**里那句
  `T-G246` 示例，而不是任何真正落地的 `（T-G246）` 标题。
- 判据本身是「状态不是 done + 有提交 ⇒ 红」，把 `failed` / `void` / `deferred` 这些**终态**
  也一并算进去了 —— 而终态恰恰**允许**历史里有提交（被取代 / 半途废弃）。

## 要做的事

1. `_commit_for()` **只认提交标题**：`git log --format=%h%x00%s --grep <task>` 多取几条，
   逐条看 **subject** 里有没有该任务号；正文提到不算。
2. `check()` 只对**活队列状态**判 `stale-pending`：`pending` / `todo` / `ready` / `in-progress` / `running`。
   `failed` / `void` / `deferred` 等终态**不判红**（docstring 写清理由）。
3. 钉子（`tests/test_wb_reconcile.py`，先红后绿）：
   - ③a `failed` + 正文提到任务号 ⇒ **不许**红（退出码 0）；
   - ③b `pending` + 只有正文提到任务号 ⇒ **不许**红（正文不算落地）。
   - 既有三条（pending 有提交红 / done 无提交黄 / 自洽绿）一条都不许破。
