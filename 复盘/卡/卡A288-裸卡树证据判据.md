# 卡 A288 · 裸卡树证据判据：gitignored 路径不算缺（T-AG402）

## 问题

- **`.gitignore:76` 的 `gates/diag/*`** 让 `gates/diag/` 下的运行态产物**不进 git**（只有 `gates/diag/` 本身和 `gates/diag/gate_lock.py` 走 `!` 例外入库）。而门禁的 cwd 是**卡树**（`.wt/<卡>`，由裸 `git worktree add` 建出来）⇒ 卡树里根本没有这些文件。
- `scripts/audit_progress.py` 的 `eval_assertion()` 对 `file:` 只判 `(ROOT / rest).exists()`（`scripts/audit_progress.py:185`），对 `text:` 只判 `p.exists()`（`scripts/audit_progress.py:193`）。台账里有 16 条 `file:gates/diag/…` / `text:gates/diag/…` 证据 ⇒ 这些断言在**任何**裸卡树里必然假红，跟本笔改了什么无关。
- **实测（修前，`48f2930` 的裸树）**：`python -X utf8 scripts/audit_progress.py` ⇒ **exit 1**，③ 段 12 条 `[FAIL] …（…）断言不成立 → 文件 gates/diag/…`，尾行「**审计不通过不许提交**」。主树同一份脚本 ⇒ 「审计通过 ✅」，且失败项 12/12 全是 `file:gates/diag/…`，没有一条是真缺的跟踪文件。
- A286 / A287 两次都是靠**把主树 `gates/diag/` 运行态与产物人工拷进卡树**才过门 —— 那是 hack，不是判据：换个窗口、换台机器拿到这份仓库，同一个环就必然复现。

## 改法

1. **新增 `is_gitignored(rel)`**（`scripts/audit_progress.py:158`）：`git -C ROOT check-ignore -q <rel>` 判这条路径是否被 `.gitignore` 忽略。结果进 `_IGNORED_CACHE`（`scripts/audit_progress.py:155`，同一路径只问 git 一次）；`subprocess.run` 带 `CREATE_NO_WINDOW`（`os.name == "nt"` 时才给，POSIX 落 0）；`OSError` ⇒ 当「不忽略」，**不许**因为 git 叫不动就静默放过。
2. **`file:` 分支接进去**（`scripts/audit_progress.py:182`）：存在 ⇒ 照旧 `True`；不存在且被 gitignore ⇒ `True` + 「gitignored：不随卡树分发，不算缺」；**不存在且被跟踪 ⇒ 照旧 `False`**。
3. **`text:` 分支同理**（`scripts/audit_progress.py:195`）：文件不存在且被 gitignore ⇒ `True` + 「gitignored：不随卡树分发，跳过断言」；否则照旧 `False`。
4. **钉子三面都钉**（`tests/test_audit_tightening.py:280`，`test_gitignored_evidence_is_not_a_missing_file`）：① gitignored 路径缺（`file:gates/diag/_never_exists_probe.md`）⇒ 过，且说明里必须含 `gitignored`；② **跟踪文件**缺（`file:tools/_never_exists_probe.py`）⇒ **必须红**；③ 真存在的（`file:tools/stack.py`）⇒ 照旧过。第 ② 面是这卡的要害：判据没放宽，只把「本来就不进 git」摘出去。

## 判据

- `python -X utf8 -m ruff check scripts/audit_progress.py tests/test_audit_tightening.py` ⇒ `All checks passed!`。
- `python -X utf8 -m pytest tests/test_audit_tightening.py -q --no-cov -o addopts=""` ⇒ **25 passed**（原 24 + 本卡 1）。
- `python -X utf8 scripts/audit_progress.py`（主树）⇒ 「审计通过 ✅」。
- **裸卡树 audit 必须自己绿**（本卡的意义）：落地后新建一次性裸树 `git worktree add --detach .wt/_probe <新sha>`，**不拷任何 `gates/diag/` 产物**，在里面跑 `python -X utf8 scripts/audit_progress.py` ⇒ **exit 0**、尾行「审计通过 ✅」。修前同一条命令在同一位置是 exit 1 / 12 条假红。
- 不变式：①被跟踪文件缺了照样红；②`gates/diag/` 仍然 gitignored（**不动 `.gitignore`**）；③不改门禁配置、不加 `exceptions` 豁免 —— 修的是判据，不是把账抹平。
