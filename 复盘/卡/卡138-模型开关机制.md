# 卡 138 —— **模型开关**：外部开关文件 + 派活器读它（用户要的那个"按一下就 true/false"）（T-G236）

**树**：`.wt/modelswitch` ｜ **base**：主控派活时的主树 HEAD ｜ **提交**：★ **不要 commit** ｜ **模型**：默认
**成员号**：任务 `B-SWITCH` 的 **M-1**（干完要交成送申请，见最后）

## 来路（用户原话）

> 「我能不能你弄个**插件**在那个页面上，我可以调整，可以**开关 GLM5.3 是否用**？大概思路就是啊，
> 当我**按下开**的时候它就变成 true，**按下关**的时候它变成 false。」

背景：`glm-5.3` 现在**被默认拒绝**（`ONE_OFF_MODELS` 已按用户令清空，见 `T-G235`）。
用户要的是**一个开关**，而不是"每次改源码 + 跑一趟门禁"。⇒ **开关必须是数据、不是代码**。
★ **本卡只做"开关的机制"**（UI 由后续卡/界面层做）—— 但机制要能被**任何 UI** 改（改文件即可）。

## 要做什么（就三件）

1. **开关文件**：`infra/pool/model-switches.toml`（**通用层**、仓库外、**只有用户能改**；UI 也是改它）。
   形态（**先写一份带注释的空壳进 infra**，由主控做 —— **你不要动 infra 仓**，只在**代码里**支持它）：
   ```toml
   [switch]
   "glm-5.3" = false      # true = 放行（一次性；不进 429 轮换链）
   ```
   ★ 键 = **模型的裸名**（与 `MODEL_WHITELIST` / `ONE_OFF_MODELS` 同一套写法）；值 = 布尔。
2. **`tools/pool/models.py`** 新增**纯读**函数 `load_switches(pool_dir=None) -> dict[str, bool]`：
   - 文件**不存在** ⇒ 返回**空字典**（**不报错** —— 大多数人没这个文件）；
   - 文件**坏**（TOML 解析失败 / 值不是布尔）⇒ **报错并点名**（★ **不许静默当空** ——
     静默当空会让"我明明开了"变成"实际没开"，这类"看着绿其实没查"的缺陷本仓吃过太多次）；
   - 复用既有的 `find_pool_dir()` 找池目录（**别另写一份路径查找**）；允许 `TF_MODEL_SWITCHES` 覆盖路径（测试要用）。
3. **`tools/wb_dispatch.py`**：把**开关打开的**模型并进允许集：
   `ALLOWED_MODELS = MODEL_WHITELIST + ONE_OFF_MODELS + <开关打开的>` ——
   ★ **名单常量一个字不动**；★ 开关打开的模型**仍然不进 `next_whitelist_model()` 的轮换链**（轮换只走 `MODEL_WHITELIST`）；
   ★ 读不到开关文件时**按空处理**（不报错）；★ 拒单文本与 `--help` 里要能看出"允许集还包含开关打开的模型"。

## 验收（照这个报）

- ★ **反例钉子**（放进 `tests/test_pool_models.py` 与 `tests/test_wb_dispatch.py`；每条要"故意坏掉会红"）：
  ① **开关开**：`{"glm-5.3": true}` ⇒ `model_rejected("glm-5.3") == ""`，且 **`next_whitelist_model("glm-5.3-flash")` 仍是 `None`**
     （★ 开关**不进轮换链** —— 与 `T-G235` 的口径一致）；
  ② **开关关**（`false`）⇒ 被拒；
  ③ **文件不存在** ⇒ 空字典、其它行为与今天**逐字相同**（名单两个照放、表外照拒）；
  ④ **坏文件**（`"glm-5.3" = "yes"` 这种非布尔，或故意写坏 TOML）⇒ **报错并点名**那个路径与那一行，
     ★ **不是**静默当空；
  ⑤ ★ **开关只做加法**：开关写 `"kimi-k2.7" = true` ⇒ 它被放行；**但 `MODEL_WHITELIST` 里那两个不会因此被关掉**
     （名单是**下限**，开关是**加法**）—— 这条要写成钉子，说清是**有意的**口径。
- 贴：`python -X utf8 -m pytest tests/test_pool_models.py tests/test_wb_dispatch.py --no-cov` 尾行；
  `ruff check tools tests` 尾行；★ 一条**真读数**：`python -X utf8 tools/wb_dispatch.py --card 000 --model glm-5.3`
  （dry-run）在**开关关**与**开关开**两种状态下的**原样输出**（用 `TF_MODEL_SWITCHES` 指到临时文件造场景，
  **别去改 infra**）。
- ★ 不改 `infra/**`（那是主控的）；不改 `MODEL_WHITELIST` / `ONE_OFF_MODELS` 的值；不跑全量门禁；不提交。
