## 判据（8 条）

1. **三个参数少给一个就 `TypeError`**（正向）：`failclosed.refuse(problem, *, what, where)` 的
   `what` / `where` 是 keyword-only 且**无默认值**；文案必须**同时**含 `what` 与 `where`，
   结构照 magpie「<要求是什么>，但 <谁> 不在服务，所以 <什么都没做>；<去看哪>」。
2. **拒绝族是一条继承链**（正向）：`issubclass(NotLimited, NotServing)` 且
   `issubclass(NotServing, RuntimeError)`；**不是** `ValueError`（`ValueError` 在本仓表示
   「你给的配置坏了」，`LanesError` / `RpmError` / `ScopeError` 都继承它）。
3. **没要求就永不过问**（边界）：卡没声明限额 + 表不存在 ⇒ `assert_serving` **不抛**，
   逐字对 magpie `gwbudget.go:102` 的 `who.KeyID == "" || len(who.Limits()) == 0 { return nil, nil }`。
4. **声明了却读不出 ⇒ `NotLimited`**（正向）：文案里必须带**表路径**，人知道该去看哪一份文件；
   表存在但坏 TOML、或路径是目录，都算「读不出」。
5. **`[default]` 也算有要求**（边界）：表里只有 `[default]` 段 ⇒ 该卡仍有额度要求 ⇒ 读不出就抛；
   「有要求」必须是**显式声明**，不许从「表非空」推。
6. **拒绝文案里没有禁词**（边界）：`failclosed.py` 与所有构造 `NotServing` 的地方，
   文案里不许出现「跳过 / 放宽 / 当作没有 / 默认放行」—— 出现任一个，说明这条「拒绝」
   被写成了「放行」。
7. **五条既有判据行为一字不变**（边界）：`tree_guard` / `domain_guard` / `registry.load` /
   `PoolNotWiredError` / `_check_account` 只加 docstring，返回的 `list[str]` 与抛的异常**逐字相同**
   （黄金值来自改前实测），坏 JSON 文件**不被改写**。
8. **反向钉子**（**反向**）：`test_reverse_notlimited_becomes_empty_list` —— 把 `assert_serving`
   从「抛 `NotLimited`」改成「静默 `return`（当没要求）」，这条必须变红。理由：magpie 的
   `ErrUnlimited` 之所以存在，就是因为「读不到就放行」这个默认行为**看起来完全正常**，
   只有钉子能发现它悄悄把限额关掉了。（`gates/diag/_rev_A336.py` 另有 8 条定点变异，
   逐条走「基线绿 → 变异 → 目标用例红 → 逐字节还原 → 复查纯 CRLF」。）

## 不许做

- **不许造 fail-open 点。** magpie 的 Agent 中间件是可选的、失败就回空切片；pool 里没有
  「可选扩展点」这种架构 —— 在这里造一个 fail-open 点等于主动放松判据，与
  `_pool_capability_map.md` D5「只有用户能放松判据」直接冲突。本卡只搬 fail-closed 那一半。
- **不许重写任何既有判据的 `if`。** 本卡只做两件事：加一个异常族、给五条判据各加一行 docstring，
  外加一条**新**判据 `assert_serving`（它判的是新引入的 `limits.toml`，不是既有判据）。
  重写 `files_intersect` / `domain_guard` / `load` 等于造第三份真源。
- **不许用 `os.kill(pid, 0)` 判「服务在不在」。** `tools/pool/registry.py:23-24` 逐字禁令；
  服务在不在的判据只能是**文件 / 表读不读得出来**（`assert_serving` 就是这么判的）。
- **不许给 `failclosed.py` 加 pool import**（含 `typing` 之外的任何本仓模块），
  否则 `guards.py` 这条纯函数链会成环。
- **不许给 `tools/pool_quota.py` 加网络或加异常族**（F23 已列，一行都不动）。
- **不许碰六份 PROTECTED_FILES**：`docs/traceability.toml`、`docs/changelog.md`、
  `复盘/交接-重构进度.md`、`复盘/新窗口交接卡.md`、`gates/last.json`、`gates/reuse.json`；
  `docs/workbacklog.toml` 也不动（台账由父代理写）。
