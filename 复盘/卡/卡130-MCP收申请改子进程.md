# 卡 130 —— MCP 的 `task_claim` 改**子进程**跑（别拿服务进程去跑门禁）（治 GLM 2.3 的放大器）（T-G227）

**树**：`.wt/mcpclaim` ｜ **base**：主控派活时的主树 HEAD ｜ **提交**：★ **不要 commit** ｜ **模型**：默认
**成员号**：任务 `B-FIX2` 的 **M-2**（干完要交成送申请，见最后）

## 来路（外部审查 GLM-5.3 的 **2.3** 的"放大器"那段，原文要点）

> 「`pool_mcp.py:1289` 的 `_capture` **进程内**调 `cmd_claim` ⇒ 最后一名 claimant 走 MCP 时，
> **MCP 服务进程**同步跑完整个门禁：**stdio 循环全程冻结**（连九个只读工具也答不了）；
> 服务中途被杀 ⇒ **锁泄漏 + 状态没落盘**。」

★ 本仓的规矩本来是「复用 `pool.task`，**进程内调用、不 shell 出去**」（卡 106）——
那条规矩**防的是"另写一份判据"**，不是"不许起子进程"。这里要**把两者分开**：
**判据仍然只有一份**（都跑 `tools/wb_task.py` 那个壳，它转发给 `pool.task`），
但**执行换到子进程**，让 MCP 服务进程**永远不替别人跑门禁**。

## 要做什么

1. **`tools/pool_mcp.py` 的 `tool_task_claim`（`:1264` 起）**：把 `_capture(lambda: task.cmd_claim(...))`
   换成**子进程**调用 —— 跑 `[sys.executable, "-X", "utf8", <ROOT>/tools/wb_task.py, "claim", <任务>, <卡>, …]`
   （参数照 `cmd_claim` 现在的 CLI 口径拼，**先读 `tools/wb_task.py` 的 `--help` 与 `pool/task.py` 的 `cmd_claim` 签名**），
   `capture_output=True`、**显式编码 utf-8（errors=replace）**、给一个**足够长的超时**（门禁 6~9 分钟 ⇒ 至少 1800s）、
   把 **stdout 原文**当回话内容（**保持现有回话形态**：`tests/test_pool_mcp_task.py` 里对文本的断言**一条都不许改**）。
   - 子进程**非零退出** ⇒ 回话里**如实带出**它的输出与退出码（**不许吞**、**不许**假装成功）；
   - 子进程被杀/超时 ⇒ 回话里写清"没跑完"（★ 对应 GLM 说的"服务中途被杀 ⇒ 锁泄漏"，改成子进程后
     **服务本身不再被拖住**，被打断的也只是那个子进程）。
2. **改口径注释**：`tools/pool_mcp.py` 里那句「进程内调用，**不 shell 出去**」（`:1164` 附近）要**收窄成实话**：
   —— **只读与快路径（register）仍进程内**；**`claim` 走子进程**（理由：它会跑门禁，5~9 分钟，不许冻住 stdio）。
   ★ 并在模块头那张"谁判什么"的表里加一行说明。
3. **`register` 不动**（它是快的，进程内调用保留）。

## 验收（照这个报，数字要真）

- ★ **反例钉子**（放进 `tests/test_pool_mcp_task.py`；每条要"故意坏掉会红"）：
  ① **真走子进程**：桩掉 `subprocess.run`（或 `Popen`）⇒ 断言 `tool_task_claim` **确实起了子进程**、
     命令里含 `wb_task.py` 与 `claim`、且**没有**在进程内调 `task.cmd_claim`（桩掉 `task.cmd_claim` 让它抛异常也不行）；
  ② ★ **stdio 不被冻住**（这条是本案的命门）：造一个"慢门禁"的任务（`gate_cmd` = 一行 python 睡 8 秒），
     在**真 stdio 端到端**里发 `task_claim`，**与此同时**发一个只读工具（`task_status`）⇒
     只读那个**必须在 5 秒内答**（贴两次回话的时间戳/耗时读数）；★ 用**现在**的实现跑这条**必须红**（先红后绿，贴两次）；
  ③ **子进程失败如实带出**：桩一个返回码 2 + 一段错的子进程 ⇒ 回话里**既有退出码又有原文**（不许吞）；
  ④ **超时**：桩一个睡很久的子进程 ⇒ 回话写"没跑完/超时"，**不许**当成成功。
- 贴：`python -X utf8 -m pytest tests/test_pool_mcp_task.py tests/test_pool_mcp.py tests/test_pool_mcp_write.py --no-cov` 尾行；
  `ruff check tools tests` 尾行；★ **两段 `tools/list` 原样对照**（不设 env = **9** 个只读；设 `POOL_MCP_WRITE=1` = **13** 个）——
  证明**工具清单没变**（本卡只改执行方式）。
- ★ 不许改工具的数量与名字；不许改 `pool/task.py`（另一张卡在治它）；不许提交。
