# 卡 A310 · 面板已装副本与生成源不许漂移（T-AG424）

## 现象

A298 / A302 / A309 的改动都进了主树、19 道门全绿，但桌面上跑的还是旧插件。
门禁只能证明「源是好的」，证明不了「装的是源的那份」——这一类事故要等重启后才暴露。

## 做法

`tools/dsh_panel.py` 新增 `check_installed(dest)` 与 `--check-installed DIR`：

- 用 `package_files()`（`--emit` 的唯一数据源）逐文件比对目标目录；
- 缺文件、内容不一致都**点名**报出；零差异打印 `[OK ]` 并退 0，有差异退 1。

## 验收

- `pytest tests/test_dsh_panel.py` 165 passed；
- `--check-installed <已装目录>` → `[OK ] 已安装副本与生成源一致`；
- 指向空目录 → 8 处「缺文件」并退 1；
- 改一个字节 → 报「内容漂移：lib/client.js（装的是 N 字符，源是 M 字符）」。
