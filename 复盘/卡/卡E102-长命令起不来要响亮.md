# 卡 E102 · 长命令「起不来」不许是一条静默的空日志（run_logged 先解析 argv[0]）

> 台账号 `T-AG611`｜分区 E（门禁与可信度）｜树 `.wt/E102`｜层 判据层｜基准 `a94af526`｜
> 依据：用户 m92988「把pool的使用打磨好，不计代价与token」+ 本仓 `AGENTS.md`「长命令怎么跑」的硬规矩。

## 要解决的问题（真机实测，不是推测）

`tools/run_logged.py` 是本仓所有长命令的落盘跑法（`AGENTS.md`、`skills/pipe-gate/SKILL.md`、
`skills/pipe-land/references/land-steps.md` 都写着要用它）。它的 `Popen(cmd)` 直接拿 argv 起进程 ——
在 Windows 上这有一个洞：

```
>>> subprocess.run(["npm", "--version"], capture_output=True)
FileNotFoundError: [WinError 2] 系统找不到指定的文件。
```

因为 PATH 里只有 `npm.CMD`（`shutil.which("npm")` ⇒ `C:\Program Files\nodejs\npm.CMD`），
而 `CreateProcess` **不做 PATHEXT 解析**。后果：日志里只剩一行「起跑」，后台作业看起来跟
「跑得很慢」一模一样 —— 而这条规矩存在的理由恰恰是「别让人猜是不是卡死了」。

同一族还有两处：

1. **批处理不能走 argv 列表**。实测 `Popen([str(bat), "a&b"])` ⇒ `'b' 不是内部或外部命令`，
   `"a^b"` ⇒ 参数变 `ab` —— 列表形态下 Windows 会把这行交给 cmd 解释，参数被改写。
   必须把**一整行字符串**交给 Popen（`%COMSPEC% /d /s /c "…"`），参数才不会走样。
2. **`--` 被整段剥掉**。旧实现 `args.cmd[1:]` 会吞掉命令自己的第一个 `--`
   （`… -- pytest -- --collect-only` 里的那个），那是另一条静默改写。

## 判据（五条）

### 判据 1 · 裸名先解析，解析不出就回 None（不猜路径）

`resolve_program(name) -> str | None`：自带路径（含 `/`、`\\` 或 dirname 非空）按路径找、
没后缀再按 `PATHEXT` 补；裸名交给 `shutil.which`。`needs_cmd_shell(resolved)` 只对 `.cmd` / `.bat`
（且仅 Windows）为真。

**钉子**：`tests/test_run_logged.py::test_bare_name_resolves_through_pathext`（造一个只以 `.cmd`
存在的裸名，断言 `resolve_program` 解析到它、`needs_cmd_shell` 为真）；
`::test_unresolvable_name_is_none_not_a_guess`（不存在的名字回 `None`、`prepare_command` 抛错）。

### 判据 2 · 批处理过 cmd 且参数原样；普通程序走 argv 列表

`prepare_command(cmd) -> tuple[str | list[str], str]`：批处理 ⇒ 一整行 `COMSPEC /d /s /c "<inner>"`
（`quote_for_cmd` 只给需要的那段加引号，内部 `"` 翻倍）；普通程序 ⇒ `[resolved, *rest]` 列表。

**钉子**：`::test_batch_gets_a_cmd_line_and_keeps_its_arguments`（`.cmd` 把 `%*` 回显 ⇒
`a&b` / `a^b` / 带空格的一段都到齐，且只回显**一次** —— 拆成两条命令就会多一次）；
`::test_normal_program_passes_argv_verbatim`（`%PATH%` / `a&b` / `q"uote` / `x y` 逐字到达，`%PATH%` 不被展开）；
`::test_quote_for_cmd_only_quotes_what_needs_it`、`::test_cmd_line_wraps_the_whole_line_once`。

### 判据 3 · 起不来要响亮：回 127、点名、不打 traceback

`main()` 在 `ProgramNotFoundError` / `OSError` 上都走 `_fail()`：stdout 打一行人话 +
`[完] 退出码=127 没跑起来 日志=…`，日志里追加「（找不到的是：<name>）」，**不打印 traceback**
（起不来不是崩溃）。退出码 127 与子进程自己的退出码分开。

**钉子**：`::test_missing_program_is_loud_and_returns_127`（`code == 127`、stdout 点名、日志有
「找不到的是：」、stdout 里没有 `Traceback`）。

### 判据 4 · 心跳按步长轮询；命令自己的 `--` 保留；退出码透传

心跳循环以 `POLL_SLICE`（0.2s）为步长、每到 `--every` 才打一行（短命令不必等满一个周期）；
只剥 `cmd[0] == "--"` 那一个分隔符。

**钉子**：`::test_heartbeat_and_tail_replay`、`::test_command_keeps_its_own_double_dash`、
`::test_command_works_without_the_separator`（不写 `--` 时不许把命令名当分隔符吃掉）、
`::test_exit_code_passes_through`、`::test_no_command_is_a_usage_error`。

### 判据 5 · 反向变异 ≥4（真改真跑真还原，记 sha256）

`gates/diag/_rev_E102.py`（本卡新建，主树 `gates/diag/` 下跑）至少四条：

- **M-A** `prepare_command` 不解析 argv[0]（直接用 `cmd[0]`）⇒ 判据 1/3 的钉子必须咬住；
- **M-B** 批处理改回 argv 列表形态 ⇒ 判据 2 的 `.cmd` 钉子必须咬住；

## 不许做

- 不许给 `Popen` 传 `shell=True`：那会把**普通程序**的参数也交给 shell，`%VAR%` 会被展开，是另一种静默改写。
- 不许把批处理也塞进 argv 列表「试试看」：实测参数会被改写（`a^b` ⇒ `ab`）。
- 不许在起不来时写 traceback 糊人；也不许静默只留「起跑」一行。
- 不许削弱 `tests/test_no_window.py`（`Popen` 必须带 `creationflags`）与 `tests/test_log_codec.py`
  （`tools/run_logged.py` 仍在「读自己那份 tail」白名单里，读法不变）。
- 不许动 `tools/cmd_guard.py` 的规则串（`tests/test_cmd_guard.py:24` 依赖它的写法样例）。
