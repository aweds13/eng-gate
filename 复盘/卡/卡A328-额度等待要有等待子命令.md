# 卡 A328 —— 额度等待要有等待子命令（T-AG530）

> 台账号 `T-AG530` ｜ 分区 A（历史线 / 号池 pool）｜ 树 `.wt/A328` ｜ 层 判据层
> 依据：magpie 的 `quota wait`（`quotaWaitMin = time.Minute` / `quotaWaitMax = 10 * time.Minute` /
> `quotaWaitMargin = 30 * time.Second` / `quotaRefreshGap = 30 * time.Second`）。
> 实测现场：`tools/pool_quota.py`（HEAD `3bfabad5`）只有 `status` 一个子命令；派活器
> `tools/wb_dispatch.py:3452` 只能拿 `wait_seconds(reset_at, args.quota_wait)` 算一个数，
> 其余靠 `DEFAULT_QUOTA_WAIT = 300`（`tools/wb_dispatch.py:218`）睡死 5 分钟。

## 要解决的问题

`tools/pool_quota.py` 的 `main()` 在 HEAD 上只认 `status`，认别的就 `return 2` ——
「等额度」这件事根本没有入口，于是每个调用方各自发明等待策略（目前就是睡死 300 秒）：

```python
def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(
        prog="pool_quota.py",
        description="额度状态按钟表算（卡 201）—— 429 不许凭记忆，一律「记录时间 vs 现实时间」。",
    )
    sub = parser.add_subparsers(dest="cmd", required=True)
    p_status = sub.add_parser("status", help="看一个卡/模型的额度四态（每次现算）")
    p_status.add_argument("--card", required=True, help="卡号")
    p_status.add_argument("--model", required=True, help="模型名")
    p_status.add_argument("--now", default=None,
                          help="注入「现在」（ISO-8601；测试用，不许靠真实钟表）")
    p_status.add_argument("--root", default=None, help="仓库根（测试用）")
    args = parser.parse_args(argv)

    root = Path(args.root) if args.root else ROOT
    if args.cmd == "status":
        st = status(card=args.card, model=args.model, now=args.now, root=root)
        print(render(st))
        return 0
    return 2
```

`wait_seconds()` 是**一次算一个数**的纯函数（签名与语义本卡不动）：

```python
def wait_seconds(reset_at: str | None, fallback: int, *,
                 upper: int | None = None, now: datetime | str | None = None) -> int:
    if not reset_at:
        return fallback
    try:
        reset_dt = _to_aware(datetime.fromisoformat(reset_at))
    except ValueError:
        return fallback
    now_dt = _to_aware(_resolve_now(now))
    diff = int((reset_dt - now_dt).total_seconds())
    cap = fallback if upper is None else upper
    return max(0, min(diff, cap))
```

病灶不是这个函数，是**没有循环、没有出口码、没有「过期 ≠ 可用」纪律**：
谁都能拿一个 `remaining_seconds == 0` 当「可以派活了」，而四态里的
`已过期，需重新探测` 恰恰是**最不该判成功**的那一态。

## 判据（7 条）

1. **一轮睡多久按记录算**：`tools/pool_quota.py::round_wait(back_at, *, now=None) -> tuple[int, str]`
   返回 `min(max(int(diff) + WAIT_MARGIN_S, WAIT_MIN_S), WAIT_MAX_S)`，即
   `+30s` 余量、下限 `60s`、上限 `600s`；`diff` 为负也只给 `WAIT_MIN_S`（**不许负数 / 不许 0**，
   否则过期记录会把循环烧成忙等）；`back_at` 为空或解析不出 ⇒ `(600, "未知续期 ⇒ 睡满上限")`。
2. **不许凭空判成功**：`wait_until()` 只在「`recorded_at` **严格晚于本次等待起点**」时退 `EXIT_OK`；
   `已过期，需重新探测` / `余额耗尽` / `未记录` 三态一律不算成功，一路等到 `--timeout` ⇒ 退 1。
   认不出的状态（含别人塞进来的「可派」）同样不算成功。
3. **反向钉子**：把 `status()` 换成永远返回 `可派` 的假货，`wait` **仍必须**在 `--timeout`
   处退 1（`tests/test_quota_wait.py::test_reverse_wait_ignores_record_hits_timeout`）——
   证明它不靠乐观假设变绿，只认记录。
4. **刷新有 30 秒抑制，且抑制只省重复问**：`refresh_once()` 在 `refreshed_within(key) < REFRESH_GAP_S`
   时只打印「30 秒内已看过，跳过」并退 0，**不改**任何额度判据；时间戳落
   `gates/diag/quota-refresh.json`（`REFRESH_REL`，与 `STATE_REL` 同目录风格），写盘走
   `tmp` + `os.replace` 原子替换，key 用 `refresh_key(card, model) = f"{card}|{model}".lower()`。
5. **读不懂就当作没问过**：`refreshed_within()` 在文件不存在 / 坏 JSON / 没这个 key /
   时间字符串解析不出时返回 `None`（立刻可问）—— 坏时间戳不许把刷新能力冻住。
6. **零网络 + 可注入时钟**：`wait` / `refresh` 都不许发网络（本模块不 import
   `requests` / `urllib` / `httpx` / `socket`；探测在 `tools/pool_accounts.py`，本卡只记时间戳）；
   两者都认 `--now`（ISO-8601），给了就全程走虚拟钟，测试里一条真实钟表都不许碰。
7. **退出码就是判据**：成功 `EXIT_OK = 0`、超时 `EXIT_TIMEOUT = 1`、缺参由 argparse 走
   `EXIT_USAGE = 2`、`KeyboardInterrupt` ⇒ 打印一行后 `EXIT_INTERRUPT = 130`；
   `wait --timeout` 默认 `"6h"`（**不是** `DEFAULT_QUOTA_WAIT = 300`）。

## 交付

- `tools/pool_quota.py`：加常量 `WAIT_MIN_S / WAIT_MAX_S / WAIT_MARGIN_S / REFRESH_GAP_S /
  EXIT_OK, EXIT_TIMEOUT, EXIT_USAGE, EXIT_INTERRUPT` 与 `REFRESH_REL`；
  加 `round_wait()` / `refresh_stamp_path()` / `refresh_key()` / `refreshed_within()` /
  `note_refreshed()` / `parse_timeout()` / `_recorded_after()` / `wait_until()` / `refresh_once()`；
  `main()` 在 `status` 之后加 `wait` / `refresh` 两个子命令。
- `tests/test_quota_wait.py`：9 条钉子（含反向钉子与 6h 默认上限），`tmp_path` 做 root、
  `--now` 注入、`monkeypatch` 替 `time.sleep`（**一条真实睡眠都没有**）。
- `复盘/卡/卡A328-额度等待要有等待子命令.md`：本文件。

## 不许做

- 不许改 `wait_seconds()` 的签名或语义：`tools/wb_dispatch.py:3452` 在用，
  `tests/test_quota_clock.py:99::test_wait_follows_record_not_fixed_300` 已钉死它。
- 不许把 `DEFAULT_QUOTA_WAIT = 300`（`tools/wb_dispatch.py:218`）当成 `wait` 的默认上限。
- 不许让 `wait` / `refresh` 发网络，不许 import `requests` / `urllib` / `httpx` / `socket`。
- 不许在测试里用真实钟表或真实 `time.sleep`（全部 `--now` 注入 + `monkeypatch`）。
- 不许改 `tools/pool_accounts.py`、`tools/wb_dispatch.py`、`tools/pool/plan.py`。
- 不许把「30 秒内已看过，跳过」当成「额度可用」的证据 —— 判定只归 `status()` 的四态。
