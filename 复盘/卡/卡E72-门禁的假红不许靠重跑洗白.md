## 要解决的问题

真红与假红在**读数形状上无法区分**：两者都是 `pytest exit=1`，都要人肉去单跑、去比对 diff、去回忆当时机器上还跑着什么。后果有三条，都实际发生过：

1. **同一棵树能出一绿一红两笔封存产物**（E71 的 `gates/last.json` 三次 `ok` 依次 True/False/False，`tree` 指纹三次不同）。落地脚本只认最后一次，于是「哪一趟算数」全靠人记。
2. **红单没有「可复现」这个维度**：`gates/last.json` 里存了 `summary` 和 `detail`（卡 E67），但没有任何字段说「这条红在隔离跑法下还红不红」。
3. **重跑到绿是个诱人的捷径**：本卡作者本人今晚就跑了三趟。规矩写在注释里等于没写。

## 判据（6 条）

1. **新增 `scripts/flake_probe.py`**，只读、只跑单个 nodeid，不碰门禁产物：

   ```python
   def probe(nodeids: Sequence[str], *, root: Path, repeat: int = 1, timeout_s: float = 600.0) -> dict
   ```
   对每个 nodeid 起**一次**子进程 `[sys.executable, "-X", "utf8", "-m", "pytest", nodeid, "-q", "-o", "addopts=", "--no-cov"]`（**串行、单进程、不挂 xdist**），返回
   `{"nodeid": str, "verdict": "reproduced" | "isolated_green" | "error", "seconds": float, "tail": str}`。
   `verdict` 三值定义：退出码非 0 ⇒ `reproduced`（隔离跑也红 ⇒ 真红）；退出码 0 ⇒ `isolated_green`（隔离跑绿 ⇒ 这条红是负载/时序相关的假红）；超时或起不来 ⇒ `error`（**不许**当绿）。
2. **`summarize()` 的红单行必须能带上判定**：`scripts/run_gates.py` 的 pytest 门在写 `detail` 时，对每条红 nodeid 调一次 `flake_probe.probe([nodeid], repeat=1)`，把结果并进 `detail` 的**第一段**（形如 `[隔离跑绿] tests/test_serve_port.py::test_own_service_alive_with_matching_fingerprint`、`[隔离也红] …`、`[判不出] …`）。`detail` 本来就只在红门写（卡 E67 判据 2），绿门逐字不变。
3. **假红不许自己变成绿**：`probe()` 返回 `isolated_green` 时，门的 `exit_code` **仍然是非 0**（判据只加信息，不改判定）。谁想把这条算过，必须显式改动，不许自动化。
4. **串行跑法可选**：`scripts/run_gates.py` 读 `TF_GATE_FLAKE_PROBE`（`1` = 开，默认 `0` = 关，保持今天行为与耗时）。关着时 `detail` 里写一句「本次未做隔离复核（`TF_GATE_FLAKE_PROBE=1` 可开）」，不许静默省略。
5. **不许把「重跑到绿」写成流程**：`skills/` 下任何一篇步骤文档不许出现「再跑一次门禁看看」这类洗白话术；`docs/subsystems/ci/README.md` 的决策表要加一条 D7，写明「红门先看 `detail` 的隔离判定，`[隔离跑绿]` 也不等于通过」。
6. **判据只许一份**：`flake_probe.py` 里不许出现任何门名判断、不许读 `gates/last.json`；它只知道 nodeid 与退出码。

## 不许做

- 不许改 `summarize()` 的既有三分支（卡 E67 判据 1-2 的牙）。
- 不许因为 `isolated_green` 就把 `exit_code` 改成 0，或让它进 `not_run`、`bad` 的豁免。
- 不许让 `flake_probe` 写任何文件（唯一的输出是返回值）。
- 不许把 `repeat` 做成「跑到绿为止」——`repeat > 1` 只允许用来数「几次里有几次红」。
- 不许碰 `tests/test_serve_port.py` / `tests/test_invest_axis.py` 的判据（它们是受害者，不是病灶）。
- 不许用 `# noqa`、不许写仓外路径、不许改六份 `PROTECTED_FILES`。
