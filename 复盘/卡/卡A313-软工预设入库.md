# 卡 A313：软工预设入库（preset-softeng 的仓内真源与安装器）

- 任务：T-AG427
- 树：`.wt/A313`
- 依赖：A311

## 要解决的问题

「软工」预设（`preset-softeng`）现在只活在 `C:/Users/example/.dsh/profiles/desktop/cordis.patch.yml` 里。
换机器、换 profile、或这份 patch 被覆盖，预设就没了；而补丁语义是「裸 `id:` 只改已有行，新增行必须 `insert:`」，
写错不会报错、只会静默跳过。所以必须把这段 YAML 变成仓内可审、可重装的东西。

## 交付

1. `docs/presets/softeng.patch.yml` —— 预设唯一真源（`- insert:` 块，18 个插件，无 `tool-pwsh` 行）。
2. `tools/dsh_preset.py` —— `--check` 查片段合规；`--install <profile>` 幂等装入（先备份，已有则跳过）。
3. `tests/test_dsh_preset.py` —— 片段合规、`tool-pwsh` 必拒、`tool-bash` 必开、裸 `id:` 行必拒、安装幂等。

## 判据

- `python -X utf8 tools/dsh_preset.py --check` 退出 0。
- `python -X utf8 -m pytest tests/test_dsh_preset.py -q --no-cov` 全绿。
- 装进临时 profile 后 `- id: preset-softeng` 恰好一条，重复安装不产生第二条。

## 不做什么

- 不改 `~/.dsh` 之外的任何用户资产；`--install` 只写调用者指定的 profile 目录（先备份）。
