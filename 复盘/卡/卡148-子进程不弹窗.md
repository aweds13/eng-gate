## 来路（用户的现场反馈 + 主控已查到的三段证据）

用户：*「为什么我一直在蹦命令行窗口？」* 主控当晚逐层查过：
- 派活器的 `--detach` **已经**带 `DETACHED_PROCESS | CREATE_NO_WINDOW`（上一轮会话为"任务栏残留"修过 `T-G96`）⇒ **不是它**；
- 工人 CLI **自己**起子进程时带了 `windowsHide: true`（在它 dist 里数到 **240 处**）⇒ **基本不是它**；
- ★ 但 **`tools/pool_mcp.py` 那个起"收申请"子进程的 `Popen`（约 1408 行）没带** —— 而它跑的是
  `wb_task.py claim`，**可能连带整趟门禁** ⇒ **一次能闪一串窗口**（门禁会起 pytest / bash / 浏览器）。
  ⇒ 这是**我们的**缺陷，本卡修掉它，并且**做成机器判据**，不再靠人记。

1. **把"不弹窗"的 flag 收敛成一处**（照 `tools/wb_dispatch.py` 里 `NO_WINDOW` 那个写法：
   Windows ⇒ `creationflags=subprocess.CREATE_NO_WINDOW`，别的平台 ⇒ 空 dict），
   让 `tools/pool_mcp.py` 用它（★ **别**在每个调用点各写一遍字面量）。
2. ★ **审一遍全仓**：`tools/**`、`scripts/**`、`gates/diag/gate_lock.py` 里**所有** `Popen` /
   `subprocess.run` / `subprocess.call` —— 逐条判定"**要不要**不弹窗"，并在回报里给**清单**（文件:行 + 判定 + 理由）。
   ★ **例外必须显式**：确实**要给人看**的交互式子进程（例如 `codebuddy_accounts.py` 的 `profile run`）——
   ★ 那在另一个仓（`infra`），**不在本卡范围**；本仓内如果真有交互式子进程，**列出来并说明**。
3. ★★ **加一条防回归的钉子**（本卡命门）：扫 `tools/**` + `scripts/**`（**只扫这两个目录**，别扫 tests 免得自伤），
   凡出现 `subprocess.Popen(` / `subprocess.run(` / `subprocess.call(` 而**同一个调用里没带**
   `NO_WINDOW` / `creationflags` / `windowsHide` ⇒ **判红**，并**逐条点名**（文件:行 + 那一行的原文）。
   例外名单**写成显式常量**（每条带一句理由），★ **不许**用"忽略整个文件"来放水。
4. `gates/diag/gate_lock.py`（**scratch 里唯一进 git 的脚本**）若也起子进程 ⇒ 同样处理。
