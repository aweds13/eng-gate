## 要做的事

### 1. 新 `tools/pipeline_view.py`（**只读**，唯一读数器）

一条命令产出一份结构化读数（`--json` 给机器、`--report` 给人读）。**六块**，每块都写清**来源文件**：

1. `cards` —— 队列全貌：每张卡的 `id / task / title / tree / spec / files / depends / risk / status`
   （来源 `docs/workbacklog.toml`）；
2. `gates` —— 最近一次门禁：`ok / rev / 每道门的 name+exit_code+seconds`
   （来源 `gates/last.json`；**文件不存在 ⇒ 明确报"没有"，不许编**）；
3. `verdicts` —— 每张卡有没有判决 / 判决首行 / 有没有 report
   （来源 `gates/diag/wb-<卡>.verdict.txt` 与 `.report.md`）；
4. `leases` —— 活租约：`card / tree / files / owner / at / ttl_seconds`
   （来源 `gates/diag/pool-registry.json`；**不存在 ⇒ 空表**）；
5. `fences` —— 任务栅栏：每个 `B-*.toml` 的 `id / on_complete / 成员数`
   （来源 `gates/diag/batch/*.toml`；坏文件 ⇒ 点名不崩）；
6. `worktrees` —— 卡树清单：路径 + 当前分支/HEAD + 是否脏（来源 `git worktree list`）。

- ★ **只读**：不写任何文件、不杀进程、不占端口、不调 git 的写命令。
- ★ **缺什么说什么**：来源文件缺失/坏掉 ⇒ 那一块**明确标注**（如 `"gates": null, "gates_note": "没有 gates/last.json"`），
  **不许**用空对象冒充、**不许**猜。
- ★ **不 import 业务代码**（`src/timeflow/**`）；只用标准库 + 读文件 + 调 `git`（带 `NO_WINDOW`）。
- ★ 幂等：同样的输入连跑两次，`--json` 逐字节相同（**不许**写时间戳/随机序）。
