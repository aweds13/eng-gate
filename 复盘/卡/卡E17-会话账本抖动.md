# 卡 E17：会话账本的写盘抖动与测试隔离

分区：E（CI 子系统）· 台账 `T-AG468` · 卡树 `.wt/E17` · 风险 mid

## 现在疼在哪（实测）

2026-10-24 20:57 那趟批落地 `T-AG460` 的 pytest 红了 1 条，退出码 `1 failed, 3010 passed`，堆栈原文：

```
tools\wb_dispatch.py:2884: in main
    ok, msg = wb_session.claim(args.card, take_over=getattr(args, "take_over", False))
tools\wb_session.py:88: in claim
    _save(data)
tools\wb_session.py:48: in _save
    tmp.replace(LEDGER)
E   PermissionError: [WinError 32] 另一个程序正在使用此文件，进程无法访问。:
    '...\.wt\batch460\gates\diag\session-leases.tmp' -> '...\.wt\batch460\gates\diag\session-leases.json'
```

两件事叠在一起：

1. `tools/wb_session.py:48` 的 `_save()` 是「写 tmp → `os.replace` 覆盖」，**没有重试**。Windows 上 `os.replace` 撞到别人正开着目标文件就是 `WinError 32`（sharing violation），而它是**瞬时**的。
2. `tests/test_wb_dispatch.py` 里凡是调 `wd.main()` 的用例**都没有隔离账本** —— `wb_session.LEDGER` 指的还是仓库真账本（该文件里一处 `LEDGER` 都没有），所以测试会去写真仓的 `gates/diag/session-leases.json`。落地链自己也在同一个工作树里写这个文件 ⇒ 两者撞上就红。

同一族今天还出现过一次：`tests/test_wb_review.py::test_chinese_paths_are_not_escaped` 的 `PermissionError`（起子进程时），单跑 4 次全过 ⇒ 已单独开卡 E14 做测试侧重试。

## 判据（5 条）

1. `tools/wb_session.py` 的 `_save()` 对 `os.replace` 的 `PermissionError`（`WinError 32/5`）**有限重试**：3 次，间隔 50 / 100 / 200 ms；三次都失败 ⇒ 抛原异常（不吞、不转成 bool、不静默丢账）。
2. 只有 `PermissionError` 才重试；其它异常（目录不存在、权限、序列化失败）立即抛。
3. `tests/test_wb_dispatch.py` 里**每一处** `wd.main()` 的用例都必须把 `wb_session.LEDGER` 指到 `tmp_path`（用该文件已有的 `sandbox` fixture 或新增一个 autouse fixture 统一处理）；改完该文件里不许再出现对真仓 `gates/diag/` 的写。
4. 不许改 `claim()` / `release()` 的语义与返回形状，不许改账本 JSON 结构，不许动 `gates/diag/session-leases.json` 的格式。
5. 跑 `tests/test_wb_dispatch.py` 时，真仓 `gates/diag/session-leases.json` 的**字节内容与 mtime 都不许变**（用前后 `stat` + 读字节比对证明）。

## 钉子（4 条，都要真跑）

1. 注入：把 `os.replace` 换成「前两次抛 `PermissionError`、第三次成功」的桩 ⇒ `_save()` 成功且账本内容正确。
2. 注入：三次都抛 ⇒ `_save()` 把 `PermissionError` 原样抛出（`pytest.raises`），且**没有**留下半截 `session-leases.tmp`。
3. 隔离：在 `tmp_path` 上建一个假 `gates/diag/`，让 `wb_session.LEDGER` 指过去 ⇒ 调 `claim()` 后真仓账本字节不变。
4. 反空转：把重试次数改成 1（故意退化成旧行为）⇒ 钉子 1 必须红。

## 交付

- `tools/wb_session.py`：`_save()` 加重试（常量 `_SAVE_RETRIES = 3`、`_SAVE_BACKOFF_MS = (50, 100, 200)`，两个常量都带注释说明是 Windows sharing violation）。
- `tests/test_wb_dispatch.py`：账本隔离（autouse fixture 或逐用例），不改任何断言。
- 新增/扩写钉子放 `tests/test_wb_session.py`（已存在就加进去，没有就新建）。

## 验收

```bash
python -X utf8 -m pytest tests/test_wb_session.py tests/test_wb_dispatch.py -o addopts= -q
```

全绿，并在回话里贴出「真仓账本字节未变」的前后读数（`stat` 的 size + mtime）。

## 不许做

- 不许把 `PermissionError` 吞掉改成「尽力而为」。
- 不许在测试里 `try/except PermissionError: pass`。
- 不许为了让某条红转绿而扩大重试次数到 10 次以上（那是掩盖竞争，不是修）。
