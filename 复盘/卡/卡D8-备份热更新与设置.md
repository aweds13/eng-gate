# 卡 D8 · 备份/热更新/设置（导出导入 + bundle 替换生效 + 红线审计脚本）

- task: T-DG008
- tree: `.wt/D8`
- risk: mid
- depends: D1, D2

## 问题

三件小事凑一张卡，因为它们都不碰核心链路，但缺了任何一个，用户都会立刻骂：
① 数据只存本机（D5）⇒ 换机必须能搬；② 装一次之后要能热更新（D2，用户不懂 adb）；
③ 红线（不碰风控、不打包 GPL、型号不写死）必须能**机器查**，不能靠人记。

## 改法

1. `Backup.kt`：导出单文件归档（DB + 图片 + `manifest.json` 含版本/计数/时间）；导入时校验版本，
   同 id 冲突保留双方并提示（**不静默覆盖**）；默认**不含**密钥（C10）。
2. `BundleUpdater.kt`：校验 → 解压到 `files/web/` → 切换 → 失败回滚到 `files/web-prev/`；
   关于页显示 bundle 版本。
3. `Settings.ts`：主题（浅/深/跟随）、字号（带预览）、代码字号、提示词预设（可存多条一键套用）。
4. `audit_redlines.py`：机器查红线——① 源码无 PoW/风控/抓取关键字 ② 依赖清单无 AGPL/GPL
   ③ 硬编码模型 id 只出现在「默认值」「探测用例」两处 ④ `src/dsmate/web` 无 CDN 外链。

## 判据

- 导出 → 清数据 → 导入 → 书/页/图/树/分支全在，且 `#p2` 能唤出同一张图（hash 相同）。
- 导入一份 `manifest.version` 更高的归档 → 明确拒绝并说明原因。
- 解包归档 `grep -r "sk-"` → **不含** key。
- 换一份新 bundle（版本号 +1）→ 重启 App → 关于页版本变化且新功能生效；**全程没重装 APK**。
- 换一份坏 bundle → 回滚到上一版并提示。
- `python -X utf8 src/dsmate/tools/audit_redlines.py` 退出码 0；人为违反任一条 → 退出码非 0 并点名。

## 证据

- 导出→清库→导入 的完整录屏。
- 换 bundle 前后关于页截图 + 应用版本不变（证明没重装）。
- `audit_redlines.py` 通过与被咬两次的输出。

## 不做

- 不做在线热更分发服务（第一版手动放包）。
- 不做云同步（D5 已排除）。
