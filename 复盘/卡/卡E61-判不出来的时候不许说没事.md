# 卡 E61 —— 判不出来的时候不许说没事：混行尾让「翻 status」静默跳过

> 台账号 T-AG519 · 分区 E（CI 子系统）· 树 `.wt/E61` · 风险 mid
> 依据：卡 E60 落地（`68cafd7c`）走 `--commit-only`，第 ⑤′ 步的**翻 status 被静默跳过**：
> `gates/diag/land-E60.log:24` 只有一句「`[队列] 找不到卡 E60 ⇒ 跳过翻 status`」，
> 而落地链**退出码仍是 0**。台账 `T-AG518` = done、队列 `E60` = pending，两边不一致，
> 直到事后人肉对账才发现（补笔 `ca972097`）。

## 要解决的问题

1. **混行尾让整块卡被吞成一行。** `tools/pool/landing.py:368`
   ```python
   sep = b"
" if b"
" in raw else b"
"   # 见到 CRLF 就选 CRLF
   lines = raw.split(sep)                          # 但 E60 那块是裸 LF
   ```
   `docs/workbacklog.toml` 是纯 CRLF（4166 行），而我新写进去的 E60 块用裸 LF。
   `split(b"
")` 于是把整块（含 `id = "E60"`）留在**上一行**里，`_scan_blocks`
   逐行比 `t == "[[cards]]"` 时看不见它独立的块头 ⇒ **这张卡凭空消失**。
   探针实测（对当时那份文件）：
   - 纯 CRLF ⇒ 4167 行 / 认出 **259** 张卡 / `E60=True`
   - E60 块换裸 LF ⇒ 4147 行 / 认出 **258** 张卡 / `E60=False`，**不抛任何错**

2. **同病六处，不是一处。** 「按原始行尾二选一再 `split`」这个写法在仓里有 5 处
   （`landing.py:368` `flip_card_status`、`:796` `backlog_blocks`、`:1445`
   `_card_files_from_backlog`、`:1724` `_integrate_multi_tree` 找成员树、
   `pool/stage_card.py:90` 写片段），每一处都会以同样方式静默漏块。

3. **两个读取器对同一份文件给出不同答案（这才是真病）。**
   `pool.plan.load_backlog` 走 `tomllib`（**认混行尾**），`_scan_blocks` 走字节切分
   （**不认**）。同一份混行尾文件、同一时刻：
   ```
   纯 CRLF      tomllib=259 张 E60=True  | 字节切分=259 张 E60=True  | 一致=True
   E60 块裸 LF  tomllib=259 张 E60=True  | 字节切分=258 张 E60=False | 一致=False
   ```
   落地链第 ③′ 步的 `wb_plan.py check`（tomllib）报「259 张卡，无冲突」，
   第 ⑤′ 步的 `flip_card_status`（字节切分）报「找不到卡」—— **没有一处钉住两者必须一致**。
   这与卡 E60 修的是同一个病：**同一件事两把尺子，两把尺子说不同的话，而没人钉住它们**。

4. **判不出来的时候默默当没事。** `flip_card_status` 的失败路径（找不到卡 / 找不到
   `status` 行 / `task` 不匹配）全部只 `print` 一句就 `return False`，**调用方
   （`landing.py:2356`）也不看返回值**，于是整条落地链以 exit 0 收场。
   「该翻没翻」「该判判不了」和「本来就不用翻」在返回值上无法区分。

## 判据（五条）

1. **一处读取口径，所有读者共用。** 抽出唯一的 `_split_blocks(raw: bytes) -> list[bytes]`：
   用 `raw.splitlines(keepends=True)`（或等价写法）**同时认 CRLF 与裸 LF**，
   返回逐块的行列表；`flip_card_status` / `backlog_blocks` / `_card_files_from_backlog` /
   `_integrate_multi_tree` 全部改走它 —— **不许留第二份切分逻辑**。
   钉子 `test_mixed_endings_still_finds_every_card`：对「E60 块裸 LF」的样本，
   `_scan_blocks` 认出的卡数必须 == `load_backlog(...).by_id()` 的卡数，且必须含 E60。
2. **两把尺子必须说同一句话（防复发）。** 钉子
   `test_byte_ruler_agrees_with_tomllib_ruler`：对 4 份样本（纯 CRLF / 纯 LF /
   首块裸 LF / 末块裸 LF）逐一断言两个读取器的卡号集合**完全相等**。
   **反向验证过**：把 `_split_blocks` 改回 `sep = b"
" if ... else b"
"`
   ⇒ 该钉子红。
3. **翻不动就要出声，不许 exit 0。** `flip_card_status` 增加返回值区分
   「不用翻（本来 done / 登记型提交）」与「**该翻却翻不了**」；后者必须让落地链
   **退非零**（`return 2`「★ 队列与台账不一致 ⇒ 停手」，与「计划外暂存区」同级），
   命令行输出必须**点名卡号与原因**（找不到卡 / 找不到 status 行 / 行尾混用）。
   钉子 `test_unflippable_card_stops_the_landing`：造一份混行尾 backlog ⇒
   `wb_land --commit-only` 必须退非零，且 stderr 里必须出现卡号。
4. **写入也不许再造混行尾。** `pool/stage_card.py:90` 与其它写 `workbacklog.toml` 的
   地方，必须**跟随文件现有的行尾**（不新引入第二种）。
   钉子 `test_writers_preserve_the_existing_ending`：写完后
   `raw.count(b"
") - raw.count(b"
")` 必须仍是 0（对纯 CRLF 样本）。
5. **全仓扫，防第七处。** 钉子 `test_no_ending_sniffing_split_left`：扫
   `tools/ scripts/ tests/ framework/src/` 里所有
   `b"
" if ... else b"
"` 后紧跟 `.split(` 的可执行行，一处都不许有；
   扫出但**不是**读队列块的行必须进白名单**并写明理由**（照卡 E60 判据 6 的
   `_NOT_A_RED_RULER` 体例）。`test_the_allow_list_says_why` 钉住白名单自己：
   理由空 / 行号越界 / 那一行已不是该写法 ⇒ 红。

## 不许做

- 不许用「把 `docs/workbacklog.toml` 强制归一成 LF」当修法 —— 那会把 4166 行 CRLF
  全部重写，diff 淹没真改动，且下一个写入者照样能造出混行尾。
- 不许让「翻不了」**静默**继续（这是本卡唯一不容妥协的一条）：可以退非零、可以要求
  显式 `--allow-no-flip`，但不许 exit 0 收场。
- 不许把 `load_backlog`（tomllib）改成跟着字节切分走 —— 修的是**字节切分向 tomllib 看齐**，
  不是反过来。tomllib 是 TOML 的权威读法。
- 不许顺手改 `docs/workbacklog.toml` 的现有内容（本卡只改读法与判据，不整理数据）。
