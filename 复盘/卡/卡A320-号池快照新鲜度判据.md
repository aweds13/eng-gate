# 卡 A320 —— 号池快照新鲜度判据：过期要响亮点名，不许拿旧快照当现场读数（T-AG597）

> 台账号 `T-AG597` ｜ 分区 A ｜ 树 `.wt/A320n` ｜ 层 判据层
> 依据：`复盘/问题清单-组5.md` 的 **Q-L9-06**「`pool/models.py` 读的是快照不是现拉 —— 谁判这份快照还新鲜？」，
> 其了结证据要求「拿一份过期快照去判可用性，工具要么现拉、要么明确标『数据 N 小时前，不足以判』」。

## 要解决的问题

`tools/pool/models.py` 的模块头自己写着「这里读的是**快照**（带 `at` 时间戳），**不是现场拉取**」，
可全库对「这份快照还新不新鲜」**零判据**：

- `grep -rn "snapshot_age_hours\|snapshot_stale\|STALE_HOURS" tools tests skills docs 复盘` ⇒ 零命中。
- 两个消费方（`tools/pool_mcp.py` 与 `tools/wb_state.py`）都只把 `snapshot_at` 当**一行文本**打印，
  不会因为它是一周前的就变脸。

现场读数（实测真号池，只读不写）：`at = '2026-10-25 20:51:56'` ⇒ 快照**已过期约 290 小时**，
而 `in_both` 仍把两个模型当「现在能用」。这正是 Q-L9-06 说的「拿旧的当现在」。

## 判据（6 条，逐条可执行）

1. **年龄是算出来的，不是猜的**：`tools/pool/models.py` 新增 `STALE_HOURS = 24` 与
   `def snapshot_age_hours(at: str | None, *, now: datetime | None = None) -> float | None`。
   `at` 为空 ⇒ `None`；`datetime.strptime(str(at).strip(), "%Y-%m-%d %H:%M:%S")` 抛
   `ValueError` ⇒ `None`（**不猜**）；命中 ⇒ `round((base - stamp).total_seconds() / 3600.0, 1)`。
2. **`load_pool_models()` 返回值带四个新键**（追加，不动既有键）：`snapshot_age_hours`（float|None）、
   `snapshot_stale`（bool）、`snapshot_stale_hours`（int）、`snapshot_note`（str）。
   ★ 加键不许破坏既有消费方：`tests/test_pool_lib.py` 里读 `load_pool_models(pool)` 的用例继续绿。
3. **★ 坏时间戳必须按「过期」处理，字段与文案不许打架**。
   旧实现 `stale = age is not None and age > STALE_HOURS` 使 `at` 有值但读不出时
   `age=None / stale=False / note='…读不出来 ⇒ 当过期处理'` —— 同一份数据两个答案。
   正确口径：**有 `at` 但读不出 ⇒ `stale=True`**，且 `snapshot_note` 与 `snapshot_stale` 同向。
   `at` 缺失（文件没有 `at` 键）时才允许 `stale=False`，并让 `snapshot_note` 为空串。
4. **派活前响亮提示，但不拦**：`tools/wb_dispatch.py` 新增 `def snapshot_stale_problem() -> str` ——
   号池目录找不到或任何异常 ⇒ 回 `""`（提示性判据，读不到就不嚷）；
   `snapshot_stale` 为真 ⇒ 回带年龄 / 上限 / `snapshot_at` 的一句话；坏时间戳时措辞必须是
   「时间戳读不出来」而不是「已过期 None 小时」。接在 `preflight()` 里 `stale_base_problem(...)` 之后：
   只 `print(..., file=sys.stderr)`，**不进 `problems`** —— 快照不是现场读数，不许因它拒派活。
5. **三条钉子逐条咬住**（`tests/test_pool_models.py`）：
   - `test_snapshot_age_is_computed_not_guessed`：`now=datetime(2026,10,23,18,0,0)` 时
     `snapshot_age_hours("2026-10-23 06:00:00", now=now) == 12.0`；坏时间戳 ⇒ `None`；`None` ⇒ `None`。
   - `test_stale_snapshot_is_flagged_loudly`：临时目录写白名单与快照，`at` 取
     `now - (STALE_HOURS + 30)h` 与 fresh 两态 ⇒ `snapshot_stale` 如预期；stale 时 `snapshot_note` 非空。
   - `test_unreadable_snapshot_stamp_is_stale_not_fresh`：一个用例并列钉两半 —— 坏时间戳 ⇒
     `snapshot_stale is True` 且 note 含「读不出来」；`at` 缺省 ⇒ `snapshot_stale is False` 且 note == ""。
6. **ruff 干净**：`python -X utf8 -m ruff check tools/pool/models.py tools/wb_dispatch.py tests/test_pool_models.py`
   ⇒ `All checks passed!`。旧成果在这里带一条 I001（文件里有一处死分支在函数体内 `import tomllib`
   并调用并不存在的 `tomllib.dumps`），必须清掉。
