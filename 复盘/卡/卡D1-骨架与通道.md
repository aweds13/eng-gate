# 卡 D1 · 骨架与通道（壳 + WebView + 桥 + 构建管线）

- task: T-DG001
- tree: `.wt/D1`
- risk: mid
- 上游：`src/dsmate/docs/`

## 问题

没有壳就没有一切。眼下 `src/dsmate/` 只有文档，没有一行能跑的代码；而后面七张卡
（数据、渲染、模型、教材、搜索、核验、备份）全都要先有一条**能发一句、能收流**的通道。
不先把通道打通，后面每张卡都得先造一遍通道。

## 改法

1. 安卓工程 `src/dsmate/app/`：单 Activity（`MainActivity.kt`），承载 WebView。
2. 前端工程 `src/dsmate/web/`：Vite 构建 → 产物落 `assets/web/`（`vite.config.ts` 里配 `base: './'`，不许 CDN）。
3. **桥只开四类**（`Bridge.kt`）：`net.chat` / `net.tools` / `store.*` / `media.*`；本卡只实现 `net.chat`。
4. `ChatClient.kt`：OpenAI 兼容请求、`stream:true`、SSE 逐块回调、取消、超时。
5. 前端 `main.ts`：一个最小界面——输入框 + 发送 + 流式追加的文本；够验证通道即可。

## 判据

- `./gradlew assembleDebug` 能出 APK，装到真机能打开。
- 填一处临时 key（环境变量或设置项）→ 发「你好」→ 屏幕上逐字长出来。
- 点「停止」→ 流断开，已收到的字**留着**。
- 飞行模式下打开 App：不崩、给出可读错误（不是白屏）。
- `grep -r "https://" src/dsmate/web/src` 里没有第三方域名（除 `baseURL` 变量）。
- 前端 `npm run build` 后 `assets/web/` 里无 `http://` / `https://` 的字面外链。

## 证据

- 装好的 APK 路径与 `versionName`。
- 一次流式对话的录屏或日志（含首字时间）。
- 构建日志尾部。

## 不做

- 不做设置页、不做会话列表（D8/D2）。
- 不做密钥加密存储（D4），本卡允许临时明文 key 并标注。
