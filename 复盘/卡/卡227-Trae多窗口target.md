**树**：`.wt/traetarget` ｜ **成员号**：`B-20261017` 的 `227`。★ **依赖卡 218**（`depends = ["218"]`）：
218 先把 `trae_pool.mjs` 的修补落地，本卡在它之上加窗口选择。

## 为什么有这张卡
Trae 那条道（CDP 驱动 Agent 面板）2026-10-13 已验通，六个会话并行跑完六张卡。
但驱动脚本 `tools/trae_pool.mjs` **只会连一个面板**：找到第一个 `solo-lite` 页面就用，
**没法选**要往哪个窗口/哪个面板说话。

后果很实在：
- 用户**多开 Trae 窗口**时，脚本可能把活派进**不是他想要的那个**窗口；
- 也没法"看一眼现在有几个面板、各自什么状态" —— 只能盲发。

★ 卡 218 里我尝试补过这段，**补丁打在陈旧文本上、静默没生效**（`--target` 报"连不上 CDP"，
其实是参数根本没接上）。本卡把它**做对 + 钉住**。

## 要做的事
### 1. `--target` 选择面板
- `--target "#N"`（第 N 个面板，0 基或 1 基要**写清楚**）与 `--target <子串>`（按 URL/标题子串匹配）；
- 匹配**不唯一**或**匹配不到** ⇒ **停手并列出所有候选**（不许"随便挑一个"）；
- 不给 `--target` ⇒ 保持现行为（第一个面板），**逐字不变**。

### 2. `listPanels()`
- 列出所有可驱动的面板（序号 / URL / 标题 / 是否已连着会话），给 `--target` 当索引；
- 一个只读 CLI 子命令（例如 `--list`）就够。

### 3. 判据
- ★ 反例：两个面板标题都含同一子串 ⇒ **停手并列出两个**（不许择一）；
- 反例：子串谁都不匹配 ⇒ 停手并列出全部候选；
- 不给 `--target` ⇒ 走老路（行为不变）。
