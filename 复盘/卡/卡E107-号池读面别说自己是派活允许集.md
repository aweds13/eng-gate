# 卡 E107 · 号池读面把「交集」说成派活允许集，快照过期只藏在 JSON 块里

> 台账号 `T-AG616`｜分区 E（门禁与可信度）｜树 `.wt/E107`｜层 判据层｜基准 `e61348a4`｜
> 依据：用户 m92988「把 pool 的使用打磨好，不计代价与 token」；m93503「之前的任务记得做完」。

## 要解决的问题（逐条实测，不是推测）

### 问题 1 · `pool_models` 把「号池批准 ∩ 号池快照」说成「真正允许派活的」

`tools/pool_mcp.py:1123` 原文：

```python
lines.append("交集（真正允许派活的）：" + ("、".join(info["in_both"]) or "（空 —— 拒绝派活）"))
```

而 `in_both` 只是号池两份静态产物（`models.whitelist.toml` ∩ `models.live.json`）的交集，
与派活器判的那份名单**不是同一件事**。现场（主树 `e61348a4` 实跑）：

```text
pool_models 交集        ：huaweicloud-maas/GLM-5.2、huaweicloud-maas/deepseek-v4.1-flash
effective_allowed_models()            = ('deepseek-v4.1-flash', 'glm-5.3-flash', 'glm-5.3', 'kimi-k3-1', 'glm-5.2')
effective_allowed_models('codearts')  = ('huaweicloud-maas/GLM-5.2', 'huaweicloud-maas/deepseek-v4.1-flash')
```

⇒ 两套 id 口径并存（号池 `provider/model`、派活器裸名），且默认池是 `codebuddy`。
「交集」既不是 `codebuddy` 的允许集、也不是 `codearts` 的允许集 —— 它谁都冒充不了。
最坏的情况是它**空**：文案说「（空 —— 拒绝派活）」，而派活器那边照样能派 5 个模型。

### 问题 2 · 快照过期 373.8 小时，人话段一个字都不说

同一份数据里 `snapshot_stale=true`、`snapshot_age_hours=373.8`、
`snapshot_note="快照已过期 373.8 小时（上限 24h）⇒ 先重新探测再派活"`，但**四段人话里没有这一行**
—— 只有 `--- tf-json ---` 之后的机器块里有。而 `skill`/MCP 客户端读的就是人话段。

### 问题 3 · 注册表坏了会把这个只读工具打成异常

要报「派活允许集」就得调 `wb_dispatch.effective_allowed_models()`，它**不 fail-open**
（注册表缺失 ⇒ `ModelRegistryError`）。今天没人调，所以看不出来；改完必须接住，
否则一个坏 TOML 就让只读工具抛异常（`tests/test_pool_mcp.py::test_nine_tools_return_and_write_nothing`
要求每个工具都回**非空文本**）。

### 问题 4 · `gateway._seat` 的 docstring 断言的是**已经不存在**的行为

`tools/pool/gateway.py:398` 原文：

```text
「不知道怎么排」由卡 E95 在 tools/pool/route.py 里定：当前 route.tier() 拿到 None 会抛 RouteError，
route.apply_strategy() 的 fail-open 于是退回原列顺序。这是**已知且可接受**的中间态
（宁可回列出顺序，也不许拿假读数排），这里**不 catch 遮掩**、也不自己排。
```

实测 `route.tier(None) == 3 == UNKNOWN_TIER`（`tools/pool/route.py:115/:126`），**不抛**；
三座（a known 90 / b known=False / c known 10）下 `smart`、`usage`、`pace`、`""` 全回 `[2,0,1]`
—— 不知道的座被排到**所有知道的之后**，不是退回原列顺序。docstring 在撒谎。

### 问题 5 · 同一条口径在模块表里还有一份投影

`docs/subsystems/pool/modules.toml:132` `models.py` 的 duty：「号池模型的只读读取：批准集 ∩ 可用集；
读快照（带 at），不联网、不写快照」—— 同一句「交集 = 能用的」。`modules.toml:56` 的 `gateway.py`
duty 也没写「不知道的座排最后」。

## 判据（五条）

### 判据 1 · `pool_models` 不再冒充派活允许集，并把真名单按池报出来

* 删掉「交集（真正允许派活的）」这句话；改成点名来源、明说**不是**派活允许集。
* 新增一段「派活允许集」：调 `wb_dispatch.effective_allowed_models(pool)`，**逐池**列
  `wb_dispatch.DEFAULT_POOL` 与 `model_registry.KNOWN_POOLS` 其余池；未接的池（`get_adapter(pool).wired`
  为假）如实标「未接 ⇒ 派它会被拒」，不许假装能派。
* schema 描述（`tools/pool_mcp.py:436`）与模块 docstring 的「诚实边界」段同步。

**钉子**（`tests/test_pool_mcp.py`）：
- `test_pool_models_does_not_call_the_intersection_a_dispatch_allow_list`：真仓 root ⇒ 文本含
  `不是派活允许集`，**不含** `交集（真正允许派活的）`；含 `effective_allowed_models`。
- `test_pool_models_reports_the_dispatch_allow_list_per_pool`：文本里 `codebuddy` 段落的那一行
  与 `wb_dispatch.effective_allowed_models("codebuddy")` 集合逐项相等（不写死名单，现算比对）。

### 判据 2 · 快照新鲜度必须出现在**人话段**（三态，不许只说两种）

三态：过期（`snapshot_stale=True`）/ 新鲜 / **没记录**（`at` 为空 ⇒ 老实说「不知道它多旧」，
不许说「新鲜」）。过期那一行必须带小时数与上限。

**钉子**（`tests/test_pool_mcp.py`，照 `tests/test_pool_lib.py:212` 造假号池目录）：
- `test_pool_models_says_the_snapshot_is_stale_in_the_human_text`：`at` 设成 3 天前 ⇒ 文本含
  `快照` 与 `过期`、含 `72` 左右的小时数、含 `24`；且 `snapshot_stale is True`（机器块与文本同源）。
- `test_pool_models_says_fresh_without_crying_wolf`：`at` 设成现在 ⇒ 文本含 `没过期`、不含 `已过期`。
- `test_pool_models_says_unknown_when_the_stamp_is_missing`：快照里没有 `at` ⇒ 文本含 `不知道`，
  不含 `没过期`（不许把「没记录」洗成「新鲜」）。

### 判据 3 · 注册表坏了，这个只读工具也不许崩

`effective_allowed_models` 抛 `ModelRegistryError` / `UnknownPoolError` ⇒ 该段如实写
「派活允许集读不出来：<异常名>：<原文>」+ 指针（`TF_MODEL_REGISTRY` / `model-registry.toml`），
整体仍 `is_error=False`、文本非空（号池那几段照常给）。

**钉子**：`test_pool_models_survives_a_broken_registry`：`TF_MODEL_REGISTRY` 指到不存在路径 ⇒
`is_error is False`、文本含 `读不出来` 与 `ModelRegistryError`、且仍含号池批准集那一行。

### 判据 4 · `gateway._seat` 的 docstring 改回**实测**，行为不弱化

docstring 删掉「会抛 RouteError」「fail-open 于是退回原列顺序」，改成实测口径：
`route.tier(None) == UNKNOWN_TIER`，四个分桶策略把不知道的座排到最后，`order/rotate/weight/free`
不看额度、保列出序；仍然「不 catch、不自己排」。

**钉子**（`tests/test_pool_gateway.py`）：
- `test_seat_docstring_does_not_claim_a_raise_that_no_longer_happens`：`inspect.getdoc(gateway._seat)`
  不含 `会抛 RouteError` 与 `退回原列顺序`，含 `UNKNOWN_TIER`。
- `test_seat_hands_unknown_quota_to_route_as_unknown_tier`：`_order([known90, unknown, known10], "smart")`
  与 `route.apply_strategy("smart", [Seat…])` 逐项相等（docstring 说的就是代码做的）。

### 判据 5 · 模块表两处 duty 同步；只读性一个字都不许退

`docs/subsystems/pool/modules.toml`：`models.py` duty 去掉「批准集 ∩ 可用集」的说法、改写成
「号池批准集 ∩ 号池快照（★ 不是派活允许集）」；`gateway.py` duty 补「不知道额度的座由
`route.tier(None)=UNKNOWN_TIER` 排到最后（不是抛错退原序）」。

**钉子**：
- `test_pool_models_module_duty_does_not_claim_the_intersection_is_the_allow_list`
  （`tests/test_pool_mcp.py`，`tomllib` 读 `modules.toml` 找 `name == "models.py"` 那条）：
  duty 不含 `批准集 ∩ 可用集`，含 `不是派活允许集`。
- `test_pool_models_still_writes_nothing`：假号池目录跑前跑后 `models.live.json` 与
  `models.whitelist.toml` 的字节与 mtime 不变（只读、不写快照、不联网）。
