# 卡 E89 —— 启用台账分片：写侧按分区落片、读侧补齐（T-AG596）

> 台账号 **T-AG596** ｜ 分区 E（门禁与可信度）｜ 树 `.wt/E89` ｜ 层 判据层
> 基准提交 `7d3f1ba8`（E88 落地笔：台账合并先做到无损）

## 要解决的问题（已实测，不是推测）

目标①「多主控共用卡池的写入隔离」的最后一步：把台账拆成 `docs/backlog/<分区>.toml`，
各分区各写自己的片，落地时合并成**只读总表**。锁（E81 `87f95ba5`）、分片读取
（`load_sharded_backlog`，先分片后总表）、**无损合并 + 覆盖守卫**（E88 `7d3f1ba8`）都已经在了。
缺口全在「接线」：写侧不落片、读侧一半不认分片、切换没有安全网。

四组缺陷，全部用真件在**仓外**沙箱复现过（探针 `gates/diag/_e89_probe2.log` … `_e89_probe8.log`）。

### 缺陷 1：写侧硬编码单文件，落片根本没接线

`tools/pool/ledger.py:85 BACKLOG_REL = "docs/workbacklog.toml"` + `:340 add_card()`、
`tools/pool/landing.py:538 backlog_rel = "docs/workbacklog.toml"`（函数 `:508 flip_card_status()`，
全文件唯一台账写盘点 `:579 ledger.write_atomic(backlog_path, …)`）都写死单文件；
`tools/wb_card.py:83` 是 `add_card()` 唯一生产调用点，全对 `partition_of` / `load_partitions` 命中 **0** 次。

不改就会出两个洞（`_e89_probe2.log` 实测）：

```
[Q1] add_card 之后：总表 159066 → 159269 B；has_card(总表)=True / 分片里有=False
     merge_lossless ⇒ 缺 1 张 / 输出 0 B，缺的是 ['Z999']        ← 覆盖守卫永久挡住 merge
[Q2] flip_card_status 返 'flipped'，done 323 → 324
     merge_lossless ⇒ 缺 0 / 输出 159066 B ⇒ done 回 323         ← 刚翻好的 done 被分片块顶回去
```

机制：`merge_lossless()` 的既有块**字节取自分片**，总表多出来的卡不在任何分片 ⇒ 守卫报「缺 N 张」不写盘；
status 只改了总表那一份 ⇒ 下次合并把分片里的 pending 顶回来。

### 缺陷 2：分片集合不全时静默少卡（本卡核心）

`tools/wb_plan.py:339 load_sharded_backlog()` 只要分片目录里有任何一个 `.toml` 就**只**返回分片结果，
不回落、不比集合（`:314 merge_shards()` 也没有比对逻辑）：

```

[_e89_probe7.log] B 段：只放 B–G 六片 ⇒ 现存 ['B','C','D','E','F','G']，返 107 张，「无异常」
```

而 `grep -rn "backlog" gates/defs/*.py` = **0 命中**、`grep -rn "wb_plan" gates/defs/*.py scripts/run_gates.py`
= **0 命中** ⇒ **今天没有任何一道门会红**。

生产形态是**七片**（`_e89_probe5.log`）：A 226 卡 110206 B｜B 8｜C 2｜D 8｜E 69｜F 12｜G 8，合计 333；
142 张纯数字旧号按 `docs/partitions.toml` 的 `[legacy] default = "A"` 全归 A（**A 片占 69%**）。
闭环：`缺卡 0 / 输出 159066 B / sha 7f936ee24892ba1d / 逐字节相同 = True`；

### 缺陷 4：切换那一刻没有安全网

H1「总表全量 + 只建一片」⇒ 少 107 张不报错；H2「总表全量 + 七片齐全」⇒ 333 张、卡号集合相同、
逐卡对象不相等 0 个（两处一致，切换可行）。`_e89_probe7.log` C 段：分片齐全时 `merge_lossless`
⇒ 159066 B / 缺 0 / 与真总表逐字节相同 = True；总表被删后分片路仍读得到 333 张。
⇒ 正确顺序是「先建七片 → merge --execute 验逐字节 → 之后才允许在没有总表的情况下读」，
**但今天没有任何判据拦住「只建一片就开工」**。

## 判据（6 条）

1. **写侧按分区落片，且两处同源。** `tools/pool/ledger.py:340 add_card()` 与
   `tools/pool/landing.py:508 flip_card_status()` 都必须按 `wb_plan.partition_of()` 找到目标分片
   （`docs/backlog/<分区>.toml`）并只改那一片；`docs/workbacklog.toml` 从此**不再被这两个函数写**。
   可测：沙箱里 add 一张带前缀的新卡 ⇒ 落在对应分片、`load_sharded_backlog` 立刻看见、**总表字节一字未变**；
   再 flip 一张 pending 卡 ⇒ 翻的是分片那份，随后 `merge --execute` 之后该卡**仍是 done**（不许被顶回 pending）。

2. **分片集合不全必须响亮失败（本卡核心）。** 两条路线都写清代价，落地**以路线②为主、路线①一并常开**：
   - 路线②（主）：**总表只由 `wb_plan.py merge --execute` 生成**，写侧（判据 1）不再写总表 ⇒
     结构上不可能不同步；覆盖守卫 E88 已落成（`tools/wb_plan.py:914 cmd_merge`，缺卡 ⇒
     `[FAIL] 分片没覆盖总表：缺 N 张卡` 退 1、**一字未动**）。**代价**：总表成为派生物，手写注释只留在分片里；不额外付读开销。
   - 路线①（兜底，**无条件常开、不加开关**）：`load_sharded_backlog()` 在分片目录存在时，再把分片卡号集合
     与总表卡号集合比一次，不等 ⇒ 抛 `BacklogError` 并点名缺哪几张。**代价实测**：每次读多付 **19.0 ms**
     （`load_backlog` 19.0 ms / `load_sharded_backlog` 20.0 ms）；对 CLI 可忽略，换来「少一片就一定响」，
     **不许**因为「多读一次」把它做成默认关。
   可测：抽掉 `A.toml`（226 张）后读队列**必须抛 `BacklogError` 并点名 226 张**，不许返回 107 张。
   反向变异摘掉守卫 ⇒ 必须退回静默 107 张并被钉子咬住。

3. **静默型 5 处必须与分片同源。** `tools/pipeline_view.py:322`、`scripts/gen_pool_readme.py:278`、
   `tools/wb_tree.py:361`、`tools/wt_prune.py:286`、`tools/wb_flow.py:83`（含 `:59` 的 git 路径）
   全改成「有分片先读分片」，**每处各一条钉子**。可测：夹具「总表少 C1 + `C.toml` 有 C1」下，
   `pipeline_view.read_cards` 必须含 C1、`gen_pool_readme.backlog_metrics` 的 pending 必须是 **10**、
   `wb_tree.load_cards` 必须含 C1、`wt_prune.backlog_pending_trees` 必须含 `.wt/C1`、`wb_flow` 的到达口径看得见分片新卡。

4. **拒单型 5 处不许再拒正常活。** `tools/wb_registry.py:45`、`tools/wb_review.py:660`、
   `tools/wb_impact.py:290`、`tools/auto_land.py:133/250`、`tools/pool_mcp.py:893/1591`
   都要能取到只存在分片里的卡。判据：夹具里那张分片卡，`wb_registry.files_from_backlog` 必须返回域（不抛）、
   `auto_land` 不许说「不在队列」、`wb_review.resolve_domain` 不许落到「权威域查不到」。

5. **按路径取历史的读者必须认分片落点。** `tools/wb_flow.py:59` 与 `tools/wb_queue_audit.py:178` 的
   `git log -- <队列路径>` 要覆盖 `docs/backlog/*.toml`。判据：造一笔只改 `docs/backlog/C.toml` 的提交 ⇒
   簿记号必须认它（今天 `-- docs/backlog/C.toml` = 0 笔、`-- docs/workbacklog.toml` = 306 笔）。

6. **切换可核、可回滚、既有钉子一条不松。** 真总表拆七片后 `merge --execute` 必须**逐字节等于**
   切换前的总表（`159066 B / sha 7f936ee24892ba1d / 缺卡 0 / 逐字节相同 = True`）；「只建一片就开工」必须被拒（判据 2）；
   `docs/workbacklog.toml` 本卡**保留不删**（`tools/pipe_root.py:20` 的根探测还认它）；
   `tests/test_partitions.py` 与 `tests/test_merge_is_lossless.py` 既有断言全绿、**一字不改**。
