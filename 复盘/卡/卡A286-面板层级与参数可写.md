# 卡 A286 · 面板层级收敛 + 参数可写 + 补分发分支（T-AG400）

## 问题

- **左栏多一行**：工作台状态在左栏单挂一行（`workbench_board` 座位 `row=True`），与「工程工具箱」里的看板重复。用户要左栏只剩 工程工具箱 / 禅道 / timeflow 三行。
- **两个处理函数是死代码**：`serveProxy`（`tools/dsh_panel.py:880`）与 `servePoolAction`（`tools/dsh_panel.py:1023`）都有定义、路由常量也在，但 `serveSeam` 里没有对应分发分支 ⇒ 反代 `/dsh-panel/proxy/z/zentao/…` 落到「未知路由 404」，派活 `POST /dsh-panel/pool-action` 被只读门挡成 405。**症状与代码对不上，查了半轮才发现是少一个 if。**
- **`serveSettings` 分发漏传 `url`**：函数体用 `url.searchParams`（`tools/dsh_panel.py:847`），分发处只传 `(req, res)`（原 `tools/dsh_panel.py:1050`）⇒ POST `/dsh-panel/settings` 必抛 `Cannot read properties of undefined (reading 'searchParams')`，参数页永远写不进去。
- **参数页只读**：白名单只有 `tf_gate_min_free_gb` / `gate_workers`，页面写着「面板只读；改参数走 CLI」；越界值被静默夹到边界 —— 夹了用户以为写进去了，实际是另一个值。
- **面板能改的数没有下文**：`tools/wb_plan.py` 的 `--concurrency` 默认写死 `DEFAULT_CONCURRENCY`，面板写的号池并发度没有消费者 ⇒ 那个输入框只是摆设。

## 改法

1. **层级收敛**：座位加 `row: bool = True`（`tools/dsh_panel.py:166`），`workbench_board` 置 `row=False`（`tools/dsh_panel.py:261`）；派生 `ROW_KEYS`（`tools/dsh_panel.py:294`）作左栏行的唯一真源。`_client_registrations()` 只对 `seat.row` 的座位注入 `sidebar.panellist` 行；`check_client` 的判据从「main 座 == 行 id 逐项相等」改成「两边各自与自己的表比」（`tests/test_dsh_panel.py:228` 的 `test_client_main_keys_equal_sidebar_row_ids` 标定）。
2. **工作台状态并进「工程工具箱 → 工作台」页签**：`TOOLBOX_TABS` 加一行（`tools/dsh_panel.py:1629`），新增 `ToolboxWorkbench`（`tools/dsh_panel.py:1868`）并接进 views 映射。
3. **补分发分支**：`serveSeam` 里加 `url.pathname.startsWith(PROXY_MOUNT + "/")`（`tools/dsh_panel.py:1061`）与 `url.pathname === POOL_ACTION_ROUTE`（`tools/dsh_panel.py:1065`）两支 —— **放在 GET 闸门之前**（一个要 POST，一个要透传上游 302）。守则：分支顺序 = 先 POST 路由、再只读闸门、最后 GET 路由。
4. **`serveSettings` 补传 `url`**：分发改成 `serveSettings(req, res, url)`（`tools/dsh_panel.py:1050`）。
5. **参数页可写**：数字框 + 保存按钮（`ToolboxParams`，`tools/dsh_panel.py:1804`）；白名单 `SETTINGS_KEYS` 加 `pool_concurrency`（1–8，`tools/dsh_panel.py:774`）；越界从「静默夹边界」改成 **400 + 明确文案**（`tools/dsh_panel.py:826`），未知键同样 400。
6. **`tools/wb_plan.py` 消费面板参数**：新增 `settings_concurrency()`（`tools/wb_plan.py:110`）读 `tools/settings.toml` 的 `pool_concurrency`；`--concurrency` 默认由 `DEFAULT_CONCURRENCY` 改成 `None`（`tools/wb_plan.py:754`），`main()` 里「没给 ⇒ 读面板；读不到 / 越界 ⇒ 退回 `DEFAULT_CONCURRENCY`」（`tools/wb_plan.py:773`）。
