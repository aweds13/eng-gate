# 卡 A327：按域跑必需门（提交闸从「19 道全量」改成「必需的那几档」）

- 台账号：T-AG442（落地后翻 done）
- tree：`.wt/A327`（分支 `card/A327`）
- risk：low（默认口径不变：只要有一处判不出来，就退回「全量」；`--affected` 的强制全量规则不动）
- depends：A324（会话闸）、A326（两根；落地链的 cwd 口径）

## 目标

把「提交前必须 19 道门全绿」换成「**提交前必须跑完这次改动所影响的那几档**」，
并把「跑了哪几档、够不够」写进 `gates/last.json`，让 `wb_review` 第 ③′ 条判据
按同一张表判，而不是只认 `profile == "all"`。

动机（用户原话，2026-10-24）：只改 `skills/**` 或文档时也要等 13 分钟（`ui_flow` 367s、
`render` 105s 全是真浏览器），与改动面严重不匹配；门禁分层（卡 A321 · T-AG434）已经
存在，但提交闸不认单档。

## 判据（都要机器可验）

1. **映射表只有一份**：`gates/defs/domains.py` 里 `REQUIRED_PROFILES: tuple[tuple[str, tuple[str, ...]], ...]`
   （`glob → 必需档集合`），`run_gates.py` 与 `wb_review.py` 都 import 它，不许各写一份。
   初始表：
   - `src/**`, `examples/**`, `harness/**` ⇒ `{lang, product}`
   - `tools/**`, `scripts/**`, `tests/**`, `gates/**` ⇒ `{lang, audit}`
   - `docs/**`, `复盘/**`, `skills/**`, `*.md` ⇒ `{audit}`
   - 其余 / 任何判不出的路径 ⇒ `{lang, audit, product}`（全量，fail closed）
2. **`last.json` 记真话**：新增 `profiles_run: ["lang","audit"]`、`required_profiles: [...]`、
   `changed_paths: [...]`；`ok` 仍表示「这次跑的门全绿」。
3. **提交闸按表判**：`wb_review.check_gate_evidence(payload, parent)` 改成
   `required ⊆ profiles_run` 且那次门禁的 `rev == parent`；缺档 ⇒ 报
   「这次改动需要 lang+audit，你只跑了 audit（缺 lang）」。
4. **退回全量是安全的**：`profiles_run` 里含 `"all"` 时永远满足；`--affected` 的
   「碰 scripts/**tools/**gates/**、空计划、当天没跑过全量」三条强制全量规则**保留**。
5. **封存字段不撒谎**：`seal()` 重算 tree 时不清空上面三个字段；`--profile` 单档跑出来的
   `last.json` 不得被当成全量（现有钉子 `tests/test_run_gates_profiles.py` 继续绿）。

## 交付

- `gates/defs/domains.py`（新，映射表 + `required_profiles(paths)` 纯函数）
- `scripts/run_gates.py`（按 `--changed-from` 选档；写 `profiles_run/required_profiles/changed_paths`）
- `tools/wb_review.py`（③′ 改按表判，报缺哪档）
- `tools/pool/landing.py`（落地前算必需档、只跑那几档；trailer 如实写「跑了哪几档」）
- `tests/test_run_gates_domains.py`（映射表钉子：每行一条、未知路径 ⇒ 全量、文档-only ⇒ audit）
- `tests/test_wb_review.py`（缺档被判红；`all` 仍通过）

## 不许做

- 不许把「缺档」判成通过（宁可多跑，不许漏跑）。
- 不许为省时间跳过 `audit`（台账/封存/`Task:` 全靠它）。
- 不许改 `tests/test_run_gates_profiles.py` 的既有断言（分层本身不动）。

## 验收

```bash
# 映射表：每行都对得上
python -X utf8 -m pytest tests/test_run_gates_domains.py tests/test_run_gates_profiles.py -q
# 提交闸：缺档必红、all 必绿
python -X utf8 -m pytest tests/test_wb_review.py -q
# 真跑一档：文档-only 的改动只该要 audit
python -X utf8 scripts/run_gates.py --profile audit --changed-from HEAD~1
```
