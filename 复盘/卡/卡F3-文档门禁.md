# 卡 F3 —— 文档门禁：`scripts/check_docs.py`（判不出就报 skip）

> 台账号 T-AG451 · 分区 F（文档治理）· 依据 `docs/文档架构.md` 计划 v2 期 2
> 外部依据：调研 §Q10（ratchet + owner/reviewAfter/exitCriteria）、§Q11（skip 不冒充 pass、`--doctor` 自证在跑）

## 要解决的问题

`gates/defs/` 里 19 道门没有一道看文档：死链没人查、代码改了文档没改没人知道、
正文写着"已废弃"却没有状态标注也照样被后来的人当权威读。

## 判据（五条）

1. **死指针**：`docs/**`、`复盘/**`、`AGENTS.md`、`skills/**` 里出现的仓内相对路径（反引号或 markdown 链接）必须存在；不存在逐条报「文件:行 → 指到哪」。
2. **drift 债**：台账 `file:` 证据指向的源文件，其最近提交晚于该文档最近提交 ⇒ 记一条债（只报告）。
3. **superseded 未标注**：正文命中「已废弃 / 被取代 / 不再适用」等词却没有 frontmatter `status: superseded` + `supersedes:` ⇒ 报。
4. **判不出来就报 skip**：解析不了的行、指向仓外/模板占位的路径、`gates/diag/**` 里的产物一律记 `skip` 并**计数打印**；`skip > 0` 时输出必须显式说"这些我没判"，不许输出干净结论。
5. `--doctor` 打印「我在跑 / 我扫了 N 个文件 / 判出 M 条 / 判不出 K 条」；`--mode report|block` 默认 `report`，`block` 时非零退出。

## 交付

- `scripts/check_docs.py`（`--mode report|block` / `--doctor` / `--json`）
- `docs/doc-debt-baseline.toml`（当前欠账条数，只能降不能升：超了报红）
- `gates/defs/contract.py` 增加一道 `docs` 门（audit 档）
- `tests/test_check_docs.py`（5 条：死指针报红 / skip 计数 / superseded 报红 / baseline ratchet / doctor 输出含三类计数）

## 验收

```
python -X utf8 scripts/check_docs.py --doctor     # 三类计数都打印，不撒谎
python -X utf8 scripts/check_docs.py --mode report
python -X utf8 -m pytest tests/test_check_docs.py -q
```

## 不许做

- 不许设"覆盖率 ≥N%"这类阈值（调研明确：我们的文档是决策与复盘，行覆盖率表达不了）。
- 不许让 skip 静默 —— 没有 skip 输出的"全绿"视为门禁没跑（照 `adda doctor` 的教训）。
- 不许在第一版就 `--mode block`（先 report 一周）。
