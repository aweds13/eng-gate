## 判据

### 判据 1 · 坏 whitelist / 坏 snapshot 是**读数**：isError=True、点名文件与解析错误首行，且与「不存在」不同形

`load_pool_models` 返回新增两键 `whitelist_error` / `snapshot_error`（各为 None，或 `{"file": "<文件名>", "error": "<首行>"}`）；`tool_pool_models` 在任一键非 None 时 `is_error=True`。

**钉子**（`tests/test_pool_mcp.py`）新增三条：

- `test_pool_models_broken_whitelist_names_the_file` —— 假池写坏 TOML，断言 `call_tool` 不抛、`is_error is True`、人话含 `models.whitelist.toml` 与 `Expected ']]'`；
- `test_pool_models_broken_snapshot_names_the_file` —— 假池写坏 JSON，断言同款，含 `models.live.json` 与 `Expecting value`；
- `test_pool_models_broken_is_not_the_same_as_missing` —— 同一 tmp root 取两次读数（先写坏、再删掉），断言两份人话**逐字不相等**：坏的那份 `is_error is True` 且含「坏了」；删掉的那份 `is_error is False` 且仍是「不知道它多旧 ⇒ 不当成新鲜，也不当成过期」。

### 判据 2 · 形状不对是读数，不许 AttributeError 冒泡

**钉子** 新增 `test_pool_models_wrong_shape_is_a_reading_not_an_attribute_error`：三条 fixture（`approved = "abc"` / snapshot 写成 `[1,2,3]` / `approved = ["x"]`）逐条断言 `tool_pool_models` 返回而不抛、`is_error is True`、正文点名「结构不对」而不是 AttributeError。

### 判据 3 · quota_status：坏 state 文件与「未记录」可区分，四态字面量一个字不改
