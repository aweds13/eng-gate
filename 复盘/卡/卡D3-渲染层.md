# 卡 D3 · 渲染层（markdown-it + KaTeX + Shiki + Mermaid，流式不整段重排）

- task: T-DG003
- tree: `.wt/D3`
- risk: mid
- depends: D1

## 问题

数学问答里公式、代码、表格、流程图是常态。官方 App 自己写了 markdown 方言词法器
（`_DSFMLexer`）和代码高亮器，那是因为它要极致性能；我们用现成库就够，但**必须解决
两件它也要解决的事**：① 公式要能取回 LaTeX 原文（C6）② 流式追加时不能整段重排（会闪）。

## 改法

1. `renderer.ts`：`markdown-it` + 三个插件（数学、代码、表格）。
2. `math.ts`：KaTeX；识别 `$...$` / `$$...$$` / `\(...\)` / `\[...\]`；渲染失败降级为等宽原文 +
   「显示源码」；复制按 **LaTeX 源**（不是渲染后文字）。
3. `code.ts`：Shiki **离线**（`createHighlighter` 只装常用语言与主题，禁 `fetch` 加载）。
4. `mermaid.ts`：` ```mermaid ` 走 mermaid 渲染；语法错 → 降级为源码，不抛到界面。
5. `stream.ts`：增量策略——只重渲**最后一块未闭合的 markdown 片段**，已闭合块不重算。

## 判据

- `$x^2$`、`$$\int x\sin(x^2)\,dx$$`、`\(a=b\)` 都渲染正确。
- 复制一条公式 → 剪贴板是 `-\cos(x^2)/2` 这类 LaTeX 源，不是 `-cos(x²)/2`。
- 代码块有高亮 + 复制；宽表格横向滚动不撑破容器。
- ` ```mermaid ` 画出一个流程图；把语法写错 → 显示源码且不崩。
- **流式压力测试**：让模型输出 200 行含公式的回答，录制滚动 GIF——已渲染区域不闪、
  不出现「整段跳动」（视觉判据，附录屏）。
- 断网（飞行模式）时上述全部仍然工作；`grep -r "unpkg\|jsdelivr\|cdn\." src/dsmate/web/src` 为 0。

## 证据

- 录屏（流式 200 行 + 折叠公式展开）。
- 复制公式后的剪贴板内容。
- 离线渲染截图。

## 不做

- 不自研词法器/高亮器（**理由**：官方自研是为了极致性能，我们的瓶颈在别处）。
- 不支持富文本粘贴（第一版）。
