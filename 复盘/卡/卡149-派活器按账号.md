# 卡 149 —— 派活器 **`--account <名>`**：两个号**并行**派活（不切号、不打扰在跑的活）（T-G249）

**树**：`.wt/acctflag` ｜ **base**：主控派活时的主树 HEAD ｜ **提交**：★ **不要 commit** ｜ **模型**：默认
**成员号**：任务 `B-ACCOUNT` 的 **M-1**（干完要交成送申请，见最后）

## 来路（用户的多号需求 + 今晚已经**实测跑通**的隔离法）

用户问：*「假如我 work buddy 还有个号呢，你能不能保存现在这个号的登录态？然后开另一个 CLI 你能不能切号？」*
→ 接着又给口径：*「一个 windows 用户和沙箱这样太麻烦了，能不能直接开一个沙箱，把一个隔了，另一个放在外面。
或者是试一下能不能按 profile 分区。」*

★ 主控当晚**实测出结论**（三组对照，写进了 `infra/pool/codebuddy_accounts.py` 的文件头）：
- 登录态住在 **`<USERPROFILE>\.workbuddy\`**（`app/session/Network/Cookies` · `keyblob` · `device-id` …）；
- ★ **`WORKBUDDY_CONFIG_DIR` 挪不动它**（CLI 的认证路径只认 `homedir()`）；**`APPDATA`/`LOCALAPPDATA` 里也没有**；
- ★ **只挪 `USERPROFILE` + `HOME` ⇒ 实例变成"未登录"**，而外面那个号**一字未动**。
⇒ `infra/pool/codebuddy_accounts.py` 已实现并自证：`profile new/env/run/check`
（`profile check --run` 真起一次实例，判出"未登录 ⇒ 可以安全登录第二个号"）。
★ **本卡只做"把它接进派活器"那一半** —— 让**工人**能跑在指定的 profile 里。

## 要做的事（三件）

1. **`tools/wb_dispatch.py` 加 `--account <名>`**：
   - 起工人时把 `infra/pool/codebuddy_accounts.py profile env <名>` 那**六个**环境变量**并进工人的环境**
     （`USERPROFILE` / `HOME` / `APPDATA` / `LOCALAPPDATA` / `WORKBUDDY_CONFIG_DIR` / `CODEBUDDY_CONFIG_DIR`）；
   - ★ **`--account` 不给 = 今天的行为逐字不变**（用真家目录）—— 这条要**钉死**；
   - ★ **profile 不存在 / 拿不到那组变量 ⇒ 拒绝派活并点名**（不许"悄悄退回默认号"—— 那会让工人跑到**别的号**上，
     这类"看着成了其实用错号"正是本仓最恨的假绿）。
2. **留痕**：派活日志 / 收批任务 / 租约里**记下这一趟用的是哪个 profile**（★ 与 `project` 同一风格：
   让"这批活是哪个号跑的"**一眼可查**）。★ 记法与字段名你定，但**必须**在 `wb_registry.py list` 或
   派活日志里看得见。
3. **不许动** infra 那份工具（它已经自证过）—— ★ **只调它、只读它的输出**，**别复制一份**"六个变量"的清单进本仓
   （★ 那就是第二份真源；两个仓之间同理）。

## 验收（照这个报）

- ★ **反例钉子**（改 `tests/test_wb_dispatch.py`；每条要"故意坏掉会红"）：
  ① **给了 `--account`** ⇒ 工人进程的环境里**确实有**那六个变量，且值指向那个 profile（用桩打印环境核）；
  ② ★ **不给 `--account`** ⇒ 环境里**没有**那六个变量（= 今天的行为，**逐字不变**）；
  ③ **profile 不存在** ⇒ **拒绝派活并点名**（不许退回默认号）；
  ④ ★★ **"没有第二份真源"**：桩掉 `codebuddy_accounts.py`（比如让它输出另一组值）⇒ 派活器跟着变
     （★ 证明它**调**而不是**抄**）；把本仓里复制的那份清单再塞回去 ⇒ 某条钉子必须红；
  ⑤ **留痕**：`--account` 那一趟之后，租约或派活日志里**看得见**那个 profile 名。
- 贴：`python -X utf8 -m pytest tests/test_wb_dispatch.py --no-cov` 尾行；`ruff check tools tests` 尾行；
  ★ 真读数：`--account demo --dry-run`（用今晚建的那个 `demo` profile）打印出的**环境摘要原样**
  （★ **真派活**要谨慎：它会在那个 profile 里跑工人 —— 若你没登录，工人会因未登录而失败；**如实说**你做到哪一步）。
- ★ 不许跑全量门禁、不许 commit/tag、不许动 `infra/`、**不许**在真 profile 里登录任何号。
