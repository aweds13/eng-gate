# 卡 A322 · 软工预设项目化：项目书 + 技能对应表 + 装副本一致检查

**task**：T-AG435　**risk**：low　**tree**：`.wt/A322`

## 为什么

软工预设已经是一个**独立项目**（33 条插件、9 个技能、一份 persona），但名下只有一个文件
`docs/presets/softeng.patch.yml`。它真正的行为真源分散在六处：

| 处 | 管什么 |
|---|---|
| `docs/presets/softeng.patch.yml` | 预设形态（插件清单 / persona） |
| `tools/dsh_preset.py` | 装进 profile、备份、`--check` |
| `tests/test_dsh_preset.py` | 形态与 persona 的钉子 |
| `~/.dsh/profiles/desktop/cordis.patch.yml` | **已装副本** |
| `~/.dsh/skills-softeng` | 软工会话的技能目录 |
| `skills/pipe-*`、`skills/softeng-manage` | 技能内容真源 |

缺三样东西：**项目书**（是什么 / 边界 / 怎么算验收）、**技能对应表**（预设 ↔ 技能 ↔ 三个登记目录）、
**变更记录**。另缺一条检查：**源 ↔ 已装副本是否一致**——面板那边有同类检查（卡 A310），预设这边没有，
所以「改了没装」「装了没改」都不会报。

## 判据（怎么算做完）

**层数按 `references/doc-layers.md` 第 2、3 节判**：最小可行是「意图 + 实现」两层，出现信号才补中间层。
本卡判定的信号：**同一行为已经在两处登记（`~/.dsh/skills-softeng` 与仓内 `.dsh/skills`）且已漂移过**
（`pipe-new`、`softeng-manage` 各缺一处）⇒ 需要一份「必须做到什么」来收敛 ⇒ **补规格层**。
契约层等到出现第二个客户端（例如工人侧也吃同一份预设、或面板读预设）再补；品味层等到
「只能凭口味争执」再拆。**不摆空目录。**

1. `docs/presets/intent.md`：意图层一页 —— 为什么要有软工预设、给谁用、不做会怎样、
   与全局会话的差别（工具面窄、技能面 9 个、不含 MCP）。≤40 行。
2. `docs/presets/spec.md`：规格层 —— 「必须 / 不得」清单，每条**可验收**：
   - 必须：9 个技能在三个登记目录都可见（`sync_worker_skills.py --check` 三处 9/9）；
   - 必须：已装副本与源补丁结构一致（`dsh_preset.py --verify-installed` 退 0）；
   - 必须：预设不含 `tool-pwsh`、不含任何 `mcp-client`；
   - 必须：persona 点名入口技能与「先 grill-me 再动笔」两条规则；
   - 不得：把写工具（`pool_dispatch` / `pool_cancel`）带进软工会话；
   - 不得：在本仓之外留第二份技能内容（只许 junction）。
3. `docs/presets/implementation.md`：实现层一页 —— 模块地图（补丁文件 / 安装器 / 钉子 /
   技能目录 / 已装副本）、跑法（三条命令）、依赖方向（源 → 装 → 查，不许反过来）。
4. `docs/presets/README.md`：**索引页**，≤60 行：上面三页的入口 + 怎么验收（三条命令）+
   为什么不建契约/品味层（写清升级信号）。项目书不再单独重复内容——同一事实只留一处。
5. `docs/presets/CHANGELOG.md`：从卡 A313 起的变更，格式 `## 2026-MM-DD 卡号 提交`，
   每条一句话写「改了什么、为什么」。A315（persona 入口规则）、A316（禁长等待）必在其中。
6. `tools/dsh_preset.py` 新增 `--verify-installed`：把源 Patch 的 `preset-softeng` 段与
   profile 里已装的同名段做**结构比对**（`id` / `order` / `plugins` 的 `id`、`disabled`、
   `config` 关键键），不一致退出 1 并打印首个差异路径；一致退出 0 并打印两侧指纹。
7. `tests/test_dsh_preset.py` 加两条钉子：副本被改坏（删一条插件 / 改 persona 一句）时
   `--verify-installed` 必须退 1；一致时退 0。
8. `docs/presets/spec.md` 写明 **MCP 边界**：预设不含 `mcp-client`；要加只加 `pool` 的
   **只读子集**，并用 `mcp_connector_policy` 在工具级 deny 写工具。

## 不做什么

- 不改预设的插件清单（除非修 bug），**不加 MCP**；
- 不动 `C:/Users/example/.dsh` 里除软工预设副本之外的任何配置；
- 不把门表 / 插件清单抄进文档——文档只指路，判据在工具里；
- 不重写已落地的 persona 文案（那是 A315 的产物，只在变更记录里登记）。
