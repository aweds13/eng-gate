## 为什么有这张卡（用户 2026-10-03 12:1x 原话）

> 「那个自举路径缺失，因为你那地弄出那个框架后**第 1 步就是把我们已用那些文档全部整理一遍**。」

⇒ 这就是**自举的第一步**：拿刚做出来的框架，回头整顿**我们自己**的东西。★ **这一步是「自用优先」唯一的硬证据** ——
框架若连我们自己的文档都整不了，它对我们就没用。

## ★ 为什么本卡**只盘点、只出方案，不动文件**（这条要说给后来的人听）

`复盘/` 有 **200+ 份**文档，`docs/` 还有一整片。**大搬家是不可逆动作**，而且本仓有三条硬约束是**现成的**：
1. **台账按路径钉死证据**（`tools/` 226 条 + `scripts/` 45 条，`audit_progress.py` 会**求值** `file:` / `text:` / `test:` 断言）且**只许末尾追加**；
2. **门禁里有一条引用可达性检查**（引用断链 ⇒ 红）；
3. **本卡树只能改白名单内的文件** —— 不可能一边整 200 份、一边同步 271 条证据。

★ **所以本卡要交的不是「整理完」，而是三件能拿去做决定的东西**：一张**机器可读的索引**、一份**带代价的方案**、
以及**「哪些文档现在动不了、被谁钉着」的实测读数**。★ 真整理由**紧随其后的一张卡**按本卡给的「安全批」清单来（那时域是清楚的）。

## 你要产出什么

### ① `tools/wb_docmap.py` —— 文档地图生成器（**机器可读**）
- 扫 `复盘/**` 与 `docs/**` 的 `.md`，每份产出：**路径 / 字节数 / 顶层归属 / 被引用次数 / 引用它的位置（文件:行，最多列 6 条）**。
- **引用面**不许凭印象：用**现成的尺子**算 —— `scripts/check_layers.py` 的引用扫描 · 全仓 `grep` 反查（含**卡规格**、**台账**、**队列**、**门禁脚本**）。
  ★ 「被台账按路径钉着」与「只被人读过」要在字段上**分开**，因为**前者动不了**。
- 支持 `--json` 与 `--check`（`--check` 只报差异、不写文件）。
- ★ **不许 import timeflow 的业务代码**（这是工具，不是产品的一部分）。

### ② `复盘/文档索引.toml` —— 生成出来的索引（**提交它**）
- 由 ① 生成，**字段稳定**（后来的人可以按字段查）。
- ★ 它的用途**不是给人读**，是给**下一张卡**（和框架）当输入：**哪些能安全整、哪些不能**。

### ③ `tests/test_wb_docmap.py` —— **反例钉子**（判据随件走）
至少四条，**全部跑在临时夹具上**（不许拿真树当夹具 —— 那会让每加一份文档就红一次）：
1. **完整性**：夹具里放 N 份 `.md` ⇒ 索引里正好 N 条，**不多不少**；
2. **幂等**：连生成两次 ⇒ **逐字节相同**；
3. ★ **「被钉住」要认得出来**：夹具里造一条 `file:<某文档>` 断言 ⇒ 该文档的字段必须标成**「被台账钉住」**（而不是普通引用）；
4. **坏输入不静默**：给一个不存在的目录 ⇒ **明确报错**（不许静默出空表）。

### ④ `复盘/文档重整方案.md` —— 方案（**人读**）
- **目标结构**：照框架的分类（`Diátaxis` 四象限 + 意图 / 规格 / 契约 / 实现）给出「这类东西该住哪」。
- ★ **安全批**：挑出**≤20 份**「动了不会牵连台账、引用面清楚」的文档，**逐份**写：现在在哪、建议去哪、**动它要同步哪几处引用**（列到文件:行）。
- ★ **危险批**：列出**被台账或门禁按路径钉住、因此现在动不了**的那些，逐份写**被谁钉着**（文件:行）。★ 这一节是**本卡最值钱的读数** ——
  它就是「框架要能整文档，先得把台账与实现解绑」这条的**实测证据**（卡 178 要的解耦路径，正好拿它当输入）。
- **不做的**：明确写「本卡不移动、不删除、不改名任何文档」。

## 三条硬要求

1. ★ **一行都不许动真文档**（不许移动 / 改名 / 删除 / 改内容）—— 本卡只**新增**上面四个文件。
2. ★ **读数必须现跑现贴**：引用次数、被钉住的文档数、索引条数，全部是命令输出。
3. ★ 不许动 `复盘/不变量台账.toml`、`docs/workbacklog.toml`、`scripts/**`、`src/**`、别的 `tests/**`。
