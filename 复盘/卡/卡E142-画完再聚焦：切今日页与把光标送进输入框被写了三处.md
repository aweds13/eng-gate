## 要解决的问题（逐条实测，不是推测）

### 问题 1 · 聚焦发生在整块重写之前，节点被换掉 ⇒ 焦点落到 body

探针 gates/diag/probes/e142_v4.mjs（真浏览器、无网络延迟）一条时间轴：

        1 armed
       15 focus input#paletteInput
       39 focus body
       75 focus input#newTitle
      120 focus body
      121 main n=20 len=5768

src/web/index.html:1164-1172 原文：

    function paletteNewTask(){
      view('today');
      let n=0;
      const timer=setInterval(()=>{
        const i=document.getElementById('newTitle');
        if(i){i.focus();clearInterval(timer);return}
        if(++n>20)clearInterval(timer);              // 1 秒还不出来就放弃（不无限轮询）

render('today') 要等 /api/config（:1230）才 paint(renderToday)（:1238），而 renderToday 末尾是 m.innerHTML=（:2610）整块换掉 #main —— 焦点节点随旧 DOM 一起消失。

### 问题 2 · 只有「前态不是今日页」时才碰巧绿

探针 e142_v5.mjs（同机、同命令、只换前态）：

    == A: 前态=今日页 ==  16 focus input#paletteInput / 36 focus body / 79 focus input#newTitle / 114 focus body / 115 main n=20 len=5768 / final = body
    == B: 前态=设置页 ==  123 main n=20 len=5768 / 165 focus input#newTitle / final = input#newTitle

前态=今日页时旧渲染的 #newTitle 还在 ⇒ 轮询第一拍（50ms）就聚焦 ⇒ 随后整块重写把它换掉；前态=设置页时 #newTitle 要等重画完才出现 ⇒ 轮询落在之后。流 K 第⑥步刚把面板切到设置页，所以本机恒绿（基线 38 项 28.4s，日志 gates/diag/e142-baseline-K.log）—— 判据没覆盖到真出问题的那条路。

### 问题 3 · 同一件事在三处各写一遍，各写一种时机

- src/web/index.html:4134 guideStart() —— const i=document.getElementById('newTitle');if(i)i.focus(); 一次性取、无轮询、无上限 ⇒ 前态=今日页时必然聚焦到即将被换掉的节点

## 判据（6 条，逐条可执行）

### 判据 1 · 「画完再聚焦」只有一条实现

页面里新增 pendingFocus / focusAfterPaint(sel) / flushPendingFocus() 三件；且 flushPendingFocus() 必须在 paint 回调里 w(m) 之后被调用（src/web/index.html:1237 改成 w(m) 之后紧跟 flush 的等价形态）。不许用 setTimeout(0) / requestAnimationFrame 猜「大概画完了」。

### 判据 2 · 四处入口都改成设置 pending，不留任何轮询

paletteNewTask / guideStart / addTask / addTaskHere 四处都变成「设 pending → view() 或 render()」，各自函数体内 setInterval 出现次数为 0。

### 判据 3 · 两种前态都必须绿

流 K 在第⑦步之后新增一步：「前态已经是今日页时再走同一条命令」—— chord('k') → key('Enter') → activeElement() 必须仍是 input#newTitle。这一步在旧代码上必红（读数见「直做」），在新代码上必绿。

### 判据 4 · 聚焦那一下不许把 render 变成同步阻塞

不得为了等重画把 render() 改成 await（view() 仍不返回 promise）—— 判据 3 本来就靠「异步重画之后焦点还在」成立。

### 判据 5 · 钉子跟着改，意图不许松

tests/test_web_frontend.py:2005-2008 那条现有断言改成新形态：保 "view('today')" in fn 与 "/api/tasks" not in fn，新增 "focusAfterPaint" in fn 与 "setInterval" not in fn。理由写进提交信息：意图从「别另写创建路径」扩到「别另有聚焦时机」。

### 判据 6 · 反向变异必须红（真改、真跑、真还原）

写 gates/diag/_rev_E142.py（ROOT 取脚本向上三级 = 仓根；锚点必须用 CRLF，缩进逐字），删掉 paint 里的 flushPendingFocus() 调用 ⇒ node tools/ui_flow_check.mjs --only K 必红（就是判据 3 新增那一步），还原后 sha256 与改前一致。读数落 gates/diag/_rev_E142_result.txt。
