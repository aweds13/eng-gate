## 判据（8 条）

1. **五因是五个字符串常量，原样存盘**：`tools/pool/holds.py` 定义 `HOLDS_FLOOR: float = 5.0`、
   `HOLDS_LOW = "low"` / `HOLDS_NO_CLOCK = "clock"` / `HOLDS_BEFORE_LOG = "log"` /
   `HOLDS_NONE_ROUTED = "none"` / `HOLDS_CREDITS = "credits"`，加「不估」的 `"-"`。
   `why` 字段**只放这些原串**（判据标识，tests 与日志按原串匹配），要人话另加 `why_text`。
2. **窗口边界照 `Bounds()` 的三档**：`bounds(w: Window, read_at: datetime) -> tuple[datetime, datetime] | None`
   —— `resets_at` 优先（`end = resets_at`）；否则 `reset_secs > 0` ⇒ `end = read_at + reset_secs`；
   都没有 ⇒ `None`。`span_s == 30*24*3600` 时 `start` 用**日历减一月**（`replace(month=...)` 手算），
   否则 `start = end - span_s`。
3. **判定顺序逐条同序**：`holds_bounds(w: Window, at: datetime) -> tuple[datetime, datetime, str]` 必须
   照 `internal/usage/window_holds.go:69-91` 的顺序 —— 先挡「读不出来的配额」（`error/from/user/balance`
   一类）、再挡 `unlimited` / `aside and not pool` / `family` / `pool and not pool` / `used is NaN` ⇒ `"-"`；
   然后 `used < HOLDS_FLOOR` ⇒ `"low"`（`:80-81`）；然后 `bounds()` 回 `None` ⇒ `"clock"`（`:85`）；
   最后 `not end > at or not start < at` ⇒ `"-"`（`:88`）。**顺序不许调换** —— 调换会让
   `used=3.0` 且无重置时间的窗口从 `low` 变成 `clock`，两种「不估」混成一因。
4. **`used` 缺失 ⇒ `"-"`，绝不当代 0**：`test_holds_unmeasured_used_is_dash_not_low` 钉死
   `used=None` ⇒ `why == "-"` 而**不是** `"low"`。理由：`low` 是「有值但太小」（`:80-81`），
   `"-"` 是「没有这个数」；把 `None` 当 0 会让 `scale := 100 / 0` 或假出天文数字。
5. **估算式逐字照抄**：`estimate(windows, *, routed_tokens, routed_cost, first_log_at, read_at,
   paid_otherwise=False) -> list[Holds]` —— `scale = 100 / used`、
   `tokens = round(routed_tokens * scale)`、`cost = routed_cost * scale`（`:288-292`）。
   `used=25.0`、`routed_tokens=1000` ⇒ `tokens == 4000`。
6. **后三个因的判据也照抄**：`first_log_at is None or first_log_at > start` ⇒ `"log"`（`:201`）；
   `routed_tokens <= 0` ⇒ `"none"`（`:274`）；`paid_otherwise=True` ⇒ `"credits"`（`:276`）。
   三者互斥按 magpie 的赋值顺序（后写的覆盖先写的），不许自创优先级。
7. **区间读取新增纯函数，且时区写死**：`tools/wb_dispatch.py::usage_in(model: str, start: datetime,
   end: datetime, *, root: Path = ROOT) -> tuple[int, float]` —— 按 `模型` 过滤、区间取 `[start, end)`、
   `开始` / `结束` 无时区字符串一律按本地时区（`tools/pool_accounts.py:47` 的
   `TZ = timezone(timedelta(hours=8))` 同一口径）解析，**不许**用 `astimezone()` 猜；
   `dry run` 行（`退出码` / `判决` 里带 dry-run 标记的）**不计入**（照 `window_holds.go:100` / `:108`
   的 `dryRun` / `dryRuns` 就是为排除它）。
8. **反向钉子**：把 `used is None` 的分支改成 `used = 0` ⇒
   `tests/test_holds_window.py::test_holds_unmeasured_used_is_dash_not_low` 必须**变红**。
   同理把判定顺序里 `low` 与 `clock` 两条对调 ⇒ `test_holds_low_when_used_under_floor` 必须变红。
   两条反向验证都要在验收里手工跑一遍。
