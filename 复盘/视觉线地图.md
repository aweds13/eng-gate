> **每个新窗口都要重付一遍这个税**。这张纸把它一次性沉下来：先看这里，再去读具体文件。

## 2. 改了 X → 动这几处（经验表）

| 要改什么 | 动哪里 | 会惊动哪道门 |
|---|---|---|
| 颜色 / 令牌值 | `app.css` 的 `:root` 与 `[data-theme=dark]` 两块（**颜色只许住这里**） | `contrast`（--strict，任何一条不达 AA 就红）、`render` 黄金 |
| 间距 / 圆角 / 字号档位 | `app.css` 令牌区 + 用例处 | `style`（一次性裸值 / 同形状重复 / 档数报告）、`test_web_frontend` 的 R5 护栏 |
| 悬停 / 焦点等状态 | `app.css` 末节「互动态」（**放最后**，选择器要带 `:not([disabled])`） | `contrast`（会自动读 `:hover` 的底+字）、`style`（`:hover` 规则数） |
| 卡片 / 列表布局 | `app.css` 的卡片段 + `index.html` 模板 | `render` 黄金、`squeeze_scan`（诊断） |
| 模板文字 / 新按钮 | `index.html` + `ACTIONS` 表（`data-action` 必须已注册） | `test_web_frontend`（每个 data-action 都要有处理器）、`ui_dom_probe` |
| 新视图 / 新路由 | `index.html` 的 `VIEWS` + `view()` + 后端路由 | `commands`（命令表要与契约/路由/界面三处对得上）、`render`（黄金要新增一份） |
| 后端行为 | `src/timeflow/**` | `pytest`（1038 条）、`check_layers`（分层不许反向依赖）、`lf1_live` |
| 台账 / 规格 | `docs/traceability.toml`、`docs/specification/**` | `audit`（证据指针**必须真存在**）、`audit_titles`（SR 卡必须有同号规格） |

**改颜色的两条铁律**：① 不自己发明颜色 —— 跟 workbench 包的值（`复盘/设计基线-workbench与去AI味-T-G26.md`）；
② 强调色**不做小字**（只允许当色块/点/边条），状态由"点 + 字"承担（T-G42 定的口径）。

## 3. 门禁：三层速度，别一个速度用到底（T-G47 起）

```powershell
$env:PYTHONPATH="$PWD\tools\sandbox_shim"          # 跑门前先设（沙箱垫片）
python -X utf8 scripts/run_gates.py --fast         # ① 十几秒（实测 7.4s）：改完一行就跑这个
python -X utf8 scripts/run_gates.py --quick        # ② ~90 秒：提交前（含 pytest，不含真浏览器）
python -X utf8 scripts/run_gates.py                # ③ 全量 ~3 分钟：验收/封版前（两层浏览器都跑）
python -X utf8 scripts/run_gates.py --no-reuse     # 不信复用记录，全跑
python -X utf8 scripts/run_gates.py --serial       # 全串行（对照"并行下的偶发失败"）
```

- **`--fast` 不落盘**（不写 `gates/last.json`）：它不是提交闸。写了就会让审计的第 ⑤ 条
  （"门禁产物与提交的 tree 一致"）失效 —— 那是拿半轮结果冒充一轮。
- **两条泳道并行**（T-G47）：轻门一路、真机浏览器一路，各自内部并行 → 全量从 ~412s 降到 ~3 分钟。
- **输入没变就复用上次判定**（`gates/reuse.json`，带输入哈希）：只有 render / ui_flow / lf1_live /
  web_live / ui_dom_probe 这几道可复用，条件写死在 `scripts/run_gates.py` 的 `REUSE_INPUTS`。
  ★ **pytest 永不复用** —— 它是唯一"从行为上证明功能还在"的那层。
- 提交前若门禁产物与工作树不同步：`python -X utf8 scripts/run_gates.py --seal`（只改 tree 字段）。

### ★ 最快的档其实不是门禁，是 `--only`（改一处界面时用它，实测过）

两个真机层本来就支持按名字过滤，**不要**为了改一个视图去跑整层（实测数字见括号）：

```powershell
node tools/render_check.mjs --only setting     # 只采设置页的 3 档宽度（18.9s，全量 116s）
node tools/ui_flow_check.mjs  --only 收起右栏   # 只跑名字/编号里含这几个字的那几条流（17.5s，全量 177s）
node tools/ui_flow_check.mjs  --list           # 先看有哪 17 条流、各替掉哪条人工项
```

三条已验证的边界（别踩）：

★ **`--update` 不能和 `--only` 合用**（工具现在**直接拒绝**，除非 `--force`）—— 这条是 T-G51 **用错一次**换来的：
我确实用它重采了 offline 的 3 份、**16.4 秒**（全量 110 秒），看着是最划算的一步，可**判据采错了**：
离线页那半页「上次联网时看到的样子」读的是**别的页面联网时**写下的缓存（`rememberForOffline` → IndexedDB），
而 `--only` 根本不访问那些页面 → 缓存为空 → 采到的是**退化版式**。下一次全量跑立刻红 ——
那不是界面变了，是**判据坏了**（假红会让人去"修"一个没坏的东西，比慢 110 秒坏得多）。
**改黄金一律跑全量**；确实与其它视图无状态耦合的视图（如 `setting`）才加 `--force`。
`--only`（**只查、不写**）仍是最快的档，但它对这类"读别的视图写下的状态"的视图给不出可信结论 ——
提交前仍要全量（这本来就是 `--only` 的既定边界）。

1. **`--only` 是"名字里含这几个字"**，可能匹配到不止一条（例如 `--only 设置` 会选中「新手引导…设置里能再看」
   那条）—— 它会**列出跑了哪几条**，看清再信。
2. 写错字匹配不到时它**报错退 1**，不会报"0 条通过"（空集永远满足"全部通过"，这条他们早防过了）。
3. `render --only` **不会把别人的黄金当"多余"删掉**（早期版本这么干过），也不写任何文件；`--update` 才写。

`--only` 之后仍要记住：**它是内循环，不是提交闸**。提交前跑 `--quick`；给用户看/封版前跑全量。

### 想再压全量时，先看这条（我查过、结论是"不能"）

`ui_flow` 的输入里有 `src/**`，看起来"CSS 不影响行为"、可以把 `app.css` 摘掉省 177 秒 —— **不行**：
有两条流直接断言样式（`.sidebar` 的 `display` 看右栏折叠、`.card.hard` 的 `borderLeftWidth` 看硬考核边条）。
摘掉就是**造一个假的绿**。真要压只能并行拆流（有顺序耦合风险，得当场验证）或弱化 `render` 的两遍自检
（那条自检是"区分界面变了 vs 采集器不可靠"的根据）。**两条都需要单独一张卡 + 用户点头，别顺手做。**

## 4. 渲染层（`render`）怎么用

- 清单=判据，PNG=证据：`node tools/render_check.mjs` 只比清单；`--shots` 才另存 PNG 到
  `gates/render/shots/`（**不进仓库**，人看用）。
- 改黄金**必须**写理由：`node tools/render_check.mjs --update --reason "…"`（进 `LAST_UPDATE.md`）。
- 清单每行：`选择器 \t 文字 \t x,y,w,h \t 字号/行高/字重 \t 字色/底色 \t 圆角;内边距`。
  **伪元素采不进清单** → 要用真元素（这就是状态点做成 `<i class="dot">` 的原因）。
- 采两遍逐字节比 = 工具自检；不一致退 4（**不当成"界面变了"**）。
- 起不了真浏览器 → 退出码 3 → 记 `not_run`：**NOT RUN 不是 PASS**。

## 6. 陷阱清单（每一条都真踩过）

| 陷阱 | 后果 | 怎么避 |
|---|---|---|
| TOML 基本串里写 ASCII `"` | **整份台账解析不了** → audit 红、6 个 pytest 连坐（**一个会话踩了 8 次**） | 正文用「」；**改完 TOML 立刻跑 `python -X utf8 scripts/check_toml.py`（0.1 秒，会说清第几行第几列）** |
| PowerShell 里 `Get-Content`/`Set-Content` 过文件 | 编码被改写、**整个文件被压成一行**（`ui_hotmap.py` 那次） | 一律用 read/write 工具；**连"只替换一个词"也别用管线过文件** |
| `python -c "…引号…"` 在 PowerShell 里 | 引号被吃掉、语法错 | 写临时脚本文件再跑 |
| 注释里**原文引用**裸像素/CSS | 护栏把注释当代码判红（第 3 次才改成"先剥注释"） | 护栏一律先 `re.sub(r"/\*.*?\*/", "", css)` |
| 伪元素（`::before`） | **采不进渲染清单** = 没有任何一层能验 | 要验就用真元素 |
| 行内 `style` | 优先级高于任何选择器（`.card-body` 那次） | 静态值一律进 CSS 类；只有"随数据变"的才留内联 |
| `:not([disabled])` 的权重 | 比 `.ghost:hover` **高**，hover 会被通用规则盖掉 | hover 选择器一条条写全 + 放全表最后 |
| `.card` 默认是 flex 行 | 块内容并排互压（摘要卡 68×80 那次） | 块内容卡写 `class="card block"` |
| flex 不换行 + 中文 | 文字被压成竖排、按钮断成两行（T-G45） | 动作行一律 `flex-wrap: wrap`；窄列给 `min-width` |
| `npm` 在本环境 | `npm.ps1` 被执行策略拦 | 用 `npm.cmd` |
| 端口写死（8531） | 门并行时两个服务抢端口 = **随机失败** | 真机门自己挑空闲端口（T-G47 已改 `web_live`） |
| **把门禁套进 `\| Select-Object -Last`** | 输出被缓冲 → 看不到进度 → 误判卡死 → 杀掉 job **留下孤儿浏览器占端口** → 下一轮假红（白花 ~40 分钟） | 门禁一律 `*> 日志文件` 再读；**别用管线包** |
| **按进程名清进程**（`taskkill /F /IM msedge.exe`） | 把**用户正在用的 Edge** 一起杀了（GUI 就开在里面 = 闪退） | 只按"是不是我起的"杀：命令行里带 `--remote-debugging-port=85xx` / `tf-*-profile` |
| **台账状态与提交不一致** | 提交挂 `Task: X` 而 X 还是 `todo` → audit 红（"台账漏更新"）；一张卡装了两件事 | 一张卡只装一件事；提交前想清楚这条卡是不是 `done` |
| **约定层规则忘了标来源 N** | `check_layers` 红（现在会**报行号**） | 每加一条约定就写 `（N…）`；改完跑 `--fast` |
| **changelog/复盘里写相对文件名** | `check_layers` 报"引用断裂"（写 `LAST_UPDATE.md` 而真路径是 `gates/render/LAST_UPDATE.md`） | 引用一律写**从仓库根算的全路径** |
| **中文正文里混 ASCII 双引号** | 同一个病根的两副面孔：① 写进 TOML → 整份台账解析不了（见第 1 条）；② 写进**脚本里的字符串** → Python 直接语法错（T-G51 踩了两次） | 中文正文的引号**一律用「」**；脚本里的 `"` 只留给语法 |
| **用"字符级替换"脚本改文件**（例如把 ASCII 引号换成中文引号） | 它**越界把代码/结构里的引号也换了** —— T-G51 把 `[entries."T-G57"]`、`id = "T-G57"` 换成了 `[entries.「T-G57」]`（T-G51 现场） | 替换脚本**按块定位**（`'''` / `[entries.]` 之类），**改前先 `Copy-Item` 备份**，并把每次替换**逐条打印**出来核对；能用「片段文件 + 按 id 拼接」就别做字符级替换 |
| `test:` 断言写成 `文件::函数名` | audit 只判**文件存在**（`tests/<rest>`）→ 解析出一个不存在的路径 = **假红** | `test:` 一律只写到**文件名**；想把函数名记下来就写进卡的 `gaps` |
| **`render --update --only <视图>`** | 采到**退化版式**当黄金：离线页的缓存是**别的页面**联网时写下的，`--only` 不访问它们 → 下次全量跑假红，白查一轮（T-G51 实测，工具现在默认拒绝这条组合） | 改黄金**一律全量**；确有需要才 `--force` |
| **门禁红了只看摘要就去猜** | 全量跑原来只印一行摘要、门自己的输出被丢掉 → 唯一的办法是把那道门**单独再跑一遍**（render 110s / ui_flow 176s），而随机失败重跑还未必复现（T-G51 白花两轮） | T-G58 起：每道门的全量输出落 `gates/logs/<门名>.log`，失败时**当场印尾部 12 行** |
| **界面校验工具的差异只印前 8 行** | 整页往下挪一格时前 8 行全是**坐标**，真正的原因（多出来的是哪一行）在中间 → 误诊（T-G51 现场） | 改成**优先印"文字列非空"的差异行**，并如实说还剩多少行没印 |
| **改短一句话时连带删掉被钉着的边界事实** | 测试/探针/流里钉着的是**能力边界、二次确认的必要信息、诚实披露**（不是解释句）→ 一删就红，而且删掉的是该留的东西（T-G57 被拦了 5 处） | 先 grep 要改的那句话（`tests/` + `tools/*.mjs` + 黄金），区分"解释句"与"边界事实"；后者只许**改短**、不许删 |
| **给界面文案做上限门时，尺子先修干净** | 第一版尺子把注释**续行**当界面文案（13 条噪声）；第二版状态机被正则字面量弄错位（19 → **38** 条假账）。基线里混着噪声，棘轮就是假的（T-G57） | 尺子改完要**证明新清单是旧清单的子集**（"只有旧的 N 条 / 只有新的 0 条"），再定基线 |

## 6.5 教训只写一处（T-G52 / L6，用户 2026-09-24 定）

同一件教训以前会在**三处**重复写一遍（复盘的正文、changelog 的条目、台账的 `gaps`），
而卡的 `gaps` 里有一半篇幅是在复述这张表里已经有的话。规矩改成：

- **教训（踩了什么、怎么避）只写在这里**（本文件 §6）—— 新踩的直接加一行；
- 卡的 `gaps` 只写**这张卡特有的事实**（改了什么、数字、没做什么），教训**给指针**（`见地图 §6`）；
- 这样 gems 从 500–800 字降到 ~200 字，而"下一个窗口能不能避开坑"这件事**不受影响**（它读地图）。
