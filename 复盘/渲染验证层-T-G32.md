# 渲染验证层（T-G32）：把「界面看起来对不对」交给机器，人只看该看的那一眼

> 起因是你问的那句话：**「为什么是要我来验证？你不能验证吗？想一个不会漂移的验证方式。」**
>
> 这一卡就是对它的回答，而且是**用做出来的东西回答**，不是用保证回答。
> 结论先写在最前面：**我以前没验证过界面，不是不能，是根本没试过。**
> 我把「沙箱不让我起浏览器」当成了「这台机器上没有浏览器」—— 而你这台机器上装着 Edge，
> 就是 Chromium。写这一卡的第一条命令就截出了真机界面（那张 1280×900 的图），
> 然后这一层在**建成当天**就抓出了三处真缺陷，其中一处是"打开首页第一眼就能看见"的那种。

---

## 1. 为什么之前的 14 道门看不见界面

先把账说清，免得把这一层吹成万能：

| 已有的门 | 它真能证明什么 | 它证明不了什么 |
|---|---|---|
| pytest（1000+ 用例） | 行为对不对（接口、领域、口径） | 界面上**长什么样** |
| `ui_dom_probe.mjs` | 9 个视图在**假 DOM** 里不抛错、不空渲染 | 真浏览器里的**几何**（假 DOM 没有布局引擎） |
| `web_live_check.py` | 页面能打开、关键片段在 | 画出来是什么样 |
| 对比度门 / 一致性门 | 令牌层的数与体系 | 这些令牌**落到哪儿去了** |
| 命令表 | 四个面的入口对得上 | 入口**看得见、点得到**吗 |

一句话：**没有任何一道门渲染过界面。** 于是下面这三类缺陷能一路穿过全部 14 道门。

## 2. 这一层是什么：真浏览器 + 几何清单当黄金

`tools/render_check.mjs`，接进门禁（`run_gates.py` 的 `REAL` 段）。

**怎么采**

1. 起一个**临时空库**的服务（`serve.py --fresh`，不动真实数据）；
2. 用**真 HTTP 接口**造一份确定性种子数据（逾期/今天/有计划/重要/已标记/完成/子步骤/试了几回/
   课程/考核/成绩/习惯/复习卡/备忘/团队/账本 —— 走界面一样的路，不直接写库）；
3. 起**真浏览器**（Edge/Chrome，CDP 驱动），**3 档宽度**（desktop 1280 / narrow 820 / phone 390，
   正好跨过 `app.css` 的三条断点）× **14 个视图**，逐个点开、等页面安静下来，采集；
4. 每个**可见元素一行**：`选择器路径 / 文本 / 盒子(x,y,w,h) / 字号·行高·字重 / 前景·背景 / 圆角·内边距`；
5. 与 `gates/render/*.txt`（42 份）**逐字节比**；任何差异 → 退出码 1 → 门禁 FAIL。

**为什么是文本清单，不是图片**：图片能给人看，但**判不了"变了没有"**（抗锯齿、字体、编码噪声）。
所以分工是：**清单当判据（机器逐行比），PNG 当证据（`--shots` 另存，给人看）**。

**为什么它不会漂** —— 四条，一条都不能少：

| # | 机制 | 防的是什么 |
|---|---|---|
| ① | 黄金**进仓库**，跟代码一起版本化 | 谁也改不了"上次是什么样" |
| ② | 门禁**每次重跑** | 人写的检查会烂（本仓库自己烂过两次：空的动线自查表、过期的 gaps）；机器不会 |
| ③ | 每轮**把同一份清单采两遍**，逐字节比 | 工具自己不靠谱时**当场喊停**，而不是把噪声当"界面变了" |
| ④ | 改黄金必须 `--update --reason "…"`，理由落进 `gates/render/LAST_UPDATE.md` | 改判据不留痕（跟台账登记、棘轮销账一个道理） |

第 ③ 条这一卡就立了功：它**连抓 6 次**，每次都是"页面里有会自己变的东西"（§4）。

**没有浏览器时**：退出码 3 → 门禁记 `not_run`（**不是通过**）：`gates/last.json` 里单列一栏、
`Gates:` trailer 里写 `render NOT RUN`。想假装没跑过也藏不住。

## 3. ★ 它建成的当天抓到的三类真缺陷（都修了，都有机器证据）

### 3.1 卡片正文被一排按钮挤成"一列一个字"（最严重，全站列表）

**证据（黄金 diff）**：今日页第一张逾期卡，标题盒子 `34×105` —— **34px 宽、105px 高**，
一张 653px 宽的卡片里，标题竖着排了 6 个字，右边一大片空白。截图见 §3.1 末。

**机制**（量出来的，不是猜的）：卡片正文原来是行内 `style="flex:1"` = `flex: 1 1 0`
（基宽 0、只在有剩余空间时才长）；而右边那排动作按钮的**自动基宽是 max-content**
（一张逾期卡 10 个按钮 ≈ 540px），于是自由空间是负的 → 正文一点长不到，
只能缩到 `min-width:auto` 的下限 —— 而**中文处处可断行，那个下限就是"一个字宽"**。
`.card .title { flex:1 }` 那条规则在**外层**的 div 上，管不着里面。

**规模**：写了个扫描脚本把 42 份清单里"文字 ≥4 字、盒子窄而高、高 ≥36"的都捞出来 ——
**24 个元素**，横跨 today / tasks / important / planned / flagged 五个视图 × 3 档宽度。

**修法**：把 19 处行内 `flex:1` 换成类 `.card-body`（`app.css` 一条规则：`flex: 1 1 240px; min-width: 8em`）——
给正文一个**真实基宽** + 一个**下限**，按钮挤不下就自己换行。
（行内 `flex` 的优先级高于任何选择器，所以这条规则要生效**必须同时把行内样式拿掉** —— 试过 5 个"只改 CSS"的候选，
浏览器实测**全都没生效**，只有动标记才行。这也是"视觉线步 0：收 114 处内联 style"的第一批。）

**修后证据（同一份清单）**：扫描从 **24 → 1**（剩下那 1 个是手机版习惯页，见 §6）；
`important` 页整页高度 **791 → 450**（卡片不再被撑高）；标题盒子 `34×105 → 149~221×21`（一行）。

### 3.2 复选框被当文本框画

**证据**：`#newMyDay`（今日页「也放进今天的清单」）= `76×13` 的**白底盒子**、`flex: 1 1 220px`；
`#offMyDay`（离线页「放进今天」）= `130×13` 白底盒子。同时标签文字被挤成 **122×64（竖排三行）**。

**机制**：`.new input { … }` 与 `.field input, .field select { … }` 命中了**里面那个 checkbox** ——
它拿到了输入框的 `flex` 基宽、内边距、边框、卡片底色。复选框于是长得像输入框，
而它的标签（同一个 flex 行里的匿名文本项）被挤到了旁边那条窄缝里。

**修法**：两条规则加 `:not([type="checkbox"]):not([type="radio"])`。

**修后证据**：`#newMyDay` `76×13 → 13×13`（真复选框）；标签 `122×64 → 122×19`（一行）；
`#offMyDay` 也不再是白盒子（截图确认是原生勾选框）。

### 3.3 离线页那张「这台设备用不了离线存储」**永远挂着**

**证据**：黄金里 `#offlineUnsupported` 在 3 档宽度下**全部存在**，而**同一屏下面**就是能用的
「离线记一笔」表单（`capture` 是按 `ready` 判断的）—— **自己打自己的脸**。
实测这台机器上 `indexedDB` 是好的（打开成功、配额 10 GB）。

**机制**：`const notReady = \`…\`` 无条件拼进 `m.innerHTML`，而 `capture` 用了 `!ready ? '' : …`。
**两半用了两套判断**，于是"能用的浏览器"也永远看到那张说明卡。

**修法**：`const notReady = ready ? '' : \`…\``。

**为什么以前没人发现**：字符串护栏只能证明"这句话在源码里"，证明不了"它在能用的浏览器上不该出现"。
**同屏自相矛盾**只有渲染出来才看得见。

## 4. 建这一层时踩到的 6 个"确定性"坑（每一个都是自检抓的）

这一节是这一卡最贵的部分：**黄金要能活过"明天再跑一次"和"换台机器再跑一次"。**
每一条都是同一句话的不同变体：**比的是界面，就别把环境一起比进去。**

| # | 症状 | 根因 | 怎么钉 |
|---|---|---|---|
| 1 | 设置页"哪个色板是选中的"两遍不一样（来回翻） | 强调色的"当前选择"是**页面加载那一刻**从 localStorage 读进内存的（`initTheme`），之后再写也不改它；而"有没有值"取决于首屏时序 | 采集前把 `tf_accent` 钉成 `/api/config` 里的那个值（黄金 header 里写明用的哪个色） |
| 2 | 离线页的设备号 `ph-8a23a7cbffbe` 每遍都换 | `offline.js` 首次运行**随机生成**再存下 | 钉成常量 `ph-000000000000`（比"把值涂掉"好：值本身照比） |
| 3 | `narrow/setting` 的内容宽 740 ↔ 725（差 13px） | 设置页高 6000px，**竖滚动条吃掉 15px**；`--hide-scrollbars` 不够硬 | `Emulation.setScrollbarsHidden`，而且**每次改视口尺寸后都要重钉**（`setDeviceMetricsOverride` 会把它重置） |
| 4 | 同一句「默认 <导出目录> · 文件名就是日期」折行位置会在 820px 上翻 | `serve.py --fresh` 用 `mkdtemp` 的**随机目录名**，长度一变，正好在换行临界宽度上换了折行 | 用环境变量把导出目录钉成固定路径（`serve.py` 用的是 `setdefault`，我们先设就能盖住） |
| 5 | 字面日期在**明天**就全变（`2026-09-21`） | 种子用的是**相对今天**的日期（这样「今天/还有 3 天/已逾期 2 天」这类相对标签才稳定） | 绝对日期与时刻归一成固定形状（`YYYY-MM-DD` / `YYYY-MM-DD HH:MM`）—— **判版式与状态，不判"当时几点"**；日期算得对不对是 pytest 的事（那里才有断言） |
| 6 | 选择器路径里出现 `asTarget-a5289330e5c2` | 有些元素 id 是**拿数据 id 拼的**，种子每次都新建 uuid | 长得像"拼出来的" id（`-<hex≥6>` 结尾）不进路标，退回"标签 + nth-child" |

另外两条**不是噪声、是取舍**，写在这里免得以后误会：

- **`#clock` 与 `#toast` 不采**：一个每秒在走，一个是过场提示。它们的**存在**仍然被别处的几何覆盖。
- **`<code>` 里的机器标识**（设备号/配对码/落盘文件名）整段归一成 `‹code:N›`，**长度照比**（长度是版式的一部分）。

> 顺带一个教训：中途我用 `--only today --update` 冒烟，把另外 **39 份黄金删了**，
> 日志还写着"界面里已经没有这个视图"—— **一句假话**。已改成：`--only` 一律不动别人的黄金。

## 5. 验证责任怎么重新分（这才是你那个问题的正解）

| 谁验 | 验什么 | 频率 |
|---|---|---|
| **机器** | 结构、真机 HTTP、对比度、一致性、命令表、**渲染几何**；下一步：真实点击/按键/断网/窄屏溢出 | 每次提交 |
| **你** | **选风格方向**（这一件真是你的，别人替不了） | 一次 |
| **你** | 看一张 **diff 图**：「这符合我想要的吗」 | 每次**有意的**视觉改动，3 秒 |
| **你** | 定口径、措辞、产品判断 | 偶尔 |

**那 28 条"待人工确认"怎么办**：里面绝大多数是**功能性**的（能点开吗、断网还能记吗、窄屏会不会溢出、
手机上看得全吗……）—— 属于第一行。这一层给了它们一条可走的路：CDP 能发**真点击**、**真按键**、
能模拟断网、能改视口。下一步就是逐条搬，搬不动的（"喜不喜欢"、"这句话说得对不对"）
**如实留下 —— 而那种不该叫"验证"，该叫"决策"**。

## 6. 这一层**不**假装能做到的事（边界，写清楚）

1. **它判"变了没有"，判不了"好不好看"。** 好看是人的事 —— 所以留给你那"3 秒看 diff 图"。
2. **黄金与这台机器绑定**（字体度量、渲染引擎、临时目录路径）。换机器第一次跑大概是红的：
   先看 diff 是不是只有字体度量差异，是的话 `--update` 并写清理由。
3. **归一是取舍，不是免费**：把日期/时刻/机器路径归一之后，**这一类值变错它也不会红**
   （例：日期算错、配对码显示错）。那些归 pytest 与各自的检查管 —— 分工要写在明处，别假装全覆盖。
4. **起不了浏览器就报 NOT RUN**，不是 PASS（`gates/last.json` 的 `not_run` 栏 + trailer 里 `render NOT RUN`）。
5. **headless 与真浏览器可能有细微差异**。这一卡已经见过一个真实的例子：headless 里离线页曾报
   "不支持 IndexedDB"—— 而那其实是 §3.3 那个 bug（永远挂着），不是 headless 的限制。
   换句话说：**"headless 的怪现象"值得先当成缺陷查一遍，再考虑归因给环境。**
6. **它慢**：一轮 ~90 秒（3 档宽 × 14 视图 × 采两遍）。这就是"每次重跑"的代价，认了。
