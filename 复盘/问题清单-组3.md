### Q-L3-01 断言有没有牙，靠什么判？——覆盖率不是这个判据

- 该由谁回答：机器判据（突变 / 断言密度扫描），由主控定目标口径。
- 什么证据能把它了结：一份读数——「有单点突变钉子（能红）的判据数 ÷ 总判据数」，外加一个反例钉子：对某条弱断言做单点突变，它必须红。

### Q-L3-02 判据跨求值——「两次取值之间世界会变」谁拦？
- 为什么它会咬人：`tests/` 里至少 8 个文件现读 `git rev-parse`，还有一批现读 `datetime.now()` / `time.time()` / `date.today()`（`test_clock.py` · `test_insights.py` · `test_docs_fragments.py` 等）。门禁自己也是这个病：`docs_fragments_problems()` 现算 `git diff`，`staged_tree()` 再算一次，两算之间工作区能变。种子 L3 第 3 条点的是「判据不许跨求值」，可现在落到哪里去了？没有机器判据。
- 该由谁回答：机器判据。
- 什么证据能把它了结：一条反例钉子——在同一判据的两次现读之间插一次改动，若测试仍绿，就证明它是跨求值的漏；或一条「一次求值、全程用同一快照」的静态检查。
