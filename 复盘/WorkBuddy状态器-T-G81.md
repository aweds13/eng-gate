# WorkBuddy 状态器（T-G81）—— 给"看不见的那个进程"开一扇窗

> 一句话：外包模式下工人（CodeBuddy CLI）在**另一个进程**里干活，我和用户都看不见它做了什么。
> `tools/wb_status.py` 把它的 `--output-format stream-json` 事件读成**人能看的时间线**：
> 它在说什么 / 调了哪个工具、动了哪个文件 / 结果如何，一行一条。
> 2026-09-26；分支 `line/impl-v1`；台账 `T-G81`；**不改 `src/` 一行**。

---

## §1 为什么要有它

用户 2026-09-26 的原话：「假如我不能在 GUI 里看他干活也无所谓，你让他干就行了，然后你可以弄一个
状态器，让我看看他干了啥，就是把那个 CLI 给调出来，让我看看。」

这句话定了三件事：① 工人不需要被实时围观；② 但**必须留痕**；③ 留痕要**人看得懂**。
CLI 自己会吐 `stream-json`（实时流）—— 但那是给程序读的，一屏 JSON 里混着模型回话、工具调用、
工具回话、结果摘要，人读不动。这个脚本就是那层"翻译"。

## §2 它做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 读 `gates/diag/wb-*.jsonl`（或任何 stream-json 文件），渲染成时间线 | **不跑 CLI**（派活是 `tools/workbuddy.ps1` 或主控的直接调用） |
| 摘要：模型、工具调用次数与分布、碰过的文件、工具报错数、最后一条结果 | **不改任何东西**（不动 `src/`、不动台账、不写 log） |
| `--tail N` 看进度、`--json` 给主控解析、`--repo` 附 `git status`/`git log -1` | 不是门禁的一环（它是**尺子**，不是门） |

## §3 设计上的三个取舍（都是为了"别骗人"）

1. **认不出来的一行也不丢。** 对方会升级、事件形状会变 —— 状态器最坏的长相是
   「什么也没说」而工人其实干了一堆（**比没有窗更坏**）。所以：不认识的 `type` 原样截断打印，
   数进 `unknown_events`，并在摘要里念出来；半行 JSON（进程被 kill 时很常见）也记一句继续读完。
2. **一行最多 240 字。** 工具回话里可能塞着整个文件内容 —— 不截断的话，真正的动作会被淹掉；
   `files` 也只列前 12 个并报总数。
3. **顺手把"它有没有那个工具"摆在第一行。** `init` 事件里有 `tools` 清单 ——
   用户问的「它不一定有你那么多 grep 工具链」看这一行就有答案（真值等第一次派活）。

## §4 ★ 边界（不假装）

- **事件形状还没被真 log 钉住**：现在只有**合成用例**（`tests/test_wb_status.py` 8 条）。
  第一次真派活之后，必须拿真 log 复钉一次（哪几个 `type` 真的会出现、`content` 真的是数组还是串）——
  这条写在 `tools/wb_status.py` 的 docstring 里，别让它漂。
- 它只读 stdio 那一份输出。CLI 的**内部日志**（`~/.codebuddy/logs/<日期>/…`）不归它管 ——
  但排查"为什么它没动"时要去看那份（T-G80 的登录问题就是在那儿读到
  `[AuthenticationManager] userId changed: c7adcb83-… -> <empty>` 才确认的）。

## §5 顺带实测的两件事（写进 T-G80 的 gaps，这里留个指针）

1. **工人有没有我这一套工具？** 静态查了 CLI 的 bundle：`Read` / `Write` / `Edit` / `Bash` /
   `Glob` / **`Grep`** / `WebFetch` / `WebSearch` / `Task` / `TodoWrite` 都在 → **大概率能调**
   （`--tools` / `--allowedTools` 也现成）。**真验要等登录**（见下）。
2. **登录是当前唯一的阻塞**：`-p "…" -y` 回 `Authentication required. Please use /login command…`，
   而 CLI **没有 `login` 子命令** → 只能用户本人在交互式 TUI 里敲 `/login`。

## §6 一句话教训

> 把活交给**别的进程**时，"**它干了什么**"必须落在一个**人读得懂**的地方 ——
> 否则"外包"就变成了"失联"。窗的成本很低（一个只读渲染器 + 8 条测试），
> 但窗自己也要有护栏：**不许静默丢掉认不出来的东西**。
