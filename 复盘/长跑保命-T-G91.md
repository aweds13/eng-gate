# 长任务怎么保证跑得完（T-G91）

> 用户 2026-09-26：「有的任务，时间花很多，怎么保证长时间运行」。答案分三层，前两层已经有了，
> 这张卡补的是**第三层：主控不在场的时候**。

## 1. 第一层（最硬）：不要做"一次长跑"，做"一串短跑"

**长任务先拆成卡**：一张卡 = 一次提交 = 一次验收。状态存在 **git / 台账 / 复盘 / 交接文档**里，
**不依赖任何进程活着** —— 任何一环断掉，下一个人（或下一个窗口）都能从仓库读出"干到哪了"。
这比任何"保活"手段都硬，也顺手解决了上下文膨胀导致的"工人越跑越糊涂"。

所以规矩写成：**能拆就拆**（每张卡 30–60 分钟量级）；只有"确实没法拆"的单卡才走下面的长跑模式。

## 2. 第二层：单卡内部的护栏（T-G88/89/90 已做）

看门狗（静默 8 分钟 / 窗口内重复 5 次 → 掐）+ 心跳（每 2 分钟）+ 回合上限（写卡 240）+
铁律进系统提示 + 断点续跑（`--resume` / `--retry`）。

## 3. 第三层：主控不在场（T-G91 补的）

以前看门狗跑在**我的 DSH 后台任务**里 —— 我窗口一关，就没人盯了。现在四件套：

| 机制 | 命令 / 文件 | 保证什么 |
|---|---|---|
| **扔出去跑** | `--detach` | 派活进程**活过我的窗口**（Windows `DETACHED_PROCESS` + 新进程组）；输出落 `wb-<卡>.dispatch.log` |
| **看状态** | `--status` | 一条命令只读**文件**：心跳 / 判决 / 会话 / log 尾巴 + 工具与文件计数（不必去翻 1 MB 的 log） |
| **断点续跑** | `--resume auto`（或 `--retry`） | 会话落 `wb-<卡>.session.txt`；续跑指令写明「★ 不要重做已完成的部分」+ 中断现场 |
| **现场落盘** | `wb-<卡>.heartbeat.txt` / `wb-<卡>.verdict.txt` | 心跳每 2 分钟一行（带时间戳）；收工或被掐都写判决 —— 半夜/新窗口回来**先读这两个文件** |

**超时不是失败**：默认 2 小时（`--timeout`，卡 002 用了 44 分钟），到点会**掐掉再续跑**。
机器睡眠、断网、CLI 崩了也都走同一条路：日志静默 → 判卡死 → 掐 → 续跑（`should_resume` 允许"超时"续）。
**这是故意设计的**，不是 bug —— 它把"卡住"从"干等一小时"变成"一次重试"。

## 4. 证据

- `tests/test_wb_dispatch.py` **32 → 40 条**：`detached_argv`（去掉 `--detach`、补内部标记，
  免得无限生小进程）/ `--detach` 只扔一次就返回 / `--status` 只读文件且**不需要 `--spec`** /
  没派过的卡给一句人话 / 心跳文件带时间戳 / 判决文件写全（卡号·尝试·退出码·会话）/
  `--spec` 漏了给人话退 2 / 默认超时 ≥ 2 小时。
- 真机探针：
  - `spawn_detached(...)` 起一个 python 子进程 → pid 立刻活着、**5 秒后它的输出已落在文件里**
    （证明 `DETACHED_PROCESS` 在这台机器上真能让子进程独立跑完）；
  - `python -X utf8 tools/wb_dispatch.py --card 002 --status` 读**真卡 002 的 1.1 MB log**
    → 报出「322 行 / 工具调用 111 次 / 碰过文件 21 个 / 工具报错 0 次」+ 最后那条回话；
    心跳与判决如实说"还没有"（那一轮早于这两个功能 —— 不假装有）。

## 5. 边界（如实写）

- `--detach` 之后，**看门狗是那个脱离进程自己带着的**：它活着就有人盯；它被系统杀掉
  （重启 / 休眠断电 / 被任务管理器结束）就没人盯了 —— 此时只能靠 `--status` 看到"心跳停在几点"。
  想要更强的保证，得让看门狗也独立于派活进程（**还没做**，是这张卡之后的候选）。
- `--status` 只报"它在动、动到哪了"，**不判断内容对不对**（那是主控复核的事）。
- 状态文件都在 `gates/diag/`（gitignored）：**证据不进仓库** —— 要留档就把结论写进复盘/台账。

## 6. 没动的

- 看门狗 / 心跳 / 回合上限的判据与阈值一个字没改。
- 续跑（T-G90）的判定逻辑没改：仍然**只对"被打断"续、不对"空转"续**。
- 模型默认值、`--autocompact 1m`、`--effort` 默认都没改。
