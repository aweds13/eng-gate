# 界面不解释（T-G49）—— 把复盘从产品里搬出去

> 用户原话（2026-09-24）：
> 「你是不是有点小问题啊？为什么有些没有必要写的解释，你也写进去啊。就是那个很多的框里面，
> 你写进去干嘛？**这是给人用的**，我知道哪些要用什么。如果我不知道的话，你可以设计一个小小的
> 用户文档。而不是把他们那些一大堆解释塞在那里。」
>
> 补一句（同日）：「如果一个功能足够简单的话，就是用户知道它是干嘛的，然后这没有步骤的话空的，
> 就是这种情况空的，用户也知道没有步骤，那就**没必要再弄了**吧。有些思想上的东西，用户用了就知道，
> 他就是设计我就是这么设计的，我还不知道我想干嘛吗？**不跨人比这种没必要强调**。」

---

## 1. 这是谁的毛病、怎么长出来的

**我的。** 成因很具体：每落地一个功能，我就顺手在界面上写一段"为什么这么算"——
「不折算成投入时间（时间折算只在有真实时长时才算）」「各轴各自归一到本图最大值，
只看「是否均衡」，不用于跨人比较」……

**这等于把复盘写进了产品。** 复盘是给我自己（和下一个窗口）看的，界面是给用的人用的。
两者混在一起，结果是：一屏里字比控件多，读完才知道要点什么 —— 视觉上也就是用户说的
「平庸 / 一坨」。

★ 而且这不是"审美不同"，是**包里早有明文**：workbench 的空态原语 `.wb-empty`「**一句暗淡的话 + 一个动作**」
（一张插图都没有）。我写的是 40 个字的说明。

## 2. 定下来的规则（先写死，再动手）

| 类别 | 怎么处置 |
|---|---|
| **空态** | 旁边就有输入框/按钮的 → **一个字都不写**（空着就空着）；纯列表区 → 最多 **6 字的事实**（「还没有任务」） |
| **空态措辞** | 不写怎么用、不写为什么、**不写评价**（「没有逾期，很好」「轻松一下」这种一律去掉评价词） |
| **数字口径** | 留 **≤ 8 字**（用户 2026-09-24 选的口径：如「不含手动投入」「只记次数」），其余删 |
| **设计意图** | **删**（「不跨人比」「标记不代表重要」这类"我为什么这么设计"，用的人不需要被解释） |
| **操作标签 / 字段名 / 单位 / 状态 / 报错原话** | 留（这些是"说什么"，不是"解释什么"） |
| **教学（新手引导）** | 用户 2026-09-24 选：**卡留着**（三步算操作标签），**解释句删** |
| 更长/更细的说明 | 需要的话进**小用户文档**（下一批一起建），不塞进界面 |

判据是机器可查的：`tools/ui_text_scan.py`（诊断尺子，跟 `squeeze_scan.py` 一个待遇）。

## 4. 顺带**反转**了一条既有做法（诚实记）

`tools/ui_dom_probe.mjs` 的复习改判档里，第 ④ 条原本要求：
**「空态：今天还没复习过时给一句带路的说明（不是干巴巴「暂无数据」）」**，断言写的是
`includes('今天还没复习过卡') && includes('还能改判')`。

这条要求现在**与用户口径相反**（空态就是要"干巴巴"）。处理：
- 注释改写成新口径（并写明"原来那条是把产品当教学材料"）；
- 断言从"含两句"改成**"空态就是这 5 个字，没有别的"**（`<div class="empty">` 里文本必须恰好等于
  `今天还没复习过卡`）—— 不是放宽，是**换个方向钉住**。

## 7. 教训（一句话）

**产品里只放"用的时候需要看到的东西"；"为什么这么设计"是我和下一个窗口之间的事，
它有别的地方去（复盘、代码注释、用户文档）—— 放在界面上，它会把界面淹掉。**

## 8. 2026-09-26 用户加严：直接删解释、只留必要语义（含 T-C8 那句的处理）

（本节由卡 051 / `T-G142` 追加；本节以上的一字未动。）

- **加严原话**（用户 2026-09-26）：「我发现你还是留了些解释在前端界面，不简洁」+
  「**直接删解释，只留必要语义**」。**处置的默认值从本节起改为「删」**；
  「压到 ≤N 字」只在"删了就没法用"时才用（单位 / 字段名 / 状态标签 / 报错原话）。
  这条压过 §2 判据表里与此冲突的写法。
- **判据（一句话）**：这句话是在**告诉用户"为什么 / 怎么用"** → **删**；
  它是在**说"这是什么"**（标签 / 字段 / 单位 / 状态 / 错误）→ **留**。
- **T-C8 那句怎么处理的**：硬考核区的说明
  「这类是「逾期不候」的：交了就计成绩，没交就没了 —— 所以单独放前面、标出来。不催你，只是别让它被忘掉。」
  → **删掉解释后半句**，只留状态语义 **「这类是「逾期不候」的。」**（「逾期不候」是状态标签，属"留"类）。
  断言换方向钉住（不是放松）：`tests/test_web_frontend.py` 在原 presence 断言之后**新增**
  「交了就计成绩 / 没交就没了 不许出现」的 not-in 断言；`tools/ui_flow_check.mjs` 流 ④
  新增 `t.lacks('解释句不许回来', body, '交了就计成绩')`。节标题「硬考核：临期与逾期」未动，
  台账 `T-C8` 的 `text:` evidence 不受影响。
- 第二批 ≥20 字那 33 条的逐条处置见 `复盘/界面解释文案第二批-T-G142.md`。
