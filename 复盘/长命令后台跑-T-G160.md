## 一、为什么有这张卡

- 工人（我）在这个工作区干活，**单次 Bash/工具调用有 10 分钟上限**；本仓全量门禁实测
  约 **6–7 分钟**：`pytest` **1489 passed / 107s**、`render` ≈ **110s**、`ui_flow` ≈ **176s**
  （卡 066 §1；062 实测）。一旦要「重采黄金 + 再跑一遍」就**必越过** 10 分钟。
- 越过后：**调用被掐** → 之前起的 `serve.py` / 无头 Edge 变**孤儿** → 下一张卡撞端口 / 撞进程
  → **跨树误杀**（铁律 27/28）。
- 代价读数：本轮 058 烧掉 **37M tokens / 2h15m**，其中一大块就是在跟这个上限搏斗。
- 与 062（`T-G156`）的分工：`TF_GATE_PORT_BASE` 治的是**排队**（端口按树隔离），
  本工具治的是**被掐** —— **两者都要**。

## 二、做了什么

1. **`tools/run_bg.py`（新，标准库）**
   - `run`：`subprocess.Popen(argv_list)`（**不用 shell**、不拼命令行字符串），
     Windows 加 `creationflags = CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS` 起**分离进程**；
     `stdout`/`stderr` 都进 `--log`（同一份），**立刻返回**并打印 `pid=` / `log=` / `rc_file=`，退出码 0。
   - `status`：判据是**哨兵文件 `<log>.rc`**（**包装器**在命令结束时写入退出码，先写临时文件再
     `os.replace`）——**不看端口、不看进程名**；打印 `state=running` / `state=done rc=<N>`、
     日志静默秒数（按 mtime）与日志尾 `--tail` 行（默认 20）。
   - **退出码约定**：`running → 0` / `done rc=0 → 0` / `done rc!=0 → 3` / 用法错或日志不存在 → `2`。
   - **不改被测命令**：rc 由**外部包装器**（隐藏子命令 `__wrap__`）落盘，被测命令（如
     `scripts/run_gates.py`）**一个参数都不加**。
2. **`tests/test_run_bg.py`（新，5 条钉子）**：秒回 / 两态轮询 / 两条负样例（rc!=0 → 3、
   log 不存在 → 2）/ 两条用法负样例（缺 `--`、`--log` 不可写 → 2）。用 `sleep 2` 级别，
   结束前轮询到哨兵，**不留孤儿**。
3. **`复盘/长任务执行协议.md` 新增 §十三**：判据（预计 >8 分钟一律后台跑 + 轮询、不许死等）、
   为什么（10 分钟上限 → 孤儿 → 跨树误杀）、代价读数、与 062 的分工、四条坑。

## 四、开发时自撞的一个坑（已写进工具注释与协议 §13.4）

`DETACHED_PROCESS` 的子进程**不把重定向过的 std 句柄再传下去** —— 初版让包装器用
`Popen(cmd)`（`stdout=None` 继承）跑真命令，孙进程的 stdout **丢了个干净**（日志空、rc 却正常）。
隔离复现：同一个包装器里 `stdout=None` 的孙进程无输出、**显式**传句柄的孙进程有输出。
改法：**包装器自己打开日志**（`open(log, "ab")`），**显式**把句柄交给被测命令
（`stdout=out, stderr=subprocess.STDOUT`）。这一点在卡 §7.1 只提了「分离进程的坑」，
**具体形态是这套 std 继承**，留给后来人。

   `复盘/交接-重构进度.md`）本卡没写** —— 依据卡 §4（台账条目「放复盘末尾……**供集成者粘贴**」、

   与 `复盘/外包-卡表与规矩.md` §16.3（共享文件由主控串行收口）。**台账条目在本文件末尾**。
   白名单把它们列出来是「本卡可能涉及 / 集成者的那一份」；本卡只交**新增工具 + 钉子 + 协议一节 +
   复盘 + 盖章件**。
2. 测试里的慢命令只用 **2 秒**级（卡 §2.3/§7.5），**没**把 20 秒 sleep 放进 pytest；测试结束前
   一律轮询到哨兵，**不留真在跑的孙进程**。
3. `gates/logs/` 是 **gitignored**（本机产物）：本题所有 `*.log` / `*.rc` 都不入库；
   `gates/logs/` 目录也**不在** §3 白名单，仅作运行产物落点。
4. **未**在同一棵树同时跑两个全量 `run_gates.py`（会互写 `last.json`/`reuse.json`/`.coverage`，
   且违反「重活不许并发」）。
5. 门禁锁是**跨树一把**：本卡跑门禁时，锁被 card=063（`.wt/pypath1`，正在跑）持有，
   **等锁是串行要求的正常代价**，不是本工具的问题。
