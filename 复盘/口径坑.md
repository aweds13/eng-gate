1. ★ `last.json` 的「复用」在【顶层 `reused` 字典】，不在每道门里

33. ★★ **迁移卡树 ≠ 重跑一遍**：卡树里 rebase 撞了硬冲突（今晚 113 那次四个文件全撞）之后，
    **不能只把树 `checkout` 回主 HEAD 就重跑** —— 那会把**工人已经提交在卡树里的代码悄悄丢掉**
    （`checkout` 只搬工作区，不动卡树那笔提交；重跑时工人成果已经"看起来不在"了）。
    正确修法：`rebase --abort` → 用 `git checkout <主HEAD>` 把树重建 → 只把**那笔提交里的代码文件**
    `git checkout <卡树提交> -- <代码文件>` 挑回来 → `git reset -q` 取消暂存 → 再跑集成。
34. ★ **`contextlib` 上下文管理器里 `yield` 不许写在 `while True` 里**：`tf_batch.spin_lock` 把

    `contextlib` 直接报 `RuntimeError: generator didn't stop`（红得莫名其妙：栈里没有任何业务代码）。
    修法：**先取到锁、`break` 出循环，再 `try: yield / finally: unlink`**。
