# 改字面前先查钉子 —— `tools/pin_check.py`（卡 053 · 台账号 `T-G145`）

## 为什么有这张卡

同类事故本会话已发生四次（卡 053 §1，逐条有据）：改一个「字面」，而这个字面被别处
**逐字钉着**，每次都是「撞上了才知道」：

1. 主控改写 `复盘/外包-卡表与规矩.md` 的措辞 → 打穿 3 条 `text:` 台账证据（提交前 audit 才红）；
2. 卡 036 的 `test:` 指针写错前缀 → 求值恒假（`test:` 只按 `ROOT/tests/` 求值）；
3. 卡 029 改 `DEFAULT_MODEL` → 打穿 `T-G85` 的证据指针（集成时 audit 红）；
4. 卡 049 扩 `TASK_TYPES` → 打穿 `tests/test_web_frontend.py:518` 的逐字断言。

仓里已有 `tools/evidence_map.py`（按**文件**查谁挂着断言，只读参考、未动它一个字）；
本卡补另一半：**按「字面」查谁钉着它**。

## 做了什么（口径照卡 053 §2，没有自己发明）

- **只读工具** `tools/pin_check.py`：读 `git ls-files` 与工作区文件，只打印报告，
  不写任何仓库文件。
- 调用：`--literal <字面>`（可重复给多个）+ `--ledger-only`（只看 `docs/traceability.toml`
  里 `text:` 证据的命中）。
- 输出（每个字面一节）：命中清单 `文件:行` + 原文（截 120 字符）+ 分类 +
  「钉子吗」标注；每个字面一小结，末尾总计。
- **分类**：`源码`（`src/**`）/ `测试`（`tests/**`）/ `工具`（`tools/**`、`scripts/**`）/
  `文档`（其余被跟踪文件）/ `台账证据`（`docs/traceability.toml`，命中时**点名台账号**）。
- **退出码**：零命中 = 0；有命中但无钉子 = 0；有任何 `★ 钉子` 命中 = 1；用法错误 = 2。

## 「钉子」判据（tools/pin_check.py:44-45）

命中行里出现任一**断言/证据语境**标记 → `★ 钉子`，其余 → `叙述`：

```python
PIN_MARKERS = ("assert", " in ", "==", "includes(", "has(", "text:")
```

- 故意**子串级、保守**：宁可少标、不可滥标（滥标会让「零误报」检验失去意义）。
  例：`tools/wb_dispatch.py:98` 的 `DEFAULT_MODEL = "deepseek-v4.1-flash"` 是**赋值**，
  不含任何标记 → 标 `叙述`；而 `tests/test_web_frontend.py:518` 那行含 `assert` 与
  ` in ` → 标 `★ 钉子`。
- **台账反转义**（tools/pin_check.py:55-58）：TOML 把 `"` 存作 `\"`（转义存账），
  台账行先反转义再匹配 —— 不反转义就永远查不到 `T-G85` 那条（钉子①正是它），
  这是本卡实现里最容易漏的一步。
- 台账号点名：扫描台账时跟踪 `[entries."T-Gxx"]` 头（tools/pin_check.py:47），
  命中行落在哪个条目下就点哪个号。

## 反证（三贴，证明判据有牙）

- **改坏**：把 `PIN_MARKERS` 里的 `text:` 去掉 → 钉子①的命中**还在**（匹配没坏），
  但**不再被标钉子** —— 该行为由 `tests/test_pin_check.py::test_mutation_dropping_text_marker_kills_pin1`
  用例钉住（monkeypatch 实现，等效于手工改坏再还原）。
- **还原**：`PIN_MARKERS` 原样 → `pytest tests/test_pin_check.py` 全绿（8 passed）。
- **贴干净**：本卡只新增三个白名单文件，`git status --short` 仅含
  `tools/pin_check.py` / `tests/test_pin_check.py` / `复盘/改字面前先查钉子-T-G145.md`。

## 怎么用

```
python -X utf8 tools/pin_check.py --literal "DEFAULT_MODEL = \"deepseek-v4.1-flash\""
```

- **开工前**：凡要改常量/字面/文案，先 `--literal` 查一遍；有 `★ 钉子` 退出码 1 就先核对。
- **集成前**：改过 `src/**`、`tools/**`、`docs/**` 的卡，逐个查它改动的字面。

## 边界（如实写，没做的部分）

- **只新增**三个白名单文件；**没动**任何既有文件（尤其 `tools/evidence_map.py`）。
- **没写台账**（卡 053 §0.4）：`docs/traceability.toml` 一个字没碰；条目在本文末尾，
  供集成者粘贴。
- **没跑全量门禁**（卡 053 §0.3）；轻门 = ruff + `pytest tests/test_pin_check.py`，
  结论见提交 trailer。
- 钉子判据是**子串级**：只防「逐字钉着」这一类，抓不到**语义等价的改写**
  （如把 `==` 换成等价函数调用）；那一类本来也不在本卡口径内。
- `--ledger-only` 只认 `text:` 前缀的命中行；命中在台账 title/gaps 里的要走完整扫描。
- 零误报只对钉子③那个字面负责；新字面若撞上含 `assert` 等词的**叙述行**，会被多标 ——
  保守方向的多标（宁可多报钉子让人核对，不可漏报）。
